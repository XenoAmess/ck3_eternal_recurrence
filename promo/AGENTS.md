# CK3 视频制作

- 开工先读[视频制作手册](../docs/maintenance/video-production-workflow.md)。录制使用已授权的游戏现场、独立 profile 与实际录像管线。用途、预算、输出卷和交付位置依[实机与机器授权](../docs/maintenance/ck3-operating-authority.md)和[存储策略](../docs/storage-retention-policy.md)。
- 将实际决策文本合成到最终视频，采用无边框、纯黑底 60% 不透明度、白字。不要恢复桌面决策窗或旧蓝色面板。分别验证决策文本来源和成片实际绘制。
- 用成片、字幕、可读性和游戏证据逐项验收，记录产物路径、媒体参数、哈希与可展示的真实范围。历史需求或已关闭的交付任务见原进度记录。宣传或上传遵循该产品当前授权与所有权。
