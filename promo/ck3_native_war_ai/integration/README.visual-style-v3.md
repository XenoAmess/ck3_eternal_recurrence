# 新图解视觉：战役手稿与地图旁注

只改变布局、颜色和原创几何装饰。`teaching_visuals.py` 的机制文字、数值、SHOTS/PANELS 和阶段选择继续使用旧稿；这不意味着旧 C03 等结论已经按新台账修正，也不是新版旁白或成片批准。生成的新图只用于新 attempt，旧成片及过程资产保留。

主体底色改为深褐，强调用暗红、旧金与暖白。蓝岭保持可辨认的灰蓝/灰绿色阵营标记，但不再把大片背景画成深蓝仪表板。细直边框代替大圆角卡片，进度提示缩成小菱形书页标记；原创盾形小标只作图形语言，不声称取自 CK3 游戏资产。

候选采用窄边羊皮纸牌，分数使用深色墨迹，淘汰保留明确划线。地图用低饱和地色、细河线与少量原创地形符号，候选说明放在地图之外的页边栏，不能盖住军队和城堡。和平用两张纸面账单，角色、主动/接收方向和0/−30分别保留；只让当前账页更亮，避免所有块同时抢眼。

共享 `box` 边框与调色映射也作用于求援旧布局，继承此前“同侧求援者/助手”和固定位置修正；本包没有改求援机制文案。三张代表预览选择候选牌、地图旁注和和平账本。底部 y=1120–1440 留作字幕，纹理与正文止于其上。纹理是固定种子的低对比点状代码绘图，不使用外部图片或 AI 生成资产。
