# Episode04 source-card renderer a04

This project asset generator renders the nine existing story-a03 source cards to editable2560×1440SVG. It uses the series brown/gold palette, Microsoft YaHei and the existing title69/body45/kicker34/source25 hierarchy, leaving y1120–1440 clear for subtitles. `theme-source.json` pins those existing project files. It does not replace the generic promo pipeline or create a production run.

```text
<verified-python-with-Pillow> -B promo/ck3_native_war_ai/episode-04-march-logistics/tools/review02/source_cards/render_source_cards.py --episode-root promo/ck3_native_war_ai/episode-04-march-logistics --output-dir <new-external-directory> --font-regular <explicit-msyh.ttc> --font-bold <explicit-msyhbd.ttc> --preview-id D01 --preview-id D05 --preview-id D09
```

The output directory must not exist. Every invocation produces nineSVGs and at most three optional1280px-or-smallerPNG previews. Omitting all `--preview-id` flags makes SVG assets only. Source-map and source-index bytes are pinned to the independently delivered source-a03 patch; apply that patch first. There are no providers, TTS, FFmpeg, raw captures, screenshots, SDK, game, desktop, network or signoff calls.

`generate` is callable from a later project composer. Each SVG contains original paragraph IDs, common source IDs, proof layer and explicit hypothetical labels. It keeps the same scene graph for SVG and Pillow preview pixels. Font metrics record each line's actual ink bounding box; every card is checked before the first preview is emitted. PNG previewing is not an independent browser SVG render. Another renderer must install the recorded font family; different font bytes require new outputs and review.

The nine checked-inSVGs are generated projections under `review02/story-a03/cards-svg-a04/`; edit this generator and regenerate instead of hand-editing generated bytes. No generatedPNG is added to the repository. `render-manifest.json` in the explicit output directory retains source/font hashes, line bounds and per-asset hashes.

These source-explanation assets do not supply missing live movement, loss or split footage, do not raise research-card counts and do not grant clean spans or human approval. D01/D02/D03/D04/D05/D06/D08 carry hypothetical inputs; D07/D09 show conditional source structure. The role1/1 card does not claim an observed birth, physical refill, Knight or assigned commander. Fullmovie rendering/actual narration timing belongs to a later separately bound run.
