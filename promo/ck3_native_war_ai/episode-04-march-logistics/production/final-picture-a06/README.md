# Episode04 final picture source and rows

This package preserves the exact source used by the actual Review01 render and the actual Root-approved nine incremental picture rows. It includes six relative chapter intent files and the measured PCM/frame allocation. It excludes all original recordings, images, WAV/MP3 files, intermediate MOVs and final movies.

Run `python plan_metadata.py` for the local metadata summary and `python verify_package.py` for byte validation. Both use only the standard library and read the local small files. Neither renders, downloads, probes media, executes game tools, or approves a film.

`source/bc_pipeline.py` exposes the actual `plan/check/render` CLI; `source/checked_entry.py` checks the exact Root gate before delegating. `source/execute_review01_a01.py` records the real check, formal `xar_promo start-run`, and render argv/stdios in a fresh external attempt. Original configs and receipts retain their absolute historical locators and exact bytes. Replaying those actions on another machine needs the real external inputs and a fresh explicit source binding and Root review; this package does not claim a portable one-command render.

The actual renderer reuses 60 prior dry picture segments, renders seven changed voice paragraphs and covers the old cards on C05-01 and C05-15. Real source intervals occur once at 1×. The source overlay names A, B, C or an independent research background at each cut. C05-05 uses actual C +77 London post-state pixels; C05-15 and the first part of C05-16 identify A. B post-state footage does not depict the split, merge click, or positive write instant. The final file name is `CK3-War-AI-Episode04-March-Logistics-Review01.mp4`.

The integer audio graph uses a 48 kHz sample time base and `asetpts=N`; the MP4/AAC encode declares a 48 kHz time base and movie timescale. The old A-only exact-AAC-PTS RED stays preserved. Final packet/decode observations remain a separate actual audit, and no source sample review is a full continuous clean-span or full human 1× watch/listen/signoff. B stopped after its conditions changed; C retains sampling deviations. There is no strict ABC winner.

`results/production-state-at-freeze.json` states the actual state at this append-only freeze. The running external attempt's later movie and audit require separate immutable result additions; no NULL is replaced by a guessed future result.
