# R0172 periodic-loss evidence

This is a portable, media-free file evidence package for the exact 1.20.0.3/a08 R0172 observation. Run `python -B verify_evidence.py` from any checkout/export; only the standard library is needed, and original C:/D: paths in receipts are provenance text.

The verifier checks complete original JSON bytes, joined paused frames,27actual regiments/37DATA records, observed net loss67 and a conditional native ordered-allocation arithmetic replay. Unpublished per-regiment eligibility is a stated assumption. It does not prove an applied-loss/refill ledger, zero hidden refill, deaths, starvation, unseen-event absence, film review or signoff.

`raw/before` and `raw/after` contain all8original JSON files for batch01 i08→i09. `boundaries/boarding` (+30→+32) and `boundaries/landing` (+42→+44) retain independent unchanged-count route endpoints. Landing changes18chunk permissions to true. Extra unit190 remains unavailable/unknown in the original failed collection; it is never treated as zero.

`source/arrival-actual-checkpoint-pin.json` and `arrival-checkpoint-result.json` reference the already preserved73,795,635B save by its actual Root pin; the save bytes and all raw media remain outside Git. This packaging did not reread the save or rehash media. SDK readiness/session closure, actual a08 build pins and small original native/source excerpts are retained, including public source version/EXE null boundaries.

Machine verification is narrower than execution causality and human video approval. Existing attempts and raw media remain preserved; this package does not replace them.
