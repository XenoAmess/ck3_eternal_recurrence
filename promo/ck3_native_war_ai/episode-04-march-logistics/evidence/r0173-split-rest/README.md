本包只复用知识、精确原始 JSON 和只读复核代码。无需 CK3、SDK、C 盘研究目录、存档或录像。

在任意支持 Python 3.10+ 的机器执行：

```text
python review_frozen.py
```

代码只读取本目录的 `index.json` 与其相对路径，并向 stdout 输出派生报告；成功退出码为 0。索引逐文件校验 bytes/SHA-256，验证暂停源帧、人物、public/native Army 映射、27 个军团和37条完整 DATA 身份、最大人数、拆军守恒与五个观测窗口。绝对主机路径只留在原始历史 JSON 内，不是读取依赖。

数字资格已观察到；正式 ABC 仍 0/3，film/clean/human signoff 都是0。已存下来的正月值、实际库存增加、超容量封顶和整数人数增长分别检查，不互相替代。完整应用账本、死亡归因和合军加权封顶尚未闭合。Root 实际 split 资格备用保存与 session closure 小包已纳入；未拆 whole 共档仍是 d052…。Game owned termination exit1、supervisor exit0 与 GameJob0 分别保留。

`peer/` 保存独立复核原字节。`root/` 保存因外部占领变化及子军封顶触发的原 STOP 和 Root 随后限定恢复休整观测的审阅；旧 STOP 未重标。

大存档 d052… 只保存 metadata pin，录像和截图不进入本包。`index.json` 可独立读结论，`review_frozen.py` 可重新算端点；只有更换任一精确输入才需要另建版本，不能改写旧证据。
