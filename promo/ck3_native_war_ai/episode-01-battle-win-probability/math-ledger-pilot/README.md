# 第 1 集逐步算术样稿

本样稿用 EdgeTTS 和系列唯一主题曲演示 R0217 原版主阶段单个 tick 的出伤计算，数字来源是 [`docs/ck3-native-ai/battle-simulation.md`](../../../../docs/ck3-native-ai/battle-simulation.md) 的 R0217 冻结回执。开头的墨西拿实机是另一场战斗，仅提供原版战场背景，不充当这些数字的画面证据。

镜头顺序是：定点数定义 → 双侧战宽比例 → 原版边界输入 → 优势乘 0.03 → 再乘战宽 → 再乘 R14 → 双侧对拍与旧顺序误差。屏幕始终显示整数运算与截断点；`R14` 被明确标为原版当日读数，不能说成已从所有战前修正项独立还原。
