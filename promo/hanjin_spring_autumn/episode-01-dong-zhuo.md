# 第一期 董卓导演案

**已定片名：《洛阳炙手，公卿憎我，天下讨我》**

**片头独白（已定）**：

> 洛阳炙手，公卿憎我，天下讨我。
>
> 谓我董贼者，谓我董相者——
>
> 且看我董卓。

主角为 190 新档董卓，片子围绕一个问题：**手握天子和强兵，能不能守住权力与性命？** 面向喜欢 CK3 人物关系、三国故事和政治玩法的玩家。气质是“认真盘算的玩家，碰上越来越不对劲的局面”，笑点来自处境和临场反应。

建议成片约 **12–18 分钟**，内容顺畅可缩到 8–10 分钟，有好战斗或精彩意外可展开到 20 多分钟。用户允许 5–30 分钟，不按秒填满；没有故事的等待、重复点菜单和长行军直接剪掉。

这是待取材的导演案。关键旁白可直接改写配音，结果句在实况确定后补齐。当前源码依据见[董卓专题](research/dong-zhuo.md)，组合检查见[代码分析](research/code-analysis.md#开拍前只解决这四件事)。

## 故事与推荐目标

全片串成：**一封危险邀请 → 回到掌权时 → 天子与强兵带来的错觉 → 外面诸侯来讨 → 里面有人要杀我 → 亲手选择入朝或称病。**

让观众看懂三个卖点：董卓有专属本纪与剧情；皇帝和实际掌权者有不同身份；人物关系会把军事强人的处境变成宫廷危机。服装通过人物近景展示，议和扩展简短交代普通与专用结算，完整谈判留到曹操篇。

## 场一 这封邀请要不要接

**建议 40–70 秒，冷开场。** 先给玩家一个有代价的问题，再亮片名。

**画面**：若已取到“未央之约”，从邀请事件切到董卓，再到吕布关系。保留两项选择，鼠标停住，不立即揭答案。字幕“先看这局后来的一封邀请”。若该事件尚未拍到，用原创信件题卡、人物页与关系页建立问题，不仿造游戏事件框。

**骨架旁白**：

> 如果你是董卓，天子病好了，喊你进宫。王允把礼仪安排得明明白白，吕布最近却有点不敢看你。
>
> 去，还是不去？
>
> 玩别的人，我可能先看看能捞到什么。轮到董卓，我得先想清楚，这顿到底是不是冲我来的。
>
> 今天这期《汉晋春秋》，我们就从董卓的位置，看看这场乱世。

“王允”“吕布”两句只在实际事件与人物状态相符时保留。这里说模组事件情境，不补演义中未出现的细节。

**节奏**：关系页留两秒，让观众认出义父子；一个短促音效后切片名，接页首已定片头独白，以“且看我董卓”落到董卓人物近景。开头不解释下载与加载顺序。

## 场二 开局已经站在权力中心

**建议 1.5–2.5 分钟。** 回到 190 新档，用最少的界面把身份讲清。

**画面顺序**：真实日期 → 董卓人物页 → 献帝人物页及朝廷关系 → 直接领地 → 本纪。屏幕可用三张原创说明卡：“献帝：天子”“董卓：秉政者”“诸侯：各有兵地”。说明卡与原生 UI 风格区分。

**骨架旁白**：

> 把时间拨回一九〇年。董卓的起点，已经在朝廷的中心。
>
> 天子是刘协，实际秉政的是董卓。看懂这一层，再看人物关系和诸侯地图，就能明白：为什么我手里有兵，也得关心皇帝身边坐着谁。
>
> 《汉晋春秋》把这些身份做进了制度和人物关系。玩到这里，我会先查自己掌握哪些权力，又有谁还愿意听我的。
>
> 先别忙着高兴。人都认识，未必就都能放心用。

**实际操作**：查看一个确实存在的官职／摄政关系，指出谁是名义君主、谁在秉政。只讲观众当前要用的这一层，不展开全部官制。

**趣味点**：可在三人关系切完后接一句：“这个职位看着很威风，售后服务是全天下来讨伐。”语气轻，不遮住关键 UI。

**取材边界**：当前 190 源码设县侯“郿侯”；帝国级郿国是领地容器，旁白不称他已经是皇帝或实封郿王。推荐卡没有董卓，选人入口先实机核实，不拍假卡片。

## 场三 这些人和这些兵能不能放心交出去

**建议 1.5–2 分钟。** 用西凉军和吕布，把政治介绍接到玩家决策。

**画面**：真实军队面板 → 羌骑／湟中义从／重甲步兵 → 补给 → 董卓、吕布、李儒等在场人物。服装近景放在人物之间，自然带出必需服装包；至少取一组常服与披甲的实际渲染。

**骨架旁白**：

> 董卓还有一份很扎眼的家底：西凉事件兵。骑兵、重甲步兵，阵容摆出来，确实容易让人觉得自己很稳。
>
> 可军队面板往下翻，还有补给。人多的时候，路怎么走、兵怎么放，就都成了问题。我准备先看清楚这些，再决定去哪里迎敌。
>
> 身边的吕布也很有意思。开局的义父子关系已经安排好了，熟悉这个名字的人，大概很难只把他当成一张武力面板。
>
> 这就是董卓视角好玩的地方：眼前的每一份优势，都让我忍不住再检查一遍。

**实际操作**：选一处确实会影响行动的补给或驻军问题，说明自己的选择；没有该问题就讲部署，不硬剪成缺粮。约三万是脚本设计规模，片中数字以实机面板为准。不称事件兵可免费补满、永久继承或无视补给。

## 场四 诸侯来了 我准备往哪里退

**建议 2–3 分钟。** 第一次让人物处境真正影响大地图。

**画面**：反董联盟及实际成员 → 战争目标 → 雒阳与长安的地图关系 → 焚雒西迁事件 → 迁后的朝廷与人物位置。挑两三名观众熟悉的诸侯，避免逐个点名。

**骨架旁白**：

> 再把地图拉远。关东诸侯聚到了一起，而这次他们共同的目标，恰好就是我。
>
> 对面的名字越熟，董卓这个位置就越有意思。以前听故事，我在等诸侯打进来；现在轮到自己坐在这里，我得先看看，城和兵该怎么守。
>
> 接着，本纪把局面推向迁都长安。天子、朝廷和身边的人一起挪动，原来的人物关系，也跟着进了新的城。
>
> 这一段很适合看模组怎样把剧情做进地图。看完迁都，再回头看那些地方和人物，局面已经变了。

**剪辑重点**：事件前后地图用同尺度切换；如果拍到建筑、发展或控制的变化，只标实际读到的变化。展现焚城影响，用城市、地图和人物反应，不额外制造血腥画面。

**制作注**：当前焚雒西迁是单选事件，不安排“我仁慈地选择不烧城”的桥段。历史事件开关、联盟和初始化条件决定它是否出现；未出现则改拍当前真实的防御态势，说明这一局走了另一条路。

## 场五 打赢这一仗就够了吗

**建议 2–4 分钟。** 保留一段真正有前后因果的战斗或防守。

**拍法**：开战前用 15–25 秒说清目标；给出一项自己的判断；保留一次关键交锋、围城或撤退；立刻补实际结果。让观众能判断“刚才的打算有没有用”。

**开战前旁白**：

> 我现在想保住的是这条路和这片地。先按眼前兵力作判断，再给自己留一个撤退的方向。
>
> 玩董卓，强兵给了我出手的底气；诸侯到底从哪边来，又逼着我把底气算得仔细一点。

**结果分支**：

| 实际结果 | 留下的内容 | 接下来的话 |
| --- | --- | --- |
| 赢了 | 为什么赢、损耗多少、还面临谁 | “外面这一关暂时守住了。我还得回去看看，宫里是什么局面。” |
| 输了 | 错判在哪里、丢了什么、怎样收拾 | “这次的代价已经摆在地图上了。先收拾眼前，再想朝廷里的事。” |
| 僵持或退却 | 为什么值得停、守住了什么 | “这一步先求能守住。继续追下去，未必是我想要的结果。” |

措辞随实际情况改，不为给“宫中危机”铺垫而隐藏仍在继续的战争。

**议和包介绍插入位，20–40 秒**：在实际战争结算处说明这组模组包含议和扩展，普通战争可以调整条件；如果当前讨董战争走专用规则，就直接展示专用结算提示。可配：“这场战争有自己的剧情收束；普通战争里能怎样谈条件，下一期让曹操来试。”若该提示未出现，采用普通介绍字幕，不宣称已验证分流。

## 场六 谁允许我安心进宫了

**建议 2–3 分钟，全片高潮。** 回到开头的未央邀请。

**画面**：本纪与真实日期 → 王允、吕布当前状态 → “未央之约”完整选项 → 玩家思考 → 实际选择 → 选择后状态。事件命名中的“192”不进旁白；当前脚本从 190 开局后 516 天开始检查，实际触发日期要看本局条件。

**骨架旁白**：

> 现在，开头那封邀请真的摆到面前了。
>
> 对董卓来说，这个问题比刚才的兵力表还直接。我准备进宫，就得承担这次邀请的后果；我也可以称病，把这件事往后推。
>
> 我会先选称病。先多争取一年，再看看这一年能把局面改成什么样。
>
> 我喜欢这里给玩家留的这一手。熟悉故事的人知道危险在哪，游戏又真的把一个选择交到了你手里。接下来怎么用这段时间，才轮到我自己盘算。

主线拟选称病，实际拍摄可随局面改。**“多争取一年”仅指这次检查推迟 365 天，不能配音成永久免死。** 若选入朝并进入死亡结算，保留真实结果，把结尾改为“这次我把自己交给了这份邀请”，不声称是普通随机暗杀。

**未触发时的替代高潮**：取本局最尖锐的一次军事或朝廷危机，用真实选择收束；未央之约改成 20–30 秒的“专属事件预告”，用原创题卡说明代码提供称病延后分支，不能伪造已发生。

## 场七 董卓值得怎么玩

**建议 1–1.5 分钟。** 给玩家具体的推荐理由，接到第二期。

**骨架旁白**：

> 如果你喜欢 CK3 里身份、权力和人物关系互相牵扯的感觉，董卓这个位置很值得试。
>
> 你开局已经掌权，也有强兵。接下来要面对的，却是诸侯为什么来讨你，身边的人为什么靠得住，皇帝又会把你带进怎样的局面。专属本纪把这些问题连成了一段能跟着玩的故事。
>
> 这次组合是《汉晋春秋》内测主包、必需的服装资源包和议和扩展。三件链接与当次可用版本放在简介，按说明开新档。
>
> 下一期，我们换到曹操的位置。还是一九〇年，重新开一局：地盘小了，熟人更多了。等到讨董之后，他想要的立足之地，又会在谁手里？

**尾卡**：第一期董卓／第二期曹操；三件物品名称与下载入口。实际战果与生死不预先写在尾卡上。

## 可扩展内容与压缩顺序

| 素材状况 | 取舍 |
| --- | --- |
| 战斗和防守有看点 | 留一次布阵或行动判断，最多多展开 3–5 分钟 |
| 有好笑又影响局面的真实事件 | 留事件、选择和结果，先让观众看懂笑点，再补一句制度解释 |
| 权臣界面实际可用且效果清楚 | 插入约一分钟“继续控制天子还是放手”；弃天子自立须实测联动，不把按钮存在当已永久脱离剧情 |
| 需要压到短片 | 缩人物点名和长行军；保留身份说明、一次危机、一次玩家选择、推荐理由 |
| 未央事件等待太长 | 剪日期过渡，保留中间关键变化；不为追事件填满成片 |

不把受禅称帝当作本期必达目标。当前董卓开局郿国容器不自动满足受禅身份资格；官制、权臣、受禅不在一段里讲全。
