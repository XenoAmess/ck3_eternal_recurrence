问题不应简化成“卡片太多，所以全部换实机”。卡片承担比较、公式和反事实时有用，但正式游戏对象应有原图标、插画或对应界面局部。只列名称和数字，无法帮助观众把解释映射回游戏。

## 4. 朝觐与普通朝圣的关系，要按生命周期讲

两个特质独立、可以共存，没有自动转换；但“不能转换”不能成为介绍的终点。

| 玩家状态／行为 | 源码结果 |
| --- | --- |
| 普通朝圣抵达，自身尚无朝圣者 | 普通到达helper授予`pilgrim`；不是必须等返家。 |
| 首次朝觐目的地阶段完成，自身尚无朝觐者 | Hajj日志helper授予`hajjaj`；没有普通朝圣者经验轨道。 |
| 强制朝觐礼仪，尚无朝觐者 | 普通虔诚／世俗类型被这道身份守卫挡住；朝觐另核资格与麦加。 |
| 先取得朝觐者，再合法参加普通朝圣 | 普通类型的上述守卫放开；普通授予不会删朝觐者，因此可得到双特质。其它出发门槛仍独立适用。 |
| 已有朝圣者，再合法完成朝觐 | 可另获朝觐者；还会按虔诚类表现，对尚未满100的既有朝圣者请求5／10／20／40基础经验。 |
| 只有朝觐者，完成朝觐 | 不通过`has_trait=pilgrim`守卫，不能靠经验请求凭空生出朝圣者。 |
| 已有朝觐者，重复完成朝觐 | 特定学识生活方式下请求300生活方式经验；否则写额外虔诚旗标。不是朝觐者自己升级。 |
| 跨Religion改宗 | 通用转换事件删除朝圣者，没有把它换成朝觐者。同Religion内改Faith／个人Rite不满足这一条删除条件；保留特质不代表保留旧礼仪待遇。 |
| 开局／统治者设计，持有麦加伯爵领且满足礼仪条件 | 可直接取得朝觐者；这两处实际没有单独核“首都就是麦加”。运行中的月度补发事件才真正检查麦加首都。看到标签不能反推已走完旅程。 |

负结论限于已搜的现存`common/events`字面调用：未见`remove_trait=hajjaj`和自动互换；不能把它扩写为引擎、控制台与外部mod永不能删除。随从有另外的授予条件，也不能套用主办者一行。

**诺斯替主义是本轮新找到的动态覆盖漏项。** `pilgrim`携带`gnostic_learning_piety_trait`标记（traits:8893），诺斯替主义的个人信条提供`gnosticism_learning_piety_trait_gain`（`common/religion/tenet_types/00_tenet_types.txt:1043–1045`）。`common/on_action/traits_on_actions.txt:3–59`在获得特质时，检查活人、个人信条与三天冷却，然后分别处理经文研习者和神秘主义者：未持有则授予，已持有则各请求10点基础经验（`common/script_values/00_trait_values.txt:5`）。

两个额外特质本体各有学识+1（traits:17958、1912）。因此原先均无、角色满足资格且实际授予成功时，有两者本体合计+2学识的路径；经文研习者另有最低16岁等自身定义。不是所有朝圣者固定再加2，也不是每次朝圣者升级都触发；已有额外特质时走各自经验分支，不能再承诺固定属性增量。朝觐者没有该获得标记。这条仍为静态确认，未新增人物实测。

**信条的另一层收益是美德待遇。** `00_pam_tenets.txt:653–737`的Acts of Apostles信条把朝圣者列为美德；显示名称按条件为宗徒大事录／使徒行实／热忱传教。`weight=15`是特质选择权重，不是给15经验或15属性。这项在库存里有，但本片没有把玩家收益讲清。

**不能靠旧版印象补假收益。** 当前`tradition_religion_blending`（宗教融合）在`common/culture/traditions/00_ritual_traditions.txt:925–1030`定义了改宗／创建礼仪成本与异信好感等，没有这里要求的朝圣者条件附加属性。这个有限否定不影响已经确认的文化勇武、学识与诺斯替动态链，也不能外推到其它版本或mod。

旧169条库存没有把`traits_on_actions.txt`的这条动态链列入来源。因此本次同时存在“已有研究没进入视频”和“原研究检索没有跟到动态消费者”两种遗漏。后续研究要从特质flag、on_action、个人信条参数追完整链，不能以字面命中数量宣称穷尽。
