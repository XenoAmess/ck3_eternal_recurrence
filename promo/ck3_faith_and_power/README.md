# CK3：信仰与权力

2026-10-17 建立。**这是覆盖 CK3 整个宗教系统的新系列；圣地是第一个专题。** 当前交付为导演提案、待拍镜头矩阵与拍摄交接，没有创建生产 run、启动游戏、录制、配音、渲染或上传影片。

**同事接手拍摄从[拍摄交接](shooting-handover.md)开始**：其中列明已有成果、待验证问题、目标机器准备、首日两条试拍、工期估算及审阅版交付物，再按导演案和镜头矩阵推进。

系列从玩家会遇见的具体问题出发：为什么土地属于我，圣地却未必属于我的信仰？为什么相同教义在不同局面下产生不同结果？宗教规则又怎样改变统治、外交与战争？每期选择一条能用原代码与真实界面回答的主线，最后给观众一个可以用于下一局的判断方法。

## 第一专题：圣地

圣地专题建议拆成三期，每期约 **30 分钟**，以 **20–40 分钟为佳**。章节时间是编排预算，最终由实际讲述、实验与可用镜头决定。三期各自完整回答一个问题，可以独立观看，也构成“取得 → 分配效果 → 经营与权力”的连续进阶。

| 期 | 暂定片名 | 看完能回答什么 | 核心看点 |
| --- | --- | --- | --- |
| 01 | **圣地不是打下来就算：谁能把它变成自己的？** | 如何区分控制土地、信仰已有圣地、新建、采用、主要等级与放弃？跨宗教为什么有时允许、有时被拒绝？ | 从用户的巴格达采用窗口开题；同一出发局面的失败／成功条件对照；把圣地重规划的代价与限制讲清。 |
| 02 | **一座圣地，谁在吃加成？** | 普通与主要圣地的效果给谁？圣物如何成为信仰加成？同一地点为何能对应不同信仰、不同等级？ | 巴格达“聂斯托里主要／逊尼普通”的同地对照；三圣物槽与认可判定；最后有效圣物取出后的变化。 |
| 03 | **圣地为什么值得经营？** | 圣地类型、特殊建筑、圣物、朝圣和宗教领袖怎样组成一套长期经营选择？ | 十类动态类型的取舍；一座“看着很豪华”的圣地为什么未必最适合自己；从领地收益回到宗教政治。 |

完整的叙事、时间表、旁白样句、代码出处和拍摄准入见 [导演案](director-plan.md)，逐镜头的可拍条件与后验见 [镜头矩阵](shot-list.md)。三期暂定顺序跟随观众理解过程；若研究发现某项机制需要单独成篇，应改稿并给出完整新主题，不能用静态图卡填满片长。

## 后续宗教系统选题

以下是系列的扩展方向，尚无已拍或排期承诺。圣地专题中的关联机制只讲够回答本期问题的部分，之后再各自深入。

| 专题方向 | 可围绕的玩家问题 |
| --- | --- |
| 信仰、宗教与礼仪 | 创建新信仰以后，哪些关系真正变了，哪些仍由宗教和礼仪继承？ |
| 教义与信条 | 哪些选择改变合法行动，哪些改变数值，哪些改变别人怎样看待你？ |
| 改宗与传教 | 角色改宗、伯爵领改宗、接受与抵抗，为什么不是同一个过程？ |
| 热情与分裂 | 热情怎样产生、被消耗或改变；异端与改革在什么条件下出现？ |
| 神职与宗教领袖 | 谁任命神职、谁拿税、谁能施加宗教权威；世俗领袖与属灵领袖有何经营差别？ |
| 宗教外交与法统 | 正信、迷途、敌对、邪恶怎样影响婚姻、封臣、罪行与统治合法性？ |
| 朝圣与圣物 | 行程、地点、活动收益、圣物认可与信仰网络怎样相互作用？ |
| 圣战、大圣战与骑士团 | 宗教战争何时开放、谁能发动、谁会参加、收益如何分配？ |

这些是需要调查的选题，不代表所有机制已完成原生研究，也不把当前可用接口外推为整个宗教系统已可自动游玩。
