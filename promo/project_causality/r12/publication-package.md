## 简介

一个 Mod 真正昂贵的部分，往往不是写出第一版，而是以后每次改动都要重新证明：它还能玩，没有破坏旧内容，也确实可以发布。

Project 因果律把玩家可见的 Mod、文档与生成器、open-kashek、CK3 MCP、自动游玩智能体、真实游戏验收和发行证据组织成一条可反复运行的链。

这条片子从“咒、术、道、辉煌愿景”四层展开：先看今天已经存在的产品与罗贝尔连续实机；再拆开它们背后的制造方法；随后说明我们凭什么判断一次交付是真的；最后展示四个无限演进 Loop 怎样让本次结果成为下一次创造的输入。

对已有 Mod：可以只接入无人值守、可重放的真实 CK3 验收。

对新创作者：可以从玩家承诺出发，走完整个创作、测试、实机核验与发布流程。

对 CK3 本体研究：每一次 exact-build 逆向和实机结论，都能沉淀为下一轮可查询、可复用的能力。

本版使用项目所有者授权声线，简体中文为主叙事并烧录字幕，另含可选择的英文字幕轨。音乐尚未加入。

## 推荐置顶评论

如果你已经有一个 CK3 Mod，最短的接入路径不是推倒重来，而是先选择一条最重要的玩家路径，让 MCP 在真实游戏中自动重放并回读结果。

如果你正准备做第一个 Mod，则可以从玩家最终应该得到什么开始，把权威文档、生成、离线检查、实机核验和发布从第一天连在一起。

欢迎带着一个具体功能或一条最难维护的测试路径来讨论。我们会优先回答：它现在能接入哪一层、缺少什么观察口、怎样形成第一条可运行的闭环。

## 发布前检查

1. 所有者以 1× 完整审片，并返回需要修改的时间码；
2. 确认是否继续保持无音乐，或由所有者操作 Suno 后再进行最终混音；
3. 确认标题、简介、封面与公开链接；
4. 重新核对最终 MP4 SHA-256 与上传文件一致；
5. 获得明确上传授权后再对外发布。目前 sidecar 保持 `publication_authorized: false`。
