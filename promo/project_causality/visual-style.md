## 字体与层级

- 中文标题：Microsoft YaHei UI Bold；英文副标题：Segoe UI Semibold。
- 中文主字幕 46 px 等效，英文副字幕 31 px 等效；中文在上、英文在下。
- 中文最多两行，英文最多两行；按实际像素宽度断行。
- 状态标签固定在右上安全区；产品 lower-third 固定在左下，但避开 CK3 人物肖像和事件选项。

## 安全区

- 左右各 8%，上 6%，下 8%。
- 底部 UI 密集的 gameplay 将字幕整体上移，不在源画面上再叠第二套 lower-third。
- `VISION / TARGET SYSTEM` 在所有完整目标态镜头中常驻。
- `ACCEPTANCE EVIDENCE` 只用于验收素材；正常 Workshop/产品画面不得贴该标签。

## 动态

- 静态实机图只允许 2%–5% 的缓慢推拉或横移；不得制造不存在的按钮动作。
- 因果线只连接真实关系；实线表示已存在环节，虚线表示目标态或未闭合能力。
- RED 出现时不使用闪烁警报；音乐抽空、警示红线回到权威文档。
- 生成章节图不烧录文字，所有标题与状态由剪辑工程添加。
