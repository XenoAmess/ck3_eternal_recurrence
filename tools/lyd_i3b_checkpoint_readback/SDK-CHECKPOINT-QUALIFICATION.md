# Compact SDK checkpoint qualification adapter

This additive source package converts independently preserved compact JSON receipts. It does not open a checkpoint body, call the game, provider, MCP or native bridge, or modify the existing checkpoint reader. Invoke `reader/sdk_checkpoint_qualification.py --request <new-bound-request.json>` with a new output directory. The unbound templates deliberately reject execution.

ROOT must first qualify the actual new source export, DLL, private23 SDK metadata, profile and session. The live source HEAD is independently supplied; the installed reader's witness contract remains `632f0a57a07aa6299052004589ed6f7632e7d8f7`. All 69 immutable business-file hashes must equal the fixed contract in this package. Descriptor metadata is excluded from that business map. The supplied provenance is a consistency binding, not authentication of the executing game.

The five input descriptors name bounded JSON artifacts with exact bytes and SHA-256: provenance, actual SDK checkpoint receipt, saved reader STATE, and each actual G2/G3 profile receipt. The verified byte buffer is parsed once. Before and after checkpoint snapshots must have the same paused frame, exact current image HELLO, PID, connection, actor, snapshot, date and public/native revisions. Each query must bind that frame and its own independently recorded capture epoch. Public revision, native revision and capture epoch are separate fields. If actual receipts differ, preserve them and stop for a new qualified binding; do not substitute a historical revision or weaken this contract.

G2 emits the installed `lyd.i3b.native-predicates.v1` witness only when native availability and completeness are explicit, the complete current living Faith roster and all Rite IDs equal the saved observations, and every row is alive. It derives all human IDs from complete `is_ai=false` rows, maps actual effective learning and full county counts, and retains every raw public field. Negative native learning and valid zero references remain raw observations with an explicit old-reader incompatibility. Unknown leaves remain NULL; they do not become false, zero or an empty collection.

The canonical `lyd.qualified-native-head.v1` sidecar retains the native Faith-to-Title graph, complete holder identity, all four property booleans, complete law vector and static qualification, plus independent source/frame/epoch provenance. An actual saved Title join additionally requires its result reference, full AST hash, independently parsed holder and owned marker/typed owner Faith. Known contradictory saved reference kinds are rejected. A native CLandedTitle class does not establish a saved Title discriminator or property path; those fields remain NULL. C3 consumes this same sidecar rather than implementing a second converter.

Formal serial/nonce, 410/411/412/413/430 native event receipts, every alive human's consent, each active school's two-thirds quorum, and political/tenet protection remain separate checkpoint-reader and ROOT acceptance evidence. This converter grants no formal mandate or runtime acceptance. Every actual/formal pass stays NULL; business and full-product credit stay false.

The revised converter passed 15 new bounded fixture methods. The original 11-pass run and the pre-review source are retained; four independently reproduced negative categories were repaired and are preserved in the separate review history. No old static tests, old save bodies or native tests ran. `EXPORT-MANIFEST.json` lists additive installation files and exact inherited dependency alternatives, including ROOT's recorded EOF-only parser projection.
