# P28 exact-day route-contact scope correction

Actual AUTO79 executed a native-stopped day (`53432424 → 53432448`), with one daily tick, no overshoot and a paused map readback. Its original starting war contained twelve enemy army rows: eleven had the native `retreating: true` bit; the complete route horizon selected the sole other enemy. The old result classifier compared the selected hostile IDs to all twelve rows and rejected the already executed day. The subsequent semantic frame independently reported the ending date, actor, Game and paused map. Neither this correction nor the date receipt awards war, combat, action or material success, and the original action must not be replayed.

`route_contact_exact_day_war_scope_v1.py` is a portable extraction of the **scope rule only**. It treats only `retreating is True` as excluded. A missing, `None` or false bit remains in scope. A public CUnit ID of zero is valid. It validates the full original starting war/player/enemy roster and complete selected non-retreating hostile set, then validates the ending roster shape. War IDs may naturally differ after one exact day; that is an observed scope transition, never an inferred result.

The accompanying patch records the narrow runtime change against the immutable canonical classifier, base SHA-256 `cab81e36aa9b76c248ba8d3a379fce5edecf6784513f6f68d2cc1b81938502d0`, patch SHA-256 `16ab48ddf4f36cd98a61c7b11522579a4b23b0efdc1662d88c62e550c5fe1aa2`, resulting classifier SHA-256 `cea62c06eec60b0c4dd5df2c0410cb1a041797ad1ecac402edcd8c969734e9c9`. It is a research recipe for an independently pinned runtime source; it is not a direct install target for the public package. Preserve that classifier's separate exact Game/actor/source frame, full-hostile Native horizon, speed/arm/resume/query, one-day clock, pause, no-overshoot and zero-business-credit checks. Apply only after matching the base SHA and review the three hunks; do not replace a newer classifier wholesale.

The fixture is a 3.6 KB literal projection of original AUTO79, source SHA-256 `063cc5b8e6e0dd801f11d12a6df8652c5410561c114e984bbb470f511f2634e6`. The tests cover the actual scope, nine invalid variants, CUnit zero and two synthetic post-day war transitions. Those transition tests prove bounded handling, not an observed end to the actual war. The classifier correction was additionally replayed through the production AST selection boundary against the full original AUTO79 response; this portable helper does not itself classify or settle an AUTO response.
