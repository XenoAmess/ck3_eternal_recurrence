# Root saved-campaign queue

Root alone runs these controllers through the existing file-queue SDK executor.

The bounded entry loads the adjacent ordinary loop, which imports the adjacent
pure helper. All gameplay calls go through Root's existing file-queue SDK
executor. These files do not start a second SDK or Game process. Root supplies
the actual GREEN qualification, snapshot/SAVE pair and response references.

Both entry points accept an optional `--sway-observer-binding` naming Root's actual
`xar.r104.dynamic-sway-observer-binding.v1` record. The observer uses that
record's full actor, target, scheme instance/generation, episode, process and
frame identities. It does not fall back to a historical target or scheme.
Its hash-bound `xar.r104.root-held-queue-query-witness.v1` must reference the
actual target, completion and opinion request/response pairs from the same held
queue, with the completed ordinary endpoint and current frame. Source review or
capacity-guard success cannot supply those business observations.

The target query verifies an explicitly known target; it does not discover or
choose one. Without fresh target evidence, Root can continue ordinary strategy
requests while leaving this observer disabled. Without a binding, both entry
points skip Sway baseline reads and observer queries. Supplying a binding
requires both completion and opinion baselines. Initially disabled observation
does not count as an ended original episode. An adopted successor permanently disables
the original episode's observer; it does not retarget it. An unavailable Sway
observation remains unknown and does not establish campaign death.

A fresh, retained played_character_changed terminal may use the reviewed
adjacent transition validator and one ordinary continuation. Existing timeline tools
allow one modal Close, independent clearance/date-advance proof, and an actual
paired successor SAVE before ordinary play resumes. The held SDK must already
expose its --private-death-succession-modal-continue tools.

An already completed continuation is never resent. A new transition without
its independently retained terminal before-anchor stops for Root review.
Unknown responses/requests remain preserved. A response reference already
paired with successor SAVE earns zero new succession credit and repeats
neither Close nor SAVE. Public revision supplies expected_revision; native
revision is checked separately. Goal/campaign/origin come from actual snapshots.

No live M7 credit is granted by this source preparation. Actual successor
SAVE, following ordinary play and future independently paired coldrestore
remain runtime acceptance work.

Nonexecuted first or following responses, including pending unknown submissions,
stop before another ordinary action. A confirmed successor SAVE ends its chunk
immediately; the bounded owner adopts that exact snapshot/SAVE pair before
starting the next chunk. Later failures therefore retain the successor pair.
