# 超人强性交计数重新设计

2026-10-23用户指令：明确性交、日常夫妻生活、实际执行的概率受孕尝试都纳入计数，一次行为触发一次；随后要求保持纯工坊，用受支持事件按原生频率模拟日常生活。此文对应 **1.2.0开发候选**，不记录已发布或本轮实机通过。

新计数统一进入原有配对/匿名结算：先比较行为前经验，再进行一次属性抽选与守恒转移，最后合格双方各加一次。匿名对象只增加已知角色经验。角色变量和七项净修正账本保留，不倒推启用前经历。

| 来源 | 结算时点 | 去重 |
| --- | --- | --- |
| 明确的配对/匿名性交 | 原版效果实际执行时 | 预览不执行；独立多次调用分别计数 |
| 脚本中的受孕概率尝试 | 实际进入概率判定前 | 失败也计；内部性交及后续孕结果共用这次行为 |
| 原版绕行的妓院、医疗、剧情受孕 | 经来源审计的实际行为分支 | 身份已知则配对；没有对象则匿名；双胎不等于两次性交 |
| 日常夫妻生活 | 原版每信仰每月回调，成年在世正式配对每月模拟一次 | 双方本月伙伴名单；跨信仰、反向关系和读档不二算 |
| 怀孕揭晓、出生或其他延迟后验 | 不额外计数 | 保留原始性交记录，避免结果阶段再次加一 |

月度模拟独立于生育是否成功，包含孕中、不育和同性成年夫妻。模拟直接调用本模组结算，不额外调用原版性交/怀孕效果，因此不会额外制造妊娠、压力或记忆。明确性交仍可以在同月增加更多经验。

原版 defines 明确自然受孕检查按月进行，使用原生 `on_faith_monthly` 可按信仰分片处理，避免另建全世界自调度器。月份使用 `current_year*12+current_month`；双方名单只在跨月时清理，存档重载保留当前月份。妾主反向关系显式处理，不依赖尚未独立证明的 `every_consort` 双向语义。
