《超人强：越超人越强》1.2.0
相对上一公开版本1.1.0的更新

新增：日常夫妻生活计入经验
• 每对在世、年满18岁的正式配偶或侧室，每自然月模拟一次性生活，双方各增加1次经验，并使用原有属性吸取规则。
• 跨信仰配对及侧室反向关系也参与；孕中、不育不会取消当月次数，规则不按性别排除。
• 同一对在同月的重复回调及读档不会重复结算；同日或同月另外发生的明确性交仍分别计数。
• 纯工坊运行，无需原生组件或外部后台。日常部分采用月度模拟，不逐次读取引擎内部的自然受孕掷骰，也不额外触发怀孕判定。

扩展：脚本受孕尝试与遗漏入口
• 已接入的原版脚本受孕尝试，在实际开始概率判定时记作一次，即使未能怀孕也计数。
• 补入医疗、妓院、朝圣及部分剧情中的绕行入口；可确认双方身份时按配对结算，匿名对象只给合格的已知角色增加经验，不吸取属性。
• 保留原版妊娠、压力、秘密与记忆等事件效果；怀孕揭晓、出生或结婚本身不额外增加次数。

修正：同一次行为只结算一次
• 修正朝圣双人行为之后，为处理疾病风险再次进入匿名效果而重复计数的问题。
• 脚本受孕成功分支中的内部性交效果不再与外层同一次尝试重复计数；双胎等后续结果不当作多次性交。
• 独立发生的多次行为继续分别累计，没有新增同日冷却或收益递减。

存档与规则
• 可继续使用原存档，已有性经验与七项净属性账本保留；更新后参与后续月度回调，不补算过去的夫妻生活或漏记经历。
• 存活、年满18岁及双方为不同角色的要求保留。仍先比较本次之前的经验，经验多者随机吸取一项；平手或没有可转移属性时仍各记一次。
• 六项能力每次转移1点原始修正，健康每次转移0.00075；原有边界、健康门槛与面板计算规则保留。

兼容与已知问题
• 面向CK3 1.20.*，本轮源码与限定实机验证使用1.20.0.4。多人、Ironman、成就、其他补丁及全部DLC组合未逐项验证。
• 新接入了更多原版事件；覆盖相同性行为效果或同名事件的其他模组可能需要兼容补丁。
• “勾引越多，后续角色通知越多”的报告仍开放。零次/五次结算的死亡通知限定对照尚未复现，根因未定位，本版不宣称修复；该对照也不代表五轮完整勾引或所有消息类型。

《超人强：越超人越强》1.1.0

新增：健康也能吸取
• 外交、军事、管理、谋略、学识、勇武、健康，七项合格属性等权随机。
• 抽中六项能力之一，双方仍转移同一项的1点原始修正；抽中健康，双方转移同量的0.00075原始健康修正。
• 对方当前有效健康不足3.00075时跳过健康项，其余合格属性继续等权随机。
• 健康独立记账、随存档保存，不改写基础健康；原版健康惩罚抵消继续生效。
• 0.00075略低于原版25岁起始衰老参数折算的一个月期望健康损失。这是平衡基准，不保证实际寿命恰好或最多改变一个月。

改进：查看经验使用原生通知气泡
• 右键角色选择“查看性经验”后直接出现气泡，无需再确认；显示目标角色与次数、当前属性和累计净变化。
• 六项能力分两排，健康单独一排并保留五位小数；括号内为本模组累计净修正点。
• 移除原先占屏的大事件窗，缩短右键入口与特质说明；查看保持只读。

工坊展示
• 封面改为一位成年国王与一位成年王后。
• 重做宣传插画与规则图，中文介绍同步更新七项属性和通知查看方式。
• 展示正常游玩的勾引成功事件与新的经验通知实机图；插画与实机截图明确区分。

存档与兼容
• 可继续使用1.0.0存档，原性经验与六项能力账本保持；未记录的健康账本按0处理。
• 经验较多者吸取、平手不吸取、双方各记一次、18岁与存活限制、匿名对象只计数等规则保留。
• 面向CK3 1.20.*；多人、Ironman、成就及全部DLC组合尚未验证。
• 与同时覆盖had_sex_with_effect或had_sex_with_unknown_effect的模组仍可能冲突，需要合并接入点。

超人强：越超人越强 1.0.0
首次发布（initial baseline），没有上一公开版本。

新增：
• 接入游戏明确结算的成年角色性行为事件，保留原版妊娠、压力、记忆、秘密及其他效果。
• 每位角色以独立变量保存性经验，双方每次各记录1次；不使用100点特质经验条作为计数上限。最大为92,233,720,368,547次，达到上限后保持该值。
• 按本次行为之前的经验比较双方。经验相同时不吸取，经验较多者尝试吸取随机一项外交、军事、管理、谋略、学识或勇武。
• 成功转移时，同一项吸收/流失的属性修正严格守恒：接收者增加1点，来源者减少1点，不改写角色的基础能力值。
• 最终属性仍受原版百分比修正、取整和勇武惩罚抵消等规则影响，界面上的变化可能并非恰好增加或减少1点。
• 来源者当前显示为0的属性不参与抽选；接收者当前显示为0也可以接收。本模组每项累计的属性修正限于-1,000,000至+1,000,000点，无法完成转移的边界项会跳过；没有可转移属性时不吸取，双方性经验仍照常记录。
• 增加只读的角色经验查看入口和持有人特质说明；查看不会增加经验或触发吸取。
• 年满18岁、在世的玩家和AI角色均适用；同一天多次明确行为分别结算。
• 匿名对象事件仅增加已知角色的经验，不创造另一角色或属性来源。

兼容与存档：
• 目标游戏版本为CK3 1.20.*，首发验收以1.20.0.3为准；无需其他模组或DLC硬依赖。
• 可在现有存档启用，从启用后开始记录，不倒推历史经历；0代表尚未记录，经验不遗传、不跨战役保存。
• 改写had_sex_with_effect和had_sex_with_unknown_effect；与同样改写这两项效果的模组需要合并接入点。

已知边界：
• 只统计明确发生的事件，不周期性模拟日常夫妻生活，不以怀孕、婚姻或记忆数量反推次数。
• 不承诺多人、Ironman、成就、全部DLC组合或后续补丁兼容。
• 非简体中文的本地化仅进行格式、键和动态标记检查，未进行其他语言的实机验收。
