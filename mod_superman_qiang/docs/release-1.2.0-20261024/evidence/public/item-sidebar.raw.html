超人强：越超人越强
王冠给你权力，情场给你属性。

你的野心，现在连寝宫都不放过。

在《超人强》里，性经验是一种实打实的力量。明确性交、已接入的脚本受孕尝试，以及日常夫妻生活模拟，都能积累经验。两位合格成年角色的经验不同时，老手会尝试从新手身上吸取随机一项属性。

一场风流，七种可能。
外交、军事、管理、谋略、学识、勇武，还有健康——你的下一份成长，也许就藏在下一段亲密关系里。

老手收利息，新手交学费
先比较双方本次之前的性经验，再结算这次经历。

  • 经验更多：从合格的七项属性中等权抽取一项。抽中六项能力之一，你得到1点原始修正，对方失去同一项的1点。
  • 抽中健康：你得到0.00075原始健康修正，对方失去同量。细水长流，积少成多。
  • 经验相同：这次不吸取，双方各记1次经验。
  • 每次都记账：无论这次有没有吸到，双方性经验各增加1。确实发生多次，就分别累计。

吸哪项，交给随机；谁来吸，经验说了算。

每月一次，夫妻生活也记账
每对在世、年满18岁的正式配偶或侧室，每自然月模拟一次性生活，使用同一套经验和吸取规则。跨信仰配对、侧室反向关系也参与；孕中、不育不会取消当月次数，规则不按性别排除。

同一对在同月的重复回调或读档不会重复结算；同日或同月另外发生的明确性交仍分别计数。日常部分采用月度模拟，不逐次读取引擎内部自然受孕掷骰，也不额外触发怀孕判定。

已接入的原版脚本受孕尝试，在实际开始概率判定时就记一次，失败也计数。同一行为内部的受孕、疾病与后续结果不会重复加次数。

这场成长游戏，AI也会玩
玩家与成年AI使用相同规则。整个宫廷都在积累自己的经历，亲密关系也多了一层实力博弈。

想从别人身上变强，先别碰上比你更老练的。

每个角色，都有自己的情场履历
右键角色，选择“查看性经验”，无需再确认，气泡直接显示这个人的次数、当前属性与累计净变化，健康保留五位小数。六项能力分两排，健康单独一排；括号里是本模组累计的净修正。经验特质的说明也会显示持有人的次数。

每个人单独记账，随存档保存。经验不受100点特质经验条限制，最高可记录92,233,720,368,547次。足够让你的王朝谱系写满了，角色的履历还在继续。

看完就走，继续你的王朝大业。查看不会增加经验，也不会触发吸取。可继续使用原存档，既有经验和净属性账本保留；更新后的月度生活从后续回调开始参与，不补算历史。0只表示尚未记录，不代表处子身份；经验不遗传、不跨战役保存。

健康也能吸，数值有分寸
每次健康吸取为0.00075，略低于原版25岁起始衰老参数折算的一个月期望健康损失。对方当前有效健康不足3.00075时，健康项不参与抽取，其余合格属性继续等权随机。

这是健康修正，不是寿命秒表。年龄、疾病、健康修正与随机死亡判定都会影响实际寿命，不保证恰好多活或少活一个月。

装上，开始你的另一条成长路线
  • 无需其他模组或DLC硬依赖。纯工坊运行，不需要原生组件或外部后台。
  • 面向CK3 1.20.*。本轮以1.20.0.4为来源，月度计数与独立保存重载完成限定实机验证。
  • 保留原版事件效果。妊娠、压力、秘密和记忆继续按原版处理；怀孕揭晓、出生或结婚本身不额外算一次。
  • 仅限年满18岁、在世角色。配对要求双方为不同角色；匿名对象只为可确认的合格角色增加经验，不吸取属性。

玩法细节与兼容
吸取作用于属性修正，不改写基础能力或基础健康。六项能力的面板数值仍受原版百分比、取整和勇武惩罚抵消影响，实际显示变化不一定恰好是1点；健康惩罚抵消也继续生效。来源者显示为0的能力不参与抽取；没有可转移属性时，双方仍累计经验。单项累计修正限于±1,000,000，无法转移的边界项跳过；经验达到上限后保持上限。

与覆盖相同性行为效果或同名原版事件的模组可能冲突，需要合并接入点；第三方自行绕过这些入口的脚本不保证自动统计。其他游戏补丁、多人、Ironman、成就及全部DLC组合尚未逐项验证。

已知问题：“勾引越多，后续角色通知越多”的报告仍在排查。限定死亡通知对照尚未复现，根因未定位，本版不宣称修复。

提供九种游戏语言的本地化文本；真实界面检查只使用简体中文，其他语言完成格式与动态标记检查。
