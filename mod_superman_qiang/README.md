# 超人强：越超人越强

**1.2.0 发布候选：月度计数与独立冷重载已验证，用户已授权同ID发布。** 每对在世成年配偶/侧室每自然月模拟一次性生活；已接入的原版脚本受孕尝试失败也计数，同次行为中的受孕、疾病及后续结果不重复计数。模拟使用原版月度回调，不额外制造怀孕，不需要原生组件或外部后台。[R0030/R0031](docs/2026-10-24-monthly-and-cold-native-acceptance.md)证明的是限定月度和保存范围；C2脚本受孕分支的逐分支实机仍有缺口，详见下文。新规则与去重边界见[重新设计](docs/2026-10-23-encounter-redesign.md)。

当前实际公开版本仍为 **1.1.0**，2026-10-04 更新：[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3812991990) · [GitHub 下载](https://github.com/XenoAmess/ck3_eternal_recurrence/releases/tag/superman-qiang-v1.1.0)。该版本的健康吸取、保存重载和通知一步查看已通过当时的实机验收，完整更新说明、封面、五张媒体和真实订阅包均已核对。1.2.0正在准备正式上传、公开全文回读与真实订阅缓存加载；这些发布事实完成前不将候选称为已发布。计划与待补回执见[发布方案](docs/release-plan.md)。

独立 CK3 模组。明确性交、已接入的脚本受孕尝试和月度夫妻生活模拟共用结算；两位合格成年角色经验不同时，经验较多的一方可以从经验较少的一方吸取随机属性。

性经验记录在角色变量中，双方每次各增加 1；结算前经验相同则不吸取。经验不受特质经验条的 100 点限制。右键选择“查看性经验”后直接出现气泡，无需再确认；气泡显示这个人的次数、当前属性与累计净变化，健康保留五位小数。特质说明也读取持有人的次数。

外交、军事、管理、谋略、学识、勇武、健康，七项合格属性等权抽取。六项能力使用独立净转移账本：同项接收者 +1、来源者 -1；健康独立账本转移同量的 0.00075。均投影为永久属性修正，基础属性与基础健康保持原样。每项账本范围为 ±1,000,000。来源者有效能力为 0 或方向账本越界时跳过该项；健康另外要求来源者当前有效健康至少 3.00075。没有合格项仍累计经验。原版百分比、取整及负修正抵消继续生效，因此不承诺面板变化严格对称。

0.00075 略低于原版 25 岁起始衰老参数折算的一个月期望健康损失，只用作平衡基准，无法保证实际寿命最多改变一个月。健康通知读数保留五位小数。详见 [健康设计及来源](docs/health-design-1.1.0.md)。

1.2.0同时记录启用后的明确事件、已接入的脚本受孕尝试和月度夫妻生活模拟。原存档的经验与七项净属性账本继续使用，新月度状态从后续回调开始参与，既往经历不倒推。双方须为不同的、在世且年满18岁的角色，玩家和AI使用相同规则；匿名对象仅给合格的已知角色增加经验，不创造属性来源。同一行为的后续效果不重复结算，同日独立发生的多次行为仍分别累计。

日常部分按每对正式配偶/侧室每自然月一次模拟，不逐次读取引擎内部的隐藏受孕掷骰；跨信仰、侧室反向关系、孕中和不育配对参与，规则不按性别排除。同月重复回调与读档不重复计算同一模拟配对，明确事件仍可额外累计。怀孕揭晓、出生与结婚本身不另记一次。

本轮限定实机来自 `machine_id: desktop-3fevhd2-1c74096080`，游戏为CK3 1.20.0.4/build25734779，完整来源、观察时间与SHA见上述报告。首发及1.1.0的1.20.0.3验收保持历史身份。C2所列医疗普通50%成功/失败、强制妊娠、双胎和朝圣疾病辅助调用的完整逐分支实机仍未完成；现有来源审计和离线回归不替代它们，R0030/R0031月度与R0035配对结算也不外推为全部C2分支通过。同性婚姻设置未作独立实机验收。

“勾引越多，后续角色通知越多”的根因仍未定位。R0033零次与R0035五次结算的限定死亡通知对照未复现累加，审阅帧各可见一张卡片；五次结算不是五轮完整勾引，逐类型通知设置及原生HUD消息实例仍有读口缺口，公共case负断言保留。见[通知诊断](docs/2026-10-24-notification-diagnostic.md)，不将本版描述为已修复此问题。

纯工坊独立加载，无其他模组或原生组件硬依赖。除两个统一结算效果外，新增了原版效果/事件窄投影；与覆盖相同效果或同名事件的模组可能冲突，第三方自行绕过这些入口的脚本不保证自动统计。其他补丁、多人、Ironman、成就及全部DLC组合未逐项验证。
