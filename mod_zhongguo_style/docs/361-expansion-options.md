# 361 绩效文化扩展：现实语境、CK3 机制与施工批次

更新：2026-08-29

本文只讨论把中国互联网公司的绩效文化翻译为 CK3 决策系统，不扩张成泛化的“中国官僚 mod”。

固定边界：

- 只有天朝制公爵、国王、皇帝考核自己的直属官员；伯爵和男爵只受评，永远不能考核别人。
- 公爵及以上既是下属的考核者，也可能是上司榜中的被考核者。
- AI 天朝制公爵及以上完整运行后台考核；这是项目所有者授权的第二个 AI 例外。
- 京察是免费、定期、半强制的绩效季活动；拒办是上司下轮扣分的重大理由。
- 3.25 保留四重问责：制度支持时地方国库 -50、所有人个人金币 -25、制度支持时贤能 -60，以及有俸禄时一年俸禄 -25%；不被任何新功能替换。
- 独立最高领主没有虚构的“自我上司考核”；只承担制度威信或组织后果。
- 不涉及宗教域。

## 一、现实语境中真正有机制价值的矛盾

公开资料并不完全等价于各公司的现行内部制度，媒体访谈和厂商案例尤其只能作为文化原型。这里采用的不是“某公司一定如此”的断言，而是多类资料反复出现、能转成游戏矛盾的共同结构。

1. **361 的核心是稀缺档位和连锁兑现。** 典型公开口径是 30% / 60% / 10%，低档影响奖金、晋升、转岗，连续低绩效可能进入 PIP 或退出；后来又出现保留分级、取消刚性末位比例的争论。这给游戏提供了“严格配额还是松绑”的制度路线，而不只是三个数字。[经济观察网](https://www.eeo.com.cn/2020/1228/450768.shtml)、[钛媒体低绩效访谈](https://www.tmtpost.com/5995803.html)
2. **完整绩效是循环，不是年末抽奖。** 目标制定、跟踪辅导、自评/全面反馈、上级与组织评审、结果反馈、申诉、改进发展构成闭环。[腾讯 ESG 报告](https://static.www.tencent.com/uploads/2025/04/08/7ef7e3b3749bfcbbeccbcc837b794e60.pdf)
3. **业绩与价值观是两张表。** 阿里公开资料把目标、业绩、价值观、团队绩效、发展对话、晋升、短长期激励联系起来；公开案例还给出了业绩与价值观 50/50、“野狗/小白兔/明星”式矛盾原型。[阿里巴巴员工发展](https://www.alibabagroup.com/zh-HK/esg-employee-development)、[36Kr 价值观考核案例](https://www.36kr.com/p/1724803563521)
4. **OKR 是方向和证据，不应机械等于绩效。** 公开案例明确区分目标完成度与最终绩效：探索性目标若与奖金一比一绑定，会诱导所有人只报保守目标；实际组织贡献仍需校准判断。[飞书 OKR 说明](https://okr.feishu.cn/blog/okr-performance)、[店匠案例](https://okr.feishu.cn/customers/shoplazza)
5. **360 能补跨部门盲区，也会制造互评政治。** 自评、同级、下级和上级反馈能让直线经理看见协作，但会出现互相抬轿、恶意低分、评估人“手松手紧”、匿名黑箱和填表疲劳，因此必须有限权、证据、可信度和权限设计。[来也科技案例](https://okr.feishu.cn/customers/laiye)、[理想汽车案例](https://okr.feishu.cn/customers/li-auto)、[绩效黑箱访谈](https://www.thepaper.cn/newsDetail_forward_16378353)
6. **校准会是权力场。** 统一分布迫使经理横向比较、为自己的人争档位；隔级上级、HR/政委和历史数据用来限制“人人优秀”与护犊子，但最终仍需要管理者承担判断责任。[清华经管案例](https://www.sem.tsinghua.edu.cn/info/1171/37305.htm)
7. **软指标会诱发向上管理。** 做事与让领导看见并不相同；汇报、占资源、抢曝光可以提高短期主观评价，却可能降低真实产出和协作信用。[36Kr“阿里味儿”访谈](https://www.36kr.com/p/3570963880115328)、[清华经管案例](https://www.sem.tsinghua.edu.cn/info/1171/37305.htm)
8. **晋升不是高绩效自动领奖。** 绩效只是门票，还要有合法空缺、晋升材料、价值观、同事反馈和跨部门评委；材料表达与实际贡献之间又会产生新的博弈。[阿里巴巴员工发展](https://www.alibabagroup.com/zh-HK/esg-employee-development)、[界面晋升答辩访谈](https://m.jiemian.com/article/7158323.html)
9. **HC 是组织资源，不是角色数量按钮。** 编制同时受人数和预算约束，团队负责人要证明投入产出，业务收缩时 HC 会冻结或被重新分配。[HC 预算产品复盘](https://www.woshipm.com/pd/6181693.html)、[腾讯降本增效报道](https://finance.sina.cn/tech/2022-04-08/detail-imcwipii3072639.d.html)
10. **PIP 与申诉必须有证据和期限。** 单纯“你是末位，所以你不胜任”无法形成公平或有趣的系统；目标是否合理、公司是否提供支持、员工是否完成改进、原评分是否有依据，才构成可复核的过程。[PIP 劳动案例](https://www.7-dimension.com/index.php?id=1182)
11. **小团队、矩阵组织与换老板会破坏简单排名。** 小 cohort 可用合并统计，矩阵岗位需要事前约定实线/虚线目标和权重；调岗或换上司后，目标与证据也应同步交接，而不是机械继承旧动作。[小团队强制分布](https://blog.ihr360.com/p/22158/)、[矩阵绩效](https://www.jiemian.com/article/716432.html)、[调岗目标错位](https://www.knx.com.cn/resource/696/)
12. **周报既是信息工具，也是可见度军备竞赛。** 过长周报和 PPT 会挤占真实产出，因此“短文档、保留证据、取消形式主义”本身可以成为制度路线，而不能只做一场写周报事件。[互联网周报访谈](https://m.pedaily.cn/news/457792)、[反内卷改革](https://www.jiemian.com/article/7591109.html)
13. **绩效、现金、职级和任命可以分离。** 公开案例存在宽带薪酬、专业/管理双通道、职级与工资逐步脱钩，以及公司、组织、个人三层奖金差异；这为 CK3 提供了“只加钱、只晋级、只扩权或三者兼得”的资源取舍。[美团职级调整](https://www.36kr.com/p/918011580970245)、[腾讯员工发展](https://static.www.tencent.com/uploads/2024/05/29/64c2c411b5694a79bbd8ef4db73d6e57.pdf)
14. **HC 还包含来源、期限、职级结构与 backfill 归属。** 增长 HC、补缺 HC、临时项目 HC 的责任不同；名额到期、关键岗位特批、年底突击招人和离职后名额是否收回，都能形成资源博弈。[HC 调整案例](https://www.jiemian.com/article/2570344.html)
15. **人才盘点的终点是继任，不是贴九宫格标签。** 关键岗位和关键人才并非同一概念，继任者还需经过代理任职等真实验证；经理雪藏高潜或不培养接班人，也应反噬自己的管理绩效。[人才盘点与配置](https://www.sinostrong.com/article/2275.html)、[继任系统](https://www.huxiu.com/article/4836377.html)
16. **申诉不仅有“是否翻案”，还有送达、独立性和反报复。** 结果未正式送达会破坏申诉时钟；原班人马审自己决定、申诉后骤降软性评分、把组织裁撤污染成个人低绩效，都是可以被制度识别的程序问题。[考核通知案例](https://chinajob.mohrss.gov.cn/h5/c/2021-04-07/298077.shtml)、[正当申诉案例](https://www.sdcourt.gov.cn/wfzy/442541/442474/40352364/index.html)
17. **自评和 360 可能只是既有判断的补充材料。** 对多家大厂研发考核的公开调研显示，上级评价仍掌握最终决定，员工甚至会认为正式流程开始前结果已大致形成；这使“预期管理、预校准、锚定和留痕”比再加一张评分表更有机制价值。[大厂研发绩效调研](https://36kr.com/p/1846659280554632)
18. **晋升是一条多道闸门的漏斗。** 达到绩效门槛后，还可能依次经过主管提名、部门预审、跨部门评审与复审；候选人不仅争最终通过，也争一张上桌的门票和有限辅导资源。[晋升六阶段](https://time.geekbang.org/column/article/313540)、[大厂晋升答辩](https://www.infoq.cn/article/k9jz9GSgBAFC7yyvKICR)
19. **技术团队必须同时计算交付速度和稳定性。** DORA 将吞吐与不稳定性并列；只奖励上线数量会诱发大批次、返工和故障，因此 CK3 中的冲刺政绩也必须有质量、返工和延迟爆雷的对账项。[DORA 度量](https://dora.dev/guides/dora-metrics/)、[价值流说明](https://dora.dev/guides/value-stream-management/)
20. **值守、维护和预防性工作最容易成为隐形劳动。** on-call、事故响应、复盘和重复运维会吞掉项目时间，成熟实践会限制 toil 比例并让值守者免背同量项目目标；这可以转成急务轮值、积弊治理和目标减免，而不是随机加班减益。[Google SRE 值守](https://sre.google/workbook/on-call/)、[消除 toil](https://sre.google/workbook/eliminating-toil/)
21. **共享平台既节约成本，也会重新分配功劳。** 腾讯公开的内部开源实践以减少重复建设、跨部门复用和长期维护为目标，但平台发起者、贡献者、维护者与使用团队对“谁创造价值”并非天然一致。[腾讯内部开源协同](https://cloud.tencent.com/developer/article/1556709)、[腾讯开源治理](https://static.www.tencent.com/uploads/2020/11/20/080fa12557087ba52b7ac4bef6504359.pdf)
22. **在线时长会被错误地代理成投入度。** 公开报道记录了准点下班、未及时回复、日报周报等与低绩效担忧相连的经历；这为“可见苦劳—真实成果—倦怠”三角提供现实原型，也要求制度允许审批加班、调休和拒绝表演性在线。[中国经济网加班调查](https://www.ce.cn/xwzx/gnsz/gdxw/202110/19/t20211019_37005938.shtml)
23. **外包和派遣会绕开正式 HC，却不会消灭管理责任。** 灵活用工可突破编制与工资总额限制，并衍生转正式编制竞争；公开招聘舞弊案例还显示，非雇员链条会反向问责直接和间接管理者。[外包用工报告](https://cos.hrtools.club/6/58667/pdf/1745663906541860bf049ccab34d3667c8eb5e7add55d.pdf)、[非雇员招聘问责](https://m.eeo.com.cn/2025/0311/715876.shtml)
24. **研发度量应回答价值流问题，不能奖励可数的忙碌。** 阿里与腾讯相关实践都强调从局部工作量转向持续、高质量、可持续地交付价值；代码量、需求数或会议数一旦直接挂绩效，就会把度量工具变成新的刷分入口。[阿里研发效能](https://developer.aliyun.com/article/689242)、[腾讯 CODING 效能洞察](https://cloud.tencent.com/document/product/1726/96969)

## 二、CK3 中的总循环

```mermaid
flowchart LR
    A[上级定组织目标] --> B[直属官员认领目标 / 讨价还价]
    B --> C[治理成果与跨部门贡献落证]
    C --> D[自评 + 背靠背 360]
    D --> E[直属上司初评]
    E --> F[校准会：强制分布 / 背 C / 护人]
    F --> G[公示与个人告身]
    G --> H[申诉 / PIP / 晋升包 / 调薪 / HC]
    H --> I[管理者自己的上轮组织绩效]
    I --> A
```

要点：皇帝不能越级改伯爵的个人分；他只能考核直属公爵的团队结果、校准质量和履责情况。HR/政委或复核席可以判定流程/证据是否成立，但改分仍回到直属考核链，避免破坏“谁管理谁负责”。

## 三、候选功能包

以下每项都必须同时有玩家决策、AI 后台决策、可见后果和实机验收；只有文案而没有状态变化的不立项。

### A. 目标、证据与评分

1. **KPI 分项证据单（P0）**
   - 决策：考核者能看见治理成果、效率、成长、协作、价值观、京察履责、奖惩和政治修正分别贡献多少。
   - 后果：高低分必须附具体事例；申诉、PIP 和晋升包复用同一份冻结证据，杜绝事件窗口读取下一年的 live 值。
   - 验收：各分项之和严格等于落盘 KPI；转封、存读档和下一轮开始后旧案卷不漂移。

2. **年度目标责任书：OKR 方向 + KPI 结果（P0）**
   - 决策：京察时为直属官员选择财政、治安、军备、发展或跨部门协作方向；官员可接受激进目标、协商普通目标或报保守目标。
   - 后果：激进目标提高 3.75 与“高潜”上限但失败风险更高；保守目标容易完成但不能只靠完成率获得头档。原生治理成果承担主要分值，目标只决定权重与证据上下文。
   - 验收：同一成果在不同目标下解释不同但有硬上限；全员报保守目标不能自动挤进 3.75。

3. **期中 Check-in 与目标重置（P1）**
   - 决策：每轮一次，管理者可辅导、加压、补资源或不干预；战争、叛乱等明确外部冲击允许一次 rebaseline。
   - 后果：提前救回风险官员，或留下“上司早已预警/从未提供支持”的 PIP 与申诉证据。
   - 验收：每人每轮至多一次；无真实危机不能洗目标，同一危机不能重复重置。

4. **自评与认知差（P1）**
   - 决策：官员先报 3.75 / 3.5 / 3.25 并提交代表成果；可诚实、邀功或故作谦逊。
   - 后果：自评不会直接定档，但巨大高估会伤价值观/可信度，低估会错失曝光，高质量证据能进入校准案卷。
   - 验收：自评与终评分开保存；同一轮只提交一次，AI 性格产生稳定而非随机乱跳的策略。

5. **岗位化记分卡（P1）**
   - 决策：地方治理、军务、财政、管理岗使用不同证据权重，但仍在直属 cohort 中横向校准。
   - 后果：避免所有人都堆同一属性；转岗可以成为救济，也会失去原岗位优势。
   - 验收：同属性文武官在对应岗位得到不同分项；换岗只影响下一轮，不重写历史。

6. **起点与难度校正（P2）**
   - 决策：接烂摊子换取更低基线，或守富庶地但承担更高目标。
   - 后果：考核改善量而非只看绝对繁荣；校正只能小幅封顶，不能成为长期失败豁免。
   - 验收：期初状态被冻结；战争结束或上司更换后不永久保留借口。

### B. 背靠背互评与校准政治

7. **背靠背 360 邀评（P0）**
   - 决策：被评人、上司和系统各可邀请少量真正有共同任务/战争/治理关系的同侪或下属；评价业绩、协作、价值观并附事例。
   - 后果：补足跨部门贡献的可见性；360 总权重封顶 10%–15%，不能单独跨越两个绩效档。
   - 验收：无协作证据者不能邀评；匿名反馈不暴露作者，但底层案卷可供复核。

8. **评价者“手松手紧”与同侪信用（P1）**
   - 决策：系统按历史均值、离散度、举荐准确率和翻案率显示“宽松/严苛/可信/惯犯”。
   - 后果：互相抬轿会逐轮贬值，恶意低分可能反噬评价者自己的价值观和管理信誉。
   - 验收：新评价者有中性先验；归一化不改变原留言，且修正值有硬上限。

9. **校准会驾驶舱（P0）**
   - 决策：按 KPI、价值观、目标、360、历史趋势和申诉风险筛选；点名抬一人时必须点名同档边界的承担者进行配额中性交换。
   - 后果：玩家真正做“为什么是他，不是别人”的人事决定；AI 经理会按数据、关系、性格和财政争档位。
   - 验收：三档总人数不变，只结算被交换者；并列、重复点击、延迟一天和旧轮 scope 均不串账。

10. **“背 C”与护人（P0，严格 361 核心戏）**
   - 决策：当所有人都达标但仍有末位名额时，管理者必须指定承担者；可以牺牲新人/边缘人、按硬证据选末位，或消耗自己威望与下轮管理 KPI 保护一人。
   - 后果：背 C 者产生怨恨、申诉和流失风险；护人会让上司认为管理者“分布失真”，但提高团队忠诚。
   - 验收：新人保护与现有首轮快照豁免不冲突；所有路线仍保持当轮配额或明确产生管理者代价。

11. **隔级校准 / HR 政委席（P1）**
   - 决策：隔级上司只审查直属管理者的分布、极端证据和流程，不直接给孙级官员打分；政委可要求补证、回避或重开校准。
   - 后果：压制护犊子和恶意打压，同时制造“业务经理 vs 政委”的权力矛盾。
   - 验收：皇帝能退回公爵榜但不能点改伯爵档位；最终结果仍由公爵重新发布。

12. **利益冲突与回避（P1）**
   - 决策：亲族、挚友、情人、仇敌或恩主关系在校准前暴露；管理者可回避、公开坚持或暗箱操作。
   - 后果：不回避可短期保人/踩人，但提高申诉翻案率和管理者自身被扣分的风险。
   - 验收：冲突关系只影响本轮一次；小 cohort 没有替代评分者时走抽象复核席而非卡死。

13. **透明 / 半透明 / 黑箱公示制度（P2）**
   - 决策：选择公开完整名次与理由、只公开档位，或只让本人看结果。
   - 后果：透明提高公平感但加剧竞争和羞辱；黑箱减少公开冲突却加剧猜忌、向上管理与申诉。
   - 验收：三种制度严格控制 GUI 字段权限，不靠文案假装隐藏。

### C. 申诉、PIP 与末位退出

14. **绩效申诉案卷（P0）**
   - 决策：被评人以“计算错误、漏记成果、利益冲突、强制背档、目标不合理”之一申诉，并提交冻结证据；可先与直属上司沟通，再请求流程复核。
   - 后果：成功则回到直属上司重校准，逐笔退回 3.25 已缴的地方国库、个人金币与贤能，并立即停止尚未结束的一年俸禄 -25%，同时修正榜单；失败会消耗关系/威望，恶意申诉伤信用。
   - 验收：退款逐项对账且不可二退；复核席不越级创建自己的考核记录。

15. **PIP 改进任务书（P0）**
   - 决策：3.25 后从财政、治安、军备、发展、协作中选择可验证里程碑；受评人可接受、协商或拒绝。
   - 后果：成功减轻低绩效连击并给下轮有限补正；失败/超时升级降岗或退出；拒绝 PIP 本身成为下一轮重大负面证据。
   - 验收：成功、失败、超时、拒绝四路只结算一次；任务必须在当事人的真实权限范围内可完成。

16. **PIP 支持预算与“只给指标不给资源”（P1）**
   - 决策：上司可给导师、临时治理资源或关注度，也可省钱硬压目标。
   - 后果：支持提高可完成性但消耗组织资源；不给支持若最终失败，会成为申诉证据并降低上司管理 KPI。
   - 验收：投入不能直接买成 3.5；同任务有无支持产生可量化、封顶的差异。

17. **末位处置阶梯（P0）**
   - 决策：首次 3.25 在沟通、PIP、调岗中选；连续低档在降岗、冻结晋升、释放 HC、辞退/剥夺任命中选。
   - 后果：激进处置快速提高“人才密度”但造成恐惧、申诉和空岗；保守处置保留经验却让上司质疑管理者。
   - 验收：所有动作服从原版合法任免/头衔规则；没有合法替补时不能脚本删除岗位或角色。

18. **个人告身与四重后果清算单（P0）**
   - 决策：不是额外按钮，而是所有后续判断的事实入口。
   - 后果：清楚显示本轮绩效、KPI、名次、上司、主要理由，以及 3.25 的地方国库 -50、个人金币 -25、贤能 -60、一年俸禄 -25% 四重后果和申诉退款/止扣状态。
   - 验收：结算时冻结，不读取一日后的 live 上司或余额；重复打开不重复执行奖惩。

### D. 晋升包、薪酬与 HC

19. **晋升资格门槛（P0）**
   - 决策：连续 3.75、价值观、无活跃 PIP、任职年限和合法空缺共同决定是否能“提包”；3.5 可积累但不能直接进入答辩。
   - 后果：高绩效终于兑现为机会，而不是自动塞头衔；低绩效冻结晋升但不永久抹杀职业生涯。
   - 验收：无空缺/无资格时不出现；转封后历史绩效仍可核验，但新上司不能伪造旧成绩。

20. **晋升包与跨部门答辩（P1）**
   - 决策：候选人选择展示真实治理成果、团队影响、方法沉淀或包装可见度；评委从其他同级管理单元抽取，恩主可 sponsor 但不能改硬证据。
   - 后果：强表达能改善边界判断，却不能让空心材料碾压持续政绩；失败可能“延期晋升”而非清空履历。
   - 验收：同口才下高低履历差异显著；同履历下包装只有限幅影响。

21. **奖金—调薪矩阵（P1）**
   - 决策：领主在有限奖金池内决定头档奖金厚度；3.75 可获一次奖金或短期晋薪，3.5 保持，3.25 继续四重处罚。
   - 后果：奖励头部会真实挤占财政；欠赏的连续 3.75 人才会请求转岗或被挖走。
   - 验收：奖金总和不超池；与品级俸禄、降岗 -50% 和 3.25 -25% 的叠加有统一上限。

22. **软 HC / 编制预算（P1）**
   - 决策：HC 不直接等于 CK3 角色数量，而是“可资助的招募、培养、晋升与补员名额”；公爵以上根据团队成果、财政和空缺向上司申请增编、保编或临时借调。
   - 后果：高绩效团队获得人才资源，低绩效团队可能冻结补员；裁掉末位可释放名额，却可能因无替补损害治理。
   - 验收：绝不阻断原版合法角色生成/头衔任命；只控制 361 提供的额外人才资源和 shortlist 加成。

23. **HC 答辩与团队投入产出（P1）**
   - 决策：管理者用团队目标完成、翻案率、人才流失和财政效率申请资源；可以夸大需求、借调别组名额或主动瘦身。
   - 后果：夸大成功会暂时拿到资源，后续未兑现则伤管理绩效；瘦身提高短期效率但增加倦怠与单点风险。
   - 验收：京察仍完全免费；HC 是年度状态，不因反复打开事件重复发放。

24. **内部活水与转岗博弈（P1）**
   - 决策：PIP 人员可申请错岗救济，连续 3.75 人员可申请更好岗位；原上司可放人、加薪挽留或卡人。
   - 后果：卡住明星会短期保产出、长期伤管理信誉并触发挖角；低绩效转岗成功后按新岗位重新建基线，但旧账不消失。
   - 验收：所有调动走原版合法岗位；旧榜是不可变快照，新榜从下一轮纳入。

25. **高绩效人才被挖与反 offer（P2）**
   - 决策：其他天朝制领主可对连续 3.75 且晋升停滞的人才发出合法邀请；原上司选择晋升提名、加薪、画饼或放人。
   - 后果：绩效体系产生跨组织人才市场；滥发 3.75 也会抬高自己的留人成本。
   - 验收：无合法岗位不能挖；转入后不继承原团队的当期配额。

### E. 向上管理、跨部门抢功与指标异化

26. **真实贡献 / 上司可见度双账（P0）**
   - 决策：官员每轮在“埋头做事、主动汇报、经营关系”间分配有限精力；上司也可主动做 skip-level 访谈降低信息差。
   - 后果：可见度只影响主观分与证据被采纳概率，不直接制造治理成果；高可见低产出短期占优，换上司或审计时容易露馅。
   - 验收：两张账分别冻结；汇报不能凭空增加原生控制、财政或任务结果。

27. **跨部门贡献账本（P1）**
   - 决策：共同参与战争支援、治理任务或联合项目时，冻结 owner、主责、协作者、救火者和 blocker；结束后各方申报贡献。
   - 后果：给背靠背 360 和晋升包提供硬证据，也为抢功争议提供同一事实底座。
   - 验收：只有真实参与者可申报；贡献总量封顶，同一成果不能在多个角色名下全额重复计分。

28. **抢功仲裁 / 甩锅复盘（P1）**
   - 决策：成功项目可独占、共享或让功；失败项目可认责、分责或甩锅。上司按贡献账本、证人、关系和口才裁定。
   - 后果：抢功成功提高可见度但伤同侪信用；错误裁决伤管理者信誉并成为申诉理由；认责可保价值观但承担短期 KPI。
   - 验收：每个成果或事故有唯一责任 ID，只结算一次；硬证据不能被口才完全覆盖。

29. **指标包装、造假与京察审计（P1）**
   - 决策：官员可追求真实改善、选择有副作用的“刷指标”，或直接虚报；管理者可深查、抽查或睁眼闭眼。
   - 后果：刷税收/治安数字带来短期 KPI 和延迟领地代价；查实虚报会追回奖励、加 PIP、降低价值观，并反噬包庇者。
   - 验收：短期得分与延迟代价各只触发一次；没有真实治理基线的指标不允许进入造假池。

30. **资源赛马与抢预算（P2）**
   - 决策：两个团队争取同一项目、HC 或奖金池；可提交真实小规模试点，也可靠 sponsor 抢先拿资源。
   - 后果：胜者获得资源和曝光，败者可能重组；如果胜者只会包装而交付失败，下一轮产生更大的管理问责。
   - 验收：资源守恒；同一 HC/预算不能同时给两个团队，失败回收有明确时间点。

31. **恩主 / Sponsor 网络（P2）**
   - 决策：高层可为晋升包、HC 或复核提供背书；官员可经营恩主，也可选择只靠硬业绩。
   - 后果：Sponsor 只提高进入讨论桌的机会，不能改原始 KPI；恩主倒台会让过度依附者失去可见度和信用。
   - 验收：关系效果有期限和上限，不形成永久世袭晋升通道。

### F. 管理者与制度反馈

32. **管理者自己的团队绩效（P0）**
   - 决策：公爵以上不仅看个人能力，还要为目标完成、按期京察、校准质量、PIP 成功、翻案率、人才留存和 HC 效率负责。
   - 后果：拒办京察的 -50 成为这套管理分的一条重大理由；护人、乱打分、不给资源和高流失会沿直属链向上反馈。
   - 验收：使用上一轮冻结团队数据，避免同轮递归；孙级官员的单项表现不能直接写进皇帝榜。

33. **管理者画像与可解释理由码（P0）**
   - 决策：数据派、护犊型、政治型、仁厚型、残酷型 AI 对校准、申诉、PIP、奖金和 HC 有不同稳定偏好。
   - 后果：同一个分数遇到不同上司会有不同处置，但个人告身能说明命中了哪类理由，而不是暗骰黑箱。
   - 验收：人格权重不能盖过硬证据上限；固定输入下结果可复现。

34. **绩效×潜力九宫格（P1）**
   - 决策：历史绩效为一轴，成长、岗位适配和能力潜力为另一轴；决定培养、导师、关键人才、调岗或淘汰建议。
   - 后果：区分“当前明星”“高潜新人”“稳定贡献者”“错岗人才”和“待退出者”，不让一次 3.75 决定一生。
   - 验收：至少四类构造人物落格正确；九宫格只消费冻结历史，不重复奖励当前属性。

35. **严格 361 / 松绑 361 / 混合门槛（P2，游戏规则）**
   - 决策：严格模式必须背 C；松绑模式保留三档但不强制 10%；混合模式仍横向排名，但绝对达标者的末位处分减轻。
   - 后果：让玩家亲自看到强制分布提升人才密度与制造内耗的两面性。
   - 验收：全员优秀、全员低劣各跑一组；三种规则结果明确不同且默认仍为严格 361。

36. **十年制度报告（P2）**
   - 决策：按领主展示档位、翻案、PIP 成功、晋升、淘汰、奖金净流、HC、人才外流、真实治理和管理者信誉。
   - 后果：玩家能判断这套制度究竟提高了治理，还是只制造更漂亮的榜和更高的流失率。
   - 验收：逐年日志与十年汇总一致；换领主不串账，非天朝角色无数据。

### G. 强制分布的配额工程

37. **跨团队配额互换（P1）**
   - 决策：同一上司治下的两个小团队可交换一个 3.75 或 3.25 名额；双方经理要拿真实贡献、团队难度或历史欠账出价，也可拒绝交易。
   - 后果：救下本组末位会消耗政治信用或下轮资源；口头让档却不兑现，会形成可追索的校准债务并伤害两位经理关系。

38. **小样本合池校准（P1）**
   - 决策：直属人数过少时，选择与同职能单位合池、按绝对门槛暂缓强排，或仍在三四个人里硬切 361。
   - 后果：合池更稳定但把本组命运交给外部评委；硬切可保自主权，却提高偶然背 C、申诉和离职风险。

39. **分母管理与名单锁定（P1）**
   - 决策：校准前决定借调者、长期缺勤者、刚转入者和将离任者是否进入 cohort；名单锁定后只能以正式理由变更。
   - 后果：把强者移出分母能保护本组头档，把弱者塞入分母能替人背 C；审计发现临时调名单会扣管理绩效并重开校准。

40. **“离职者背 C”灰色操作（P1）**
   - 决策：对已请辞、将被撤职或转出的官员，经理可按实际表现评级，或把末位名额记在即将离开的人身上。
   - 后果：现团队短期皆大欢喜，但该名额若被审计为“死人头”，管理者承担分布造假、错误 backfill 和人才判断失真。

41. **新人保护、参评与献祭三路线（P1）**
   - 决策：制度可规定首轮不入分布、入榜但不占配额，或完整参评；经理也可违法把新人当最便宜的末位。
   - 后果：保护降低新人恐惧但压缩老员工名额；完整参评提高竞争，新人被献祭则打击导师、招募口碑和经理自己的育人分。

42. **轮流背 C 的跨周期合谋（P2）**
   - 决策：团队成员可私下约定今年甲背 C、明年乙补偿；经理可默许维稳、拆穿合谋或假意承诺后毁约。
   - 后果：轮值降低短期内耗，却让绩效失去区分度；毁约会造成强烈怨恨，抽查出固定轮转模式则整组互评信用下调。

43. **校准会发言席与注意力预算（P1）**
   - 决策：经理只能为少数边界候选人做完整陈述，必须选择保明星、救末位、替隐形贡献者补证或把席位让给另一团队。
   - 后果：没被讲到的人更依赖硬证据；每次越时争辩会提高某人翻档概率，同时消耗上司耐心和经理政治资本。

44. **盲审初排、实名复议（P2）**
   - 决策：制度可先隐藏姓名、亲缘和关系只排证据，再在实名阶段处理岗位难度与组织影响；也可从头实名校准。
   - 后果：盲审压低裙带和仇怨，却可能误判不可量化的救火工作；两阶段差异过大时自动暴露潜在偏见供复核。

45. **“不得惊讶”反馈债（P1）**
   - 决策：经理发现问题时可立即留下一条辅导记录，也可拖到年终突然给低档；下属可确认、补充或拒绝承认记录。
   - 后果：没有期中反馈却年末判 3.25，会显著提高申诉成功率并扣经理管理分；滥发警告则损伤士气和反馈信用。

46. **机会分配审计（P1）**
   - 决策：校准时同时展示谁获得了富庶领地、关键项目、援军和高层曝光；经理可承认机会不均、做小幅校正或坚持只看结果。
   - 后果：长期把好项目给亲信再称其“高潜”会被识别；校正只能解释表现，不能把失败者直接送进 3.75。

47. **近因偏差与证据时间窗（P2）**
   - 决策：采用全年等权、近期加权或重大里程碑加权；受评人可用期初成果反驳“只记得最近一次事故”。
   - 后果：近期加权鼓励年底冲刺和藏雷，全年等权更稳但反应迟缓；制度切换只影响新周期，不重算旧榜。

### H. 背靠背互评的微观博弈

48. **评价者工时与邀评额度（P1）**
   - 决策：每人只能认真评价有限对象；可优先写共同项目伙伴、上级指定对象或政治盟友，也可拒绝无真实接触的邀评。
   - 后果：广撒邀请会得到更多声量却降低反馈质量；敷衍模板和超量打分使评价者信用下降，不能靠填表数量刷存在感。

49. **封存提交与截止时点（P1）**
   - 决策：互评在截止前背靠背封存，提交后不可看他人再改；迟交者只能缺席，或付出信用请求一次补交。
   - 后果：阻止看风向跟票和即时互抬；故意拖延会让自己的证据也可能无人补充，并计入协作履责。

50. **互相抬轿契约与背叛（P1）**
   - 决策：同僚可暗示互给高评；玩家可履约、给诚实反馈或抢先揭发，经理可对高度互惠的评价对抽查。
   - 后果：合谋未暴露时能推高边界判断，但相关系数异常会双双降权；背叛赢得短期合规信用，却结下私人仇怨。

51. **可推断匿名与最小样本阈值（P1）**
   - 决策：反馈不足三人时可合并摘要、延后公开或征得署名；不得用“一名匿名下属说”假装匿名。
   - 后果：保护举报者会降低细节，强行公开可提高可操作性但制造报复风险；猜出作者后报复会进入独立审计。

52. **保留评价形状，不只看均分（P1）**
   - 决策：GUI 同时显示“稳定好评”“两极分化”“只获上司好评”“只获下属好评”等结构；经理选择追问冲突还是直接取平均。
   - 后果：同样 3.5 均分可以指向可靠协作者、对上不对下或跨部门冲突者，产生不同辅导、晋升和管理风险。

53. **360 只作发展、不入奖金的制度路线（P2）**
   - 决策：可将 360 用于校准加权、只用于发展建议，或只在价值观红线时影响档位。
   - 后果：与奖金脱钩会提高坦诚度但降低填写认真度；直接挂钩更有分量，也更容易催生结盟、报复与匿名黑箱。

### I. 周报、汇报与可见度军备竞赛

54. **汇报工时挤占真实产出（P1）**
   - 决策：官员每轮在办事、写材料和经营关系间分配有限精力；经理可以要求长周报、短周报或只报异常。
   - 后果：材料越精美越容易被看见，但治理进度相应受损；长期只奖励包装会把整个团队推向低产出的汇报均衡。

55. **上司注意力席位（P1）**
   - 决策：上司每周期只能深读少数报告、接见少数人；官员可争取汇报席、把机会让给团队，或走 sponsor 插队。
   - 后果：获得席位提高证据被采纳率，不会创造硬成绩；反复占席而无交付会反噬信誉并挤压真正救火者。

56. **逐级汇报中的截功（P1）**
   - 决策：中层可原样转报下属成果、署为团队成果，或改写成自己的统筹功劳；下属可留痕、私下越级抄送或忍耐。
   - 后果：截功帮助中层向上管理，却降低团队忠诚并积累申诉证据；正确让功牺牲个人曝光，换取育人和留才分。

57. **贡献留痕与版本签名（P1）**
   - 决策：项目节点可花少量管理注意力冻结主责、协作和版本；不留痕则依赖事后口供与关系。
   - 后果：留痕降低抢功空间但增加流程负担；只有发生争议、晋升或审计时才兑现价值，不能日常直接加 KPI。

58. **越级抄送（CC）与信息政治（P1）**
   - 决策：官员可把重大成果或风险抄送隔级上司；直属经理可鼓励透明、要求先沟通或把它视为挑战权威。
   - 后果：越级能救回被压住的信息，也可能伤直属关系；隔级只获得审计线索，仍不能直接替孙级官员定档。

59. **坏消息早报、迟报与隐瞒（P1）**
   - 决策：项目出险时立即上报求援、等到有方案再报，或藏到考核后；上司决定支援、追责或奖励透明。
   - 后果：早报短期伤可见 KPI 却降低最终损失；隐瞒若侥幸解决可保分，爆雷则叠加诚信扣分和经理监督责任。

60. **材料泄露与创意窃取（P2）**
   - 决策：竞争团队得到未公开方案后，可归还、共同立项或抢先包装上报；原作者可公开争执或走证据仲裁。
   - 后果：抢跑可能拿到资源，但版本留痕会决定翻案；无留痕时人脉与口才影响裁决，推动玩家建设证据制度。

61. **短文档 / 长叙事汇报制度（P2）**
   - 决策：领主可要求一页事实卡、完整叙事材料或仅异常上报；制度决定哪些角色更易获得可见度。
   - 后果：短文档节省工时但不利于解释复杂协作，长叙事容纳背景却奖励文胆和形式主义；两者都不直接改硬成果。

### J. 矩阵汇报、换老板与重组

62. **实线与虚线目标冲突（P1）**
   - 决策：矩阵官员面对地方上司和项目上司的相反要求时，选择服从一方、请求联合裁决或两边都口头答应。
   - 后果：押对方向可获一方高评，另一方会留下协作差评；两头隐瞒一旦暴露，价值观和晋升包同时受损。

63. **周期初权重契约（P1）**
   - 决策：两位上司在开局冻结 70/30、50/50 等评分权重和交付边界；中途改权重必须有危机理由和双方确认。
   - 后果：事前约定减少年末抢人抢功；拒绝签约保留弹性，却让冲突由更高层校准并扣双方管理质量。

64. **换老板交接双签（P1）**
   - 决策：旧上司冻结已完成事项与辅导记录，新上司确认剩余目标、可重置一次优先级或拒认旧承诺。
   - 后果：完整交接保护员工免受“新官重算账”；拒签者短期获得裁量，后续申诉时承担证据不连续的责任。

65. **空降主管与旧部包（P2）**
   - 决策：新主管可沿用旧团队、带入少量亲信或全面洗牌；老成员可表忠、靠硬成果自保或申请内部流动。
   - 后果：亲信提升执行一致性却放大机会不均和裙带审计；全盘清洗会获得空岗，却损失组织记忆与团队士气。

66. **项目取消：业务失败与个人失败分离（P1）**
   - 决策：战略转向叫停项目时，校准会选择按已验证里程碑认可贡献、全部归零，或追究是否早该止损。
   - 后果：合理承认探索能鼓励挑战目标；一律归零会让所有人只做短平快项目，错误坚持则把沉没成本写进经理绩效。

67. **合并后“一岗两人”（P2）**
   - 决策：组织合并产生重复负责人时，可公开竞聘、双人过渡、按绩效留一，或把其中一人调入新赛道。
   - 后果：公开竞聘较公平但加剧短期内斗；暗定人选更快，却提高申诉、人才外流和新团队派系化。

68. **可携带履历与本地重新证明（P1）**
   - 决策：转岗者携带冻结历史档位、成果语境和争议记录；新上司选择给予保护期、立即纳入本组分布或要求试运行。
   - 后果：旧 3.75 只是可信先验，不自动占新组名额；旧 3.25 也不能永久定罪，但未完成 PIP 仍需明确承接或关闭。

### K. 结果送达、申诉正义与裁员边界

69. **正式送达与申诉时钟（P0）**
   - 决策：上司必须当面反馈并送达冻结告身；受评人可签收、注明异议签收或拒收，拒收后由见证人送达。
   - 后果：只有送达才启动申诉期限和奖惩；故意不送达不能让上司无限拖延，程序超时会自动扣其管理履责。

70. **申诉后的反报复观察期（P1）**
   - 决策：申诉后一年内，调岗、撤职、降俸和新增软性差评必须附新事实；上司可正常管理，也可冒险借题报复。
   - 后果：时间相近不自动等于报复，但缺新证据、理由突然反转会提高独立复核概率；恶意申诉者同样不能获得永久免考护盾。

71. **内部论坛长文与公开升级（P2）**
   - 决策：私下沟通和正式申诉失败后，当事人可发布实名长文、匿名爆料或保持沉默离开。
   - 后果：公开升级迅速提高隔级关注和同僚站队，也损害双方声誉；硬证据充分时推动重审，纯情绪控诉则可能反噬可信度。

72. **提前泄露绩效档位（P1）**
   - 决策：校准参与者可严守封存、私下提醒亲信准备申诉，或向团队放风试探反应。
   - 后果：被提醒者获得准备材料的先机；泄露会引发抢跑离职、互评串供和校准信任下降，查出来源则扣管理信誉。

73. **恶意泄密与善意吹哨分流（P1）**
   - 决策：收到内部材料时，复核席判断其揭示程序造假、仅为报复，还是两者兼有；举报者选择实名担责或匿名降低证明力。
   - 后果：揭出真实问题者受保护并触发专项审计；篡改、断章取义或卖给竞争团队者受罚，不能把所有泄密都包装成正义。

74. **诚实裁撤与“洗成绩裁人”（P1）**
   - 决策：财政或战略需要缩编时，领主可公开按组织原因撤岗并支付代价，或先强塞 3.25 再伪装成个人不胜任。
   - 后果：诚实裁撤花国库、伤短期士气但不污染个人履历；洗成绩更便宜，若翻案则追回处分、重创制度信任并问责两级经理。

75. **保履历自愿离开包（P2）**
   - 决策：边界末位可接受一笔由国库支付的离开俸、保留中性履历并释放 HC，或拒绝后进入正常 PIP/申诉。
   - 后果：快速降本会真花组织金币且流失经验；强迫“自愿”若有证据，会被重新认定为程序性裁撤。

76. **程序失败的多级责任（P1）**
   - 决策：翻案时区分直属经理漏证、隔级校准失察、制度设计错误和当事人虚报；可单责、分责或认定系统事故。
   - 后果：不再让一线经理或 HR 单独背锅；责任比例写入各自下一轮管理分，但孙级个体分仍由直属链重做。

77. **独立复核人轮换（P1）**
   - 决策：从无直接关系的同级管理者中抽取复核席，或让原校准席自纠；当事人各有一次有因回避权。
   - 后果：独立复核更可信但耗费管理工时，原班复核更快却降低翻案公信力；复核人也会因草率结论积累质量记录。

78. **分布公平性仪表盘（P2）**
   - 决策：按新人、转岗者、亲族/非亲族、派系、岗位和任职年限查看历年档位差异；只提示异常，不自动判歧视。
   - 后果：经理可主动修正机会分配或解释业务原因；长期异常且无事实支持，会提高审计、流失和上司扣分概率。

79. **隔级接待日（P2）**
   - 决策：高层每轮开放少量席位听取孙级官员的障碍、成果或申诉线索；下属可预约，直属经理可陪同但不能阻断。
   - 后果：降低信息截留，却会增加越级政治；接待日只产生证据和调查任务，高层不能在现场直接承诺孙级档位。

80. **公开指标缺陷单（P1）**
   - 决策：任何人可提交“指标可刷、目标冲突、数据失真”的缺陷单；指标 owner 可修复、解释接受风险或压下问题。
   - 后果：及时修复获得制度贡献，不因承认缺陷受罚；压下后爆雷则将个人刷分转为设计者和包庇者的共同责任。

81. **绩效信息层级压缩（P2）**
   - 决策：选择逐级汇总、隔级可读原始证据，或由中央复核席看完整案卷；权限只改变信息流，不改变直属评分权。
   - 后果：层级越多越容易截功和失真，中央全看则增加行政负担与黑箱恐惧；玩家需在速度、隐私和纠偏能力间取舍。

### L. 薪酬、奖金与长期激励

82. **总回报配方（P1）**
   - 决策：把待遇拆为固定品级俸、岗位津贴、绩效奖金、专项奖和递延奖；领主可偏稳定、偏绩效或偏长期。
   - 后果：所有奖励都由地方/上级国库流向个人金币，不凭空造钱；高浮动强化 361 刺激，也放大焦虑、抢功和财务波动。

83. **公司—团队—个人三层奖金系数（P1）**
   - 决策：奖金依次乘天朝总体、直属团队和个人档位系数；制度可提高团队权重鼓励协作，或提高个人权重强化竞争。
   - 后果：明星身处失败团队可能拿不到高奖，普通档身处强团队也能分享成果；调整权重改变合作均衡而不改绩效历史。

84. **递延奖金与分期归属（P2）**
   - 决策：连续 3.75 可把部分奖金立即领取，或换成未来三年分期的“长期功赏”；离任、翻案和项目反噬决定剩余归属。
   - 后果：递延减少当期国库压力并提高留任，却制造未归属金手铐；若从不兑现，组织信用和人才市场吸引力下跌。

85. **续期激励断崖（P2）**
   - 决策：旧递延奖即将归属完毕时，上司可发新一轮留才包、只给口头承诺或允许人才自由流动。
   - 后果：不续期会出现“到点即走”；滥发续期包透支未来国库，并让未获包的同档人员产生薪酬不公。

86. **奖金暂扣与追索（P1）**
   - 决策：高风险项目的奖金可全发、暂扣一部分到审计后，或在证实造假时追索；暂扣比例必须事前写进规则。
   - 后果：全发激励强但追回困难，暂扣降低造假收益却伤即时激励；临时改规则会成为成功申诉和离职理由。

87. **薪酬带宽与带内位置（P1）**
   - 决策：同一职级内按资历、市场稀缺和历史表现分布在低/中/高位；调薪可优先补低位、奖励明星或压缩倒挂。
   - 后果：高绩效但已在带顶者可能只拿奖金不再加固定俸；新招人才高于老臣会触发薪酬倒挂与留才压力。

88. **市场调薪与绩效调薪争预算（P1）**
   - 决策：有限调薪池用于给稀缺岗位普调、给 3.75 奖励，或修复明显内部不公。
   - 后果：市场调薪不应伪装成高绩效，绩效调薪也不能解决整体外部竞争力；偏一端会让另一类关键人才流失。

89. **职级、任命、权力与现金解耦（P1）**
   - 决策：高绩效者可只加俸、升专业级、获得代理权，或等待真正职务空缺；玩家不必用封地承载每次晋升。
   - 后果：缓解 CK3 合法头衔稀缺，但长期“只给级不给钱/只给钱不给权”会形成晋升空心化和离职风险。

90. **专项即时奖（P1）**
   - 决策：对救火、跨部门支持和制度建设发一次性奖，不占 3.75 配额；经理选择真奖励、只表扬或侵占团队奖金池。
   - 后果：隐形贡献终于可兑现，又不改终评名次；专项奖过多会绕开 361、掏空国库并被上司质疑分配失控。

91. **年功奖与绩效奖分账（P2）**
   - 决策：长期服务、艰苦任职和当年高绩效分别奖励，不允许用“忠诚多年”偷换本轮 3.75，也不让一次低档抹去全部年功。
   - 后果：稳定贡献者有留任价值，强制分布仍保有区分；两账同时透明会减少争议，也提高国库承诺成本。

### M. 职级、双通道与晋升校准

92. **专业 / 管理双通道（P1）**
   - 决策：高绩效人才可走专家路线继续亲自办事，或走管理路线开始为团队分布、育人和 HC 负责。
   - 后果：不再把所有明星都逼成经理；两条路线待遇可相当，但管理权、风险和考核表不同。

93. **失败经理回归专家岗（P1）**
   - 决策：个人业务强、团队管理差者可降管理权保留专业级，接受辅导后再竞聘，或硬撑管理岗。
   - 后果：回归不会等同人格羞辱和全额降薪；硬撑若继续高翻案、高流失，会升级为真正的管理 PIP。

94. **微职级与“升半级”缓冲（P2）**
   - 决策：在大任命之间设置少量专业级台阶；玩家可用微晋升留人，也可把资源集中到真正跨级候选人。
   - 后果：减少“多年零晋升”的断层，但台阶过密会制造通胀、复杂薪酬倒挂和人人等升级的行政负担。

95. **高级管理任命年度复审（P1）**
   - 决策：公爵及以上的 361 管理资格每年根据按期京察、团队结果、翻案、流失和继任重新确认、辅导或收权。
   - 后果：封建头衔不被脚本非法剥夺，但其 361 预算、复核席和人才权限可暂时收紧；管理者也成为被管理者。

96. **破格晋升包（P2）**
   - 决策：对连续超预期或关键战功者使用极少破格额度；经理需说明为何跳过年限，并点名被延后的正常候选人。
   - 后果：快速留住明星，却透支公平感和未来名额；破格者次年若表现平庸，会反噬 sponsor 与评委信用。

97. **跨团队晋升校准（P1）**
   - 决策：各经理提交候选包争夺有限晋升槽；评委比较当前级别之外的影响范围，而非简单重排当年 3.75。
   - 后果：团队内第一不必然战胜跨组织贡献者；经理可以强推亲信，但失败提包次数会影响其人才判断信誉。

### N. HC 的来源、结构与回收

98. **增长、补缺、项目三类 HC（P1）**
   - 决策：新增业务申请增长 HC，离任岗位申请 backfill，临时战役申请项目 HC；用途之间转换必须重新答辩。
   - 后果：三类名额有不同期限和验收责任，防止拿“补缺”暗中扩编；项目结束未回收会扣经理资源纪律。

99. **HC 到期、结转与年底突击招募（P1）**
   - 决策：未使用名额可到期回收、付出信用结转，或年底仓促招人保住分母。
   - 后果：突击招募能保名额却提高错配和试用失败；主动归还短期少人，换取下次申请的预算可信度。

100. **冻结期与关键岗位特批（P1）**
   - 决策：财政紧张时冻结增长 HC，只为关键岗位、承诺项目或安全底线开特批；经理可停招、换更低成本结构或向上争例外。
   - 后果：特批集中资源却制造寻租；把普通岗位包装成关键岗若未兑现，会连累后续所有 HC 申请。

101. **一个资深 / 两个普通 / 学徒梯队（P1）**
   - 决策：同一预算可买一个高阶人才、两个中阶人才，或一名正式官员带若干培养名额。
   - 后果：资深者见效快但形成单点依赖，梯队成长慢却能产出继任；HC 不再等价于“多生成一个角色”。

102. **零基编制重审（P2）**
   - 决策：每隔数年让所有团队从零说明岗位价值，而不是自动沿用去年名额；高层可全量重审或只审低效/长期空缺部分。
   - 后果：能把资源从衰退部门挪向新战略，也会制造周期性不安和汇报风暴；频繁使用降低长期建设意愿。

103. **空编占坑审计（P1）**
   - 决策：岗位长期空缺时，经理可说明候选不足、主动归还、借给别组或用虚拟候选拖延。
   - 后果：占坑保留未来选择权却让当前团队超负荷；查出虚假招聘进度会立即回收并扣 HC 信用。

104. **新人池 / 成熟人才池之争（P2）**
   - 决策：预算投向廉价可培养的新人、能马上交付的成熟人才，或内部转岗；三者使用不同 HC 与培养成本。
   - 后果：新人提高长期梯队但加重导师负担，成熟人才造成薪酬倒挂，内部转岗则把成本和名额争议转给原团队。

105. **离任后的 backfill 归属（P1）**
   - 决策：人员离开后，名额可自动回原组、由上级收回重分，或随业务责任一起转移；事前制度决定默认归属。
   - 后果：自动归还鼓励经理放人，中央回收提高结构调整能力；规则模糊会激励卡转岗和把人拖到考核后再放。

### O. 人才盘点、继任与关键人才

106. **关键岗位与关键人才分离（P1）**
   - 决策：先标出一旦空缺就会伤害治理的岗位，再判断现任是否真是不可替代人才；可保岗位不保人，也可培养一人覆盖多岗。
   - 后果：避免把上司偏爱的明星自动叫作关键人才；岗位风险进入 HC 和继任优先级，个人标签则影响留任投入。

107. **继任准备度阶梯（P1）**
   - 决策：每个关键岗位列“现在可接、两年可接、长期培养、无人可接”候选；经理分配导师、代理任务和曝光机会。
   - 后果：有名字不等于可继任；长期无人可接会扣经理育人分并提高岗位空缺时的治理冲击。

108. **代理任职试炼（P1）**
   - 决策：让候选人在原任离岗、短期战役或专项期代理管理权；可给充分授权、保留否决权或只让其背责任。
   - 后果：真实试炼更新潜力证据并可能提前暴露不适配；不给权只给责会成为候选申诉和经理育人失败的证据。

109. **高潜标签的公开层级（P2）**
   - 决策：高潜名单可只对上级可见、告知本人但不公开，或全团队透明；经理也可拒绝固定名单。
   - 后果：公开能提高被选者投入，也制造“太子党”和未入选者流失；秘密降低攀比，却方便经理暗箱雪藏或偏爱。

110. **潜力校准与绩效校准分会（P1）**
   - 决策：先按当期成果排 361，再单独讨论学习速度、岗位跨度和未来责任；不得用一句“有潜力”挤掉本轮高绩效者的奖金。
   - 后果：高潜低绩效获得培养而非直接 3.75，稳定明星获得当期兑现但未必自动晋升；两张表减少概念偷换。

111. **遗憾流失与健康流失分类（P1）**
   - 决策：人才离开时判断是应挽留的高绩效/关键人才、合理错配退出，还是被错误标记的低绩效；上司可承认误判或粉饰为“优化”。
   - 后果：遗憾流失扣经理留才和继任分，健康流失释放 HC；事后出现高成就会反向检验原评级与人才判断。

112. **留任访谈（Stay Interview）（P1）**
   - 决策：对连续 3.75、关键继任者和明显不满者，经理可询问其要钱、机会、授权、换岗还是减少内耗，并选择兑现一项或画饼。
   - 后果：兑现消耗真实资源但降低离开概率；承诺未兑现形成可见的“饼债”，比从未沟通更伤信任。

113. **关键人依赖与知识移交（P1）**
   - 决策：明星可垄断信息保持不可替代，也可培养副手、写下制度资产；经理决定奖励英雄救火还是团队可复制性。
   - 后果：单点英雄短期 KPI 高、议价力强，离开时造成严重冲击；培养副手会分走个人曝光，却提高晋升管理岗的资格。

### P. 内部流动、招聘与新人落地

114. **经理“人才输出”积分（P1）**
   - 决策：原上司放出优秀人才时，获得育人分、未来 backfill 优先或跨团队人情；也可继续卡人保当期产出。
   - 后果：把“培养的人被挖走”从纯损失变成部分荣誉；若输出后团队立刻崩溃，仍会暴露继任准备不足。

115. **匿名内部应聘（P1）**
   - 决策：员工可在初筛阶段隐藏申请，进入最终面谈才通知原上司；制度可保护隐私、要求全程透明或限制活跃 PIP 者。
   - 后果：匿名降低经理事前报复和雪藏，却增加突然空缺；最终转出仍走合法任命，不能凭申请瞬移角色或头衔。

116. **放人时限与一次交接延期（P1）**
   - 决策：内部录用后，原上司须在期限内放人，可因关键交付申请一次短延期并提交继任计划。
   - 后果：合理延期保护业务，反复拖延则扣人才输出和管理信用；新团队也要承担等待或放弃候选的选择。

117. **转岗爬坡保护期（P1）**
   - 决策：转岗者首轮按明确爬坡目标评价、部分参与分布或直接完整参评；保护只能使用一次，跨组来回不能无限刷新。
   - 后果：给错岗人才真正重启机会，同时保留旧履历；爬坡期结束仍不适配时，PIP 或再次流动理由更扎实。

118. **试用期绝对门槛，不占末位配额（P1）**
   - 决策：新人按预先写明的胜任门槛决定通过、延长辅导或退出，不拿其失败去填正式员工 10% 的 C。
   - 后果：堵住“招一批新人专门背 C”的玩法；招聘质量差会回写招聘经理和导师，而不是给老员工腾出虚假好档。

119. **招聘质量回写（P1）**
   - 决策：新人才入职若快速成功、错岗或试用失败，结果延迟写回提出 HC、选人和批准招聘的管理者。
   - 后果：低价乱招和只看关系会污染未来 HC 信用；高质量招募提高组织能力，但不能在入职当天提前算功。

120. **导师与 onboarding 绩效（P1）**
   - 决策：为新人指派导师并选择轻量答疑、结构化带教或放养；导师获得时间成本和可验证的育人目标。
   - 后果：新人爬坡速度、留存和独立交付回写导师贡献；强者拒绝带人可保个人产出，却限制其管理晋升包。

### Q. 管理者自己的绩效文化

121. **首次任经理试运行（P1）**
   - 决策：新经理先管理小团队或一个周期，接受导师和隔级复盘；可提前转回专家岗，也可申请正式管理权限。
   - 后果：把“业务好所以必会带人”变成可验证假设；试运行失败不必直接职业死亡，但不能继续无成本管大团队。

122. **管理者 4-3-3 记分卡（P1）**
   - 决策：默认以 40% 团队硬结果、30% 人才与组织、30% 价值观/管理过程评价经理；制度可小幅调权但不得只看短期结果。
   - 后果：经理压榨团队拿结果可能先赢 40 分，却在流失、继任、翻案和反馈债上失分；好人缘也不能掩盖长期不交付。

123. **下属评经理专表（P1）**
   - 决策：下属只评价目标清晰、资源支持、反馈质量、授权、公平和育人，不对经理业务 KPI 投票。
   - 后果：与普通 360 分开可减少概念污染；一致性差评触发辅导或审计，单个仇敌的报复性低分会被可信度模型限权。

124. **“先有接班人，才升经理”（P1）**
   - 决策：经理进入更高管理岗前，需交出至少一名经代理验证的继任者；无继任时可延期、临时双岗或由上级冒险放行。
   - 后果：倒逼知识移交和人才输出；硬性执行过头会奖励经理藏着不升，上级放行则要承担原团队断层风险。

125. **亲自救火与授权取舍（P1）**
   - 决策：经理遇到危机可亲自下场抢救、授权下属成长或从外部借人；个人产出和团队能力使用同一时间预算。
   - 后果：长期亲自救火能刷“英雄经理”可见度，却让下属无机会、继任永远空白；授权失败短期受损，成功则形成组织杠杆。

126. **绩效 × 价值观处置矩阵（P1）**
   - 决策：高业绩低价值观的“野狗”、低业绩高价值观的“兔子”、双高明星和双低末位采取不同留用、辅导或退出策略。
   - 后果：玩家必须决定是否容忍能打但破坏协作的人；养兔子过多拖累结果，纵容野狗则提高抢功、报复和团队流失。

127. **管理幅度与评分失真（P2）**
   - 决策：团队过大时，经理可增设合法中层/项目负责人、减少汇报频率或继续一人直管；HC 结构与考核质量互相约束。
   - 后果：直管过多节省层级却增加漏证、近因偏差和模板反馈；层级过多则产生截功、信息衰减和更多管理成本。

128. **强制分布气候指标（P2）**
   - 决策：制度报告跟踪压力、协作、主动报险、互评可信度和遗憾流失；高层可维持高压、减弱配额或只修复某一副作用。
   - 后果：361 的“人才密度”与内耗同时可见，不再只看平均 KPI；气候不会直接替个人翻档，但决定长期组织产能和招募吸引力。

### R. 项目制、目标制与系统纠偏

129. **晋升排队与职业平台期（P1）**
   - 决策：资格已满但无槽位者进入有期限的候选队列；上司可给轮岗、扩大职责、现金补偿或继续画饼。
   - 后果：队列透明减少每年重复提包，长期停滞则显著提高被挖和消极工作；插队必须使用破格名额并解释被跳过者。

130. **把低绩效“倾倒”给别组（P1）**
   - 决策：经理可诚实携带 PIP 和错岗证据转出，也可隐瞒问题把人包装成高潜；接收方可查履历、试用或拒绝。
   - 后果：真实错岗转岗可能救活人才，绩效洗白则在下一次失败时追责原经理并降低整个内部市场的信任。

131. **探索型 OKR 与承诺型 KPI 双赛道（P1）**
   - 决策：目标制定时声明是必须兑现的承诺，还是高不确定探索；探索目标按验证了什么、何时止损评价，不能临到失败才改标签。
   - 后果：允许真正挑战性目标而不逼人人报保守数；把日常职责伪装成探索会被校准席剔除并扣目标质量。

132. **及时砍项目也算功（P1）**
   - 决策：项目 owner 可在证据表明不可行时主动停止、缩小范围或继续赌；上司判断是高质量止损还是逃避承诺。
   - 后果：正确止损保护剩余国库与 HC，并计入判断力；逢难就砍会失去 sponsor，死扛则积累沉没成本和坏消息隐瞒责任。

133. **无责复盘与有责追究分轨（P1）**
   - 决策：事故后先冻结事实和系统原因，再单独判断造假、隐瞒或重大失职；可公开学习材料而不自动给所有参与者扣分。
   - 后果：认错和早报不会必然自杀式降档，故意违规仍被追责；把复盘变批斗会降低未来主动报险率。

134. **共享指标的唯一 owner 与仲裁（P1）**
   - 决策：跨团队目标事前指定唯一结果 owner、共同责任人和依赖；依赖方未交付时，可协商改基线或提交事实仲裁。
   - 后果：避免成功人人领功、失败无人负责；owner 有最终协调权也承担整合责任，协作者则凭真实交付进入贡献账本。

### S. 预校准、尾差与影子档位

135. **影子初评与预期窗口（P1）**
   - 决策：正式校准前，上司可向下属透露“当前若今天结算”的影子档位；下属选择补证、纠偏、改目标或接受预期。
   - 后果：诚实预告减少年末惊雷，但并不锁死结果；用虚假好预期维稳、最终突降档，会同时触发反馈债和申诉加权。

136. **跨经理预校准小会（P1）**
   - 决策：正式大会前，三四位经理先交换边界案例、统一证据标准，也可暗中提前分完名额。
   - 后果：只讨论异常能缩短大会，私下定局则让正式辩论沦为表演；会议纪要与最终结果差异可供审计。

137. **议程顺序与锚定效应（P2）**
   - 决策：校准按随机、先头档、先末位或先战略团队排序；主持者也可冒险把亲信放在注意力最充足的前段。
   - 后果：先讨论者更容易形成比较锚，后段受疲劳和剩余配额挤压；随机化较公平，却牺牲主持人的政治控制。

138. **人数取整与尾差归属（P1）**
   - 决策：比例算出小数名额时，采用最大余数、跨年轮换、上级合池或由本轮主持人裁定。
   - 后果：取整规则决定小团队是否必须出一个 3.25；规则必须周期初公开，不能看完名单才把尾差甩给弱势组。

139. **跨周期配额债（P2）**
   - 决策：极端优秀或极端困难团队可借用下一轮一个头档/末位名额，或坚持每年当场清零。
   - 后果：借档能避免荒唐强排，却把压力递延给未来 cohort；欠债换老板、重组或解散时由批准借档的经理承担。

140. **重组中的配额归属日（P1）**
   - 决策：官员跨组时按周期内服务天数、目标 owner 或期末组织决定由谁占配额，且在召集令时冻结。
   - 后果：防止两边都不想收末位、两边都想认头档；归属只影响分布，旧新上司仍分别提交自己观察期的证据。

141. **高层“保送 / 必杀”名单（P2）**
   - 决策：隔级上司可用有限干预额度声明一名必须讨论的保留或问责对象，直属经理可接受、公开反驳或要求书面理由。
   - 后果：高层不能直接改孙级分，但会制造强烈校准压力；若事实推翻红线，提出名单者自己的判断信誉受损。

142. **里程碑待定档（P2）**
   - 决策：证据截止日前后恰有重大交付时，可按截止日立刻定档，或保留一个短期“待定”直到结果可验证。
   - 后果：待定保护真实临门成果，却延迟奖金和配额封账；里程碑失败后不得再用过程努力兑换头档。

143. **截止后重大事故对称处理（P1）**
   - 决策：封榜后发生重大成功或事故，制度可仅记下一轮，或在奖惩尚未发放前以同一门槛重开。
   - 后果：正负事件必须对称，不能只为爆雷追责、对成功装作没看见；重开一次即重新封存，禁止反复改榜。

144. **校准异议票与少数意见（P1）**
   - 决策：每位参会经理可对最终边界案留一条实名异议，也可服从多数不留记录。
   - 后果：后续翻案时，正确异议提高判断信用并暴露谁曾预警；滥留异议逃避共同责任则降低协作评价。

145. **三档之内的影子排序（P2）**
   - 决策：管理者可在 3.5 大档内部维护发展用先后序，或禁止产生“B+ / B-”潜规则。
   - 后果：影子排序帮助分配晋升和机会，却可能让表面 60% 实际再切末位；若影响奖金必须公开，否则只能作辅导参考。

### T. 绩效反馈、谈判与承诺债

146. **直白档位 / 委婉话术制度（P1）**
   - 决策：反馈时先说最终档位与证据，或先谈发展再逐步揭示结果；经理可选择温度，但不能隐去实质奖惩。
   - 后果：直白降低误解却更伤当场关系，委婉减轻冲突却容易让“符合预期”被误读；理解偏差进入反馈质量。

147. **强制“一扬一抑”反馈模板（P2）**
   - 决策：制度可要求每份反馈至少一条认可和一条改进，也可允许全好或全坏但必须附证据。
   - 后果：模板能逼出建设性建议，也会产生虚假夸奖和鸡蛋里挑骨头；重复套话使经理反馈信用下降。

148. **先讲证据还是先报结果（P1）**
   - 决策：上司可先展示案卷让下属自行判断，或先宣布档位再解释；下属可逐项确认事实而非只争最后数字。
   - 后果：证据优先提高程序认同但耗时，结果优先更快却强化“结论早已定好”的感受；两路都不能在谈话中改原始数据。

149. **绩效结果谈判包（P2）**
   - 决策：边界员工可接受较低档，换取明确奖金补差、下轮目标保护、转岗面试或晋升保留；也可拒绝交易走正式申诉。
   - 后果：谈判能减少零和翻案，却把上司承诺变成真实债务；私下只画饼不落盘，兑现失败时比直接拒绝更伤信誉。

150. **“这次先委屈你”的补偿承诺（P1）**
   - 决策：经理让某人因配额背低档时，可承诺下轮优先机会、专项奖或 PIP 减免；当事人选择信任、要求书面或拒绝。
   - 后果：承诺不能预定下轮 3.75，只能兑现资源和机会；跨周期失约会形成强烈背叛、申诉旁证和人才流失。

151. **签收不等于认同（P1）**
   - 决策：受评人可“确认收到并同意”“确认收到但保留异议”或拒绝确认事实错误；三者分别记录。
   - 后果：避免把签收当作放弃申诉，也避免拒签让流程永久悬停；虚假声称未收到可由送达见证反驳。

152. **反馈可行动性评分（P1）**
   - 决策：下属在下一轮评价上司反馈是否具体、可控、有期限和资源；“提高格局”之类空话不能算可执行目标。
   - 后果：长期给模糊建议却持续扣分的经理会被上司问责；下属不能因不喜欢建议就抹掉其中的明确事实。

153. **反馈后行动项闭环（P1）**
   - 决策：谈话产生的辅导、资源、改进或调岗事项各有 owner 与期限；双方可完成、改期或说明取消。
   - 后果：完成事项进入下轮证据，长期无人跟进则成为经理或下属的履责扣分；不能把一次反馈无限复制成多轮功劳。

154. **录音式完整纪要 / 摘要纪要（P2）**
   - 决策：制度可保存逐项完整纪要、双方确认的短摘要，或仅存结果；信息越全，隐私和行政成本越高。
   - 后果：完整留痕利于复杂申诉，摘要更易执行；无纪要时口才和关系权重上升，但不能伪造不存在的硬证据。

155. **公开表扬与私下批评边界（P2）**
   - 决策：上司可公开头档理由、只公开团队成果，或连末位问题也公开；本人可请求对敏感反馈保密。
   - 后果：公开认可提高榜样效应，公开羞辱则增加恐惧和报复；隐藏所有理由会让抢功和黑箱猜疑抬头。

156. **团队结果说明会（P1）**
   - 决策：出榜后经理向全组说明分布原则、共性问题和下一年资源，但不泄露个人申诉材料；也可只做一对一反馈。
   - 后果：说明会提升制度可预测性，却可能引发集体质疑；拒绝解释节省时间，但团队会用流言填补信息真空。

### U. 晋升提名与部门预审

157. **自荐权与主管提名权（P1）**
   - 决策：制度可只允许主管提名、允许合资格者自荐，或自荐后必须取得一名 sponsor；主管需明确支持或反对理由。
   - 后果：自荐打破雪藏却增加陪跑材料，主管独占入口更省事但放大人才控制；自荐成功不会绕过后续评审。

158. **主管提名额度（P1）**
   - 决策：每位经理只能提交少量晋升包，可集中押一名稳妥候选、分散押多名边界人，或主动归还额度。
   - 后果：提名成为真实稀缺资源；无差别全报会稀释辅导并降低经理判断信用，归还额度则可能被其他团队拿走。

159. **雪藏明星不提名（P1）**
   - 决策：经理可因无人接替而压住合资格明星、先培养接班人后提名，或立即放其竞争更高职责。
   - 后果：雪藏保住当期产出，却累积晋升停滞和内部流动风险；长期无正当理由不提名会扣经理人才输出分。

160. **部门预审淘汰赛（P1）**
   - 决策：正式答辩前，同部门候选先按材料完整度、职级证据和战略匹配争少量出线席；经理可亲自辩护或让候选独立应战。
   - 后果：预审避免正式评委淹没在弱包中，也可能成为派系提前封杀；落选者保留资格但消耗本轮窗口。

161. **“陪跑包”与虚假竞争（P2）**
   - 决策：经理可提交明显较弱候选凑数、衬托主推者，或只提交真正愿意支持的人；陪跑者可知情接受或公开退出。
   - 后果：陪跑成功能集中票源，却浪费候选声誉和准备工时；被识别后反噬经理公平信用与主推者合法性。

162. **资历门槛例外申请（P2）**
   - 决策：未满任职年限但证据强者，可占用破格审查额度；评委先判断是否准入，再评能力，不把两步混成一次人情投票。
   - 后果：准入不等于通过；频繁为普通表现申请例外，会压低主管未来所有破格包的可信度。

163. **晋升绩效观察窗（P1）**
   - 决策：采用最近一轮、最近两轮或完整当前级别履历；遇重组、病假或长期项目时可附语境但不得挑最漂亮年份。
   - 后果：短窗响应快却受偶然性影响，长窗奖励稳定却拖累真正转变者；规则周期初冻结。

164. **跨团队成果进入晋升包（P1）**
   - 决策：转岗者可携带旧团队已验收成果，由旧 owner 共同签名；新主管选择主推、只作辅助证据或质疑贡献边界。
   - 后果：防止换组清零，也防止拿团队总成绩冒充个人影响；旧主管恶意拒签可走贡献账本复核。

165. **“先干到下一级”试岗证据（P1）**
   - 决策：候选先承担一项更大范围职责，获得代理授权、明确期限和失败退出条件；也可拒绝无权无薪的无限试岗。
   - 后果：真实试岗提高评审确定性，长期只加活不评审则形成职级债和离职风险；失败只否定该职责适配，不自动改当期绩效。

166. **候选主动撤包（P2）**
   - 决策：材料不足、评委不匹配或关键成果未验证时，候选可在预审前撤回，保存部分材料到下轮；主管也可劝其硬上。
   - 后果：撤包避免一次明显失败却失去本轮窗口；反复撤回会被视为准备度不足，不能永久占提名额度。

167. **Sponsor 的晋升信用债（P1）**
   - 决策：Sponsor 为候选作事实背书、强力担保或只提供上桌机会；支持强度与未来责任成比例。
   - 后果：被担保者晋升后持续胜任会提高 sponsor 话语权，迅速失配则使其下次背书折价；不直接追回候选已得的合法待遇。

168. **经理提名命中率（P1）**
   - 决策：系统跟踪提名通过、晋升后胜任和无故漏提三类结果；上司可辅导低命中经理或收紧其提名额度。
   - 后果：逼经理承担“推谁上桌”的判断责任，又避免只为保命而不提人；命中率需结合候选难度，不能奖励只报稳赢包。

### V. 晋升答辩与评委政治

169. **评委专业匹配（P1）**
   - 决策：按候选职能匹配熟悉领域的评委、刻意加入外行检验表达，或使用混合席位。
   - 后果：专业席能判断深度却可能有圈内关系，外行席检验业务价值但易低估技术贡献；二者权重事前公开。

170. **随机评委与熟人评委（P2）**
   - 决策：评委完全随机、由候选团队推荐部分人，或从固定跨部门池抽取；候选可经营熟人但不能指定多数席。
   - 后果：熟悉背景减少解释成本也放大人脉优势，随机更中立却增加误判；长期同一评委组合触发轮换。

171. **答辩评委利益回避（P1）**
   - 决策：项目合作者、竞争 HC 的经理、亲族和仇敌必须披露；候选与评委各有一次有因回避，由备选席补位。
   - 后果：回避提升公信力但可能换来更陌生的评委；隐瞒冲突被发现会重审整包，而非直接保送对方。

172. **一票否决 / 多数票 / 平均分（P2）**
   - 决策：高阶晋升可采用红线一票否决、简单多数或去极值平均；制度选择决定候选应争取广泛认可还是避免关键反对。
   - 后果：一票否决守住底线却易被政治阻击，平均分抗极端却掩盖致命短板；否决必须附可复核理由。

173. **盲材料审查与现场答辩（P2）**
   - 决策：先隐藏姓名审材料，再实名提问；也可完全现场或只看书面工件。
   - 后果：盲审减少关系锚定，现场能检验判断与表达，书面更照顾沉默实干者；三者结果差异进入评委质量复盘。

174. **答辩时间预算（P1）**
   - 决策：候选在有限时长内分配背景、个人动作、结果、复盘和未来范围；可少讲项目数量、深讲代表案例。
   - 后果：罗列越多越显忙碌却更难证明个人杠杆；超时会压缩提问环节，不能靠无限 PPT 淹没评委。

175. **模拟答辩与辅导资源（P1）**
   - 决策：经理把有限辅导时数给最有希望者、平均分配，或建立跨团队公共教练池；候选也可请 sponsor 私教。
   - 后果：辅导提升表达但不制造成果；只辅导亲信会形成机会不均证据，公共池更公平却泄露竞争策略。

176. **团队成绩的个人归因质询（P1）**
   - 决策：评委追问候选独有判断、资源杠杆、他人贡献和离开后的持续性；候选可诚实拆分或把团队成果全据为己有。
   - 后果：诚实让功可能减少表面规模，却提高领导力可信度；查出全盘抢功会同时伤晋升包和同侪信用。

177. **项目规模与个人杠杆分离（P1）**
   - 决策：评委区分“大项目上的小角色”和“小项目里改变打法的人”，候选选择展示资源规模或自己改变了什么。
   - 后果：搭上战略快车不再自动晋升，逆风小项目也可证明能力；仍需达到目标职级要求的影响范围。

178. **可复核工件与故事表达双证据（P1）**
   - 决策：晋升包同时提交案卷、成果物和口头叙事；制度可偏工件、偏答辩或保持双门槛。
   - 后果：工件压低吹牛空间，叙事允许解释复杂背景；只强一项的候选可延期补齐，而不是随机过关。

179. **失败答辩的具体反馈 owner（P1）**
   - 决策：每条“不通过”理由由一名评委负责写成可验证差距，主管与候选确认下一轮证据；也可记录“当前无槽位”而不伪装能力不足。
   - 后果：空洞拒绝会扣评委质量，明确差距可形成发展任务；完成任务不承诺必过，但评委下次不能无故换口径。

180. **晋升冷却与材料刷新（P1）**
   - 决策：失败后立即重试、冷却一轮，或完成指定差距即可提前重开；旧材料可复用但必须补充新影响。
   - 后果：冷却避免反复消耗评委，过长则放大平台期；换评委不等于清空上次已确认的问题和改进证据。

### W. PIP 启动、毕业与复发

181. **能力、意愿、错岗三分诊（P1）**
   - 决策：低绩效先判断是不会做、不愿做、目标失真还是岗位错配，再分别选择训练、纪律、改目标或转岗。
   - 后果：分诊错误会让 PIP 变成注定失败的处刑；正确错岗救济可保人才，但不能抹掉当期真实损失。

182. **PIP 启动证据门槛（P1）**
   - 决策：制度可规定一次严重失职、一次 3.25 加多条已反馈问题，或连续低档才启动正式 PIP；红线违规另走纪律链。
   - 后果：门槛低能快速施压却产生大量假 PIP，门槛高保护稳定性却拖延处理；强制分布名次本身不能替代证据。

183. **PIP 目标双签与拒签理由（P1）**
   - 决策：上司提出可控里程碑，当事人可签署、提出一次修改或说明目标超出权限；上司可接受调整或请求独立确认。
   - 后果：拒签不自动等于失败，恶意拖延也不能无限阻止启动；谁拒绝了何种合理条款会进入终局案卷。

184. **经理的 PIP 承载量（P1）**
   - 决策：每名经理只能同时认真辅导有限人数，可投入时间、指派导师、错峰启动或申请上级支持。
   - 后果：把半个团队都塞进 PIP 会稀释支持并扣管理质量；超量时失败责任不能全甩给被改进者。

185. **PIP 中期检查（P1）**
   - 决策：中途确认按计划、明显落后、目标已失效或上司未给资源；可继续、纠偏一次或提前结束。
   - 后果：及早纠偏降低无谓失败，频繁重写则破坏可验证性；中检证据同时约束双方的年末叙事。

186. **PIP 目标膨胀锁（P1）**
   - 决策：上司新增要求时必须替换同等工作量、延长期限或证明真正紧急；当事人可把“不断加码”提交复核。
   - 后果：堵住为逼退而移动终点；拒绝合理业务变化也会留下不适应证据，不能把目标锁变永久免疫。

187. **PIP 毕业标准（P1）**
   - 决策：按全部里程碑、关键里程碑加稳定期，或独立复核决定毕业；上司不能仅以“感觉还不放心”无限续期。
   - 后果：毕业关闭当期处分升级但不自动给 3.75；不透明的临门否决会提高翻案与经理问责。

188. **毕业后的复发观察期（P1）**
   - 决策：PIP 成功者进入一轮轻量观察，复发时区分同类问题、新问题或外部冲击；也可完全恢复普通管理。
   - 后果：同类快速复发可升级处置，新问题不得偷换成“从未改好”；观察期不能无限续命为永久污点。

189. **二次 PIP / 调岗 / 退出三岔口（P1）**
   - 决策：复发或首次失败后，上司根据支持是否充分、错岗证据和替代岗位选择再给一次、内部救济或结束任用。
   - 后果：二次机会成本更高但可能保住稀缺人才；直接退出更快，却要承担招聘、交接和空岗的真实代价。

190. **PIP 随转岗披露的最小范围（P1）**
   - 决策：向接收经理披露原目标、支持、完成度和争议，而非只贴“低绩效”标签；当事人可附自己的陈述。
   - 后果：防止绩效洗白，也防止永久污名；无关匿名反馈和旧仇怨不得随包无限传播。

191. **PIP 退出后的团队成本单（P1）**
   - 决策：人离开后冻结补缺周期、交接缺口、同事加班和招聘成本，分配给原岗位、经理或组织裁撤预算。
   - 后果：经理不能靠批量 PIP 只拿“人才密度”收益而不付替换成本；真实健康退出仍可获得长期效率改善。

### X. 值守、故障与救火绩效

192. **急务值守轮盘（P1）**
   - 决策：团队按平均轮值、能力分层、志愿换班或固定英雄值守；战争、灾害和财政爆雷进入同一急务队列。
   - 后果：平均轮值培养广度但短期响应较慢，固定英雄更稳却积累倦怠与单点依赖；漏值守有明确责任人。

193. **值守津贴 / 调休二选一（P1）**
   - 决策：额外值守由国库支付个人金币、兑换下一阶段减负，或混合补偿并设上限。
   - 后果：不给补偿会提高流失和消极响应；无限现金鼓励争抢事故，补偿上限同时限制过度值守。

194. **值守对项目目标的等量减免（P1）**
   - 决策：发生真实急务后，值守者可下调同周期普通交付、延长期限或要求临时替补；也可自愿两头全扛争头档。
   - 后果：减免让隐形劳动进入事实账，全扛成功有额外证据、失败则不能把过载全怪个人能力。

195. **假警报与告警质量（P1）**
   - 决策：值守者可每次照单响应、调整过敏阈值或要求告警 owner 治理噪声；关闭告警需承担漏报风险。
   - 后果：大量假警报消耗团队时间并扣系统 owner 管理分；误关真正危机则把短期清静变成更大事故。

196. **事故等级申报博弈（P1）**
   - 决策：owner 可按真实影响报级、压低等级保绩效，或抬高等级争取资源；复核席按损失、范围和恢复时间校正。
   - 后果：压级隐瞒会在后续扩大时加罚诚信，虚抬则浪费高层注意力；校正后的等级才进入绩效。

197. **事故指挥官与技术救火者分功（P1）**
   - 决策：冻结谁发现、谁决策、谁执行、谁协调外部资源；上司可奖励个人英雄或完整协作链。
   - 后果：指挥与解决问题都是贡献，不能让最后动手者独占全部功劳；错误指令也由有权决策者承担。

198. **“纵火者拿救火奖”识别（P1）**
   - 决策：救火功劳必须与事故根因关联；若同一人制造风险又成功修复，上司可认可响应、抵消过失或只追根因。
   - 后果：堵住先造险再当英雄的刷分法；无过失的正常变更失败也不能被一概污名为纵火。

199. **未发生事故的预防功（P2）**
   - 决策：对演练发现的隐患、被采纳的防护和后续无事故期授予延迟证据，或只奖励真实交付。
   - 后果：预防难以证明但可减少救火偏见；收益延迟且有上限，不能靠声称“我阻止了未知灾难”无限邀功。

200. **紧急处置临时授权（P1）**
   - 决策：事故指挥官可短期越过正常审批调资源、回滚政策或封停项目；事后必须复核必要性。
   - 后果：授权提高恢复速度，也可能被借事故夺权；越权但救急与越权牟利进入不同责任链。

201. **不可改写的事故时间线（P1）**
   - 决策：事故开始即冻结发现、升级、命令、行动和恢复节点；参与者可补充注释，不能删除原记录。
   - 后果：复盘不再依赖谁嗓门大，早报和迟报可核对；记录行政成本只在真实事故触发。

202. **复盘行动项 owner（P1）**
   - 决策：每项修复指定唯一负责人、支持者、期限和验收人；可按风险排序，不要求一次修完所有愿望。
   - 后果：按期关闭形成质量贡献，写完复盘不落实会扣 owner 和经理；同一修复不能重复领奖。

203. **重复事故升级到管理责任（P1）**
   - 决策：同类事故再次发生时，区分行动项未做、修复无效、资源被拒和新根因，并把责任提升到能配置资源的层级。
   - 后果：一线值守者不再永远背锅；经理若主动承担债务治理可挽回，持续拒绝则进入其上司的团队绩效。

204. **可靠性预算与停止上线（P2）**
   - 决策：事故损耗超过年度容忍度时，团队必须暂停部分新项目修稳定性，也可由高层书面接受风险继续冲刺。
   - 后果：停冲刺会损失短期 KPI 却降低未来爆雷；强行继续的收益和后续损失都归签字决策者。

### Y. 技术债、维护与隐形质量劳动

205. **重复运维（toil）比例上限（P1）**
   - 决策：团队把巡检、催办、手工对账等重复劳动冻结为工时比例；超过上限时可自动化、停接需求或申请增援。
   - 后果：继续硬扛能保短期交付，却挤掉创新并积累倦怠；降低 toil 后减少可见忙碌，但提高长期产能。

206. **积弊本金与利息账（P1）**
   - 决策：每个赶工留下的制度/技术债记录原始省时、后续维护成本和风险增长；owner 选择承认、隐瞒或提前偿还。
   - 后果：欠债让当期 KPI 更漂亮，利息在以后项目和事故中兑现；换老板、换团队都不能让已知债务凭空消失。

207. **固定还债预算（P1）**
   - 决策：每轮预留少量人力清积弊，或在业务高压期挪去冲指标；还债项目按风险下降而非新功能数量评价。
   - 后果：保留预算牺牲近期产出却降低复发，长期挪用会让经理承担债务膨胀和未来事故责任。

208. **渐进修补 / 全面重做（P2）**
   - 决策：面对高债旧系统，可逐步修补、一次性重建或保持现状直到退役；三路有不同工期、失败面和可见度。
   - 后果：重做容易成为宏大晋升项目也可能烂尾，渐进收益小却稳定；现状路线把节省资源换成持续利息。

209. **旧系统危险津贴（P1）**
   - 决策：无人愿接的积弊岗位可给专项金币、晋升证据或轮值减免，也可强派最弱势员工。
   - 后果：津贴让脏活有人做但花国库，强派省钱却提高离职和事故；危险岗位成功治理后津贴自动到期。

210. **维护 owner 轮换（P1）**
   - 决策：核心旧务由固定专家、周期轮换或主创者终身负责；轮换必须配套交接和最小培训。
   - 后果：固定 owner 效率高却形成知识垄断，轮换扩散能力但短期变慢；主创终身背锅会抑制创新与主动承担。

211. **文档与操作手册功劳（P1）**
   - 决策：官员可花时间把经验写成可由新人完成的流程，并由另一人实际演练验收；也可保持口传心授。
   - 后果：有效手册降低爬坡、值守和单点风险；只写无人使用的长文不计功，口传垄断提高个人议价却限制晋升管理岗。

212. **自动化“做完就看不见”悖论（P1）**
   - 决策：自动化项目按节省的未来工时、故障和交接难度记账，或仍按当期处理件数奖励。
   - 后果：正确计账鼓励消灭自己的重复工作；只看件数会逼人保留低效手工流程来维持可见产量。

213. **审阅与质量把关贡献（P1）**
   - 决策：把审方案、复核公文、提前拦错的时间记给审阅者，同时记录阻塞时长；审阅者可严谨、快速或滥用门禁夺权。
   - 后果：高质量把关减少返工，过度挑刺拖慢交付；只统计“亲自完成”会系统性惩罚资深守门人。

214. **覆盖率数字与真实质量（P1）**
   - 决策：团队可刷检查数量、围绕高风险场景做少而深的验证，或以事故率反推质量；三种证据联合校准。
   - 后果：数量漂亮但漏掉关键风险会在爆雷时加倍反噬，少而深需留下为何选这些场景的记录。

215. **退役旧制度也算交付（P1）**
   - 决策：owner 可关闭无人使用的流程/平台、继续维护兼容，或把少数用户迁走后退役；用户有一次申诉必要性。
   - 后果：成功退役释放长期维护 HC，粗暴关停会把成本转嫁给边缘团队；“上线新物”不再是唯一可见功劳。

216. **离岗交接完整度（P1）**
   - 决策：转岗、晋升或离任前按资产、风险、联系人和未结事项完成交接；上司可给时间、强行立即放人或暂扣部分专项奖。
   - 后果：完整交接减少后续事故并进入组织贡献；用交接无限卡人会扣人才输出，隐瞒烂账则追溯原 owner。

### Z. 中台、共享官署与内部开源

217. **共享平台强制采用 / 自愿采用（P1）**
   - 决策：高层可命令各团队使用统一制度工具、让平台凭价值争取采用，或只强制底线接口。
   - 后果：强制统一减少重复建设却可能压死本地需求，自愿采用更真实但扩散慢；采用率不能直接等同价值。

218. **内部客户满意与战略底座双评分（P1）**
   - 决策：平台团队同时接受使用者体验和高层长期能力评价；可修眼前痛点、建不可见底座或平衡两者。
   - 后果：只讨好客户会积累架构债，只做宏大底座则无人愿用；两张表共同进入校准，不由单个强势客户一票定生死。

219. **采用数量 / 使用深度 / 节省成本（P1）**
   - 决策：平台 owner 选择追求接入团队数、关键流程依赖度或真实节省；制度要求至少一个结果指标与一个反指标。
   - 后果：刷浅接入能涨数字却制造迁移负担，深度少客群可能更有价值；虚荣采用率在审计中降权。

220. **共享成本展示与内部结算（P2）**
   - 决策：平台成本可由中央全包、按使用量分摊或只展示不扣款；使用团队决定继续、降配或自建。
   - 后果：中央全包鼓励采用也掩盖浪费，分摊促节制却诱发绕平台；任何路线都保持总体国库守恒。

221. **迁移成本谁来付（P1）**
   - 决策：统一平台发起方、使用团队或上级改革预算承担迁移 HC；可按未来受益比例共同出资。
   - 后果：只让使用方付钱会遭消极抵抗，平台全付限制扩张速度；成本归属写入双方绩效，不能只奖励发布者。

222. **新旧双跑过渡期（P1）**
   - 决策：立即切换、限期双跑或按风险分批迁移；双跑期有明确结束条件和额外维护工时。
   - 后果：立即切换快但爆雷面大，长期双跑最安全却吞噬资源；无期限兼容会变成新的积弊债。

223. **重复造轮子扫描（P1）**
   - 决策：新项目立项前检索已有能力，选择复用、贡献改造或以明确差异批准自建。
   - 后果：复用节约 HC 但让功劳分散，自建更容易拿 owner 光环却承担重复成本；隐瞒已有方案会扣立项信用。

224. **重复方案合并赛（P2）**
   - 决策：两个成熟方案并存时，可按公开试点选一、吸收双方优点重构，或继续多元竞争。
   - 后果：选一释放维护成本却伤落选团队，重构昂贵但保留贡献，多元竞争促进创新也持续重复投入。

225. **“不是我造的不用”与合法分叉（P1）**
   - 决策：团队可直接采用外组方案、提出改动回馈主线，或因真实安全/性能差异建立分叉并承担维护。
   - 后果：情绪性拒用会扣协作与 HC 可信度，合法分叉成功可形成新平台；分叉者不能把主线问题全甩给原团队。

226. **内部开源贡献归因（P1）**
   - 决策：跨组成员可提交修复、文档和新能力，由维护者接受、要求修改或说明拒绝；贡献进入双方案卷。
   - 后果：被采纳者获得跨组织影响，维护者的审阅也计功；刷无用提交或无理拒绝会降低各自社区信用。

227. **创始人、贡献者与维护者分账（P1）**
   - 决策：平台成功后分别冻结最初创新、后续扩展和长期稳定贡献；晋升包选择展示哪一种而不能一人全拿。
   - 后果：解决“发布者升走、维护者背锅”；创始光环会随时间衰减，持续维护也不能抹去真正原创。

228. **中台事故的爆炸半径责任（P1）**
   - 决策：共享平台出险时，区分平台根因、使用方违规和迁移决策；中央可快速止损、允许本地降级或强撑统一。
   - 后果：平台带来的规模效益伴随规模风险；高层强推统一后不能把所有损失甩给单个使用团队。

### AA. 数据口径、实验与指标反噬

229. **指标字典与口径 owner（P1）**
   - 决策：每个 KPI 写明定义、数据源、频率、适用范围和唯一 owner；变更需说明为何旧口径失效。
   - 后果：减少同词不同数，owner 也承担口径缺陷；指标字典本身不产生成绩，只保证比较对象一致。

230. **多数据源对账（P1）**
   - 决策：国库、地方报表和项目台账给出冲突数字时，选择权威源、联合核对或暂缓结算；不得挑最有利的一份。
   - 后果：对账会延迟绩效却降低错奖错罚；明知冲突仍选漂亮数，后续审计按虚报处理。

231. **业务指标分母变更（P1）**
   - 决策：覆盖人口、辖地范围或统计对象变化时，保留旧分母、重算基线或并列展示新旧口径。
   - 后果：防止靠缩小服务对象刷增长；合理变更可解释趋势断点，但不能倒算已经发放的旧奖金。

232. **缺失数据与人工回填（P1）**
   - 决策：数据中断时使用保守估计、人工凭证或延期结算；回填者和审批者共同签名。
   - 后果：及时回填恢复决策，也创造篡改入口；事后与真实数据偏差过大时追责方法和审批，而非自动罚业务 owner。

233. **看板访问权不对称（P2）**
   - 决策：关键指标可全员可见、只给 manager，或按岗位分层；没有访问权者获得目标调整或查询渠道。
   - 后果：数据透明利于自我纠偏也方便刷数，封闭则让上司垄断叙事；不能要求员工为从未可见的异常负责。

234. **领先指标与滞后结果分账（P1）**
   - 决策：长期目标同时选择早期行为信号和最终治理结果；上司决定在结果尚未成熟时给暂定认可还是等待。
   - 后果：领先指标能提前纠偏却容易被刷，滞后结果更真实但反馈太慢；两者矛盾时进入校准说明。

235. **主指标与护栏指标（P1）**
   - 决策：追税收、发展或交付速度时，必须配一个民心、质量或协作护栏；可在危机中书面突破护栏。
   - 后果：主指标上涨而护栏崩溃不能拿完整 3.75；批准突破者享受成功也承担延迟副作用。

236. **KPI 达标悬崖（P2）**
   - 决策：目标可采用 100% 才计功的硬门槛、连续区间，或关键底线加连续奖励。
   - 后果：硬门槛刺激最后冲刺却让 99% 与 0% 同奖惩，连续区间更公平但可能缺少紧迫感；制度决定不能年末改。

237. **时间窗挑选与“截最美一段”（P1）**
   - 决策：成果按完整周期、固定同比或预先指定里程碑计算；官员可申请解释异常，但不能自由截取峰值月份。
   - 后果：挑窗刷数短期提高故事性，审计还原全周期后会扣诚信；真实季节性由固定对照修正。

238. **虚荣指标与最终价值（P1）**
   - 决策：在访问数、活动数、文件数等易涨数字之外，选择一个实际采用、节省或治理改善结果。
   - 后果：只做热闹会先获得可见度，长期没有价值转化则追回专项功劳；难量化价值仍可用经验证据而非强塞假数。

239. **失败实验的学习收益（P1）**
   - 决策：试点未达主目标时，判断是否验证了关键假设、及时停止并留下可复用结论；也可掩盖失败或硬上线。
   - 后果：高质量负结果获得有限探索功，不等于成功 KPI；无假设、无记录的失败不能包装成“宝贵经验”。

240. **实验污染与多团队抢样本（P2）**
   - 决策：多个试点同时影响同一辖地时，排队、划分样本或接受互相污染；高层分配稀缺实验窗口。
   - 后果：排队降低速度但结果可信，并行提高产量却难归因；明知污染仍宣称确定结论会伤数据信用。

241. **长尾效果归属期（P1）**
   - 决策：项目上线后保留一段归因窗口，原 owner 转岗时可与接任者按建设、运营和改进分功。
   - 后果：防止发布即升走独占多年收益，也避免接任者只吃现成果；延迟副作用同样按这一窗口追溯。

### AB. 加班、会议与在线表演

242. **在场时长 / 真实成果双账（P1）**
   - 决策：上司可明确禁止用晚归作为绩效证据、把它仅作负荷信号，或继续奖励长期在场。
   - 后果：奖励时长会迅速形成全员表演性加班，短期可见度上升、长期效率和健康下降；结果制也不能忽略真实过载。

243. **非工作时段回复规则（P1）**
   - 决策：只有值守者必须即时回应、所有人限时回应，或一般消息次日处理；发送者要标明紧急级别。
   - 后果：全员随时在线提高短期响应，却制造假紧急与倦怠；真正紧急未响应只追值守链，不污染所有人的软评分。

244. **“自愿奋斗”与隐性强制（P1）**
   - 决策：官员可自愿冲刺换明确奖励，也可拒绝未写入目标的额外工时；经理不得用“大家都自愿”掩盖统一压力。
   - 后果：真自愿成功有专项证据，拒绝者不因单纯准点离开扣分；若拒绝合理急务仍按值守规则处理。

245. **审批加班 / 影子加班（P1）**
   - 决策：额外工时需提前批准、事故后补录，或不允许记录；经理可能暗示“别申报但要做完”。
   - 后果：批准会花国库或调休额度，影子加班表面省钱却在审计时转为经理责任；员工虚报同样损害信用。

246. **加班金币 / 调休 / 目标减免（P1）**
   - 决策：真实额外劳动可在个人金币、未来休息或本轮目标下调中择一，管理者按财政和交付权衡。
   - 后果：三种补偿都消耗不同组织资源，不能重复领取；长期只许调休却不让休会形成未兑现债务。

247. **战时冲刺的起止令（P1）**
   - 决策：重大活动、战争或灾害可开启有期限冲刺，写明目标、人员和结束日；到期必须关闭或由上级续批。
   - 后果：短冲刺提高交付并积累疲劳，常态化冲刺会被识别为管理失败；事后不得把普通赶工冒充危机功劳。

248. **长期缺编反噬经理（P1）**
   - 决策：经理可用加班长期填空岗、削减任务、申请 HC 或自动化；连续超负荷会进入其资源规划分。
   - 后果：靠团队透支达标不再是纯优秀管理，拒绝所有救济后爆雷由经理承担；短期合理过渡仍允许。

249. **会议工时预算（P1）**
   - 决策：团队每周期设置会议上限，新增会议必须取消旧会、缩短时长或说明决策价值。
   - 后果：压会释放办事时间，也可能遗漏协作；无结论、无 owner 的长会消耗经理组织绩效，而非参与者个人 KPI。

250. **出席人数 / 决策贡献分离（P1）**
   - 决策：会议只邀请决策者、提供信息者和受影响代表，其余人读纪要；也可全员列席换透明。
   - 后果：少数会议效率高但要求高质量纪要，全员出席透明却昂贵；到场本身不计协作功。

251. **拒绝无效会议的政治成本（P2）**
   - 决策：官员可拒绝无议程会议、派代表或仍去刷脸；召集者可接受质疑或视为不服从。
   - 后果：合理拒绝节省时间并推动流程改进，持续缺席关键决定则承担协作责任；上司报复性低评可被纪要反证。

252. **休假与缺勤的目标归一化（P1）**
   - 决策：合法离岗按实际可工作期缩放目标、交给替补并分功，或保持原目标但提供更多资源。
   - 后果：防止把休假者天然塞入末位，也防止同一产出由本人和替补双领全功；未经批准的长期缺勤另行评价。

253. **低绩效后的躺平反应（P2）**
   - 决策：感到不公者可继续冲刺求翻身、只完成最低职责、申请转岗或公开抗议；上司可修复信任、强压或置之不理。
   - 后果：最低履责不等于违纪，但会降低成长机会；若翻案证明不公，团队士气损失回写原经理和制度气候。

### AC. 外包、派遣与借调灰区

以下外部用工均表现为项目、容量和预算账，不凭空生成角色，也不进入直属官员的 361 cohort。

254. **外包绕 HC（P1）**
   - 决策：HC 冻结时，经理可削减目标、申请特批或从采购预算买临时外部容量。
   - 后果：外包快速补人却不等于免费编制，费用、知识和质量风险都入账；长期用外包掩盖正式岗位会被零基审计。

255. **正式 HC / 外包总成本比较（P1）**
   - 决策：比较薪俸、招聘、管理、流失、供应商利润和交接成本后选择正式、外包或混合团队。
   - 后果：外包单价低不代表全周期便宜，正式人员贵却沉淀能力；只报采购价会构成 HC 答辩失真。

256. **外部团队独立绩效池（P1）**
   - 决策：供应商按交付、质量和 SLA 评价，不拿外部人员给正式官员填 3.25；可续约、整改或换商。
   - 后果：堵住“两种身份同榜、弱势者专背 C”；供应商低评影响采购与项目，不直接改某个未建模外部人的性格或金币。

257. **外包转正式的有限通道（P1）**
   - 决策：表现稳定者可争少量正式 HC，按公开门槛、直属举荐或统一考试；也可保持双轨无转正。
   - 后果：通道提高外部团队动力并带来配额政治，黑箱转正诱发依附；转正后从下一轮进入正式 cohort，不带外包名次。

258. **权限差导致的绩效校正（P1）**
   - 决策：外部人员缺少数据、决策权和核心会议时，项目评价需冻结可控范围；经理可补权限、调目标或仍强压同一结果。
   - 后果：不给工具又罚交付会扣采购经理责任；过度开放则增加治理风险，必须与项目重要度相称。

259. **供应商 SLA 与个体责任分开（P1）**
   - 决策：延期先判断合同能力、甲方需求变更、供应商管理还是具体执行失误；整改对象对应不同层级。
   - 后果：不能用“外包不行”替代事实，也不能把供应商违约算成甲方一线官员的 C；甲方 owner 仍为选择和协作负责。

260. **人力补位 / 结果承包二种合同（P2）**
   - 决策：按工时购买可调度容量，或按明确成果验收；中途改需求时分别走增时或变更价款。
   - 后果：买人力灵活但管理负担留在内部，包结果省管理却怕需求变动；合同类型决定谁为延期负责。

261. **多层转包与真实执行者披露（P1）**
   - 决策：供应商再转包必须披露层级、关键人员和差价；甲方可批准、要求直签或终止。
   - 后果：层级越多，信息与报酬衰减越大；隐瞒转包出险时，同时问责采购、供应商和知情管理者。

262. **借调人员双线评价（P1）**
   - 决策：借出经理评能力发展，借入项目 owner 评实际交付，周期初冻结权重；两边不能各把全部成果记给自己。
   - 后果：双线冲突进入联合校准，借调者不因没有本组日常产出被自动判低；名额和成本仍只记一次。

263. **借调结束的返岗权（P1）**
   - 决策：借调前写明原岗保留、同等级返岗或可转永久；结束时双方可协商续借，但本人有一次表达选择。
   - 后果：无返岗保障会降低参与跨部门急务意愿，永久抢人则需要 HC 和补缺结算；不能无限“临时”借调。

264. **供应商退出的知识移交（P1）**
   - 决策：合同尾期安排文档、影子跟岗、实操验收和遗留问题；可付尾款换完整交接，或省钱立即切断。
   - 后果：尾款与交付绑定能减少知识蒸发，粗暴退出造成后续故障和重复采购；已验收内容成为内部资产。

265. **外包招聘舞弊与管理连责（P1）**
   - 决策：采购和招聘中的回扣、泄题、亲属输送可由抽查、举报或异常价格触发审计；直接、间接经理分别举证履责。
   - 后果：查实追回国库、冻结相关权限并扣价值观；只有确有监督缺失才连责，不能因下属偶发违规机械株连。

### AD. 招聘门槛、面试官与 Offer

266. **招人门槛 / 空岗紧急度（P1）**
   - 决策：岗位急缺时坚持统一门槛、降一档快速补人，或用短期外部容量等更好候选。
   - 后果：降门槛缩短空岗却提高试用失败和导师成本，坚持门槛则让现团队继续超负荷；选择写回 HC 判断。

267. **面试官先独立投票（P1）**
   - 决策：每位面试官在集体讨论前封存“录用/保留/拒绝”和证据，之后可因新事实改票。
   - 后果：减少最高职级先发言导致的从众；无理由改票会降低面试官判断信用，候选不需要知道个别票身份。

268. **面试官手松手紧校准（P1）**
   - 决策：展示各面试官历史通过率和入职后结果，选择仅提示、有限归一或暂停明显失真的面试资格。
   - 后果：长期放水和逢人必拒都会折价，新面试官有中性先验；统计只辅助，不替代本次具体证据。

269. **面试判断的延迟回写（P1）**
   - 决策：候选入职数轮后，把其胜任、错配和流失分别写给各证据维度的面试官，而非只找最终拍板者。
   - 后果：能识人的面试官获得组织贡献，反复误判者接受训练；战略改变导致的失败不算面试官全责。

270. **误招 / 漏招成本偏好（P2）**
   - 决策：关键岗位可偏保守避免误招，增长岗位可偏开放避免漏掉潜力，普通岗位保持平衡。
   - 后果：保守提高平均质量却延长空岗，开放增加人才多样性也提高培养成本；同一门槛不再硬套所有 HC。

271. **内推奖励与利益回避（P1）**
   - 决策：内推人可提供事实并在候选通过试用后领奖，不能参与最终录用票；亲族关系必须披露。
   - 后果：奖励扩大人才来源，先付会诱发撒网，后付使内推者关心质量；隐瞒冲突会追回奖励并重审录用流程。

272. **Offer 职级特批（P1）**
   - 决策：候选超出岗位带宽时，可提高正式级别、给限期稀缺津贴或拒绝竞价；特批由跨团队席复核内部公平。
   - 后果：高定级抢到急才也增加倒挂和错误成本，津贴到期可重审；不能入职后偷偷改低已经承诺的级别。

273. **候选人归属与“抢简历”（P2）**
   - 决策：多个团队争同一候选时，按最初岗位、候选选择或组织优先级分配；招聘者可共享而非藏住简历。
   - 后果：藏候选保本组机会，却可能让公司整体错失匹配；共享成功给原发掘者部分人才贡献。

274. **反 Offer 竞价上限（P1）**
   - 决策：候选拿到外部或内部竞争条件后，团队可一次加价、改岗位/机会，或守住公平线退出竞价。
   - 后果：加价提高到岗率也制造新老倒挂，机会承诺必须可交付；反复抬价会降低候选和经理双方信用。

275. **Offer 拒绝与 HC 保留期（P1）**
   - 决策：候选拒绝后，名额可为备选保留短期、立即回收或重新开招；拒绝原因写入岗位而非怪罪所有招聘者。
   - 后果：短保留提高补位速度，长期占坑浪费 HC；多次因同一条件拒绝会强制重审薪酬或岗位设计。

276. **离职人才回聘（P1）**
   - 决策：旧员工可按冻结履历、离职原因和外部成长简化面试、完整重审或拒绝回聘。
   - 后果：回聘爬坡快且能纠正遗憾流失，也可能把旧冲突带回；旧 3.25 不自动清零，外部成果也不自动保送。

277. **PIP 退出不自动补 HC（P1）**
   - 决策：低绩效者离开后，经理需说明工作仍存在、是否可自动化/合并及替代成本，才能取回正式名额。
   - 后果：堵住“先做低人再扩编”的循环；真实关键岗位可快速 backfill，虚构工作量则名额被上级重分。

### AE. 薪酬透明、发放纪律与公平修复

278. **年度总包实得对账单（P1）**
   - 决策：年末把承诺的固定俸、岗位津贴、绩效奖、专项奖和已归属长期奖，与实际支付逐笔对账。
   - 后果：差额形成有到期日的兑现债，不能被漂亮的“总包”数字掩盖；完全兑现提高组织信用但真花国库。

279. **额外月份俸禄的契约属性（P1）**
   - 决策：周期初明确额外一月俸是固定收入、达标奖金还是领主酌情赏赐，年末不得为省钱临时改名。
   - 后果：固定项无论档位都应支付，绩效项随规则变化，酌情项虽可不给却影响组织信用；三者分开记账。

280. **年中入离职奖金折算（P1）**
   - 决策：对中途入职、转岗或离任者按服务月份、里程碑贡献或全周期门槛折算，规则在其加入 cohort 时冻结。
   - 后果：合理折算减少“熬到发奖日再走”，全有全无更能留人却制造临界离职与不公平申诉。

281. **奖金发放日与延期信用（P1）**
   - 决策：国库紧张时准时少承诺、写明期限延期，或无期限拖欠已确定奖金。
   - 后果：延期款进入国库负债并在到期时自动复核；再次逾期降低招聘、留任和经理兑现分，不能当作免费融资。

282. **调薪生效日与追溯补发（P1）**
   - 决策：调薪在出榜当日、下季度或周期起点生效；审批晚于承诺日时选择追溯补差或形成欠款。
   - 后果：流程慢不再偷偷吞掉个人收入；追溯会集中冲击国库，促使经理及时完成京察与薪酬审批。

283. **“干升职”兑现期限（P1）**
   - 决策：先升职责/职级、稍后加俸时必须写明最迟兑现轮次；候选可接受、拒绝或改走专家现金路线。
   - 后果：干升职短期省预算，逾期则形成职级债和离职风险；不能把持续承担高阶职责当作无偿忠诚测试。

284. **降级薪俸缓冲坡（P1）**
   - 决策：撤回职责后立即降俸、分两轮递减，或保留专业薪级只撤管理津贴。
   - 后果：缓冲花国库却降低羞辱和申诉，骤降便宜但可能逼走仍有专业价值者；重大舞弊不享默认缓冲。

285. **同档调薪二次校准（P1）**
   - 决策：361 定档后，另在同档内比较带内位置、稀缺性、历史欠账和留任风险；经理不能用调薪会偷偷改绩效名次。
   - 后果：同为 3.75 不必同幅上涨，也让长期低位者追赶；每项差异需理由码并守住总池。

286. **超带冻结与低带追赶（P1）**
   - 决策：高于薪酬带上限者冻结固定俸改发一次奖，低于下限者优先补齐，或允许有期限的带外例外。
   - 后果：修结构会挤占明星增量，不修则积累倒挂；带外例外到期必须重审而非永久隐身。

287. **密薪 / 带宽公开 / 匿名分布（P2）**
   - 决策：只让本人知金额、公开职级带宽和本人位置，或再公开同岗匿名分布；不得泄露申诉材料。
   - 后果：越透明越容易发现不公，也越会引发比较；全黑箱给经理议价空间，却提高猜忌、泄密和流失。

288. **新老薪酬倒挂修复（P1）**
   - 决策：高价招入新人后，可补关键老臣、压低新 offer、用限期稀缺津贴解释差额，或暂记公平债。
   - 后果：立即补齐昂贵但稳团队，放任倒挂会让稳定 3.5/3.75 人才集体打听市场；差额不直接改变绩效档位。

289. **薪酬申诉与绩效申诉分轨（P1）**
   - 决策：员工可接受档位但质疑奖金计算、带宽位置或欠款，也可两案并行；薪酬复核只改钱账和规则执行。
   - 后果：避免所有不满都变成改分战争；计算错误补发金币，不能因此凭空改成 3.75 或重排名额。

### AF. 长期激励、归属与流动性

290. **长期功赏提名池（P1）**
   - 决策：有限长期奖在连续绩效、关键岗位、潜力和留任风险间分配；3.75 只是资格，不保证人人获授。
   - 后果：集中明星提高留任杠杆却扩大阶层差，广覆盖增强共同命运但单人激励弱；提名理由进入下一轮兑现审计。

291. **定份额 / 定授予价值（P2）**
   - 决策：按固定份额、固定金币价值换算份额，或设置上下限；授予规则决定价格波动由个人还是组织承担。
   - 后果：定份额在组织上涨时奖励大、下跌时缩水，定价值会改变份额池稀释；不能事后挑对组织最省的一种。

292. **高风险期权式 / 保底份额式（P2）**
   - 决策：受奖者在高上限但可能归零的期权式功赏、归属即有价值的限制份额或较少现金间选择。
   - 后果：冒险型人才可能押注组织增长，保守者换确定性；选择不改变原绩效，也不能由经理强迫接“纸面财富”。

293. **当期奖金自愿换长期份额（P2）**
   - 决策：合资格者可拿全现金、按比例换长期功赏或全额递延，转换价格和风险在选择前公开。
   - 后果：换份额缓解当前国库并增加留任，也把未来波动转给个人；选择后只能按既定退出规则处理。

294. **授予价、当前估值与可变现值三栏（P1）**
   - 决策：界面只报历史授予额、定期重估，或同时给悲观/基准/乐观区间和当前流动性。
   - 后果：透明降低画饼能力却提高信任；长期拿历史高值当现值，兑现落差会集中触发离任和申诉。

295. **首授 Cliff 长短（P2）**
   - 决策：选择一年后开始归属、两年后加速归属或从首季小额归属；只影响新授予批次。
   - 后果：长 Cliff 金手铐强、临界裁撤争议大，短 Cliff 可信但留任力弱；与续授断崖分别结算。

296. **月度 / 季度 / 年度归属节奏（P2）**
   - 决策：Cliff 后按细粒度、季度或年度兑现；制度改革保留旧批次合同，新批次才切换。
   - 后果：年度制产生归属日离职潮，细粒度降低断崖却增加账务负担；不得临近归属日单方面改慢。

297. **服务归属与绩效归属分轨（P1）**
   - 决策：每批长期奖明确只需持续任职、需个人达档，还是服务与绩效各占一部分。
   - 后果：纯留任份额不会因一次 3.25 全没收，绩效份额则按冻结条件失效；防止模糊合同任意解释。

298. **组织门槛 × 个人门槛双闸（P1）**
   - 决策：组织未达长期目标时，全体失效、同比缩减或顺延一次；个人条件仍独立判断。
   - 后果：明星不能只靠个人分越过组织失败，也不必无条件陪葬；顺延会占未来份额池和留任承诺。

299. **Good Leaver / Bad Leaver 分类（P1）**
   - 决策：离任按组织裁撤、正常调动、退休/死亡、主动跳槽或重大舞弊分类，决定未归属与已归属权益。
   - 后果：好离任者保留合法成果，坏离任者可能失去未归属并被追索；分类引用冻结事实，不能为省钱改写履历。

300. **回购窗口与流动性队列（P1）**
   - 决策：定期开有限回购、优先离任者、按申请排队或暂时关闭；开放金额必须由国库支付。
   - 后果：关闭窗口省现钱，却让长期奖折价并伤招聘；暗箱插队会触发份额公平审计。

### AG. 业务周期、组织形态与重组折算

301. **核心业务光环折算（P1）**
   - 决策：校准时把战略顺风、资源倾斜与个人增量分开；核心团队可主张规模难度，边缘团队可主张资源劣势。
   - 后果：搭上大船不再自动 3.75，核心复杂度也不会被全抹掉；证据不足时只作小幅校正。

302. **衰退业务的逆风责任（P1）**
   - 决策：市场/领地自然衰退时，官员选择守住基本盘、主动收缩、寻找第二曲线或继续报增长神话。
   - 后果：守住跌幅可能是高质量表现，长期借逆风免责则失去资源；隐瞒衰退会把业务问题升级为诚信问题。

303. **孵化团队的限期分布保护（P1）**
   - 决策：新业务在一两轮内按学习、试点和里程碑评价，不与成熟现金牛直接比绝对产出；到期必须毕业、转向或关闭。
   - 后果：保护探索不等于永久免 C，超期仍无证据会失去 HC；过早拉齐则逼孵化团队只做保守小事。

304. **项目归属与职能归属双家长（P1）**
   - 决策：跨职能项目中，项目 owner 评交付，职能经理评专业成长和长期配置，周期初冻结权重与最终主责。
   - 后果：项目成功与专业退化可以同时成立；两位经理冲突进入联合校准，不能让员工两边背满目标。

305. **校准前重组静默期（P1）**
   - 决策：临近证据截止日禁止无危机理由的大规模转组、改汇报线和换岗位；确需重组则由上级签字承接名单。
   - 后果：堵住为配额临时挪人，又不阻止真实战略调整；违规重组会冻结旧 cohort 并扣发起者管理分。

306. **双帽临时负责人容量拆分（P1）**
   - 决策：一人同时代管两组时明确 50/50、70/30 等精力和目标，给临时津贴、削减目标或补代理副手。
   - 后果：双帽成功体现范围能力，长期两份满额任务则把失败责任转向任命者；状态到期必须正式任命或卸任。

307. **利润中心 / 成本中心记分卡（P1）**
   - 决策：直接产出国库的团队看收益与质量，共享/保障团队看节省、稳定和内部价值；可跨表比较组织贡献但不硬套同一指标。
   - 后果：避免后台团队永远输给赚钱团队，也防止成本中心只讲不可量化重要性；预算仍需答辩。

308. **管理岗与专业岗比例（P2）**
   - 决策：组织可压缩管理 HC、增加一线专家，或为过大团队补中层；每次调整同时改变审批速度和管理幅度。
   - 后果：管理层过多产生汇报税，过少造成评分失真与决策阻塞；不能只靠“扁平化”口号拿绩效。

309. **边远团队的可见度折损（P1）**
   - 决策：总部/京城外团队可定期轮值述职、由上司主动巡访，或继续依赖远程材料；出差曝光占真实管理时间。
   - 后果：补曝光降低地理偏见但花成本，长期忽视会让边远硬成果被总部关系网淹没并提高外流。

310. **并入团队的旧档映射（P1）**
   - 决策：收并外部/异制团队时，旧评级可按等值表折算、只作背景或经过一轮共同基线后启用。
   - 后果：直接等值快却可能尺度失真，完全清零伤害履历；映射只影响历史解释，不预占新组配额。

311. **战略转向不得倒改旧目标（P1）**
   - 决策：高层改变方向后，旧项目按当时已批准目标结算已完成部分，新方向从变更日立新责任书。
   - 后果：防止“昨天让你向东、今天罚你没向西”；若员工在明确信号后仍拒转，后半周期责任仍可追究。

### AH. 内部市场、离职与回流

312. **内部岗位全量挂牌（P1）**
   - 决策：空岗对所有合资格者公开、只在经理圈流转，或先内部后外招；岗位说明必须带汇报线、带宽和目标。
   - 后果：公开提高匹配并削弱私相授受，也让经理更难雪藏人；长期假挂牌会降低内部市场信用。

313. **原经理推荐信标准化（P1）**
   - 决策：转岗候选的原经理按成果、风险、PIP 和交接提供结构化事实，或拒绝推荐但必须说明可复核理由。
   - 后果：减少私下电话一句话封杀；隐瞒严重问题构成绩效洗白，夹带报复性软话则在复核时反噬。

314. **跨地域调任包（P2）**
   - 决策：远距离转岗可给一次性金币、短期津贴、家属安置或拒绝补助；本人决定是否接受。
   - 后果：调任不再是免费瞬移，补助提高关键岗位到任率；临时津贴到期后仍需靠岗位本身留人。

315. **转岗试运行与双向退出（P1）**
   - 决策：正式转任前用一段短试运行验证岗位匹配；本人、新经理或原经理可按事前条件结束试运行。
   - 后果：减少一次错误转岗毁掉两组，试运行期间成果按双线分账；失败返岗不自动等于 3.25。

316. **转岗薪酬带映射（P1）**
   - 决策：新岗位带宽更高/更低时，保留原薪、分期调整或按新岗立即重定；专业级与岗位津贴分开。
   - 后果：保薪促进流动但可能产生同岗倒挂，立即降薪会阻塞低成本岗位的合理转入；规则入场前公开。

317. **未录用转岗申请的保密（P1）**
   - 决策：初筛失败只通知本人，进入终面才告知原经理，或全程公开；泄露后针对性降评进入反报复审计。
   - 后果：保密鼓励人才探索，完全公开方便资源规划却强化卡人；最终录用仍必须走正式放人流程。

318. **转岗申请频率与占位费（P2）**
   - 决策：每人每轮有有限正式申请，可撤回但消耗一次机会；高潜可获额外探索面谈而不占正式槽。
   - 后果：防止海投拖垮面试，也不把一次失败变永久封锁；经理不能用无故拖延耗尽下属次数。

319. **原团队一次反 Offer 后必须放人（P1）**
   - 决策：收到内部录用后，原经理只能给一次真实的职责、薪酬或资源方案；本人拒绝后按时限交接。
   - 后果：给团队合理挽留机会，又防止无限加价和卡人；未兑现的反 Offer 会加重人才输出扣分。

320. **离职访谈的聚合信号（P1）**
   - 决策：离任者可选择实名、匿名或不答，反馈按经理、岗位和制度聚合，单条不能直接给在职者定罪。
   - 后果：重复出现的薪酬、报复、加班问题触发审计；经理无法只把所有离职都分类成“不适应文化”。

321. **离职人才库与回流关系（P2）**
   - 决策：将正常离任者保留为可联系校友、完全断联，或只保关键技能名单；维护关系有少量组织成本。
   - 后果：友好离任提高未来回聘、推荐和跨组织合作，恶意羞辱则把一次离职变长期声誉损失。

322. **回流人才的旧账与新证据（P1）**
   - 决策：回聘时保留旧绩效案卷、离职原因和外部成长，按完整重审或针对差距简化评估。
   - 后果：外部成长可以纠正旧判断，旧舞弊不能凭回流清零；重新入职从新周期进 cohort，不占旧团队名额。

### AI. 学习、训练与知识扩散

323. **学习预算争夺（P1）**
   - 决策：有限培养金币和时间投向低绩效补短板、高潜扩能力、经理训练或全员基础课。
   - 后果：补弱提高底线，投高潜扩大上限，投经理产生团队杠杆；培训不能直接买成绩，需后验验证。

324. **结课 / 应用 / 业务结果三阶段（P1）**
   - 决策：课程完成只记学习，随后必须在真实任务应用，再观察是否改善结果；可中止无关课程。
   - 后果：堵住刷课时和证书，应用成功才进入绩效；合理学习失败仍可提供能力诊断。

325. **证书 KPI 与能力抽测（P1）**
   - 决策：岗位可要求证书、实操抽测或二者结合；员工选择背题过证、真实练习或申请以既有成果免测。
   - 后果：只看证书会催生刷证，只有实操成本高；抽测失真会回写培训 owner 而非自动判员工 C。

326. **外部会议与行业曝光（P2）**
   - 决策：派人才参加外部交流、对外分享成果或留在内部交付；出席者需带回可复用知识而非只刷名片。
   - 后果：外部曝光提高招募和专业声誉，也可能成为跳槽跳板；带回内容被采用后才兑现组织贡献。

327. **内部授课分账（P1）**
   - 决策：资深者可开课、写案例、带实操或拒绝教学专注个人项目；听课人数与后续应用分别记录。
   - 后果：有效教学提高影响范围并支持管理/专家晋升，空洞大课只有可见度；授课工时从个人目标中折算。

328. **专业共同体贡献（P2）**
   - 决策：跨团队同职能官员可共同维护标准、案例库和评审规则；原经理选择支持、限制或索要本组回报。
   - 后果：共同体减少重复学习并提高跨组尺度一致，参与者短期少做本组项目；雪藏会伤经理人才输出。

329. **跨团队导师匹配（P1）**
   - 决策：本组缺少合适导师时，从共同体匹配外部专家，由受益团队支付时间或人情；双方可因冲突换一次。
   - 后果：打破经理对成长资源的垄断，外部导师也获育人证据；无目标的泛聊不持续计功。

330. **衰退业务再技能化（P1）**
   - 决策：业务收缩时，把人员训练到增长岗位、直接外招替代、或维持旧技能直到退出。
   - 后果：再训练慢且有失败率，却减少健康人才流失；直接外招更快但增加裁撤、招聘和公平成本。

331. **受保护的学习时间（P1）**
   - 决策：每轮保留少量学习容量、只在项目间隙学习，或危机中挪用并承诺补回。
   - 后果：持续挪用让短期 KPI 稳定、长期技能和创新管线枯竭；硬保学习也不能无视真正急务。

332. **继任演练与灾备替岗（P1）**
   - 决策：关键岗位定期让候选独立主持一次安全演练，现任只观察或保留紧急否决权。
   - 后果：暴露“名单上有人、实际接不了”的假继任；演练失败是发展证据，不等同真实事故或当期低档。

333. **高价培训服务承诺（P2）**
   - 决策：组织出资昂贵培养时，可要求合理服务期、按月递减返还，或完全无绑定；组织裁撤则免返。
   - 后果：绑定保护投资却降低参与意愿，粗暴全额追索伤人才品牌；培训收益仍需真实应用验证。

### AJ. 需求入口、交付与跨部门依赖

334. **统一需求入口与来源标签（P1）**
   - 决策：每项新差事标明来自上司、属地、事故、同僚还是官员自荐，统一排队；也可允许私聊插单。
   - 后果：统一入口使被拒需求也可追踪，私聊成功提高 sponsor 债并挤掉无关系项目；来源决定谁为价值负责。

335. **紧急插单预算（P1）**
   - 决策：每周期预留少量急件槽，超出后必须延期旧目标、加资源或由插单者书面承担取舍。
   - 后果：真正危机得到响应，滥用“紧急”会降低提出者优先级信用；未用槽在期末释放而非奖励制造事故。

336. **需求准入完成定义（P1）**
   - 决策：未说明受益人、验收、边界和依赖的需求，可退回补充、以小额探索进入，或由高层强塞正式承诺。
   - 后果：强塞后返工不能全罚执行者，反复提交空洞需求会扣 owner 的目标质量；准入不是成功保证。

337. **需求变更税（P1）**
   - 决策：冻结后改范围必须延长、删掉等量事项、增加预算或承认原需求失误；真实灾变可免一次。
   - 后果：把“领导一句话改需求”的成本写回提出者；合理变更仍能进行，但不再让执行者无条件背延期。

338. **范围—期限—质量三角签字（P1）**
   - 决策：约束冲突时明确砍范围、延期限、补 HC 或降低质量门槛，并冻结批准人。
   - 后果：取舍本身不自动扣分，假装三者全要却最终失约会同时伤预测与诚信；降质量后的事故追签字者。

339. **估算校准而非只奖准时（P1）**
   - 决策：比较承诺与完成，区分复杂度误判、故意留水、外部阻塞；奖励逐轮变准，或仍只看是否准时。
   - 后果：只奖准时会让所有人报保守目标，校准制允许真实改善计划能力；频繁无因超支仍会受罚。

340. **在制品上限（WIP）（P1）**
   - 决策：每名官员同时只承诺少量项目，可集中完成、申请临时超限或偷偷多开刷忙碌感。
   - 后果：集中减少可见项目数却更快交付，超限使所有项目延迟并把半成品带入下一轮容量。

341. **跨周期未完工债（P1）**
   - 决策：未完成事项可原样结转、拆小重估、诚实取消或伪装成“第一期完成”。
   - 后果：结转优先占下一轮容量，拆分保留已验收部分；虚假分期会产生重复计功和永不关单审计。

342. **阻塞时间归因（P1）**
   - 决策：项目暂停时记录等待谁、从何时、是否及时升级；被阻塞者可协助解阻、换方案或继续等待。
   - 后果：等待不直接等于个人低产，长期不升级则承担部分责任；制造瓶颈者进入协作 KPI。

343. **提出、执行、验收三方签收（P1）**
   - 决策：提出者确认范围，执行者交付，受益方确认可用；可有条件接收、退回或变更需求。
   - 后果：提出者事后改口需付变更税，执行者不能用“动作做完”冒充被采用价值；验收拖延也有 owner。

344. **上线 / 采用 / 价值三阶段结算（P1）**
   - 决策：项目上线先给有限交付分，经过真实采用和治理改善后再兑现剩余奖金；owner 可继续运营、修正或关停。
   - 后果：无人采用的上线项目不再永久占功，长期效果也不会全归后来运营者；三阶段共用一个项目 ID。

### AK. 绩效制度本身的运营与审计

345. **年度 / 半年度 / 季度周期（P2）**
   - 决策：选择年评配一次期中、半年双评或季度轻评；频率越高，反馈越快，行政和 AI 事件负担也越大。
   - 后果：短周期响应快却鼓励短平快并制造考核疲劳，长周期适合长期结果但纠错慢；默认仍避免事件风暴。

346. **周期外重大表现信号（P1）**
   - 决策：重大功过可立即记录为“off-cycle 信号”，只触发奖励、调查或目标调整，不当场重跑整组 361。
   - 后果：组织能及时响应又不反复开校准会；信号在正式周期消费一次，不能重复当即时奖和年末全额分。

347. **经理人工 Override 预算（P1）**
   - 决策：算法初排后，每位经理只有极少人工调整点，须点名受益者、承担者和理由；也可完全不用。
   - 后果：保留人类判断又限制任性改榜，Override 命中后续好结果会提高信用，翻案则降低下轮额度。

348. **制度例外自动到期（P1）**
   - 决策：新人保护、稀缺津贴、特殊 HC、配额豁免和临时权限均有到期日；续期必须提交新事实。
   - 后果：防止一次特批变永久特权，到期过快又会失去政策稳定；批量到期在京察案卷统一处理。

349. **抽查率与审计成本（P2）**
   - 决策：随机抽查少量、高风险定向审查或全面核验；经理可增加透明度换较低抽查。
   - 后果：抽查越强造假收益越低也越耗组织容量，过低则使包装蔓延；查无问题不是失败，能提高制度可信度。

350. **档位通胀与跨年标杆漂移（P1）**
   - 决策：比较历年 KPI、档位和后续兑现，发现“同样成果今年只算普通”；可更新标杆、保持稳定或承认战略变难。
   - 后果：控制人人越来越优秀的通胀，也防止门槛无止境抬高；变更只用于新轮，不重写旧榜。

351. **分区域制度试点（P2）**
   - 决策：在少数公爵领试行松绑分布、短文档或新奖金规则，设对照组与结束日，再决定扩张。
   - 后果：试点降低全境改革风险，也会产生暂时待遇差；必须按预注册结果判断，不能只挑成功领地宣传。

352. **制度改版的旧记录映射（P1）**
   - 决策：改变档位、职级或公式时，保留旧制原值并增加可比映射，或从新轮另起一条序列。
   - 后果：历史可解释却不假装精确等值；静默重算会污染申诉、晋升和十年报告，禁止采用。

353. **绩效行政成本进入经理报表（P1）**
   - 决策：统计填表、会议、申诉、校准和事件打断占用的总工时，高层可简化低价值环节或继续加码控制。
   - 后果：制度不再假装免费，过重会直接挤压治理成果；删流程若导致错误上升，同样在报告中可见。

354. **“公平指标”也会被刷（P2）**
   - 决策：经理可为降低翻案率压制申诉、为降低流失把人归类健康退出，或接受真实坏数据；元审计抽查原始事实。
   - 后果：任何单一管理 KPI 都不能成为新目标迷信；主动暴露问题并修复比粉饰漂亮曲线更有长期收益。

### AL. 361 的制度极限与终局

355. **高绩效目标棘轮（P1）**
   - 决策：上轮超额完成后，目标保持、限制增幅，或完全按峰值上调；经理须区分可复制能力与偶然红利。
   - 后果：重棘轮提高表面挑战，却诱发员工压产出、拒绝救火和只求刚好达标；合理加码需同步资源或权力。

356. **好消息雪藏与截止日套利（P1）**
   - 决策：官员可立即上报全部成果、只报达标部分，或把可控交付推迟到下一轮；审计按实际完成时点核对。
   - 后果：雪藏平滑两轮绩效却损失治理时机，查实后扣诚信；消除棘轮会降低藏成果收益。

357. **先锁事实、再套 361 配额（P1）**
   - 决策：校准第一阶段只判绝对表现与证据，第二阶段才执行相对分布；也可继续一次会倒推理由。
   - 后果：两阶段明确显示谁因配额降档，为申诉和管理者责任提供事实；流程更长但显著降低编理由填 C。

358. **申诉不加重原则（P1）**
   - 决策：复核只能维持或减轻当前处理；若发现独立新造假，必须另开新案而不能在原申诉中报复性加码。
   - 后果：提高正式渠道使用率，同时不给申诉者违法免疫；新案仍需完整送达与举证。

359. **翻案后的配额回流与连环送达（P1）**
   - 决策：低档翻案后使用预留名额、重审原边界人，或把缺额记成经理下轮配额债；若波及他人必须重新送达。
   - 后果：守住配额与程序，却可能引发连环申诉；暗中改另一人档位会重创制度信用。

360. **经理集体拒绝“硬背 C”（P2）**
   - 决策：当多名经理认为全员达标时，可各自硬切、联合申请例外、以管理分代价拒绝，或公开推动制度改革。
   - 后果：形成天朝范围的制度政治：强压可守住人才密度叙事却伤管理层信任，松动则需解释如何继续区分和兑现。

361. **《三六一绩效宪章》（P2，制度终局）**
   - 决策：长期运行后，最高领主从强制竞争、证据公平、长期创新和组织温度中确定优先顺序，锁定一套可再次修订的制度包。
   - 后果：宪章统一配额、申诉、奖金、HC、经理责任和透明度默认值，但没有“全是好处”的最优解；十年报告持续检验它究竟治理了天下，还是只治理了报表。

## 四、应当砍掉或延后的伪功能

- 只弹一段“晋升答辩”“周报”“复盘会”文案，但不读取证据、不改变资格、不留下后果。
- 把 OKR 完成百分比直接兑换成 3.75；这会让挑战目标必然输给保守目标。
- 让 360 成为另一套多数投票；直属上司必须承担最终责任，互评只补信息。
- 皇帝直接改孙级伯爵的个人档位；这破坏“直属管理者负责”的制度核心。
- 用 HC 硬拦原版封臣/角色生成、凭空删头衔或批量生成朝臣；只做 361 自己提供的资源层。
- 把 PIP 做成必败的辞退倒计时；没有可完成目标、支持选择和申诉证据就没有决策。
- 只用随机事件表现抢功、甩锅和造假；必须先有唯一项目/成果/责任账本。
- 同时全开季度绩效、季度 360、月度汇报和多层事件；AI 公爵会制造事件风暴，应以年度终评 + 一次期中 Check-in 为主。
- 为固定俸、专项奖、递延奖各造一种不可互通的新货币；它们应是国库与个人金币上的可解释账目，而不是 UI 数字收藏。
- 让“高潜”“关键人才”“继任者”三个标签自动互相推出；必须分别回答未来能力、留才价值和具体岗位接替准备度。
- 把 361 项全部做成独立弹窗；大部分应进入同一案卷、同一校准会、政策包或后台账本，只在真正需要抉择时打断玩家。
- 把员工压力做成一次随机减益；制度气候必须由配额、反馈、汇报工时、报复、流失和经理行为长期累积。

## 五、推荐批量施工方案

361 项是已经确认的完整设计范围，但不是 361 个彼此孤立的弹窗，也不是要求每局无条件同时触发。施工按共享数据、政策开关和同一实机夹具打包：每批内部一起实现并做静态验收，多个代码批次合并为一轮 CK3 实机；每个机制都必须存在可达的玩家或 AI 路径、真实状态变化、可见后果和验收映射。低频、长周期或互斥制度按条件启用，不能拿“本局没弹窗”冒充未实现，也不能拿一段换皮文案冒充已实现。

### 批次 A：先做“完整绩效季”（推荐下一批一起实现和验收）

`1 KPI 证据单 + 2 目标责任书 + 4 自评 + 7 背靠背 360 + 8 手松手紧 + 9 校准驾驶舱 + 10 背 C/护人 + 14 申诉案卷 + 15 PIP 任务 + 18 个人清算单 + 32 管理者团队绩效 + 33 AI 理由码 + 45 反馈债 + 49 封存提交 + 69 正式送达`

这 15 项共用同一轮冻结数据，拆开做会反复改 schema、GUI 和验收夹具。完成后，玩家会经历完整的“定目标—交证据—互评—校准—背 C—正式送达—申诉/PIP—上司因管理质量被再考核”闭环。

统一实机矩阵：

1. 任一天朝制公爵及以上玩家考核自己的直属官员；皇帝长名单和普通公爵短名单各跑一局，非独立 AI 公爵同时在后台考核直属官员。
2. 伯爵与男爵进入受评名单但永远没有考核入口。
3. 一名硬绩效高/360 低、一名硬绩效低/可见度高、一名新人、一名利益冲突者、一名拒办京察者参与同轮校准。
4. 玩家点名交换、严格背 C、护人三路分别验证配额与管理者代价。
5. 3.25 处罚、申诉翻案、PIP 成功/失败/拒绝逐项对账。
6. 公爵的完成率、翻案率和拒办记录只在下一轮写入皇帝对他的管理分一次。
7. 存读档、转封、上司死亡后旧证据、旧榜与个人告身均不漂移。

### 批次 B：再做“职业与编制兑现”

`19 晋升门槛 + 20 晋升包答辩 + 21 奖金调薪 + 22 软 HC + 23 HC 答辩 + 24 活水转岗 + 25 人才挖角 + 34 九宫格`

统一验证至少需要合法空缺、富裕/赤字两类财政、晋升成功/延期/失败、HC 增编/冻结、明星留任/流失和 PIP 转岗救济。

### 批次 C：补“绩效政治事件包”

`26 贡献/可见度双账 + 27 跨部门账本 + 28 抢功甩锅 + 29 指标造假审计 + 30 资源赛马 + 31 Sponsor`

这批必须建立在 A 的冻结证据与 B 的兑现资源上；否则抢功没有可抢的成果，Sponsor 也没有可影响的资格或名额。

### 批次 D：制度实验

`3 期中 Check-in + 5 岗位记分卡 + 6 难度校正 + 11 隔级校准 + 12 回避 + 13 透明度 + 16 PIP 支持 + 17 退出阶梯 + 35 制度规则 + 36 十年报告`

其中严格/松绑 361 和长期组织效果应在 A–C 取得实机数据后再定默认平衡。

### 批次 E：配额工程与互评博弈

`37–47 强制分布细节 + 48–53 360 微观博弈`

共用 cohort 锁定、配额债务、评价者信用和反馈时间线。重点实机用 3 人、7 人、20+ 人三种名单，验证合池、分母变动、新人保护、跨队换档、轮流背 C、封存互评与互抬检测；任何路线都不能凭空多出 3.75 或消灭应承担的 3.25。

### 批次 F：可见度、矩阵汇报与组织变动

`54–61 汇报政治 + 62–68 矩阵/换老板/重组`

共用“时间—硬成果—可见度”三账和带上下文的可携带履历。实机至少验证写长材料确实挤占产出、越级抄送只添证据不越级定档、两位上司权重守恒、换老板前后双签，以及项目取消不能自动把全组洗成低绩效。

### 批次 G：程序正义与诚实缩编

`69–81 送达、申诉、泄露、反报复、裁撤与信息权限`

共用不可变案卷、操作时间线和理由码。实机将“正常后续管理”和“申诉后报复”做成两组对照，并分别跑诚实裁撤、洗成绩裁人、拒收告身、独立复核、隔级接待；程序纠错只能要求直属链重做，不能让高层直接给孙级改分。

### 批次 H：总回报与职业兑现

`82–91 薪酬 + 92–97 晋升/双通道 + 129 晋升队列`

共用国库预算、个人金币、薪酬带和资格队列。验收必须逐项证明钱从哪一级国库扣、谁的个人金币增加、延期/追索是否守恒，以及“加钱、升级、任命、给权”四类兑现不会被脚本错误地视为同一件事。

### 批次 I：HC、继任与内部人才市场

`98–105 HC 生命周期 + 106–113 继任 + 114–120 流动/招聘 + 130 绩效洗白`

共用岗位、名额、预算、候选人与 backfill 账本。实机用一个关键空岗贯穿“申请 HC—选择人才结构—招聘/内转—试用—导师—代理任职—正式继任—原岗位补缺”，并验证经理放出人才有收益、卡人有代价、低绩效转岗不能删除旧案卷。

### 批次 J：经理 361 与学习型目标

`121–128 管理者机制 + 131–134 探索目标/止损/复盘/共享指标`

共用经理 4-3-3 记分卡和项目责任账本。实机对照“亲自救火的英雄经理”与“能产出继任者的授权经理”，以及早报止损、隐瞒死扛、无责复盘、甩锅四类路径；团队高 KPI 不应自动洗掉高流失、报复和校准造假。

### 批次 K：预校准、反馈债与晋升提名

`135–180 预评级、尾差、反馈承诺、提名与晋升评委政治`

共用暂定评级、反馈纪要、候选包和评委票四类冻结记录。静态夹具先批量生成不同经理宽严分布、双线上司分歧和晋升票型；实机只跑一次“预评级—终评答辩—提名—跨部门评审”，把评级锚定与晋升政治放进同一条职业链。

### 批次 L：PIP 与事故责任链

`181–204 PIP 程序 + on-call、事故与稳定性`

共用里程碑、支持承诺、值守轮次、事故时间线和责任归因。实机用同一组官员同时跑 PIP 成功、部分成功、支持缺位、目标偷换，以及值守救火、稳定性观察、复盘和责任洗锅；证明低绩效不等于事故背锅，救火也不自动等于高绩效。

### 批次 M：技术债、平台与内部开源

`205–228 技术债、维护预算、平台采用与贡献治理`

共用债务登记册、维护 owner、平台服务账与复用证据。实机用“继续堆新功能 / 偿债 / 建平台 / 复用他人成果”四条路线跨两个周期对照，让短期可见政绩与长期稳定成本真正冲突。

### 批次 N：数据指标、实验、工时与会议

`229–253 指标 owner、A/B 试验、数据质量、加班与会议负担`

共用指标定义版本、实验预注册、护栏、工时和会议账。实机在一次周期里制造漂亮主指标但护栏恶化、无效实验、口径漂移、表演性在线和会议过载；验证“忙”不会直接兑换成 3.75，提前暴露坏数据反而可获长期信用。

### 批次 O：外包、派遣与招聘漏斗

`254–277 非正式用工、转正、招聘、面试与 offer`

共用正式 HC、影子 HC、供应商责任、候选漏斗和入职质量回写。实机从一个关键空岗出发，比较正式招聘、内部转岗、外包绕编和延期不招；招聘者的判断要在新人后续绩效中反向结算，不能只看“招到了几个人”。

### 批次 P：薪酬透明与长期激励

`278–300 薪酬核对、倒挂、奖金发放、递延与长期激励`

共用工资带、奖金池、递延批次、追索和归属账。实机统一对账国库与个人金币，覆盖干晋升、同工不同酬、奖金延期、事故追索、归属期、离职未归属和关键人才保留；任何奖励和扣回必须守恒并可追溯到批准人。

### 批次 Q：组织变动、内部流动与学习成长

`301–333 组织健康、重组、转岗、退出、导师与学习应用`

共用组织快照、岗位履历、流动许可、交接、导师和学习成果。实机至少跨一次换老板与重组，验证旧证据不漂移、经理卡人与放人的后果、培训必须转成工作行为，以及健康退出不能洗掉历史绩效。

### 批次 R：需求治理、交付价值与制度运营

`334–354 需求准入、范围变更、交付价值、周期治理与制度审计`

共用需求版本、验收人、价值观察期、制度版本和行政成本账。实机对照“按时上线但无人使用”“延期但真实创造价值”“范围偷加”“及时止损”与“用公平指标刷公平”，让交付、价值和制度成本彼此独立可见。

### 批次 S：361 制度终局

`355–361 目标棘轮、截止日套利、事实/配额分离、翻案守恒与绩效宪章`

这是长周期制度实验而不是七个结局文案。至少跨三轮观察高绩效目标加码、藏成果、申诉翻案后的配额回流和经理集体拒绝硬背 C，最终生成《三六一绩效宪章》及十年报告；宪章只改变后续默认值，不重写旧案卷。

### 一次 361 整批实机验收 + RED 定向重跑

代码批次仍逐批跑静态校验和确定性夹具，但发布基线只启动一次 CK3：加载专用 acceptance 存档，通过外部 fixture 在同一隔离运行中执行 361 条参考路线、共享核心链与 AI 公爵后台考核，最后一次性导出日志、截图、存档和覆盖清单。只有出现明确 RED 时才另建 artifact 目录定向复跑失败场景；不得为了沿用旧文档再拆成四次昂贵启动，也不得覆盖失败 attempt。

整批运行覆盖每号 BEGIN/PASS、14 本组织账、严格分布、小 cohort、新人保护、互评、校准、告身、考核榜、申诉/PIP、免费京察、拒办后果、3.25 四重问责与非独立 AI 公爵。角色权限边界由同一候选的脚本/静态审计补足：天朝制公爵及以上可考核直属官员，伯爵和男爵只受评。

结论必须诚实区分：`361/361` 表示每号参考路线在真实引擎中执行并通过，不表示 1,083 个 A/B/C 分支都被人工点选；未实际完成的自然 300 日等待、跨三年存读档、玩家公爵/皇帝/伯爵/男爵逐角色截图矩阵继续列为边界，不能由 fixture 或代码审计冒充实测。正式发布树仍剥离全部测试入口。

## 六、当前最高优先级缺口

在批次 A 内，最先落地的底层能力不是新事件，而是“不可变绩效案卷”。当前考核榜冻结了人物引用和表头，榜行仍读取人物的当前 KPI、名次、档位和 modifier；若官员转封后被新上司再次考核，旧榜行会被新值污染。KPI 明细、自评、360、申诉、晋升包和十年报告都依赖旧轮数据，因此必须先把每轮结果改为真正的历史快照，再扩展上层玩法。

其后依赖顺序是：

1. **唯一周期 / 项目 / 证据 ID**：让抢功、互评、申诉、奖金追索都引用同一事实，杜绝重复结算。
2. **名单与规则冻结**：锁 cohort、配额、目标、矩阵权重、薪酬规则和申诉时钟，禁止年末临时改口径。
3. **经理上一轮组织快照**：玩家或 AI 公爵本轮评下属，下一轮才由其上司考核管理质量，避免同轮递归。
4. **资源守恒账本**：奖金、俸禄处罚、退款、HC、晋升槽都能说明来源、去向与是否已结算。
5. **按风险统一实机夹具**：先测公爵短名单、皇帝长名单、小 cohort、换老板和转岗，再扩展事件文案与长期平衡。

## 七、完整交付与发布计划

本轮不是只交一份创意清单。361 项的交付状态按 `设计完成 → 静态可达 → fixture GREEN → CK3 实机 GREEN → 发布可玩` 五级记录；共享底座或代表性事件通过，不能自动把依赖它的其余编号标成完成。每个编号必须在机器可读清单中映射到实现入口、触发条件、状态变化、玩家可见反馈、AI 路径、静态断言和同批逻辑覆盖组；四个逻辑组在同一次 CK3 启动内连续执行，不代表四次启动。

施工顺序：

1. 冻结 361 条设计与编号，做语义排重并建立机器可读 manifest。
2. 审计前任代码，先修影响真实游玩的语法、作用域、AI 边界、快照和资源守恒故障。
3. 建立不可变案卷、唯一 ID、政策配置、通用卡片/选择、AI 决策、资源账本和覆盖遥测，再按 A–S 批量接入 361 条。
4. 每完成多个代码批次后集中启动 CK3，在同一次隔离运行中批量验收 361 条参考路线与共享核心链；只有出现明确 RED 时才做定向复跑。保留失败 attempt，不用静态 GREEN 冒充实机 GREEN，也不把参考路线覆盖冒充 1083 个 A/B/C 分支逐一人工点选。
5. 完成简体中文和英文文案后，按发布国际化流程补齐其余七种语言并做占位符、术语、BOM 和游戏内抽检。
6. 制作并核对 `thumbnail.png`、README、Steam BBCode、功能矩阵、已知限制、实机截图和六至八张工坊媒体图；正式上传只使用 release staging。
7. 为本 mod 创建一个全新的隐藏 Steam 创意工坊物品，严禁复用仓库中其他 mod 的三个既有物品 ID；记录上传时间、新物品 ID、staging manifest 和页面核验截图，完成新鲜缓存复验后再公开。上传后重建无 `remote_file_id` 的干净 staging。
8. 录制不超过 20 分钟的宣传片：中文为主叙事，简体中文 / 英文双语字幕，`zh-CN-XiaoxiaoNeural` 配音；切掉 CK3 启动 loading，直接从“欢迎参加今年京察，你的 C 已经在路上了”进入机制演示。内容依次展示核心循环、强制分布与背 C、互评和抢功、申诉/PIP、薪酬与 HC、经理也被考核、AI 天朝领主后台运行、制度终局与诚实边界。
