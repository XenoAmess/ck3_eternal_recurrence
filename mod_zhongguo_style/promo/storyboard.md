## 节奏与音效

- 开场不铺陈世界观，三十秒内交代“公爵也要上班”和 mod 名称。
- 数字结算镜头不快切：国库、金币、俸禄至少各留 2 秒，保证观众能自己对账。
- 校准、互评、抢功三段可以用轻微“会议室”节奏音；3.25 落档只用一次短促提示，避免综艺音效轰炸。
- 京察拒办、PIP 启动、申诉改判各保留原版/Mod 游戏音效；旁白在关键 UI 出现前后留约 0.3 秒呼吸。
- 361 政策卡只快切机制差异，不逐项读完；每张至少能看见标题和 A/B/C 选择中的一个真实代价。

## 必须拍到的完整因果

宣传片可以剪辑，但下面三条必须各自来自同一 acceptance run，不能拿不同存档拼成一个假闭环：

1. `京察到期 → 拒办 → 直属上司关系下降 → 下一轮考核消费该重大理由`。
2. `3.25 → 国库/金币/俸禄精确扣减 → 申诉改判 → 榜单、连续次数与同笔金额修正`。
3. `目标/证据 → 背靠背互评 → 校准 → 公示榜单 → 本人告身 → PIP/晋升后续`。

最终证据卡必须诚实区分：静态实现、夹具实机、正常实机与完整同轮闭环。字幕和旁白不使用“全部 361 均已实机逐项展示”
这类成片无法证明的表述；361 项批量 acceptance 由独立报告承担，视频只展示核心机制和代表性卡片。
