# 361 宣传片实机素材清单

当前 `promo-manifest.json` 有 14 个待实录章节。所有原始录像、失败 take、选择版、音频和 QA 抽帧都保留；不覆盖、不删除。

## 目录与命名

每次录像新建独立 run：

```text
artifacts/zg361/promo/captures/<YYYYMMDD-HHMMSS>-<run-name>/
├─ raw/                 # OBS/录屏器原始长录像，绝不裁切覆盖
├─ selects/             # 从 raw 派生的剪辑选择版
├─ stills/              # PNG 无损关键帧
├─ evidence/            # acceptance 报告、debug.log 摘录、sidecar、哈希表
├─ notes/               # 口误、重录点、时间码和剪辑意见
└─ qa/                  # 合成后抽帧，不覆盖旧目录
```

推荐文件名：`<capture-id>__<take-id>__raw.mkv`、`<capture-id>__<take-id>__select.mp4`。原始素材优先 MKV，
录制结束后再 remux；不直接把唯一原件录成容易因中断损坏的 MP4。

每段 `notes/<capture-id>.json` 至少记录：CK3 版本、mod commit、acceptance run id、游戏内日期、角色 id、
原始文件 SHA-256、可用起止时间码、是否含 loading、是否同轮证据、已知视觉瑕疵。

## 录制前检查

- 工坊缓存已经从当前仓库同步，mod commit 与 runner 报告一致。
- 游戏分辨率、UI 缩放和语言固定；鼠标不遮住核心数字。
- 关闭右下角系统通知；禁止点击通知正文。
- OBS/录屏器有音轨但不录旁白，后期统一用 Xiaoxiao；保留 CK3 游戏音效。
- 录制热键不会与 CK3 快捷键冲突。
- 开始录屏后先留 2 秒静止，再进行动作；结束后再留 2 秒，方便剪切。
- 如果录像包含启动或存档 loading，只能留在 `raw/`；`selects/` 必须从玩法已可见处开始。

## 镜头入 manifest 的最低条件

把占位章节换成 `video_clip` 前，逐项确认：

1. 原始文件、select、evidence 与 notes 都存在，SHA-256 已记录。
2. `capture.exclude_ck3_loading = true`，并人工看过实际起始时间码。
3. `source` 指向 select，不指向可能继续修改的临时文件。
4. `start_seconds/end_seconds` 落在 source 时长内；构建器会用 ffprobe 再检查。
5. 旁白声称的数值、人物和后果在画面或绑定证据中真实存在。
6. 需要同轮因果的镜头没有跨 run 偷拼；失败 attempt 继续保存在原 run。

## 正式成片仍需人工抽检

自动门禁只能验证媒体和布局合同。最终至少观看完整成片一次，并抽查：开场 30 秒、强制分布边界、京察拒办理由、
考核榜个人告身、3.25 三重扣款、申诉退款、PIP/末位、晋升/HC、361 驾驶舱、结尾证据卡。确认中文笑点没有压过
关键 UI，英文字幕不是机械漏译，任何占位水印均已消失，且第一帧不是 CK3 loading。
