# 成长 + 100% 高分模型 v1

本文件是策略层的第一版假设，不替代项目权威实现。计分细节以
[docs/scoring-rules.md](../../../docs/scoring-rules.md) 为准；契约以
[docs/contracts-and-progression.md](../../../docs/contracts-and-progression.md) 为准；祝福/诅咒以
[docs/blessing-curse-pools.md](../../../docs/blessing-curse-pools.md) 为准。

## 规则解释

- `xar_inherit_100`：把历史余烬纪录对应的完整预算带进开局当铺，不是把上局分数加进本局。
- `xar_score_growth` 的赛道小计为 `S = max(0, 死亡绝对小计 − 基线)`；最终总分还要乘以
  `max(0, 1 − 0.01 × 拒绝次数)`，不能把 `S` 直接称为最终分。
- 基线只采集一次，时点是当铺结束且首轮垂青会话结束之后。它是当时的**完整绝对小计**，包含开局已有的六维、资源、
  死时计分口径下的头衔与领地规模、已有后代，以及当铺结果。未花预算会先转成金币；若首轮接受祝福，基线也包含该祝福和
  随后的已选诅咒（或封印）造成的状态；若首轮拒绝，则在没有祝福/诅咒的状态下采集并把拒绝次数记为 1。
- 因而开局直接增加计分项通常会随基线一起抬高；寿命、健康、生育、收入和扩张能力的主要价值是放大基线采集后的增长。
  “首轮选择可通过压低基线、日后恢复来获利”只是待实机检验的策略假设，必须同时计入生存和发展损失。
- 当前统治者死亡即结束一个 episode；不能把继承人的继续游戏计入同一局。

## 可优化项

| 项目 | 计分关系 | 策略含义 |
|---|---:|---|
| 六项能力 | 每点 1 | 直接增长稳定，但开局直接购买会被基线扣除 |
| 契约 | 每点 10，最多 100 | 最可靠的大项，应尽早完成以防意外死亡 |
| 持有头衔 | 伯爵 1 / 公爵 2.5 / 国王 5 / 皇帝 10 / 霸权 20 | 只计算死亡时仍由本人持有的头衔；临时取得后丢失不计 |
| 领地规模 | `floor(log2(size)) × 10` | 动态追踪 `2^n`；当前实现 `1 ≤ n ≤ 30`，实际可达上限还受地图规模限制 |
| 金钱 | `floor(log2(gold)) × 5` | 511→512 有 5 分，512→1023 没有新分；当前幂阶梯在 `2^30` 封顶 |
| 威望/虔诚/影响力 | 各 `floor(log2(resource)) × 3` | 三者的幂阶梯同样在 `2^30` 封顶；计分始终读取影响力，非影响力政府下隐藏值如何变化须实机验证，不能因 HUD 隐藏而忽略 |
| 五代内在世后代 | 同宗族 +0.1，同家族再 +0.1 | 年轻、生育、子女婚配和多分支繁衍形成复利 |
| 后代最高头衔 | 伯爵 .25 / 公爵 1 / 国王 2.5 / 皇帝 5 / 霸权 10 | 每名后代只取最高级；分散授地可能优于集中 |
| 琉焰之视 XP | 本身不直接进入分数；完成一轮交易增加 1 XP | 10、20……100 XP 的属性与交易代币里程碑会间接改变死亡快照与后续交易，构成接受交易的机会价值 |
| 拒绝垂青 | 最终乘数为 `max(0, 1 − 0.01N)` | 固定赛道小计 `S` 时，新增一次拒绝损失 `0.01S`，并错过本轮 XP 与奖励 |

## 第一版生命周期策略

1. 开局预算优先寿命、健康、生育、收入与低风险扩张能力；这是待实机检验的乘数假设。
2. 立即建立“突然死亡也有收益”的底仓：婚姻/继承人、医师、稳定内阁、财政储备。
3. 尽早拿满一个与开局能力匹配的契约：建设、十个低压力生日、出生或短战争优先于 UI/策略尚不稳定的密谋与改宗。
4. 在资源阈值之间投资，逼近下一幂时转为囤积；高死亡风险阶段守住已跨越的阈值。
5. 扩张时按死亡快照追踪仍由本人持有的头衔组合，并动态计算下一个 `2^n` realm-size 阈值；不为 64→65 的规模项冒与
   63→64 相同的风险。
6. 建立同家族后代网络，但“儿子父系婚、女儿母系婚”只作为常见启发式；婚制、接受度和支系创建都会改变结果，必须在
   运行中复核后代的宗族与家族。授地仍须服从当前统治稳定、继承和叛乱风险。
7. 每次交易按两个不可逆阶段决策：

   - 祝福窗口：此时诅咒尚未抽取。用三个可见祝福的价值、基于已验证池规则估计的条件诅咒风险、完成组合所得 XP/里程碑、
     生存价值和三年机会成本，与拒绝造成的 `0.01 × 预计拒绝前赛道小计` 比较；不能把未知诅咒写成“可见损失”，也不能
     硬编码“永不拒绝”。
   - 接受祝福后的诅咒窗口：在两个已显示诅咒中选择损失较低者，或使用封印；此时已经不能退回拒绝整轮。封印优先覆盖
     健康、生育和严重失稳风险，并计入代币未来价值。

   首轮交易另行求值，因为其完整结果会进入成长基线；后续会话均在上一会话结束 1095 天后触发。
8. 晚年降低战争、旅行和亲自领军风险，随时兑现可创建头衔，并在可见资源阈值上做临终快照优化。

## 实验纪律

- 伯爵、公爵、国王、皇帝、自建角色以及不同政府分榜；CK3/mod/Git/DLC 指纹或余烬位阶变化也要分层。
- 主指标为可见死亡结算总分；同时报告分数/年、存活年数、契约进度和有效局率。
- 首个 `growth100.v1` 只是研究假设。至少以多局、固定开局和一次只改少量策略变量的方式更新置信度。
- 崩溃、未知窗口、环境漂移、日志进入策略或回档都使该局无效，不得拿来证明策略更优。
