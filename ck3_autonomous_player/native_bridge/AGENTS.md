# CK3 Native bridge

- 按实际 EXE 和构建绑定 ABI、布局、候选来源、调用者、所有权与消费路径。先读[原生 AI 专题](../../docs/ck3-native-ai/README.md)及[研究工具流程](../../docs/ck3-native-ai/research-tooling-workflow.md)。缺少绑定或读回证据时保留真实 Unavailable/UNKNOWN。
- 共享协议变更与真实 Java/存量 Python 消费者、序列化和回归联动。优先补决策所需的通用只读 MCP 能力，验证原始帧、输入输出语义和动作后态。
- 离线复用 CMake 开发输出，先编改动 target 与关联夹具，记录真实结果。DLL、能力合成与实际装载分别核验。只有现场 owner 可采用新产物或操作游戏，并先按[实机权限](../../docs/maintenance/ck3-operating-authority.md)核对。
