# 创建按钮的失败原因

创建草案的页面和悬停提示共用 `RRF_COMMIT_BLOCKERS`。七个独立的 Customizable Localization 分支分别检查操作者、来源、重新校验、内容、核心数量、双方贡献与实际报价；通过的分支返回空文本，失败的分支附带自己的换行。创建按钮仍由原来的 `rrf_ready_trigger` 控制，提交仍执行原来的效果。

`RRF_COMMIT_HOVER` 是本地化键。GUI 的引号字符串不接受字面 `\n`，换行应放在各语言的 YML 值里。九种语言必须同步保持键与格式标记一致。

2026-10-29，`machine_id: 4-8e1c2f1861` 的 R0053 实机中，草案缺少 B 方贡献且虔诚为 499（报价 500）时，按钮正确禁用，但原先通过 `IsValidTooltip` 拼接的原因正文为空；去掉一个核心后也未显示额外的数量原因。该失败促成本次改用共享谓词和独立本地化分支。R0053 保留为失败证据；自动回归验证谓词、报价边界、GUI 接线和语言合同，修复后的实际显示仍须独立实机验收。
