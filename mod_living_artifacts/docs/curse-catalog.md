# 活武器诅咒图鉴 v0.3

设计日期：2026-10-22。**32 种原创诅咒，8 类各 4 种；全部机制与接口均为原型待证，尚未实现或实机验证。** 本文定义诅咒内容，不修改[主设计](design.md)的成长概率、无喂养冷却、四档稀有度喂养或两咒槽规则。

## 1. 重代价与退出规则

诅咒应让主人认真考虑要不要继续穿戴。rank 1 已经影响正常使用；rank 3 允许显著缩短寿命、压垮现金流、破坏家庭或放大现有政治危机。它们不会自动转成奖励，没有「吃了诅咒就多一份经验」的补偿。

- 同件最多 **2 个诅咒槽**。满槽后替换类型时，新诅咒继承被替换槽的 rank；把 rank 3 血税换成别种诅咒，仍得到 rank 3，不能免费洗回 rank 1。
- 诅咒独立计算，**不受基础饥渴 5 点上限、共鸣倍率或付费镇压削弱**。镇压仍按主设计暂缓成长，不能半价关闭诅咒。持续减益由所有实际穿戴物品各自贡献并相加，**同名诅咒也相加**；事件惩罚依各条明确的每角色／每物品次数归并去重，同一源事件对应的同一次扣款、转移、泄密或其他动作不得重复提交。
- **所有新惩罚均要求触发当时真正穿戴该件物品。卸下免费停止成长、失去活武器持续加成，并撤销本表的持续减益。** 诅咒不能禁止卸下，库存不会隔空发动新的扣款、泄密、伤害或关系事件。
- 已经实际发生的金币与耐久损失、压力、伤病、公开秘密、关系损伤、所有权转移和债务不倒带。持续的健康／属性／收入／速度修正与「已造成一场病或一笔债」必须分开：前者卸下即撤，后者按原生病程、关系期限或已承诺合同继续。
- 除明确写明的概率外，符合条件即 **100%** 发生。概率在一个实际源事件上只抽一次；同一来源不因多条回调重抽。月／季度指游戏月／游戏季度，天数为游戏日；频率上限跟随原承担者，转赠和突变不刷新。
- `r1/r2/r3`用`a/b/c`表示。金融基数`W`为扣款前实际非负钱包；`M`为当次诅咒扣款前、按当前原生经常性收入减经常性支出得到的正值月结余，负值按0，不含一次性赏罚或借款本金。比例扣款按非负值`floor(x+0.5)`取整数，最低1金币；固定额与比例取大得到完整报价，再扣`min(W,报价)`。不足不造负钱，按条目产生明确压力或已约定债务。
- AI/NPC 与玩家承担同样条件、概率和后果。AI 可以正常卸下整件，装备估值必须计入持续损失、下一次事件成本和两槽合计风险；它不能免费只关闭某条诅咒，也不能为了触发而制造战争、监禁或家庭关系。
- 以下写的是**原生事件语义**，不声称已经存在某个同名 `on_action`。不得从未知日志猜参战、凭空编造秘密、生成叛乱或直接宣告计谋成功；需要的精确来源或 modifier 不成立时，该条保留为未启用候选。

**首版 8 条**：鲜血什一税、贵族胃、善变之躯、大嘴巴、离家出走、妒侣、锈蚀饥饿、失眠之国。它们分别覆盖生命、现金流、能力失灵、泄密、所有权、家庭、物质毁损与地方统治；其余 24 条为后续内容池，不能因图鉴列出就让未实现条目进入随机池。

相同诅咒的事件若采用每角色额度，同一源机会由当前已装备的最高阶版本结算一次；若采用每物品额度则各原件独立记录和结算。不同ID各自承担后果。数值持续罚项相加，具名槽位机制与概率倍率按条目限定的目标执行，不把本件异能的削弱错误扩展到所有库存。

## 11. 玩家应看到的东西

物品界面按槽展示诅咒名称、rank、**当前持续代价**和**下一次机会事件**。贵族胃显示下一月完整金币报价及现金不足会增加多少压力；善变之躯点名夺走的异能；离家出走显示真实去向；大嘴巴只在泄密真的发生后报告实际公开内容，不预告未知秘密。

发现 rank 3 诅咒时用清楚的提醒：「继续穿戴会承担这些代价；卸下可以停止成长和新惩罚，但已发生的后果保留。」不能以确认框偷偷把自动成长改回手选，也不锁死卸下按钮。主人继续穿戴时，诅咒可以很凶；主人把东西放回箱子时，它就应安静下来。

两槽的组合应自然危险，例如鲜血什一税 3 + 午夜发热 3 会同时降低健康，贵族胃 3 + 账本长牙 3 会真正逼迫主人削减开支。无需再给重诅咒安排一份正向联动奖励。正式启用时以实际原生支持的 modifier 和事件链落实本表；未经证明的条目保留「未启用／原型待证」，不把想法写成已经支持的玩法。
