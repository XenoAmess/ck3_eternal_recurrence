# 活武器：63项验收案例输入与独立后验

2026-10-22。机器无关的待执行规格；**全部63项NOT_RUN**。本文件不授予实机或发布通过，不注册63个假ready adapter；当前公共adapter支持哪些动作，仍以冻结源码和实际能力为准。配套[严格JSON](content-acceptance-cells.json)由[共享类型与parser](../tools/living_artifacts_acceptance_model.py)解析，引用[总方案](test-plan.md)、[内容矩阵](content-acceptance-matrix.md)及[实现调整](implementation-adjustments.md)。实际机器、PID、actor/artifact数字身份、输入SHA和证据只放运行回执，不能把这里的别名当原生ID。

## 共同输入与判定

- 默认seed是**初始活物**：4级、0XP、共鸣100、已装备、只有列出的异能/诅咒；实际flags/schema、owner、原生个人slot与可受益资格都须合法。36月内自然月XP最多288<400，可隔离随机升级；A12及G/F等明确覆写的例子除外。内容NPC可以seed已装备来验证处理，但这绝不证明I01的AI自主穿戴。
- 默认主人成年、存活、足额健康/金币/威望且压力留余量；健康不是免死。所有非目标buff、月收入/自然压力/原生战利品先记录。每个内容lane使用不同主人，避免角色冷却、夫妻关系、宾客730日额度互相污染；不能把24件同slot塞给一个玩家并假装都已装备。来源到达时必须重新确认仍装备：AI若因风险真实卸下，可支持I04，但不能再给该诅咒事件判正例；保留该子项未观察/BLOCKED，改排玩家独立分支或合格机会，不能禁用AI、代穿或给NPC免罚来追绿。
- seed只写**输入**。金币、XP、控制力等若是本例待测终值，fixture不得写；也不能写战胜、骑士死亡、计谋发现/成功、秘密known/exposed、抵达、活动完工、streak、ink_active、记忆或偿还结果来替生产行为。已建立真实生产checkpoint可复用，需pin其原件和父结果；不能用“有这个变量”冒称已经发生。
- 每例先读前态，真正完成原版业务，再读世界后态。独立期望不调用被测奖励计算器生成；来源callback只证明入口，不证明金币、秘密或关系已变。世界字段可由已证实只读原生查询、来源绑定的只读getter，或严格解析的实际存档切片观察，报告必须注明实际producer并校验对象身份；被测函数自行打印PASS不够。
- 正例默认满共鸣、未镇压、无额外咒。随机fixture只控制**生产门槛/目标选取**，报告标fixture_live及控制范围，不改原生战斗/计谋/死亡结果，也不证明自然概率。新主共鸣20的A07自然传承不得套旧主满共鸣35%。
- `route=existing_mcp`只引用现有实际工具，仍需本机source/live资格；已知个人装备提交工具只针对当前玩家，不凭此声称可直接操纵其他NPC。非当前玩家的穿脱要靠其真实AI行为或合法切换后的独立分支，不能拿跨owner ACK当完成。`root_gui`表示从真实界面施工并记录合法输入/原生后验，不代表已自动化；`missing`缺通道即BLOCKED。`offline`只配offline_check，离线GREEN绝不授live。所有case初始NOT_RUN，缺必需源或后验时该项BLOCKED，继续其他lane。
- 卸下撤本件持续加成/减益并停新成长；原有损失、伤病、秘密、关系、债务不倒带。A12已施给他物的30日压阶按原截止/联动解除；原件卸下立刻失去自身勇武、不能续施。

## 消费与验收边界

1. 消费者调用`read_catalog(Path(...))`，得到frozen dataclass/tuple；执行前调用`verify_catalog_sources(catalog, repository)`逐项核实际来源SHA/anchor，不消费漂移规格。用`to_json()`统一变为JSON数组。parser拒绝未知/缺字段、重复JSON键、bool/float充整数、非法slot/ID/rank、无效decimal及双向引用不一致；目录仅允许已约定63需求和NOT_RUN。
2. fixture builder只消费artifact_seeds及经审读的初始条件，不执行自由文本作为脚本。把alias绑定本场真实角色/原件并保存身份；空seed数组表示复用有出处的输入或checkpoint，不表示0对象或缺失后态。
3. 每个动作先核route与真实能力，现有stage adapter只消费自身已实现部分。GUI-only feed可引用F01/F02/F04/F05等ID，但不能把本目录写入当已实现63cell runner。新增来源/observer须在公共层真实注册，不以占位工具补ready。
4. `expected_decimal`是规范十进制字符串或null：有值用于对应metric精确比较；null代表身份/生命周期等非单数字断言，必须执行description及全部evidence_required，不是“无期望即通过”。原生固定精度、月收入和压力原生后果另计，不能从面板四舍五入猜增量。
5. 每项必需子机制均需真实来源与独立后验。尤其A02真实阵亡+记忆+决斗清理，A07真实发现+收藏+新主known，A12三真月+下一突变消费资格；只有基础属性/日志入口时整条不能完整PASS。未通过条目与后续24异能/24诅咒/6联动不混入已完成范围。
