# 最小发布验收集建议

2026-10-22。按[AGENTS.md](../../AGENTS.md)第523行“产品关键路径、代表性高风险路径和实机真实出现的 RED 闭环”裁剪[现有63个单元](content-acceptance-cells.json)。本建议不新增功能或用例编号，不改旧单元状态，也不把抽样结果追认为整条复杂用例或全部内容通过。旧[矩阵](content-acceptance-matrix.md)可继续作为细节参考，逐条、逐rank、逐概率分支全跑不应成为新的总量发布门槛。

目标是证明用户能拿到会成长的装备，玩家和 NPC 能实际使用、喂养与付费压制，代价真实有效，物品和债务在换主/重载后不出错。不同 rank 的数值、概率表达式及同类常规分支优先离线覆盖；实机集中验证脚本进入真实原版作用域、真实世界结果及难以用离线模型替代的生命周期。

下列项目可保留离线或部分实机覆盖说明，不单独扩大首次发布门槛：未选异能/诅咒/联动的低风险常规分支、全部rank排列、全部自然概率频率、所有目的地/宾客/计谋对象、同类冷却/限额的每个排列、全部兼容mod及载入顺序。若对外要声称某独有机制或兼容组合“已实测”，必须有相应真实证据；否则在已知限制中明确范围。未验证的高风险分支应先限定启用/宣传范围或补实测，不能用离线数字掩盖实际缺口，也不能削去NPC等用户核心需求后仍称原目标已完成。
