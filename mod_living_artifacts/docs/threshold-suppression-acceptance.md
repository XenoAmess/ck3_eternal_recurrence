## 判定范围

每个保存记录保留来源 Save、真实 Root 回应、原始暂停帧与独立原生物品查询的 Pin。消费者重读真实源文件，核对运行、机器、PID、连接代次、角色、日期和同一物品。JSON 数值 Q64 先在 Python 严格验证再写为十进制字符串；拒绝 bool/浮点冒充整数。完整原生请求文件闭包同时保留未成功的只读查询和来源明确的 pre-intent 库存拒绝，不能将其当成功动作；合法 Session GUI fallback 仍可使用。

压力检查只证明同一暂停日、两份独立保存之间，由这一次实际训练或镇压导致的**实际压力差额**；快照压力必须与保存一致。使用实测非负差值，允许实际为0而不因此推定修正公式正确，不能把基础10当成修正后应付10。缺失保存 stress 或原生 stress 不推为0，该压力 cell 标 BLOCKED，其他已完成 cell 仍各自保留判定。精确修正公式符合性标为 unavailable；不为较早精确版本的压力查询扩平台或添加启动门禁。普通自然日中的陌生事件沿用既有续行；同一暂停扣费窗口出现额外事件则保留阻塞，避免把其他事件压力混入费用。

诅咒/饥渴检查只授予**保存内原生 artifact modifier 已投影**，不把基础健康字段、私有变量或脚本常量当角色实时有效健康。卸下/再装备只检查镇压绑定和费用不重置，不重复授予持续效果撤销/恢复全矩阵。本包也不证明全部随机词条、所有诅咒强度、NPC AI、跨物品叠加、修理、赠送、转移或继承。

保存是历史时点，不是当前原生变量接口。首次付费设立90日期限、观察到31日内保持压制，不等于已观察90日到期。合法续期窗口为剩余≤30日，首次最早需付费后60日才进入；**到期和续期必须另设长场**，不得植入人工旧 deadline 来冒充已经付费等待90日。
