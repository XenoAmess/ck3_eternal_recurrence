# 活武器 / Living Artifacts

让 CK3 的个人装备有概率苏醒，成为能够积累经历、选择成长方向，并随家族传承的活武器。名称沿用“活武器”，设计范围包括武器、甲胄、冠冕、礼器与个人饰品。

**当前状态：研究与设计稿 v0.1，2026-10-22。尚无游戏脚本、安装包或 Workshop item ID。** 本目录依照仓库 `mod_<english_name>/` 惯例创建；英文目录名使用 `artifacts`，对应 CK3 的宝物对象。

## 文档

- [Elona 活武器设定研究](docs/elona-living-weapons-research.md)：检索来源、原版与衍生版差别，以及可借鉴的核心玩法。
- [CK3 详细设计](docs/design.md)：觉醒概率、装备范围、成长数值、附魔选择、共鸣、反噬、继承、界面与完整玩家流程。
- [实现与验收方案](docs/implementation-plan.md)：脚本落点、持久化字段合同、兼容性、待验证接口与开发顺序。
- [本次文档工作记录](docs/evidence/design-session-2026-10-22.json)：机器身份、存储检查与交付边界。

设计默认每件合格个人装备 **5%** 概率觉醒，只判定一次；已拥有的旧装备也会纳入。活武器上限 **15 级**，从 **11 级**起面临更强反噬。概率、等级、代价均为本模组的初始设计参数，实际开发后需要游戏内验证和平衡调整；它们不代表 Elona 各版本通用规则。

独立运行是预期目标，不要求《琉焰卿的永恒轮回》主模组、MCP 或外部后台。遵守仓库当前玩家限定规则：默认仅玩家触发觉醒、成长及事件；AI 持有时保存装备状态，但不运行活武器玩法。
