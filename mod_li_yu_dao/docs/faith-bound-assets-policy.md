# 一期共同体绑定对象策略

此文对应验收矩阵 M3-01，限定为既有军会、圣人登记、圣物与领袖的绑定。本文不新增军会、圣物目录、获取事件或免费资产。源码候选不构成实机通过。

## 跨 faith 的正式分合

一期采用保留与明确拒绝，不支持自动搬迁军会或圣人登记。来源 faith 有任何原生军会或圣人登记时，正式 C2 来归、另立均不得开始。来归的接收 faith 有这些对象时，也不得开始。`any_faith_holy_order` 的范围同时包括军事与修道组织，本策略不选择性搬走其中一种。

最终确认重新检查当轮捕获的实际 faith 对象，不能用提议时没有资产的事实授权后来已有资产的操作。对象缺失、不是本流程的来归／另立类型，均明确拒绝。最终资产条件不通过时，既有授权不能触发头衔退休、`set_parent_faith`、`detach_rite_to_new_faith`、创建宗主、迁移费用或五年调整冷却；当前轮次仍可等待、撤回，或依原有一年期限自然结束。

旧圣人登记及其圣物关联不重写。当前原生 PAM 圣物提取把 `pam_saint_relic_saint` 保存为圣人 Character 引用，没有在本流程中证明可以任意改写该引用来迁移所属共同体。个人持有的其他物品也不会由本模组转让、复制、销毁或再生成；迁移后原版的使用资格、效果与继承仍须按实际物品验证，不能把没有新增 setter 写成已经完成引擎验收。

来源和接收方都没有这些绑定对象时，本条件仅通过资产这一项；原有本派授权、接收各派授权、玩家同意、代表签署、领袖条款、原生归属规则、费用及冷却继续生效。

## 同 faith 的宗主制度与领袖

正式 I3b 议定宗主与共享宗主工厂不迁移 faith，只实施已授权的宗主教义和专属宗主头衔。该源码候选不改变工厂、宗主退休或生命周期 effect，也不创建、迁移或复制军会、圣人、圣物。实际建立新宗主及其后冷重载仍须确认原有组织、物品持有人与关联不变；既有政治保护合同保持。

原生偏离度自动分立、原生 AI 的宗教行为及其他模组的资产 setter 不由 C2 玩家门禁控制。本策略不能被写成覆盖这些入口的全局迁移保证。

## 关键与代表性高风险验收

| 路线 | 必须观察 | 当前实际结果 |
| --- | --- | --- |
| 当前合法无资产分合 | 原授权与费用合同仍生效；不凭门禁源码宣布分合通过 | NULL |
| 有真实既存组织或圣人登记的来源／接收方 | 正式入口明确不可实施；原绑定、持有人、费用、归属保持 | NULL |
| 提议后至最终确认前自然形成绑定对象 | 最终条件拒绝；无头衔退休、归属改变、扣费或新资产；撤回／自然结束仍可用 | NULL |
| 同 faith 合法议定新宗主后保存、冷重载 | 原组织、圣人登记及相关圣物的对象身份与持有人保持；政治保护继续全真 | NULL |

不穷举所有学派、军会、圣物或事件。使用真实既存对象的代表路径；缺少可复用的真实资产存档时保持未验，不通过脚本注入制造。当前正式 MCP 没有专门的军会／圣人／物品对象查询合同，G2/G3 不能冒充这些完整对象清单；由 ROOT 在真实保存的单次读取及已有原生证据中保全实际可读字段，缺失字段继续 NULL。

需求来源：`docs/acceptance-matrix.md` M3-01；跨仓设计 `docs/ck3-confucian-repeatable-reunion-and-schism-design.md` 的第7、10节及仅对已验证策略宣称支持的限制。军会创建、供养、征用及适用战争、圣物获得与传承并未因这项绑定保护而取得能力信用。
