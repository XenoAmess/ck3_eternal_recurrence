# 《礼与道》迭代一内容包

记录日期：2026-10-04。原生机制参考版本：CK3 1.20.0.3。

本包保存 **36 个礼仪候选、36 张信条候选**的内容数据，生成其中 **8 个样板礼仪、15 张信条的原生定义**及中英文本地化。每个样板另有一件祭礼或修养疑案，共 8 件、24 个正式选择。其目的在于让玩家通过不同的理解和行动体验学派差异；目录完整不等于全部路线已经可玩，也不等于实机验收完成。

权威输入是 [content_data.py](../tools/content_data.py)，生成方式见 [gen_content.py](../tools/gen_content.py)。设计来源是[礼仪与信条设计清单](../../docs/ck3-confucian-rites-and-tenets-design-list.md)和[整体规划](../../docs/ck3-confucian-flavor-mod-plan.md)。修改内容应改数据并重跑生成器；带 `GENERATED FILE` 标记的文件不得手改。

## 归属与时间模式

8 个样板均属于新增信仰 `lyd_common_faith`，上层仍为原生 `confucianism_religion`，主礼仪为 `lyd_rite_kongmen`。本包新增定义，不覆盖原版 `confucian_faith`、`jingxue`、`daoxue`。礼仪声明 `create = yes`、`convert = no`；当前集成使用玩家启用和选学流程，显式切换礼仪的原生语义仍须实机验证，不能由声明推定普通改宗菜单已经可用。

一期采用明确的**自由时代模式**：玩家可选孔孟、荀子、汉魏礼学、唐代经疏和南宋学问。朱子、象山样板此时是供玩家试用的跨时代思想路线，不能据此描述为 867 年或 1066 年已有的历史组织。系统不生成同名历史人物，不因路线选择改写某朝的实际祀典。

二期才加入形成期、传播条件和朝代范围：区分经典思想、学派形成、制度采用与后世官方地位。先秦及汉唐路线可作为早期继承素材；宋代学派应按各自发展阶段开放。R24—R36 保留元明清素材，既需逐派年代校订，也需说明原游戏结束时间以后的体验方式；该目录不自动扩张为完整明清地图、人物与事件历史模组。

## 历史语义与玩法边界

必须分别理解经典规范、历史解释和玩法抽象。礼仪保存学问路线，不推定古代存在同名的独立宗教组织；经学、道学、理学、心学的层级和交叠仍需在文案中解释。理气、鬼神的讨论也不能因名称相近就等同佛教法界圆融。

| 内容 | 本轮采用的历史依据 | 本轮抽象的边界 |
| --- | --- | --- |
| 孔门经礼 | 仁、礼、敬与学诗习礼 | “孔门经礼”为共同传统的设计名称；个人谒圣、习礼不授予天子礼制身份 |
| 孟氏之学 | 四端扩充、集义养气与经权判断 | 祭礼准备中救护伤者是设计疑案，不声称出自《孟子》原文；性善不免除修养 |
| 荀氏之学 | 师法、化性起伪、丧祭安情与天行有常 | 修习不以欺诈为德，丧祭不会控制天气；不把荀子简单写成排斥一切祭祀的现代自然主义者 |
| 郑氏礼学 | 昊天与五帝、圜丘与郊祭、感生与配享的解释 | 教学图与经义辨析不等于玩家实际举行帝王郊祀；经师理论不自动等于各朝采用的祀典 |
| 王氏礼学 | 王肃的天惟一体、丘郊一祭及祖源禘礼解释 | 与郑学有实际争论；共有信条不抹平对象差别，论禘也不授予越格祭祀资格 |
| 经疏正义 | 南北经学与唐代经疏的传注、名物和礼义解释 | 匿名丧服疑案未考定某一具体服制条文，不改变原生亲属等级，不提前放入后世四书中心体系 |
| 朱子之学 | 理气、居敬穷理、四书与家礼实践 | 家礼场景为综合抽象；南宋形成过程与后世官学正统有别，问学必须联系行动 |
| 象山之学 | 发明本心、立志改过、辨大本与自得 | 陆学仍可读经问师；不把任性等同道，也不提前填入成熟阳明学的全部良知命题 |

仁义、诚敬与祭祀资格均保留古代身份与责任差别。当前匿名疑案不能代表所有阶层均有相同祀典资格，也不能把古代儒家直接写成无等级的现代伦理。忠孝和谏诤不在本轮制造父母或君主的无限牵制。灾异、天命、祖先和鬼神表达的是信念及解释，不由脚本确认神灵真实施法。

主要历史依据复用已存来源：[孔子](https://plato.stanford.edu/entries/confucius/)、[孟子](https://plato.stanford.edu/entries/mencius/)、[荀子](https://plato.stanford.edu/entries/xunzi/)、[北京大学儒藏所郑王礼学资料](https://ruzang.pku.edu.cn/info/1107/1746.htm)、[《五经正义》出版资料](https://www.cp.com.cn/book/275bde04-e.html)、[宋明儒学](https://plato.stanford.edu/entries/song-ming-confucianism/)、[中央研究院宋代经学资料](https://www.litphil.sinica.edu.tw/newsletter/86/157-172.pdf)。具体路线与信条的来源关联保存在数据的 `source_keys`，本轮没有额外复制学术文章或古籍页面全文。

## 本轮尚未实现的内容

本轮没有新增正式的儒家宗主或学派领袖制度、道统继承、圣物获得与传承玩法、宗教军事修会，以及生产版学派分合流程。师长问学入口不等于宗主、全球教权或完整授受谱系；后续设计仍须分别考察祭祀主礼、经师传承和国家礼官的身份。本轮信仰沿用原游戏儒家的圣地集合，不等于新增圣物体系已经完成。

儒者从军、义兵、祭告与军礼有历史素材，但不能直接推定每一种礼仪均有隶属宗教的常设军事修会；也不能据此先验禁止后续军事玩法。分合验证若使用 `lyd_probe_*` 外置夹具，只能作为后续原生机制研究，不能计入本轮生产玩法。本轮玩家选择路线、礼学争论与完成标记均不等于正式分派与合派。
