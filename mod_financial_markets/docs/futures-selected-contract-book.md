# 所选期货合约盘口与独立限价

machine_id: `4-8e1c2f1861`。当前为外置源码候选，未由本包启动或操作 CK3、Native、Steam；不是引擎或真实成交验收。

期货页现在按当前合约 ID 显示已担保的新仓买方/卖方委托，每边前五笔，价格优先、同价按永久订单 ID 先后。它读取该合约现有 `xfm_orders`（生产容量为64），不读同币其他期限，不遍历历史合约或全世界。数量为剩余整手；总量包含该次刷新符合资格的本合约新仓委托，不是把五笔当聚合价格档位。

筛选检查订单类型、合约/资产身份、未成交或部分成交状态、剩余量、合法可用账户、同账户真实冻结 reservation、足额剩余保证金与累计手续费；同时检查当前风险开关、有效预言机、期限、最大杠杆、价格带及账户/全局仓位容量。冻结、撤销、资金不足、错误合约、自身和同受益人订单不计。刷新对最多64个本合约订单账户复用撮合器的真实法律控制者更新，确保家主/宗族/政权控制改变后按当前实际受益人判断；只更新法律控制元数据，不存款、冻结新钱、成交或制造资产。

这里只展示新仓委托。减仓换约还依赖旧仓按份保证金、价格差、替换后的双方受益人和仓位容量，故未用状态或手续费将其冒充可执行深度；正常减仓功能完整保留。盘口是手动刷新快照，并不保证新单成交，真正撮合仍复核双方权限、资金、仓位和容量。

正常入口：期货页“刷新所选期货合约盘口”、现有市场刷新、选择交割/永续系列、切换已有交割系列、从持仓选择合约。切换系列会按实际选择的同一合约 ID 重建数据；没有可用单时明确深度0；已撤单/资金冻结的旧行也有只读资格守卫。没有新增每日、AI或永久历史扫描。所有新增组件位于既有右侧 scrollbox 内，不新增顶层窗口。

价格分开呈现：币的最近现货成交价、资产参考指数、结算标记、所选合约真实成交记录。模型指数没有现货交易或实物兑付。现有 `xfm_last_execution_cents` 生产于 `xfm_futures_match` 和 `xfm_futures_reduce`，实际为最近有成交日的成交额÷手数向下取整均价；因此界面显示该日、当日均价和当日总手数，不称最后一笔，也不编造日内时刻或单笔数量。缺少任何必要成交字段时明确无已记录成交，不以现货/指数/标记代填。

期货本页限价使用独立的 `xfm_futures_limit_cents`，与现货 `xfm_order_limit_cents` 分开。选择新系列默认以当前结算标记初始化该输入（仅是可编辑委托价）；本页±修改它，开多、开空和减仓消费当前这个值。选仓会明确初始化，继承账户无需先开一次新仓便能减仓，不再沿用不可见旧开仓价。原业务整数和范围校验保留，GUI执行也检查当前范围。止损/止盈仍各自使用 `xfm_futures_stop_cents`、`xfm_futures_take_profit_cents`，不借用限价。
