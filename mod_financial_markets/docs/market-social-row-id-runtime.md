# 债务、新闻与 OTC 行的数值身份解析

本包依赖已采用的 portfolio row IDs02 + testfix03（316 项软件测试／打包通过，尚不等于游戏业务通过），修复剩余三 GUI 的六处原行回调。债权、援助两处使用完整内联的原 button_standard_list，原 name/size/text 全部保留，只有各自的选择器，不继承已有业务 onclick 的共享行，不假设实例赋值覆盖继承回调。六 GUI 总共47处数值回调（原43+两个内联实例各2处）。不再保留裸 Scope / Scope.Self 作为行参数。

债务／债权各由当前合法持有人账户的维护列表构建16引用快照，只在普通打开、刷新、切账户或分页重建。选择器读取对应快照及其账户／offset身份。债务须属于当前 debtor account，债权须属于当前 creditor 或 fund recourse account；执行时再核当前真实维护列表成员。援助选择器是另一个独立域，必须匹配当前新闻及该新闻 actor 的真实主账户，只能选择该账户仍未结清债务。正常“查看债务援助”按钮构建首16项，新增的前后页按钮可查看其余；选择本身不付款，不造欠款，也不授减记权限。

新闻选择仅在当前16项 journal 页按 news_id 唯一查找，并绑定正常刷新产生的 before_id 游标。它不在 IsValid 中遍历永久新闻 registry。OTC 选择仅在当前16买方页按合法 PRIMARY account_id 唯一查找，再核当前选币、offset、真实币持仓、账户可用性、活着成年、非本人及原 holder 主账户规则。执行前重验该 position 仍在真实选币 holders 列表，并保存真实 position/account/holder。持仓数量没有被当成现金；报价、冻结、接收人同意／拒绝／超时和原子交割全部保留原生产 effect。

所有 IsValid 及脚本计数纯读。ID<=0、缺失、错类型、错页、错账户、重复 ID、当前新闻或所选币改变全部拒绝；效果内部独立重验，不依赖上一次 IsValid 或旧 selected 值。真实 Story 引用只由服务器 effect 在当前界面页重新解析；数值从未被当成 Story。

本包新增5项生产脚本 subset 用例，复用现有 BookVM 的已验证列表计数与真实 membership 语义，无新增业务 mock。它们执行实际债务页／援助分页、合法行解析与选择、正常 OTC refresh 和目标绑定，负例覆盖错主体、错游标、失效源、同号、未成年与冻结账户。新闻页在软件用例中是明确的只读缓存输入，不将其写成永久 journal producer 的引擎实测。源合同另外检查全部47处参数、纯校验、有限缓存与清单引用。没有编跑或游戏动作由本候选作者执行。

后继由 Root 在关闭旧场后采用本独立 patch，先跑受影响 Book／SocialRow／OTC 三个测试模块，再按当前共享流程验包与冷载。正常实机分别点击一条本人负债、一条法律债权、一个新闻与其援助债务、一个当前币真实独立持有人；物理 SAVE 核对应 selected 的真实 Story 和所有余额、债务本金未变，再另验用户明确提交的财务动作。不得把控件 handled/enabled 当作财务后态，不热改任何冻结 runtime。
