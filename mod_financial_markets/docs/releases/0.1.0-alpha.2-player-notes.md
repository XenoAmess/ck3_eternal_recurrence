# 0.1.0-alpha.2：市场界面修复

本版针对首次 Alpha 试玩反馈调整市场窗口，继续更新同一[工坊条目](https://steamcommunity.com/sharedfiles/filedetails/?id=3844765196)。关闭游戏后让 Steam 下载更新，在播放集中启用 Financial Markets；原有账户、币种和委托继续使用，不需要重新开档。

- 左侧资金区、指数入口、筛选、行情列表和翻页各有明确边界，修正内容下移到父容器命中范围之外的问题。
- 右侧详情与交易面板贯穿内容区；滚动视口高 728 个界面单位，长票据在面板内滚动。
- 现货买卖和期货多空表单提前到盘口上方。币的摘要集中显示，完整说明可悬停查看。
- 币号、账户号使用普通文字显示，避免编号前的格式标记吞掉数字。

本次没有修改资金、撮合、发行、杠杆、清算或存档字段。首次 Alpha 的[功能与风险说明](0.1.0-alpha.1-player-notes.md)仍适用；20 剧情完整矩阵、4,096 币规模、长期性能和整产品实机验收仍未完成。

布局与回调的离线检查不等于实际鼠标命中验收。具体测试、发布和缓存结果另见仓库发布记录，不以版本号替代实测。
