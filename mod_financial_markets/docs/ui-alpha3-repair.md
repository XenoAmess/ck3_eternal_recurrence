# Alpha.3 界面修复

R0083 的实际鼠标与截图证明 Alpha.2 币行可以选中，但整体界面仍不可用：主导航和资金操作缺失，工具栏重叠，盘口列没有对齐。该次模型视觉评审为 FAIL，正常退出码为 0，原件保留在 [实测索引](../../docs/financial-markets/2026-11-25-r83-mouse-visual-failure.json)。

新候选采用当前安装的原版 GUI 中已有的有界根 VBox 与 HBox 顺序布局：标题、六个显式宽度的导航页签、主体；左栏是账户、指数、当前页面，行情页内依次排列筛选、查找、表头、可扩展行情列表和翻页。右栏以标题和可扩展滚动区使用主体高度。布局依据为原版 `window_activity_intent_selection.gui`、`interaction_trade_market.gui` 及 `shared/lists.gui`，不是假定布局框的绝对坐标会成为引擎命中范围。

币行分为币号与名称、最新价、买一、卖一、日成交量五列，与表头宽度一致；子文字透明穿透鼠标，仍由原父按钮选择币。选中样式使用已有选币有效条件与币号比较。买卖盘使用相同列高和尾部可扩展留白，交易表单仍在盘口与完整规则之前。

中英文动态编号前的 `#` 已移除，修复真实日志中的 `Unknown formatting tag`。构建校验器增加相应窄检查与错误／正确文本用例。原金融操作的启用与点击表达式保持，金融后端和存档字段没有改变。

源码布局检查只约束有限父容器、分配链、页签宽度、工具栏顺序和文字穿透属性，不再以静态矩形测试宣称实际命中或像素布局通过。软件检查、后继实机鼠标、最终画面和模型视觉结论分别记录；本说明本身不授予实机或发布通过。
