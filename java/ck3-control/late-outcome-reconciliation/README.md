# Late outcome reconciliation

Pure Java 21 leaf for the shared exact-day timeout path. It does not read files, start a clock, call Game/MCP, clear HALT, modify the writer, cancel a sentinel, replay a request, or grant continuation. Its result is exactly `PROPOSED`, `WAIT`, `UNRESOLVED` or `REJECTED`. Original failure credit remains zero and `neverReplay` remains true. ## Inputs and state transitions

`LateOutcome` contains immutable typed records. `Scope` binds machine, Game/Queue/application PID and kernel creation FILETIME, original session, source digests, connection, actor, episode and native world pointers. Game/Jomini pointers are equality identities, not ordered epochs. `ContentEvidenceRef` is a portable content-addressed evidence key; it is deliberately a different domain from the shared path-based `contracts.ExactRef`. No record constructor authenticates any source or kernel identity.

`Attempt` preserves original FULL/AUTO/error reference, status-query/stop-validation attempt facts, original arm and real writer-head reference. Those original facts are not rewritten after a new observation. Ordinary exact-day arms allow an empty watch list; watched public CUnit IDs allow zero, are sorted/unique int32 values and number at most 64.

The original Queue transport must supply before/after scope, fresh kernel/custody/source qualifications, unique read sequence, original response reference, receipt elapsed time, UTC observation and Win32 reader uptime. `Context.gameLife` is only the transport's typed fact, not a liveness check performed here. Scope equality is likewise a consistency check, not OS/source qualification. `Context.totalReadsConsumed` comes from the persistent original transport read ledger; complete append-only history must match it. Deleting or deduplicating history does not replenish budget. This pure function cannot authenticate a caller that fabricates both its ledger and its evidence.

The planner requests only two typed reads:

1. `CURRENT_SENTINEL_STATUS`. A matching armed slot yields a bounded wait and preserves the guard.
2. When triggered, `CURRENT_SEMANTIC_FRAME`. It must match the current live played actor, episode, world, native frame, actual paused state and owner stamp. Death, succession, pending episode identity, source/identity drift, regression and date conflict prevent a proposal.
3. `CURRENT_SENTINEL_STATUS` confirms the same terminal slot. Only then is a `PROPOSED` assessment possible.

Triggered validation preserves the existing SDK generation/date/tick/reason/speed/mode/watch-count checks, zero overshoot and native-pause ownership branch. An unrelated fresh pause is insufficient. `native_pause` requires one intermediate pause and no sentinel wrapper call; the other branch requires zero intermediate pauses and a wrapper call. No cancel operation exists in this API. The existing native cancel safeguard requiring actual paused state stays intact.

The three minimum bounds are independent **inclusive** lower bounds. A qualified future adapter must derive new frame/verified-pump/heartbeat thresholds from the preserved failed before-state, with checked increment where strict advancement is required. It must not reuse an old lower bound or substitute a new receipt timestamp for new native evidence. Native Win32 heartbeat age compares only with Win32 reader uptime. Java receipt age compares only with orchestration elapsed time. UTC clips the hard deadline. These clock origins are never subtracted from each other. Before/after reads remain separate observations, not an atomic native snapshot.

## JSON boundaries

`SentinelCodec` decodes the exact 20-field `tactical_daily_sentinel` slot emitted by `SerializeTacticalDailySentinelResult12004`. It rejects unknown fields/states/modes, bool/float/string integer aliases, negative dates, invalid widths, unknown flags and incorrect ordered trigger reasons. Legacy native uint64 JSON **number tokens** are read directly as `BigInteger`, checked against uint64, then explicitly converted to the new `CrossJsDecimalUInt64` string memory domain. Numeric strings are not accepted as legacy aliases. No JavaScript Number conversion is involved. Generation zero remains a valid shape for idle/unavailable; an original arm requires positive generation.

`NativeSemanticCodec` reads selected real fields from the existing SEM `structured_content`. It does not claim to validate the complete business snapshot or original outer MCP envelope. Selected integers/bools are strict, required fields cannot be absent/null, and the native producer markers are checked. Unknown unrelated business fields are ignored by this view and remain in the external original receipt. Its local bounded UTF-8/duplicate/trailing-token parser accepts an explicit caller byte budget up to the existing SEM producer's 8 MiB maximum. Unrelated legacy fractions are not re-encoded through phase-one canonical map JSON. Shared `StrictJson` and its integer-only canonical contract are unchanged.

`AssessmentCodec` has a separate exact-key versioned schema and canonical roundtrip. In addition to original failure SHA/AUTO and writer-head SHA, it binds `AttemptFingerprint`, a new-domain canonical SHA covering the complete typed scope, all Game/Queue/application births, session/source/world identities, original failure facts, original arm/watch list, independent freshness floors and exact writer-head reference. The decoder recomputes that fingerprint for the current expected attempt; the same old failure/head cannot carry a proposal across a new session or generation. It preserves the observed read sequence list (including bad order/duplicates in rejected evidence), and emits fixed zero original credit/never-replay. It has no resume, cancel or commit capability. Digest equality does not authenticate the corresponding external files. A serialized assessment is not an execution ticket.
