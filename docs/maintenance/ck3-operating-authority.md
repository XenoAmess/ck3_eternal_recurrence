## Steam 离线模式与账号占用

- 用户于2026-10-05明确永久允许当前 `C:/workspace/ck3_eternal_recurrence` 所在机器实机使用CK3，后续直接沿用，无需重复询问。确切原话与机器范围见 [当前机器永久授权](../handover/2026-10-05-ck3-lyd-local-permanent-runtime-authorization.md)；Z机器的历史用户占用限制不由此自动解除，以下离线、账号及现场规则继续适用。

- 除非任务确实必须联网（例如上传或更新 Steam Workshop mod），禁止把 Steam 从离线模式切换为在线模式；普通开发、构建、静态检查和 CK3 实机验收默认保持 Steam 离线。
- **2026-10-21 用户追加：Steam 在线/离线状态确认在后台完成，不占用屏幕，不激活或移动窗口、不抢焦点、不截图。** 此指令覆盖旧的启动前离线截图和为此恢复桌面的前置要求。受管 CK3 启动前运行 `tools/steam_offline_state_probe.py --receipt <new-path>`，保存当前机器、观察时间、Steam PID/出生时间、版本及实际来源绑定；只有新鲜回执的 `status=offline` 且 `offline_mode=true` 才能作为离线准入。未知版本、来源或身份漂移、冲突及缺少资格必须返回 `unavailable`，不能用缓存、配置、`BLoggedOn=false` 或调用 ACK 冒充当前离线；当前原生 provider 仅资格化离线正例，零值不等于在线。不能因查询不可用而自动切换到截图或抢焦点；修复后台查询时继续独立工作，未确认离线前不启动受管 Steam 游戏。在线状态及跨机器占用继续遵守下条。
- 因必要任务临时切换到在线模式后，该联网任务完成或终止时必须第一时间把 Steam 恢复为离线模式，不得让客户端无故保持在线。
- Steam 处于在线模式时，每次启动 CK3 或其他 Steam 游戏前必须先检查当前账号是否已显示“正在游戏中”或存在其他机器的游戏会话。若账号正在游戏中，视为别的机器正在使用：禁止强行启动、接管或挤下线，以免顶号；停止启动流程并向用户报告。
- 旧截图、窗口位移和 ToDesk 恢复文档保留为历史诊断资料，不再构成 Steam 状态确认或启动的截图前置；新任务不得自动沿用其屏幕操作步骤。后台查询的实现及边界见 `tools/steam_offline_state_probe.py` 与 `tools/steam_offline_native_provider_v1.py`。

## 桌面截图坐标换算

- 从聊天图片预览、远程查看器、缩略图或任何非原始桌面画面读取坐标时，禁止假定屏幕分辨率、宽高比、预览尺寸、等比缩放或固定倍率；历史 `2560×1440 → 2048×1152` 的 `1.25` 只是一条旧实证，不得作为默认值复用。
- 任何桌面点击都必须先取得原始截图，读取该文件真实宽高和点击当时的 `pyautogui.size()`，并显式提供预览中实际图像内容矩形的 left/top/width/height；X/Y 两轴必须独立换算。统一使用 `tools/desktop_coordinate_map.py`，完整合同见 `docs/desktop-coordinate-mapping.md`。
- 使用换算脚本执行点击时必须传 `--receipt`；源截图尺寸与当前桌面尺寸不一致、预览内容矩形缺失、点位越界或点击后回执尺寸变化时一律拒绝点击。不得绕过脚本手算倍率或直接把预览像素交给桌面输入 API。
- 键盘操作前必须切换目标窗口到英文键盘布局并确认 `LANGID=0x0409`，同时确认目标窗口和控件焦点；不得只凭任务栏图标推断。文本输入优先剪贴板粘贴，随后从目标控件读回全文；不一致时可使用 UI Automation `ValuePattern.SetValue` 并再次读回，禁止仅凭按键 ACK 声称输入成功。
- 控件提供 UI Automation 语义操作时可以按 HWND、Name、AutomationId 操作，无需制造截图坐标；`Invoke`、`Select` 返回不代表业务状态已改变，必须读取实际选中项/文本/结果。鼠标兜底仍严格执行上述换算脚本。
