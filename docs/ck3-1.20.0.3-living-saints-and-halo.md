# CK3 1.20.0.3：生前封圣与金色光环

> 2026-10-10 主线整合：恢复来源提交 `6137959cfcb684f3e13c4260bd5af108ec1e1488` 的研究。下文“当前”均指原调查时的构建与样本；没有新增实机验收，也没有把结论外推到 CK3 1.20.0.4。文中外置原始路径是历史定位，本次未重新读取那些原件。

研究日期：2026-10-04（Asia/Shanghai）。用户范围：当前原版，不考虑 mod。下文将官方 DLC 的正常机制和原版调试控制台分别说明；未修改玩法、存档或游戏安装，未启动或操作游戏。

## 结论

**当前原版正常玩法没有查到让活人获得圣人金色光环的获取路线；原版控制台赋予 `saint` 则符合光环显示条件。**

1. 新封圣系统的候选必须已经死亡。
2. 旧版生前圣人路线已经改为授予 `herald`（先驱）：神话级神圣传奇、冒险者传教成功，以及葬礼事件中生者的低概率奖励。新“宣告生活的圣言”决议也是先驱。
3. 金色光环的肖像修饰仍只绑定 `saint`，并要求亚伯拉罕宗教组 `rf_abrahamic`；没有绑定 `herald`，也没有角色已死亡条件。
4. 因此活人可以在引擎中持有圣人并符合光环显示条件，但当前正常玩法不再通过上述路线给活人该特质。允许调试作弊时无需 mod。

证据等级：`research` / `static-confirmed`。本次没有实机截图或 live artifact；控制台效果的视觉结论来自当前肖像条件，未声称已在游戏中操作验证。

“先驱”是生前宗教荣誉，特质定义明确将生者和死后圣人分开：`common/traits/00_traits.txt:12441`。该特质可在统治者设计器选择（100 点），但也不会触发圣人光环；`saint` 在 `common/traits/00_traits.txt:9605` 设置 `shown_in_ruler_designer = no`。

对当前 `common/` 与 `events/` 的 `add_trait = saint` / 角色创建 `trait = saint` 做一次检索：余下授予点是封圣 effect、葬礼死者、死亡 on_action 中修会创始人、埃斯基尔被杀后获得圣人。埃斯基尔两处均先执行 `death` 再加特质，不能作为活人路线：`events/uprising_events/emelie_events.txt:142`、`:284`。死亡钩子对应 `common/on_action/death.txt:2167`、`:2183`。

另一次只读历史解析查到 49 项有效 `trait = saint` 赋予，均位于人物死亡日期，不早于死亡；867、1066、1178 三个原版开局没有由这些记录产生的在世圣人。解析按顶层人物和日期块检查，忽略注释；不是实机人物枚举。本次未验证旧存档的引擎迁移行为，不对历史存档中的既有生前圣人作保留或清除承诺。

## 光环真正检查什么

`gfx/portraits/trait_portrait_modifiers/00_trait_modifiers.txt:2133` 的完整相关条件为：

```text
saint = {
    saint = {
        trigger = {
            faith.religion = { is_in_family = rf_abrahamic }
        }
        traits = { saint }
        dna_modifiers = {
            human = {
                accessory = {
                    mode = add
                    gene = character_halo
                    template = christianity_religion_halo
                    value = 1
                }
            }
        }
    }
}
```

这段没有 `is_alive`、`herald` 或 DLC 检查。名称虽为 `christianity_religion_halo`，实际宗教条件是亚伯拉罕宗教组，不能缩写成“仅天主教”或“仅基督教”；其他宗教组单加圣人不满足此光环条件。

资源链也在本体 `game/` 中：`common/genes/08_genes_special_visual_traits.txt:1323` → `gfx/portraits/accessories/props.txt:1512` → `gfx/models/portraits/attachments/halo/pam_christianity_religion_halo.asset:16`。它使用 `mesh_vfx_head_halo` shader。源码层未见此资源链的付费资格条件；没有做不同 DLC entitlement 的实际视觉矩阵，不能将此静态观察冒充无 DLC 实机验收。

## 不装 mod 的调试办法

以 `-debug_mode` 启动游戏后，在原版控制台使用：

```text
add_trait saint
```

不填人物 ID 时用于玩家当前人物；给指定活人用：

```text
add_trait saint 人物ID
```

例如亚伯拉罕宗教组的在世人物被赋予 `saint` 后，按上述肖像条件应显示金色光环。单独加特质并不等同于完整执行新封圣系统的圣人名册、安葬地点和圣髑登记。这里只提供原版调试办法，没有为用户实际执行作弊；不涉及 mod。

若“本体”严格指不购买任何官方 DLC，新封圣决议本身需 By God Alone，传奇和冒险者路线需各自 DLC；它们也不能作为免费基础游戏的生前光环方案。
