## 1. 设计口径

本清单按用户要求，尝试把先秦至明清的主要儒家学术传统做成 CK3 的礼仪（rite）。礼仪在这里承载**经典解释、天人观、祭祀解释、成德工夫与圣贤传承**。这些历史学派并非各有独立教会；借用礼仪槽位是明确的游戏设计。

经学是共同的经典研究传统；道学是宋代以来的一类思想与修养运动；理学有广义宋明儒学、狭义程朱之学等用法；心学也有陆、王及其后学之别。因此不再采用“经学与道学二分，其他全部塞进个人信条”的总结构。经学、道学可以作为分类标签，具体学派可以成为独立礼仪候选。参见[经学与宋明理学研究](https://www.litphil.sinica.edu.tw/newsletter/86/157-172.pdf)、[宋明儒学概述](https://plato.stanford.edu/entries/song-ming-confucianism/)。

并非每次改朝换代都会产生一套新教义。清代程朱、元代朱学可以延续同一礼仪，再增添当代师承和礼典；无须为了朝代齐整制造重复宗派。反过来，前代路线不会因朝代结束自动失效，可以通过经典、旧注和师承被继承或复兴。

清单分三种性质：

- **历史路线**：学说、学统或传注传统有依据，礼仪名称可能采用游戏概括。
- **复兴／跨界方案**：重建古代路线，或借用跨儒道的解释传统，须在说明中标明。
- **综合方案**：以真实思想素材组合玩法，不能冒称历史上有同名统一宗派。

下面的三信条组合是各路线的辨识草案。T01—T36 是本文件内的设计编号，尚非游戏脚本 ID；组合也尚未通过原生分歧计算。

孟、荀两条修养路线的依据见[《孟子·公孙丑上》](https://zh.wikisource.org/wiki/孟子/公孫丑上)、[孟子研究](https://plato.stanford.edu/entries/mencius/)、[荀子研究](https://plato.stanford.edu/entries/xunzi/)。性善与性恶都不能直接编码成角色天生拥有善良或邪恶人格；“起伪”中的伪指人为努力。

今古文分类包含后人的整理，参见[今古文经学再认识](https://zxyj.cbpt.cnki.net/portal/journal/portal/client/paper/9511dbcdd722bd91723bc52843db1a7f)。董氏天人谴告有[《汉书·董仲舒传》](https://www.shidianguji.com/mingju/7621669398360915994)依据；同处汉代亦有批评谴告的[《论衡·谴告》](https://ctext.org/lunheng/qian-gao/ens)。

**郑、王是祭祀分歧的优先样板。** 两条可以共享不少核心信条，由“祭天解释、郊丘关系、祖先配享”三个礼学配置产生不同仪式选择。这是礼仪内部教义与事件设计，不必硬塞成三个全新核心。依据见[北京大学《儒藏》：王肃经学及王郑礼学之争](https://ruzang.pku.edu.cn/info/1107/1746.htm)。各朝实际采用的制度仍须与经师的理论区分。

南北朝可以继承郑、王礼学和玄理解经等路线，不另造一个内容相同的“南北朝礼仪”。

| 867 历史开局 | 以经疏传统为广泛背景；韩、李路线已有年代依据。先秦及汉魏路线通过继承、文本复兴进入，不把古代师门原样预置为当世教会 |
| 1066 历史开局 | 周、张、二程、王安石等思想正在发展；允许早期路线及师承，不能预置成熟朱学、陆学或阳明学 |
| 1178 历史开局 | 朱、陆可呈现鲜明路线；洛、关、新学等继续共存。不能把朱学提前设成全儒家唯一正统 |
| 13—15世纪 | 宋代路线继续传承，元代朱学与草庐等按人物、文本和学统条件进入；不强制按历史年表统一改宗 |
| 明清扩展年表 | 按实际形成过程放入王门、蕺山、清学等；成熟阳明学主要晚于 CK3 通常1453年终期 |
| 架空思想发展 | 玩家可以在较早时期构建相近思想，但说明为“本局提前形成的路线”；不伪称王阳明本人或清代学派已经出现 |
| 前代路线复兴 | 以经典、师承、论礼及祭仪重建为条件；复兴的是解释与实践传统，不是自动恢复已不存在的古代组织 |

本轮列出 **R01—R36 共36项礼仪方案**；这不是34个历史上严格互斥的宗派，也不是承诺首版同时做完所有原型。

## 3. 儒家信条候选池

每张信条包含信念、实践、代价与失德后果。数值尚待原型和平衡，不将核心设计简化为税收、教育经验或永久意见加成。仁义、礼、孝等可以共同被认可；被认可不等于必须占用每个礼仪的三个核心槽位。

### 3.1 共同宗教与伦理信条

| 编号／拟名 | 信念与修养内容 | 拟议玩法及取舍 |
| --- | --- | --- |
| T01 敬天明命 | 敬天及受命者的道德责任；不同派解释天的方式可不同 | 告天、斋戒、省过；越过祭祀资格或失德后回避自省会受批评。荀学不统一套用天谴解释 |
| T02 诚敬慎独 | 无人知晓时亦须不自欺，诚连接成德与天道 | 私下诱惑、祭前整肃；隐秘失信也影响本人修养。公开献金不能抹平同一过失 |
| T03 礼乐成德 | 礼与乐调养敬、哀、和等情感 | 释奠、丧祭和雅乐准备；诚敬、节制与铺张炫耀有不同后果 |
| T04 报本敬祖 | 丧祭维系祖先、生者和家族责任 | 忌祭、告祖、丧服及追念；亲情、哀伤、费用和应尽事务之间有选择 |
| T05 正名践分 | 名号、身份与实际职责须相称 | 玩家涉及的僭号、失职、失礼争议须答辩或纠正；不做全地图名分执法 |
| T06 仁义为道 | 仁义高于财富、权势与便利 | 恤孤、救助、宽俘等承担资源或关系成本；见利忘义和滥杀破坏修养评价 |
| T07 以义匡谏 | 对父母、君主和师长的责任包含劝止不义 | 玩家主动谏诤；可能损害关系或遭惩罚。谏诤不自动授予强牵制 |
| T08 尊圣传道 | 尊奉圣贤、授业及承传成德之道 | 谒孔、受业、传书、认可师承；得真传的主张可以受到学术与德行质疑 |

共同依据见[《礼记·祭法》](https://zh.wikisource.org/wiki/禮記/祭法)、[孔子与祭礼、德性研究](https://plato.stanford.edu/entries/confucius/)、[《孝经》](https://ctext.org/xiao-jing/zh)。不会用“孝道＝父母永久无限制牵制”代替这些内容，也不把伦理谏诤改写成人人随意违礼即可获奖。

### 3.2 性论、天人观与成德工夫

| 编号／拟名 | 信念与主要适用 | 拟议玩法及取舍 |
| --- | --- | --- |
| T09 扩充四端 | 孟学：善的萌芽须扩充 | 恻隐、羞恶、辞让、是非判断的连续实践；只声称心善不增加成长 |
| T10 化性起伪 | 荀学：有意识的师法、习礼与实践成德 | 反复习礼与约束争夺；“伪”不赋予欺诈德性，也不把本派出生人物设成邪恶 |
| T11 集义养气 | 孟学：浩然之气来自持续行义 | 在已记录的义务中积累；临事违义损害积累。不能靠一次宴会获得终身大勇 |
| T12 灾异省身 | 汉代灾异经学：灾异可被理解为警告 | 已发生灾害后的告祭、问礼、罪己与解释争论；不让玩家召唤灾害，也不保证天谴是真相 |
| T13 气化同体 | 关学：气化、天人联系与民胞物与 | 丧祭中的生死解释、照料他人的责任；行动有成本，不止增加学识 |
| T14 格物穷理 | 程朱：经书、礼仪与日用人伦中探求理 | 具体伦理疑案的考察、问学与践行；不等于泛化科技速度 |
| T15 居敬涵养 | 程朱等：动静日用中持敬、约束私欲 | 持续省察骄矜、欲望和注意；不是无条件消除压力或禁止一切正常情感 |
| T16 发明本心 | 陆学：显明本心的道德根据 | 权势、章句与良心的冲突中辨大本；质疑师说须接受论辩，任性不算本心 |
| T17 致良知 | 阳明：落实良知并持续去除自欺 | 意念与实际处境相联系；不同出身人物可成为论道对象 |
| T18 知行合一 | 阳明：真知与践行相贯通 | 许诺的义务用明确记录的行动验证；空谈、失约有后果。不能宣称脚本能识别所有游戏行为 |

孟、荀与宋明来源见前述各礼仪依据。程朱实践可另参[哥伦比亚大学朱熹原典选读](https://afe.easia.columbia.edu/ps/cup/zhuxi_learning.pdf)；阳明知行见[哥伦比亚大学原典选读](https://afe.easia.columbia.edu/ps/cup/wang_yangming_knowing_acting.pdf)。T17、T18 在历史预设中不能提前成为867、1066年已经定型的王学。

### 3.3 经传、丧祭及跨时代扩展信条

| 编号／拟名 | 信念与主要适用 | 拟议玩法及取舍 |
| --- | --- | --- |
| T19 据经考礼 | 汉唐礼学、后世考礼：经据、礼器与祭序须能说明 | 郊丘、配享、丧服疑案；合理依据和诚敬共同影响结果，不以贵重礼器自动判正确 |
| T20 诸经会通 | 经传传统：多部经典相互阐发，可辨其异同 | 跨经义案、注疏选择、传书；不能一本书囊括所有圣贤真义 |
| T21 春秋明义 | 汉代公羊、清代常州等可不同解释：春秋褒贬关系于义 | 论经与现实伦理案例相连；不能无限把史论评价转成政治宣称或犯罪处罚 |
| T22 天行有常 | 荀学等：天的运行有常，道德责任在人 | 同一祈雨／灾异事件允许礼文、准备与天常解释；不因拒绝天谴而取消祭祀 |
| T23 澄心复性 | 李翱：恢复本性、诚与成圣 | 静养、澄心与返观；持久修养与逃避人伦责任区分 |
| T24 百姓日用 | 泰州：普通人的日用生活亦可成圣 | 会讲、日用伦理、向不同身份者问道；不按出身直接判德性高低 |
| T25 六艺习行 | 颜李：礼乐射御书数以亲身习行为要 | 习礼、雅乐、射礼等小型实践；身体劳作和持续训练有成本，不新增完整教育产业 |
| T26 循文见道 | 乾嘉：故训、文献证据可以通向圣贤义理 | 校勘、辨伪、考礼之后须解释伦理意义；发现伪书也可能动摇本派既有依据 |
| T27 道义事功 | 永嘉、永康等：在具体实践与效果中检验道义 | 已限定的救助、礼义抉择考虑实际后果；不能以贪财或胜利自动证明有德 |
| T28 制暴安民 | 义战、禁暴救民的历史素材；军事修会用途是游戏改革设计 | 有条件的护礼义军与誓约；滥杀、抢掠或为私利用兵违背宗教承诺，具体检查范围须验证 |
| T29 微意改过 | 蕺山：检点极微意念与迁善改过 | 私下检点、自省记录和具体补过；不成为可刷的公开认错奖励 |
| T30 义理通变 | 荆公新学、常州等：各依其经义回应时代处境；拟名为设计概括，二者传承与解释分别呈现 | 围绕经义提出有证据的变通，承受旧说争论；不回填所有晚清托古改制、大同主张 |
| T31 观象体易 | 象数易学：以象数、运行与观物理解天道 | 有范围的解卦、观物与论易；表达人物信念，不保证算命或操控随机事件 |
| T32 会通玄理 | 王弼、郭象等跨界解释为素材；拟名不代表二者同一宇宙论 | 得意、名教、自然等论辩；贵无与独化分别由礼仪教义配置呈现 |
| T33 知行相资 | 船山等：知与行互相支持、各有功用 | 问学与践行相互推进；与T18分开，不把所有知行论套成阳明的命题 |
| T34 万物生生 | 濂溪、气学等可分别解释的宇宙生成主题 | 天人、阴阳与生死解释进入祭仪、养性和责任事件；各路线保留理气差异 |
| T35 静养自得 | 白沙：通过静养与自身体认得道；与李翱复性、王学良知分别解释 | 静养、读经与自得的关系成为工夫选择；不能因安静独处就无条件成圣 |
| T36 随处体认 | 甘泉：在动静内外、具体处境中体认天理 | 祭仪与日用实践中的体认、论道；不把天理与良知等同为一个无争议命题 |

T19—T36的具体思想来源见各路线对应参考；其中机制、组合、名称抽象属于设计推论。T28的军事实践依据见[《唐会要·武成王庙》](https://www.shidianguji.com/mid-page/7620561956860100646)；该史料不能证明当时已有欧洲式宗教骑士团。

T02与T29、T11与T13、T18与T33存在相关内容，但代表不同侧重；原型发现重复时可以合并事件模板或改为礼仪内配置，不能堆叠相同奖励冒充内容量。

## 4. 教义配置：把三核心以外的真实差异放进宗教

| 设计轴 | 候选值或内容 | 设计边界 |
| --- | --- | --- |
| 经典与解释权威 | 五经／多经传注、四书中心、故训证据、微言大义、师承论义 | 可以兼采；不强制经学与义理互斥 |
| 天人解释 | 天人感应、天行有常、理气与天理、气化生生、心理相贯 | 这不是五套必然互斥的神谱；细分是否采用排他教义组须做原型 |
| 祭天与祖先配享 | 郑氏、王氏及其他考定的解释 | 资格、礼典、祭祀对象与配享分别处理；经师理论不等于每朝实际制度 |
| 性与成德 | 扩充、师法化性、复性、涵养穷理、发明本心、良知实践 | 不直接给人物套善恶人格；后世引用古说可有不同理解 |
| 家礼与孝 | 照料、丧祭、诚敬、谏诤；礼典可不同 | 不授父母无限制永久牵制；反对不义也不能自动抵消其他失礼 |
| 学统与传承 | 经典与德行、师门认可、朝廷认可、奉祀世系 | 不把学派宗师、孔氏后裔与天子合成一种权威 |
| 对佛道与民间祀俗 | 批评出世、允许兼采、礼典筛选、具体论辩 | 依派与时期变化；不把全部儒家设成三教合一或永久全面仇视 |
| 文武与义战 | 礼义约束用兵、无常设宗教军、护礼义军、改革军事修会 | 和对其他宗教的相容性分别配置，不能一条信条捆绑全部结果 |

新增教义组和值均为候选。已有脚本提供同组继承与覆盖，但某项能否被独立读取、能否附带对应效果仍须验证；目录中有一项不代表引擎已经存在该项。

## 5. 宗教领袖与礼仪领袖清单

儒家可以有明确宗教与礼仪权威。历史上没有普遍照搬教宗的单一组织，并不意味着应取消所有领袖。

| 编号／权威 | 历史依据 | 拟议职能 | 权力范围与承载 |
| --- | --- | --- | --- |
| L01 国礼宗主 | 天子亲祭及官员代祭传统 | 主持国家祭礼、认可礼典、处理其承认范围内的礼议 | 朝廷或承认其礼统的共同体；不能默认控制世界所有儒者 |
| L02 礼仪主持者 | 太常、礼官、太祝等仪式职责 | 筹备与主持仪式、解释祭序、考礼、拟定祝文 | 一次祭仪或本朝礼务；职位名称随时期配置 |
| L03 奉祀领袖 | 孔氏后裔的守祀与受封 | 曲阜孔庙及相应世系的奉祀、礼物保管与仪式认可 | 南宗按时期另设；不当然管辖各地学宫文庙，也不拥有全部儒家经义裁判权 |
| L04 学统宗师 | 师承、著述、讲学与德行认可 | 授业、承传、论礼、认可学说与传人；可被质疑 | 某礼仪或师门认可范围；不是血统永久世袭教宗 |
| L05 共尊宗主 | 以真实礼统素材构建的可选架空制度 | 共同体明确共尊一位宗主，可尝试承载原生宗教领袖功能 | 属宗教改革设计；需先证明原生全faith权限与继承适合 |

[《新唐书·百官志》](https://zh.wikisource.org/wiki/新唐書/卷048)明确记太常寺的礼乐、郊庙、社稷职责及太祝等分工。[皇帝亲郊研究](https://iahs.fudan.edu.cn/info/1010/2476.htm)支持国家祭祀权威与代行礼务的区分。孔氏1055年改封衍圣公见[孔子博物馆资料](https://www.chinakongzi.org/cbpj/202105/t20210525_517313.htm)；867年不能使用1055年才出现的这个爵号，应按当时封号配置。

孔氏奉祀范围与官员主持的国家、地方学宫释奠分别处理，参见[曲阜文博：孔庙的发展与奉祀差别](https://qfwbw.cn/wbjy/rxlt/2016-03-23/1156.html)。

**每个主要礼仪均设计 L04 的宗师或传承主持方案。** 原生“礼仪领袖”接口能否完成任命、继任和权限，列为优先原型；若不足，以实际角色、师承关系与事件职能承载，清楚区分这与原生头衔。也允许分散师门或多人争传，不强迫每一派在历史上都曾有唯一总领袖。

L01—L04可以并存，彼此争议是宗教内容。主张礼典、师承或从祀资格的影响力不自动扩成宣称分发、赦免所有犯罪或无限抽取贡金。

## 6. 军事修会与义战清单

**不再采用“所有儒家礼仪一律禁止军事修会”的设计原则。** 每条礼仪都有可评估的军事教义路线，但是否建立常设组织，应由宗教改革、危机和组织条件决定。

| 编号／方案 | 地位 | 玩法条件与用途 |
| --- | --- | --- |
| M01 礼义约束用兵 | 跨派可接受的普通伦理；不等于已有军事修会 | 祭告、出师与禁暴救民誓约；军事实践仍用普通游戏机制 |
| M02 护礼义军／义勇社 | 以义兵等素材借用holy order的游戏抽象 | 防护共同体和祀所；要求组织资源、授权和誓约。原生可参战对象须验证 |
| M03 儒门义战修会 | 明确的架空宗教改革 | 玩家推动常设军事组织、地产与领导、师承或朝廷认可；须承担不义用兵的后果 |
| M04 不立常设宗教军 | 合理可选教义 | 继续认可义战与军事礼制，由普通军队承担；不是宣称该派全部反战 |

历史上有武庙、出师祭告和义兵、乡兵等制度素材。[《唐会要·武成王庙》](https://www.shidianguji.com/mid-page/7620561956860100646)、[《宋史·兵志》](https://zh.wikisource.org/wiki/宋史/卷192)可支持相关素材；这些组织不能直接作为真实宗教骑士团的存在证明。

M02、M03的原型须核对：创建条件、租地、供养、领袖、同faith不同rite使用权、可参与战争及AI原生入口。原生holy order未必能参加普通同教内战，不能先许诺它可以随时守边、平乱或执行所有护民战争。开放军事修会也不自动开放大圣战。

## 7. 宗教实践与共同叙事清单

| 编号 | 内容 | 核心目的 |
| --- | --- | --- |
| P01 | 敬天、告天与斋戒 | 天人观、祭祀资格与受命者省身 |
| P02 | 告祖、忌祭与丧祭 | 祖先、生死、哀与敬；各礼学解释可分歧 |
| P03 | 释奠、谒孔与尊圣 | 圣贤传承与诚敬，不只是文化声望 |
| P04 | 问礼、考礼与配享争议 | 郑王等路线具有真正仪式差别 |
| P05 | 受业、传书与道统论辩 | 宗师权威、经典解释与传承 |
| P06 | 居敬、慎独、静养及改过 | 自我修养进入隐秘意念与具体行为 |
| P07 | 四端、养气、习礼、穷理、良知 | 不同礼仪有不同成德路径 |
| P08 | 从祀与贤者纪念 | 德行、传承、资格与争议；与原生封圣、圣物功能分别核对 |
| P09 | 出师祭告与义战誓约 | 将文武纳入宗教伦理，但不重复实现军队控制 |

书院作为讲学或受业的场景即可。义庄、科举、官僚、财政、地产经营与朝贡扩张降为外围关联，不作为本次宗教重构的开发主线。

## 9. 实现前必须验证的代码边界

1. 原版结构是一个confucian_faith及经学、道学两个rite。宗教层的同组教义会被继承；仅在新礼仪里漏写一项，不等于删除父层默认。
2. 原版核心为经学“仁政／孝道／安居乐业”、道学“仁政／孝道／格致”。本清单将其重构为可组合池，保留贴切的伦理素材并改变具体玩法。
3. 创建分歧达到100会创建新faith；异端基础阈值为65，实际门槛须读取faith.heresy_threshold及领袖狂热修正。大量未知核心可能造成分裂，不能先承诺36条必定同faith且相互正信。
4. 共同认可池、信条局部分歧倍率可以作为原型工具；不通过修改全游戏阈值解决本mod的学派关系。
5. 圣地在faith层。各派可以有专属谒学、讲学或纪念地点，但不能假称每个rite天然拥有独立五圣地。
6. 宗教领袖教义组的main_rite标记是界面警告，不足以证明附属礼仪绝对没有领袖；实际任命与权限须看脚本和实机。
7. “法界圆融”同时提供相容性与immaterial_harmony_no_holy_orders。须用同组新方案分别处理，不能直接删去相容性来顺带开放军事修会。
8. 骑士团若检查faith参数而非角色rite参数，单个rite覆盖可能不能产生预期效果；创建和征用分别验证。
9. 孝道永久牵制涉及出生时的父母与子女参数及已存钩子，须分别处理；个人核心替换不足以证明清除礼仪继承参数。
10. 项目现行新增主动内容限玩家发起。仅给新事件加is_ai=no不会阻止原生AI改礼仪、继承传播、创建领袖或军事修会；共享宗教的被动效果也不因此只作用玩家。实施时须单独验证配置隔离与原生入口，不能把目录设计视为已经满足限制。
11. 自省、知行和军事誓约只核对明确接入的事件与原生状态；不存在尚未实现的全游戏道德识别器。
12. 所有效果和UI、存档/DLC组合均待1.20.0.3原型验证。本次仅新增设计文档，静态研究不等于游戏验收。
