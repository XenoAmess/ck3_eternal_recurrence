# 自动升级建筑维护版：2.0.0 发布本地化审阅

日期：2026-09-12（Asia/Shanghai）

## 范围

- 发布语言保持简体中文、英文、法文、德文、日文、韩文、波兰文、俄文和西班牙文。
- 二期只改动一项玩家可见范围说明：`enable_auto_build_text`。中英文由当前执行者直接编写和审阅；其余七语各更新 1 项，共 7 项。
- 新文案说明五类适用地产、主／普通／公国／特殊建筑、复合资源费用，以及住所、游牧／牧民、曼荼罗都城 Great Project、在建地产和终级建筑的排除边界。

## MiniMax-M3 候选与人工处置

- 调用前只确认 `MINIMAX_API_KEY` 已配置，没有读取、输出或记录其内容。
- MiniMax-M3 只收到该单一 key 的英文值、简体中文参考、目标语言、简短 CK3 tooltip 语境和保护 token；它没有分析项目、选择文件、修改代码或判断验收结果。
- 法文、波兰文和西班牙文候选通过调用器的严格 JSON/key/token 门；当前执行者随后修正了地产、部落、住所和建筑类别术语。
- 德文、日文、韩文和俄文候选在最多两次尝试后仍改写了受保护的 `Mandala` 或 `Great Project`，被调用器拒绝且没有直接落盘。这四语由当前执行者依照既有文件风格手工更新。
- 所有七语最终文本均由当前执行者复核 key、换行、专有名词、费用与包含／排除方向；不把同一模型重试视为独立审阅。

## 自动检查与边界

- 九份文件保持相同的 10 个 key、四行／三处 `\n` 结构和 `CK3 1.19.0.6`；英文及七种外语各保留两处 `Mandala` 和一处 `Great Project`，简体中文使用对应中文术语；无英文整值占位。
- `tools/test_translate_localization_minimax.py`：26/26 GREEN。
- `tools/validate_auto_upgrade_buildings_static.py`：GREEN，165 条链、605 条适用边、15 文件正式 allowlist。
- 法、德、日、韩、波、俄、西完成结构、保护 token 和明显语义审阅，但没有母语者签核；不声明母语级润色或逐语言实机截图。
- 简体中文运行入口及二期玩法由 R0024 正式 CK3 GREEN 覆盖；七语修改只影响同一 tooltip，不改变运行脚本。
