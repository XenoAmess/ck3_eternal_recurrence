# 《礼与道》：儒家宗教与礼仪重构规划书

更新：2026-10-04。游戏基线：本机 Steam CK3 1.20.0.3。
状态：设计与历史研究；尚未实现或完成实机验收。

本规划依据[儒家与基督教机制对比](ck3-religion-confucian-christian-comparison-1.20.0.3.md)，并按用户最新要求重写：重心放在**儒家作为宗教的天人观、祭祀、圣贤、经典、成德工夫、学派礼仪、领袖与义战**。先秦至明清的主要路线都进入设计，书院与国家制度仅作为相关场景。

具体条目、36项礼仪方案和36张信条候选见[儒家礼仪与信条设计清单](ck3-confucian-rites-and-tenets-design-list.md)。礼仪、信条、人物职能与效果均为拟议方案；原生已经存在的功能、设计推论和待验证能力分别说明。

## 1. 产品目标与基本结构

玩家应当能够回答：我如何理解天与鬼神？为何祭祖、祭孔？我依哪些经典与圣贤传承成德？与别派的差异落在何种修养及祭礼？谁能主持、解释或认可我的礼仪？如果用兵，礼义怎样约束它？

采用以下结构：

| 层级 | 主要内容 | 设计原则 |
| --- | --- | --- |
| 儒家共同宗教 | 天、天地、祖考、鬼神、圣贤、礼与成德 | 不强迫所有儒者共享同一套晚期民间神谱，也不统一改写为现代无神论 |
| 共同信仰及认可池 | 尊孔、经典、报本、礼义及可互相理解的信条 | 容纳争论与兼采；共同faith的敌意、分歧仍按实际代码验证 |
| 学派礼仪 | 经传解释、祭祀解释、性论、工夫及学统 | 主要历史学派可以用rite承载，不再限定经学／道学两条 |
| 礼仪内配置 | 郑王祭天解释、程颢程颐差异、王门内部分歧、清学兼采等 | 不把每位思想家或每个地域名都自动做成新教会 |
| 宗教权威与实践 | 国礼、奉祀、宗师、礼官及具体祭修活动 | 职能有实际用途；权限与认可范围清楚 |
| 可选宗教改革 | 共尊宗主、义战修会、提前形成新思想等 | 明确标为本局发展或架空制度，不冒称普遍史实 |

“礼仪”是CK3承载思想、祭修与传承的玩法抽象，并不是说历史上的各学派都曾有各自的教会。主目标是保留儒家共同信仰；大量独特核心可能触发原生faith分裂，须先做分歧原型再确定最终数据。

## 2. 为什么要改原版经学与道学

经学是广泛的经典解释传统，朱熹、陆九渊及清代学者也研究经典。道学具有特定历史语境，与广义理学有重叠。狭义理学常指程朱，心学常以陆王为两大代表，但陆学与成熟王学不能按年代混为一条既成宗派。依据见[经学与宋明理学研究](https://www.litphil.sinica.edu.tw/newsletter/86/157-172.pdf)、[宋明儒学概述](https://plato.stanford.edu/entries/song-ming-confucianism/)。

因此保留原版经学、道学的脚本ID以研究兼容，但改变其内容定位：

- **jingxue**：优先作为经疏／经传礼学的兼容入口，不再声称全部经学排斥义理思辨。
- **daoxue**：用于早期道学传承或兼容配置，不直接把1066年的全部儒家改成成熟程朱。
- **新增礼仪**：先秦孟荀、汉魏经礼、唐代复兴、宋元诸学、明代王门及清学等按[完整目录](ck3-confucian-rites-and-tenets-design-list.md#2-跨朝代礼仪目录)分批建立。
- **时代处理**：前代学说可以继承或复兴；成熟阳明与清学进入延长时间线或明确的架空思想发展。王阳明1472—1529，不能作为867年既成学派。[王阳明研究](https://plato.stanford.edu/entries/wang-yangming/)

每朝不必另造一套重复教义。元、明、清的朱学可以延续同一rite；吴澄会通、阳明、颜李、常州等有鲜明区别的路线另立候选。1066、1178分别表示当时可成立的思想阶段，不能用后世正统回填。

## 3. 宗教世界与共同教义重构

### 3.1 神圣叙事和宗教文本

原版儒家文本混用了玉皇大帝、盘古、女娲、文昌、关羽、孙悟空、魔罗、阎罗王等。地方祭祀与儒家实践确有交叠，但这份统一神谱不能直接作为所有时代、学派共同的标准教义。

新叙事以**天／昊天上帝、天地、祖考、鬼神与圣贤**为共同基底，再由学派、礼典和时期解释。祭祀有其资格和对象，先贤、山川、社稷、祖先也不是同一种人格神。[《礼记·祭法》](https://zh.wikisource.org/wiki/禮記/祭法)提供祭祀对象及资格素材；鬼神也可以进入气化与诚敬的解释，参见[《正蒙·太和》](https://zh.wikisource.org/wiki/正蒙/01)、[《朱子语类》卷三](https://zh.wikisource.org/wiki/朱子語類/003)。

| 当前问题 | 设计目标 |
| --- | --- |
| 神名、恶神与死后世界错配 | 移除魔罗、孙悟空等作为全儒家固定神学角色的用法；具体民间或晚期故事另按语境使用 |
| 单一多神标签概括全部儒家 | 采用更贴切的天地鬼神叙述；原生单／多神教义与新增神观的组合须验证，不简单换成西式一神教 |
| 经典仅以几本统一模板出现 | 按五经传注、三礼、四书、春秋经义等差异呈现实际阅读与权威 |
| 礼仪文本只剩治国或读书能力 | 说明如何祭、如何成德、如何理解天人及承传圣道 |
| 不同学派一律同样相容或排外 | 允许批评、兼采和祀典筛选的不同配置，不夸成完全隔绝或天然三教合一 |

历史儒者对佛道的批评及吸收都应保留。宗教相容、祭祀资格、对某种思想的批评分别设计，不把论辩自动变成对所有异教人物永久仇恨。

### 3.2 共同信条、德性与罪恶

原版“仁政、孝道、安居乐业、格致”并非全部毫无儒家基础，但组合过于概括，尤其缺乏祭修工夫和真实学派差异。重构采用[36张候选池](ck3-confucian-rites-and-tenets-design-list.md#3-儒家信条候选池)，先落实敬天、诚敬、礼乐、报本、仁义、谏诤与尊圣，再以孟荀、气化、穷理、本心、良知等分出路径。

德性评价以**仁、义、礼、智、信及诚敬实践**为准，不只奖励学识。原版慈悲、公正、诚实与博学可以保留合适部分；勤学并非自动成圣，懒惰与特定恶行的罪恶等级也不能无解释地照搬。罪恶特质、具体失德、原生法律上的犯罪须分开。

优先纠正孝道的永久牵制表现。孝包含照料、丧祭、敬与谏诤；不义之命可以劝止。[《孝经》](https://ctext.org/xiao-jing/zh)可为此提供依据。删除牵制参数、迁移已存钩子及父母子女各自的礼仪条件须分别验证，不能只替换个人核心就宣布问题解决。

### 3.3 宗教职业

保留在家、婚姻与礼官服务的历史空间，主要职能改为主持祭仪、解释礼典、授业和传承。现有“税务型神职”不能直接概括这些职责。

这首先是角色职能与宗教实践设计，不预设引擎已有“儒家教育神职”枚举。太常、太祝、祭酒与宗师的职责不同，不能全部换成一个教宗或宫廷祭司名称。

## 4. 礼仪设计：先有真实差异，再组合三核心

完整目录包括孔门、孟荀、公羊／董氏、古文、郑王礼学、经疏、韩李、宋元诸学、白沙、甘泉、王门、蕺山、船山、颜李、乾嘉汉学、常州等，也列有明确标注的跨界与综合方案。

宗教辨识样板：

| 对照 | 主要玩法差异 | 不能写成的简化 |
| --- | --- | --- |
| 孟氏／荀氏 | 扩充四端和集义养气／师法习礼、礼乐养情 | 天生善良人物／天生邪恶人物 |
| 郑氏／王氏 | 天帝、郊丘及祖先配享的不同解释 | 一个读书快、一个税收高 |
| 韩氏／李氏 | 仁义传道／复性与澄心工夫 | 都是同一种“反佛儒教” |
| 程朱／陆氏 | 居敬穷理与家礼／发明本心与立志改过 | 理学只读书／心学不读书、任性即道 |
| 阳明／江右／泰州 | 良知实践及其不同工夫、普通人日用成圣 | 一条王学加三个不同名字 |
| 乾嘉／常州 | 文献故训明道／公羊微言大义与通变 | 前者无义理、后者全都相信谶纬 |
| 颜李／其他实学路线 | 亲身六艺习行与道德实践 | 新增一个教育或兵种增益包 |

郑王祭礼差异有明确经学依据，见[北京大学《儒藏》研究](https://ruzang.pku.edu.cn/info/1107/1746.htm)。各路线允许共用信条，由教义解释、礼典、实践及学统产生区别；不能为凑满槽位强造完全排斥的神谱。

同faith各rite的三核心采用共同认可池及局部调节原型。实际分歧、异端、主礼仪变化与双向敌意是最终配置门槛，不凭“同属儒家”假定它们自动正信。

## 5. 宗教领袖与礼仪领袖：明确保留权威

上一版把“无领袖”保留得过快。儒家应有可发挥作用的宗教与礼仪权威，关键是职责与认可范围。

| 权威 | 拟议功能 | 设计边界 |
| --- | --- | --- |
| 天子／国礼宗主 | 国家祭礼、礼典认可与礼议 | 不能默认全球所有儒者服从一个王朝 |
| 太常、礼官、太祝等 | 考礼、拟祝、筹备与主持仪式 | 职位随时期；不自动成为最高经义裁判 |
| 孔氏奉祀领袖 | 曲阜孔庙及相应世系奉祀；南宗按时期处理 | 不当然管辖各地学宫文庙或全部道统；1055年前不用衍圣公称号 |
| 学统宗师／礼仪传承主持 | 授业、论礼、认可著述与传人 | 依师承和德行认可；可有多家争传、分散师门 |
| 改革后的共尊宗主 | 尝试承载原生统一宗教领袖 | 明确的制度建设；须验证全faith权限、继承与跨国影响 |

礼官职责见[《新唐书·百官志》](https://zh.wikisource.org/wiki/新唐書/卷048)，孔氏封号见[孔子博物馆资料](https://www.chinakongzi.org/cbpj/202105/t20210525_517313.htm)。国家祭祀与学统传承是不同来源的权威，不因现代“儒家是否宗教”的定义争论而全部删除。

原生faith领袖是信仰范围的对象。把皇帝直接设为它，可能产生跨国权威、继承和改朝换代问题；每派的任命也不能只凭head_of_rite字段存在就宣布完成。因此将**原生宗教领袖、原生礼仪领袖和mod角色职能**分开原型，主要学派都有宗师方案，国礼及奉祀都有实际功能。

“未能确定某个任命接口”应落实为技术调查与原型任务，不作为取消领袖的史学理由。

## 6. 军事修会：取消一律禁止的设计原则

原版“法界圆融”把宗教相容性与禁止军事修会绑定。设计上应拆开：与其他信仰相处的态度，不等于没有组织义军或军事修会的可能。

历史有武庙、出师祭告、义兵与乡兵素材，儒家义战也有禁暴救民的伦理表达。[《唐会要·武成王庙》](https://www.shidianguji.com/mid-page/7620561956860100646)、[《宋史·兵志》](https://zh.wikisource.org/wiki/宋史/卷192)提供相应内容。这并不直接证明古代存在欧洲式常设宗教骑士团。

设计三条路：

1. **普通军事礼制**：祭告、出师和礼义誓约，由普通军队承担。
2. **护礼义军／义勇社**：借用holy order表示共同体护卫，是明确的玩法抽象。
3. **儒门义战修会**：通过宗教改革建立地产、领导、供养及誓约制度，是可选架空机构。

不按学派永久贴“有骑士团／没骑士团”标签；每派都可评估对应的军事教义。也保留不建立常设宗教军的合理选项。制暴安民作为可选信条，要求具体条件及违誓后果；不是所有礼仪额外免费获得军队。

原生骑士团可能限制参战敌人的宗教身份，且同faith不同rite可能共用参数和组织。原型必须分别证明创建、租地、供养、征用、战争适用和AI入口；不能承诺它可以参加所有同教内战或平乱。军事修会、普通圣战与大圣战是不同功能，分别处理。

## 7. 开发阶段与宗教实践

### P0：引擎原型及历史配置

验证礼仪继承与分歧、年代门禁、领袖任命与范围、相容性／军事修会分离、孝道钩子、玩家限定及原生AI传播。宗教领袖和军事修会属于本轮优先原型，不再无限推迟到外围制度之后。

选择经疏、荀学、郑王及朱陆作差异样板，覆盖传注、性论、祭祀与修养四类。不必先为36条做出36套雷同事件。

### P1：共同宗教与主要礼仪

完成神圣叙事、经典、德性与罪恶、本体解释；接入敬天、告祖、释奠、问礼、受业及修身的最小实践链，逐批实现先秦—唐和宋代主要路线。权威角色必须有主持、认可、传承或争论中的实际用途。

诚敬修养优先复用原生虔诚和已有表现，不先建庞大新货币。非基督教原生宗教满足度与基督教等级不同，儒家专属修养等级仅作为待验证扩展，不先承诺新增UI已可用。

从祀、追尊与纪念采用儒家语境。原版非基督教已有可用封圣、先祖及圣物入口，须核对再复用；从祀与欧洲封圣不是同一个历史制度。

### P2：元代会通、明清礼仪及改革

完成草庐、白沙、甘泉、王门、蕺山、颜李、船山、汉学、常州等，连同延长年表或架空启用配置。深化礼典差异、传承争议、从祀和有条件的军事修会。

五处原生圣地属于faith层。曲阜等共同圣地与各派谒学、纪念地点分别呈现；鹅湖、白鹿洞等可研究为活动地点，不凭礼仪目录就许诺独立圣地系统，具体地图落点亦须核查。

书院只需成为问学、讲会或受业场景。大型科举、官僚考核、财政、地产与朝贡扩张不纳入本次主线。
