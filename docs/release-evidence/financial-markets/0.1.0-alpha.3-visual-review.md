3. **发行页：通过。** 初判首屏已完整显示档位、主体、目标、费用和登记；实际参数图显示微型 20–50 切换为标准 200–10000、目标 200.00 变为 210.00，布局保持稳定。本次到底图补足经营末行的可见性，R85 的发行操作区观察缺口仅在这个 R86 新场内闭合。
4. **盘口顶齐：通过。** 市场图中买入与卖出标题约在同一高度，第一档报价也同高；不因一侧行数较少而把该侧整体居中。该结论来自实际图，并非源码固定尺寸。
5. **整体合理性：有限通过。** 六主页签为任务入口，钱包和指数固定在上方，主体列表居左，详情/交易居右；长页各自滚动。已见区域的层次、边界和操作分组足以支持本轮 Alpha 使用。
