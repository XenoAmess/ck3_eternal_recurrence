### 既有主线 RED 的归因

失败用例读取仓库生成器、简中文案、审计分片与人工审阅 manifest，并不读取本机新 CK3。
本任务的 mod / ledger 范围 tracked diff 只有 README 命令修正；失败输入仍来自上述主线基线。
因此把这些失败归为既有源码/审计债务，不能归因于升级游戏。

- **copy ledger**：现存分片 bytes/hash 与生成索引过时，缺少 `localization-029.json`；当前可见事件数为 628，旧审阅与断言为 626。人工语义审阅 manifest 已不精确匹配当前输入。
- **career HC 分片**：当前生成器产出 293 个 effect，旧冻结断言要求 271。产物逐字节一致检查先于该计数失败。
- **简中文案**：一处决议说明复述标题，一处比例政策正文重复绑定按钮文本。
- **薪酬按钮文案**：16 个标签未满足当前金额/处置措辞断言。

本工作包保留 RED 原证据，没有为兼容任务刷新人工审核、制造 approval，或修改与新版无关的内容审计。
