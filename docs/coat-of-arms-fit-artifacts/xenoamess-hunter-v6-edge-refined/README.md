# xenoamess-hunter-v6-edge-refined

这是在 v5 非晋级候选之后生成的 1024 预算浏览器候选。它保留 v4 的覆盖安全四叉树结果，再使用剩余预算在
96 px 主评分平面的边缘残差热点上执行小范围原生矩形修补；每个修补都必须同时满足“总损失不升、边缘损失严格下降”。

## 结果

- 用户预算：1,024 个绘制实例；实际实例/逻辑图层/`colored_emblem` 块：1,008 / 1,008 / 1,008。
- 总损失：`0.024123983862988356`，相对 v4 的 `0.025898240475696027` 下降约 6.85%。
- 边缘损失：`0.040769084120764576`，相对 v4 的 `0.043043678580258954` 下降约 5.28%。
- 192 px 总/边缘损失由 `0.02906832496408973 / 0.03723507697008837` 降至
  `0.02821932790046508 / 0.03687977019519137`；256 px 由
  `0.02587151755753766 / 0.030160015594588474` 降至
  `0.025158324926235386 / 0.029980690504028344`。
- 96/230/512 覆盖门禁均为零泄漏；复制后完整重新解析为 1,008 个实例，无截断。
- 原始代码 383,865 UTF-8 bytes、14,118 行，SHA-256
  `2E1614012C4159FB280F9C18958F63D587CFD363957ED12234DF213D3F634F72`。

完整报告 [report.json](report.json) 的 SHA-256 为
`946C60D6509655215417C63F125B9E84DC5327202E55AA6C4752DBE4EB23358B`。本目录仍标记
`native-roundtrip-pending`；浏览器通过不能替代 CK3 Apply/Copy 或原生 framebuffer 结论。

## 复现

pnpm exec playwright test e2e/reference-hunter-fit.spec.ts
