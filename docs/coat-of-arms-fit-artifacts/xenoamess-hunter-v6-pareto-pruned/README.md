# xenoamess-hunter-v6-pareto-pruned

本目录在 [`xenoamess-hunter-v6-pruned`](../xenoamess-hunter-v6-pruned/README.md) 的零像素差固定点上，继续执行
`metric-pareto-leave-one-out-fixed-point-v1`。这是有视觉变化的质量剪枝，与 exact 结构剪枝分开记录。

运行前固定的累计损失预算为：96/230/512 px 的总损失增量 `0`、边缘损失增量 `0`，数值噪声容差
`1e-12`。每次删除还必须不劣于当前状态；任一分辨率失败即可证明保留并短路其余昂贵重绘。

## 结果

- 输入/输出实例：1,006 → 1,003；删除 3 个可见但在三档评分上均有害的实例。
- 固定点：2 passes、2,009 个候选；最终 1,003 份必要性证据中，1,001 个由 96 px 门禁阻止删除，2 个由高分辨率门禁阻止删除。
- 96 px 总/边缘损失：`0.024123983862988356 / 0.040769084120764576` →
  `0.024011474732441213 / 0.040573889197948965`。
- 230 px 总/边缘损失：`0.019849667382907506 / 0.030110552966677882` →
  `0.019813096544771237 / 0.03008042410290529`。
- 512 px 总/边缘损失：`0.014740265590914493 / 0.0161573498225531` →
  `0.014713388869018178 / 0.016140431250088766`。
- 输出 262,138 UTF-8 bytes、9,106 行；SHA-256
  `CEFFC1E116BDD335ACECF28789A05BE3B0E1A8CA8680399A9C1E1D8734BF9EF7`。
- 与 exact 输入相比确有 96/230/512 px 的 9/51/240 个 RGBA bytes 变化，最大 byte 差 151；这些变化不被冒充“无损”，
  而由上述三档零累计损失预算约束。

报告 [report.json](report.json) SHA-256 为
`1158B3DA500B2CD8122AADD87DEEACA38B69F8C1D09742E62BE5A1F9A585A07F`。
