# 自动游玩 Agent 日/周计划会制度

计划会负责把“下一阶段要做什么”冻结为可核对的承诺账本；日报和周报负责对照结果。计划会不能替代 native evidence，也不能在
周期末倒改以美化完成率。

## 午夜顺序（Asia/Shanghai）

1. 每天 00:00 收口刚结束自然日的日报；逐项对照该日早会。
2. 日报收口后立即创建新一天的早会，路径为 `daily/YYYY-MM-DD.md`。
3. 每周一 00:00 同时收口上一 ISO 周周报；逐项对照上一周计划会。
4. 周报收口后立即创建新 ISO 周计划会，路径为 `weekly/YYYY-Www.md`。
5. 每月 27 日 00:00 更新月报及完整能力双语 show-off 视频；月报不新增独立计划会，长期入口仍由路线图、日早会与周计划共同承接。

若 00:00 没有活动会话，下一次恢复工作时必须先补录；补录文件要写真实时间，并把补录前已经完成的事情单列为 opening baseline，
不能冒充早先承诺。周期末新增任务不得篡改原计划，只能记为“计划外完成”或明确的 owner reprioritization。

## 结果词汇

| 结果 | 定义 |
|---|---|
| `完成` | 验收条件全部满足，并有对应证据或提交。 |
| `部分完成` | 有真实增量，但至少一个验收条件未满足。 |
| `未完成` | 未形成承诺的可交付结果；必须写原因。 |
| `取消` | 经所有者改优先级或前置事实变化后不再执行；不能伪装为完成。 |
