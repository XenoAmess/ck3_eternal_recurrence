## 失败尝试与学到的事实

- Event Attempt1：Windows/PhysFS 路径过长，是 harness RED；缩短 root 并增加 preflight。
- Event Attempt2：`CEventWindowData+0x2C` 实为 timeout index，不是 cancel；cancel 必须按 authored index 读取
  `CEventOption+0x47A`。这是 capability RED，未通过降低预期掩盖。
- Event Attempt3：calculated event ID/runtime stats ordinal 是 process/playset-local 数值，不能作为 seed/cold identity；它们仍须在
  单进程同帧稳定。cancel/indicator/readiness 字段本身通过。
- loaded-effect preview 在战争退出路径已有真实崩溃证据，因此完整 exit-terms v2 保持 production disabled；不以 ACK 或猜测代替 terms。
