The actual controller phase measurements separate approximately 84 seconds of observation from approximately 91 seconds of planning in the first post-recovery sample. Observation includes Native capture, frozen Driver joining, source qualification, semantic/archive validation, planning inputs and history, and Ready publication. The measurements do not identify all of that time as serialization.

One concrete repeated operation occurs in `NativeReadinessCollector.qualifyPhysical`: the same frozen complete Driver was fully encoded for the original equality check, then encoded again before its DRIVER archive publication. The collector now reuses that first complete byte array within this one callback when the actor ID has the exact `BigInteger` class. Its first encoding remains after the original stamp guard. Conditional encoding of the separate facts Driver and every dynamic source, pin, frame, Native, head, FileStore and archive call remain in place. There is no cache across a call, frame, request or Session.

The exact-class restriction matters because `BigInteger` can be subclassed. For that existing compatibility branch, the full encoding still occurs at its original later position: after semantic encoding and before semantic preservation. An earlier candidate compiled successfully but was rejected as a complete source-equivalent candidate because it reused bytes unconditionally. Its actual compiler result is preserved separately, not described as a compiler failure or a zero-JVM attempt.

The corrected source passed independent review and its own necessary one-translation-unit compilation: 38 classes, 6.3632524 seconds, zero errors. All 38 class structures were unchanged, with no new type, field or method. Four source spans invert exactly to the currently installed collector that includes the retained-planning read fix. This removes one redundant full encoding on the ordinary exact-class path. Runtime loading and measured speed remain separate; the change does not establish that serialization explains the entire observation duration.
