# 自动游玩 Agent 月报规范

月报是项目唯一固定要求配套视频的进度报告。日报与周报只交付文字；它们以及阶段性录像为月报提供索引和素材，但不承担
视频交付门槛。

## 节奏

- 截止时间：每个自然月 27 日 00:00（Asia/Shanghai）。
- 文件：`monthly/YYYY-MM.md`。
- 首份月报以项目迄今的累计能力为基线；此后每份月报同时总结上次截止以来的增量和当前完整能力快照。
- 若月报正文已经完成但成片仍在生成或重制，状态写“未完成/重制中”；只有成片及抽检全部通过后才能写“已交付”。

## 正文最小内容

- 本月完成了什么、正在做什么、为什么做；
- 截至截止时的全部能力清单、严格 evidence 等级与每项诚实边界；
- 测试、production/fixture live artifact、RED 与未闭合观察口；
- 下一月主线、相关 commit/push；
- 按最新用户授权记录宗教/战争研究及普通战役与独立机制实验边界；dated历史owner-deferred只保留其当时语境，不恢复为当前限制。

## 配套视频

- 英语为主叙事与主要视觉层级，简体中文作为画面内字幕/副标题。
- 覆盖截至月报截止时全部真实能力；不能把固定视觉脚本、fixture、schema 或 ACK 冒充 production OODA。
- 中文字幕先按句意断句，再按字体、字号与字幕安全区测量实际渲染宽度并自动换行；禁止越界、裁切或覆盖关键证据。
- 抽检至少包括：可解码、时长、分辨率、帧率、音视频编码、中文字体、字幕安全区、关键能力场景、证据等级与最终边界卡。
- 月报记录成片与 sidecar 路径、精确字节数、完整 SHA-256、关联 evidence 索引和被废弃版本原因。

模板见 [`TEMPLATE.md`](TEMPLATE.md)，媒体细则及成片索引见 [`../demos/README.md`](../demos/README.md)。
