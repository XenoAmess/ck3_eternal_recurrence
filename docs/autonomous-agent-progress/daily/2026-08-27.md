## 为什么做这些

事件窗口会中断战争、经济和长期时间推进。智能体只有知道当前真实展示的选项、合法性、身份与后果，才能在多选事件中做
高质量决定；默认第一项、OCR 或 authored count 都不能构成可靠 OODA。Attempt4 先验证 current-window observation transport，
随后仍需补完整 effect/scopes 才能解除 `readiness.semantic_decision_ready=false`。

统一进度目录则用于防止窄 native 里程碑、fixture GREEN 或大量测试被误写成“完整 CK3 智能体已经完成”。
