# 度假交接证据

本目录只保存未合入候选及收尾回执，不应用或执行任何候选。全部状态以原始报告为准。

INDEX.json 逐件列出外置来源、原始字节数与 SHA-256、gzip 对象及解压后 SHA-256。objects/*.bin.gz 是惰性档案；解压还原到新的外置目录后，再根据目标包 EXPORT/APPLY-MANIFEST 做增量集成。绝不可把压缩对象或过时的共享文件副本直接放入生产目录。

R11/R12 和已整合 L0 的旧档案不重压缩；大存档与 DLL/EXE、原始构建目录继续留在外置 runtime。I4 只保留索引与报告，原 016 payload 仍在外置目录。
