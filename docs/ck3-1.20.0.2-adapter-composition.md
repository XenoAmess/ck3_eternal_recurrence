# CK3 1.20.0.2：原生适配器组合

2026-10-02 授权更新：项目所有者已全面开放 faith/religion、rite、doctrine、tenet、fervor、改宗、宗教改革、clergy、holy order、圣战与大圣战的深入研究与实现。下列冻结记录中的旧宗教暂缓仅保留当时事实，已全部撤销；详见[当前授权](../AGENTS.md)。2026-10-03 项目所有者已取消全部非战限制，全面授权战争与战斗的研究、原生观测、实现、策略及实机执行。 旧战争研究停止及执行 OFF 仅为当时记录，已失去授权约束效力。原生 AI 研究优先、exact-build 绑定、Robert 29829 原普通战役唯一入口、玩家限定及最小化/不抢焦点继续执行；授权不代表能力已完成。

后续施工入口：先沿[宗教整合](ck3-native-ai/ck3-1.20.0.2-religion-integration.md)、[教义与Tenet](ck3-native-ai/religion_doctrine12002_overview.md)和[改革](ck3-native-ai/religion-reform12002-overview.md)的原生树与已有只读查询补齐当前exact-build输入；自然宗教事件按真实选项、作用域与效果接回事件消费者。Holy order等未闭合分支继续定位原生资格、成本、对象状态及结果查询，先交付只读bridge/MCP，再据罗贝尔paused材料设计和验证策略；旧版实机证据不自动继承。

本包将已完成迁移的 1.20.0.2 原生模块组成同一个 `GameAdapter`，保留 1.19.0.6 的独立实现。注册表以游戏 EXE SHA-256 精确选择版本；未知构建保持禁用，以新版本描述符提供诊断。构造与选择只计算当前模块地址，不访问游戏状态。

新版候选身份为 `ck3-1.20.0.2-msvc-x64`，版本 `1.20.0.2`，EXE SHA-256 为 `AE1BA6FF060BA603842F6F4A2DED0AF4B7D3666B3DD271F75FB01B0DA8E81B2D`。固定 checkpoint 名称继续使用 `xar_checkpoint`。

`read_snapshot` 在同一 owning-thread 事务中读取时钟、玩家和完整角色 ID、婚姻关系、当前事件、待处理互动、战争、军队、目标省份和死亡结算。先构造局部快照，全部必要域可读取后才返回完整结果。世界读取为 `partial`、事件依赖不可用或死亡结算 payload 非法时，整个读取返回 false，不能把这些失败包装成空战争、无互动或零分结算。Mod 尚未发布结算时的 `not_published` 是合法状态。

主菜单和加载期间沿用已知 local-player sentinel：`map_ready=false` 时只发布时钟与玩家前缀，不遍历尚未初始化的类别注册表。它不代表这些游戏域已进行实机观测。

事件与军事命令借用适配器成员中的 `CommandBindings`，构造时重新绑定回调 context，避免地址计算返回的临时依赖包留下悬空借用。婚姻、宣战、结束战争、军队强度和战斗输入直接调用新版私有 bindings。桥接层负责把需要原生查询或 validator 的工作送到新版主线程 mailbox。

本包冻结的候选描述符含 61 项能力。旧版 62 项中，完整 combat v3 的宗教输入当时受项目所有者暂缓约束，因此该轮不广告该完整能力；该限制已于 2026-10-02 撤销。缺失的宗教/rite输入仍需从当前 exact-build 的 phase/advantage 原生构造链补齐只读 producer、组合入口及实机互证，现有非宗教组合入口继续保留其内部诊断与迁移范围，不能直接改成完整v3 ready。之前已有原生访问违例证据、生产禁用的 war exit terms v2 继续禁用，并返回具体原因，未被重新广告。

本包测试使用完全由 fixture 自己持有的对象和函数。`ck3_12002_adapter_test.cpp` 覆盖跨模块完整快照、目标省份、完整结算、世界 partial 与非法结算失败、合法未发布结算、菜单前缀，以及依赖包销毁后事件和速度命令继续通过成员回调提交。`game_adapter_test.cpp` 新增新旧两个真实工厂的精确 SHA 选择及未知构建禁用检查。初次 MSVC `/std:c++20 /W4 /WX /UNDEBUG` 编译通过；最终 fixture 执行与 DLL 构建结果由本轮统一迁移验收记录收录。

以上是磁盘静态迁移与离线 fixture 工作。没有访问正在运行的 CK3，未执行注入、输入、存档写入、关闭或重启，也没有据此声称新版具备 live readiness。
