## 有实证的新版问题与修复

修复前的开发政府覆盖去掉 barter 后等同旧版原版，与新版不等同。
旧覆盖会丢掉新版的行政机制和新增能力，不能只修改版本字符串后继续使用。
该结论来自已保全的 `audits/standalones.json` 政府语义 diff，不依赖旧 native bridge 在新 EXE 上运行。

修复直接取新版原版的完整 `celestial_government` 块，再在 `government_rules` 中加入一项 barter：

- 用新版 `mechanic_type = administrative` 替代旧 `government_rules` 中的 `administrative = yes`。
- 保留 `treasury_vassal_development = yes` 和东亚庄园标记。
- 保留天朝官僚、俸禄、军事与部院预算标记。
- 保留 AI `use_legends = yes`。
- 保留可授予封臣的 `theocracy_government` 与 `ecclesiastical_government`。

除唯一 barter 规则外，政府 semantic tokens 与安装原版精确一致。
原版 `celestial_obligations` 新旧提取块及语义均相同；mod 的 obligations 文件也逐字节等于本工作包开始时的 Git HEAD，
因此本次没有改税率基线或四档贪腐扣减。
