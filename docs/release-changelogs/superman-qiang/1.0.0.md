## 玩家可见新增

记录游戏明确结算的性行为，只处理年满18岁、在世角色；玩家和AI采用同一规则。双方以本次行为之前的性经验比较，经验较多者尝试从经验较少者吸取随机一项外交、军事、管理、谋略、学识或勇武。经验相同则不吸取，双方依然记录本次经验；匿名对象事件只记录已知成年角色的经验，不创造属性来源。

成功时，同一项吸收/流失的属性修正严格守恒：接收者增加1点，来源者减少1点，不改写角色的基础能力值。最终属性仍受原版百分比修正、取整和勇武惩罚抵消等规则影响，界面变化可能并非恰好增加或减少1点。来源者当前显示为0的属性不参与抽选；接收者当前显示为0也可以接收。本模组每项累计的属性修正限于-1,000,000至+1,000,000点，无法转移的边界项跳过；没有可转移项时不吸取，经验仍照常记录。

每位角色用独立变量随存档保存经验，上限为92,233,720,368,547次，达到上限后保持该值。提供只读角色交互与经验特质持有人说明；查看不增加经验、不触发吸取。
