## 玩家可见变更

- 健康加入随机吸取池，与外交、军事、管理、谋略、学识、勇武合计七类；当次合格类别等权随机，每次仍只转移一类。
- 抽中健康时，吸收者增加0.00075原始健康修正，来源者减少同量。来源当前健康不足3.00075或任一方该次账本变化越界时，健康不参与抽取；其他合格类别仍可抽取。
- 0.00075略低于原版25岁起始衰老参数折算的一个月期望健康损失。它是平衡基准，不能保证实际寿命最多或恰好改变一个月。
- 右键“查看性经验”直接显示原生通知气泡，无需再次确认，展示目标次数、六项能力的当前值与累计净变化、五位小数的健康读数；移除原先的详情事件大窗，缩短特质说明。
- 工坊封面改为一位成年国王与一位成年王后。重做宣传插画、七项规则图和中文介绍；实机展示使用正常游玩的勾引成功事件及新的经验通知，插画明确标注为规则示意。

## 存档与兼容

可继续使用1.0.0存档。性经验和六项能力账本保持；缺失健康账本按0读取。健康以独立小数账本与正负modifier保存，不改写基础健康，原版健康惩罚抵消继续生效。

经验较多者吸取、平手不吸取、双方各记录一次、存活及18岁限制、匿名对象仅计数等规则保持。单项原始修正账本仍限于±1,000,000；多人、Ironman、成就及全部DLC组合尚未验证。与同时覆盖两条原版性行为结算effect的模组需要合并接入点。目标版本为CK3 1.20.*，本次实际游戏为1.20.0.3。
