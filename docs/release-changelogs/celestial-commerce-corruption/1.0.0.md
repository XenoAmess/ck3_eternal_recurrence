## Player-visible changes

- Restores CK3 1.19's native barter/trade eligibility for `celestial_government`.
- Adds a recurring corruption-policy decision for landed celestial officials with four persistent tiers.
- The four tiers reduce the normal 75% celestial tax rate by 5, 10, 15, or 25 percentage points, leaving 70%, 65%, 60%, or 50% respectively.
- Corruption supplies barter output while imposing corresponding merit, popular-opinion, stress, and governance costs.
- Adds AI personality weighting, a temporary clean-hands option, and a permanent opt-out.
- Includes Simplified Chinese, English, French, German, Japanese, Korean, Polish, Russian, and Spanish localization. Only Simplified Chinese is claimed as live gameplay/UI tested; the other languages passed release-level static audits.

## CK3 1.19 compatibility repairs

- Removed the upstream full `feast.txt` override. Vanilla 1.19 already routes feast costs through barter and the old file deleted current activity, house-aspiration, accolade, background, and free-feast behavior.
- Removed the upstream full `window_county_view.gui` override, which would replace the current county window and regress current shortcuts and building templates.
- Rebased `celestial_government` on the exact installed 1.19.0.6 definition. The only semantic delta is `barter = yes`; barony, accolade, house-aspiration, and current government flags are retained.
- Replaced obsolete `active_accolades` with current `accolades` and corrected the decision interval/cooldown for production use.
- Namespaced additive gameplay identities under `xccc_` / `xccc.` and corrected localization and tax-copy mismatches.

## Compatibility and migration

Target game version: CK3 `1.19.0.6`. Existing saves can add the maintained edition, but keep a backup before changing the active mod set. Do not enable it alongside the upstream item or another mod replacing `celestial_government` or the same corruption decision/traits. The removed activity and county-GUI overrides materially reduce unrelated compatibility conflicts.

## Known limitations

- The CK3 engine does not expose a direct scripted trigger for the final subject-contract transfer amount. Live acceptance proves the production tax constant (`0.75 - 0.25 = 0.50`) and production contract wiring separately.
- Native live gameplay/UI acceptance is Simplified-Chinese-only. Non-Chinese localizations passed structural, token, terminology, writing-system, numeric, and format audits; no native-speaker in-game truncation matrix is claimed.
