## 相对上一公开版本的变化

- 适配 CK3 1.20.0.3 的原版特质目录，其他特质从 108 项增加到 110 项；九种语言同步更新计数与礼仪说明。
- 使用当前原版 `erudite`、`herald`、`lifestyle_scholar` 键，移除当前目录不存在的 `scholar` 键。
- 同信仰沿用玩家当前礼仪（Rite），其他信仰使用其主要礼仪，并在信仰列表上方显示；旧 Faith-only 配置能补齐有效礼仪，交付时核对文化、信仰与礼仪。
- 修复未选择将才或性格特质时的配置校验，保留将才最多两项、性格最多三项及非法组合限制。
- 信仰选择限定为实际载入的目录条目；继续保持独立命名空间、实际金币费用、廷臣交付及宗族/家族归属。
