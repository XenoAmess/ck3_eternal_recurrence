## Player-visible changes

- Expand automatic upgrading from 301 ordinary-building edges to 605 applicable CK3 1.19.0.6 province-building edges across 165 chains.
- Cover eligible existing holding main buildings, ordinary buildings, duchy buildings and special buildings in castle, city, church, tribal and Mandala temple-citadel holdings.
- Preserve the 15-day loop and at-most-one-tier-per-target behavior. Successful upgrades still happen immediately and charge only after the target change succeeds.
- Use vanilla `upgrade_building_effect` for 400 ordinary/main/duchy edges, and a rollback-safe replacement path for 205 special-slot edges.
- Project 601 vanilla eligibility gates and all four observed cost shapes: gold; gold plus prestige; gold plus piety; and scripted cost.
- Update README, Workshop BBCode and all nine player-facing localization files to state the exact 2.0.0 scope and exclusions.

## Compatibility and migration

Target game version: CK3 `1.19.0.6 (Scribe)`. Existing saves using maintained version 1.19.0 retain the same enable flag, decisions and 15-day loop; no manual conversion is required by this update. Keep a save backup before changing the active mod set. Do not enable this edition alongside the original or another mod replacing the same `auto_build` events, `enable_auto_build` flag or building scripts.

## Known limitations

- The mod upgrades existing eligible buildings; it does not construct empty slots.
- Domiciles, nomad/herder N/A objects, the Mandala capital Great Project, terminal tiers, leased holdings and holdings with active construction remain excluded.
- Phase 2 deliberately keeps immediate upgrades and does not implement vanilla construction progress bars.
- All 605 production edges are statically exhaustive; live CK3 acceptance is a representative matrix rather than one launch per building key.
- Seven release languages passed structural/token review, but no native-speaker signoff or seven-language screenshot matrix is claimed.
