## Player-visible changes

- Add a native three-option funding selector directly to 【启用自动建造】: treasury only, personal gold only, or treasury first.
- Treasury-only and personal-only never fall back to the other account. Treasury-first uses personal gold only when the treasury cannot cover the whole gold cost.
- Never split one gold charge between treasury and personal balances. Prestige, piety and other scripted-cost resources remain personal and retain their vanilla base requirements.
- Preserve existing 2.0.0 saves: an enabled character with neither new override flag continues to mean treasury-first, with no migration action required.
- Clear the selected funding override when automatic building is disabled; disabling and enabling again allows another choice.
- Keep the Phase 2 building graph unchanged: 165 chains and 605 applicable CK3 1.19.0.6 upgrade edges.

## Compatibility and migration

Target game version: CK3 `1.19.0.6 (Scribe)`. Existing enabled saves default to the old treasury-first behavior because absence of both new override flags is the compatibility representation. No save conversion is required. Keep a save backup before changing the active mod set. Do not enable this edition alongside the original or another mod replacing the same `auto_build` events, `enable_auto_build` flag or building scripts.

## Known limitations

- The mod upgrades existing eligible buildings immediately and does not construct empty slots or use the vanilla construction queue/progress bar.
- Domiciles, nomad/herder N/A objects, the Mandala capital Great Project, terminal tiers, leased holdings and holdings with active construction remain excluded.
- Funding policy changes require disabling and enabling the automation again; there is no separate live-switch decision.
- All 605 production edges are statically exhaustive; real CK3 acceptance samples representative building and payment shapes rather than launching once per key.
- The seven non-Chinese release localizations passed structural, token and manual review, but no native-speaker signoff or nine-language screenshot matrix is claimed.
