## Player-visible changes

- Expand 【启用自动建造】 from three funding choices to six combinations: treasury only, personal gold only, or treasury first, each paired with either pause or continue when above the domain limit.
- Match vanilla's domain-limit boundary: the pause policy still builds at `domain_limit_available = 0` and skips the whole cycle only below zero.
- While paused, perform no building upgrade and deduct no resource, but keep the 15-day loop alive. Building resumes automatically after returning within the limit.
- Preserve old saves and the default choice as treasury-first plus continue-above-limit; no migration action is required.
- Continue-above-limit keeps the selected 3.0.0 funding behavior even while over the limit. Disabling automation clears both funding and domain-limit overrides so the next enable can choose again.
- Fix raw localization keys in all six choice tooltips, hide internal AI/flag conditions from the decision panel, and replace the rigid multiline confirmation with one natural current-policy sentence.
- Add a dedicated decision illustration showing the maintained character overworked among medieval construction plans while retaining the cyber-noise/glitch visual language.
- Keep the Phase 2 coverage graph unchanged at 165 building chains and 605 applicable upgrade edges.

## Compatibility and migration

Target game version: CK3 `1.19.0.6 (Scribe)`. An enabled old save without the 4.0.0 pause flag continues building above the domain limit, preserving 3.0.0 behavior. No save conversion is required. Keep a save backup before changing the active mod set. Do not enable this edition alongside the original or another mod replacing the same `auto_build` events, `enable_auto_build` flag or building scripts.

## Known limitations

- The mod upgrades existing eligible buildings immediately; it does not construct empty slots or use the vanilla construction queue/progress bar.
- Domiciles, nomad/herder N/A objects, the Mandala capital Great Project, terminal tiers, leased holdings and holdings with active construction remain excluded.
- Funding/domain policy changes require disabling and enabling automation again; there is no separate live-switch decision.
- All 605 production edges are statically exhaustive; real CK3 acceptance samples representative building/payment shapes instead of launching once per edge.
- The seven non-Chinese release localizations passed structural, protected-token and manual review, but no native-speaker signoff or nine-language screenshot matrix is claimed.
