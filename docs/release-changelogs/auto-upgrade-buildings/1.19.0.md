## Player-visible changes

- Adapt the original automatic-building feature to CK3 1.19.0.6, including its treasury economy and current script syntax.
- Check directly held eligible holdings every 15 game days. Each eligible ordinary building chain advances at most one level per check.
- Prefer treasury funds; fall back to personal gold when appropriate. Insufficient funds leave both the building and funds unchanged.
- Use current base construction costs and innovation/holding-level requirements for 43 supported building chains (301 upgrade edges).
- Skip existing construction, leased holdings and unsupported building systems; do not upgrade main, duchy or special buildings.
- Repair decision syntax and tooltips; remove the unused invalid event.
- Provide nine-language localization, distinguish the maintained title, and include original-author thanks, authorization and source/issue links.

## Compatibility and migration

Target game version: CK3 1.19.0.6. Enable or disable the loop through the mod's decisions.
Single-player is recommended. Do not enable this edition alongside the original or another mod replacing the same `auto_build` events, `enable_auto_build` flag or building scripts.
No save migration is promised; keep a backup before changing the active mod set.

## Known limitations

Costs are unmodified vanilla base costs, without construction discounts or bonuses.
Only the maintained building whitelist is covered. The documented expanded boundary matrix is not all live-tested.
