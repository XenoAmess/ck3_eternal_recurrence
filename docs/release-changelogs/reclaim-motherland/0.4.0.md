## Player-visible additions, changes, and fixes

- Gives every marked Later-Dynasty Hegemony an explicit primary heir. Because CK3 still destroys an empty-de-jure dynamic Hegemony during death settlement, the final implementation retains the same title object and restores it to the engine-selected primary heir on the following day.
- Carries the same loyal direct realm and subordinate vassal tree into the successor's Later Dynasty. Other personal titles continue to use the character's normal succession rules.
- Migrates existing Later-Dynasty titles idempotently when an older save is loaded.
- Continues the latest fallen dynasty's Three Departments and Six Ministries. Eligible loyal incumbents retain the exact nine offices; explicit defectors leave office, while genuine vacancies return to vanilla appointment.
- Does not grant the Later Dynasty the formal Grand Secretariat power-sharing system, the Mandate, or privileges reserved for the reigning Chinese Hegemony.
- Corrects Offer Vassalization so a Later Dynasty no longer receives the reigning Hegemony's celestial rank-gap, Hegemony-identity, or high-tier refusal exemptions.
- Gives direct vassals actually released by that shattering a title-bound five-year “Recently Independent / 新近自立” memory against the exact Later title, exposed as a visible `-50` acceptance reason. Changing the Later ruler does not bypass it; it expires naturally and is not a permanent ban.
- Keeps Phase 2 Divided Hearts, loyalist title/name/subtree stability, the original 51% threshold, Claim the Mandate lockout, and Proclaim the Restoration intact.

## Compatibility and save migration

- Built and tested for CK3 `1.19.0.6`; requires `Crusader Kings III: All Under Heaven`（《溥天之下》）.
- New single-player games remain recommended. Existing marked Later titles gain the succession contract on load.
- Saves already inside Chaos cannot reconstruct the exact historic list of direct vassals released by this mod. The five-year Recently Independent memory therefore applies only to shatterings that occur after updating.
- The mod now overrides `tgp_chaos_shattering_effect`, `situation_dynastic_cycle_claim_mandate_decision`, `tgp_has_access_to_ministry_trigger`, and `offer_vassalization_interaction`; another mod replacing one of those keys may conflict by load order.

## Known limits

- Multiplayer still uses the public deterministic 50-point boundary for human Pro-Hegemon candidates; the atomic shattering effect cannot pause and wait for several clients one by one.
- Controlled CK3 acceptance proves the identified formula corrections, two immediately refused real interaction targets, title-bound expiry, and the complete restoration regression. It does not claim a statistically representative first-year peaceful-reunification distribution from three natural campaigns.
- The five-year modifier is soft resistance. Exceptional diplomacy may still succeed before expiry, and normal diplomacy is deliberately restored afterward.
- Multiple historic Later titles may coexist; an unrelated warlord taking the Mandate does not automatically delete another dynasty's Later title.
- Seven additional release languages are reviewed model-generated candidates, not native-speaker certification.
