## Player-visible changes from 0.4.0

- Migrates to CK3 1.20.0.3's Offer Vassalization definition and modifier layout. Ordinary actors preserve the new vanilla formula. Later rulers retain the approved fixed `+10` ordinary rank bonus when the rank gap exceeds one tier, lose reigning-Hegemony privileges and regain vanilla high-tier refusal terms.
- Retains the exact title-bound, `1825`-day, `-50` Recently Independent memory for actual newly released direct lords; either side changing ruler does not bypass it.
- Preserves the new ministry-budget government flag while retaining the existing celestial requirement, unique latest-Later entitlement, eligible incumbents and vanilla appointments.
- Refreshes Chaos reorganization and realm-name order while protecting the former emperor's land and retained loyalists' titles, names and subordinate realms.
- Refreshes vanilla Claim the Mandate conditions and preserves the Later ruler's lockout. Restoration still references the vanilla `0.51` threshold and delegates full effects to `tgp_claim_mandate_of_heaven_effect`, then removes that ruler's marked Later titles.
- Keeps the same-title, engine-heir succession recovery and idempotent migration; keeps nine localization languages and 89 standard dynasty-name projections.
- Adds one private scripted-modifier file, raising the official runtime projection from `35` to `36` files. This is packaging for the formula migration, not a new player option.

## Compatibility and save migration

Requires All Under Heaven. New single-player games are recommended; cross-major-version CK3 save compatibility is not guaranteed. Existing marked Later titles keep the idempotent succession migration. The exact historical release list cannot be reconstructed for saves already in Chaos, so Recently Independent applies only to newly recorded shatterings.

The same four vanilla keys are overridden: `tgp_chaos_shattering_effect`, `situation_dynastic_cycle_claim_mandate_decision`, `tgp_has_access_to_ministry_trigger` and `offer_vassalization_interaction`. Other mods replacing them may conflict by load order. The private modifiers only redirect this product's offer interaction, preserving other vanilla consumers.

- Human Pro-Hegemon candidates use the existing deterministic 50-point boundary; no simultaneous multiplayer choice UI is added.
- Recently Independent is a soft penalty and does not guarantee every diplomacy attempt fails.
- Other historical Later titles may coexist; another warlord taking the Mandate does not automatically delete them.
- Nine-language format checks are separate from Simplified Chinese live verification and do not imply native-speaker certification.
- **Pending 1.20.0.3 live matrix:** 36 core markers; actual ministry-budget UI; real numeric offer-vassalization reasons; real 50%/51% production decision UI and confirmation; source and fresh-cache live acceptance. The old version's results are not substituted for these.
- The existing core fixture deliberately switches to the heir before killing the predecessor. It can test title/realm inheritance effects, but does not prove a native player death/Continue modal.
- Fixture timer compression is `1825` production days to `14` fixture days; observing this timer does not prove five natural in-game years.
