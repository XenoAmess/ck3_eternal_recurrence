## 玩家可见内容

- 新增同一信仰内的礼仪融合入口，以及不同信仰间的宗教融合试验入口。
- 独立窗口对照双方来源，从候选中选择恰好三个不同核心信条，并按教义组单选；双方都须提供独有内容。
- 默认礼仪融合 500 虔诚、宗教融合 1000 虔诚，成功后十年冷却。由玩家发起，不为 AI 自动执行。
