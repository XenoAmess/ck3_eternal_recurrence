# Financial Markets 0.1.0-alpha.2

相对 0.1.0-alpha.1，修复市场窗口的布局边界，重排行情和交易面板。筛选、刷新、列表、翻页使用相互独立的明确区域，右侧详情有 728 界面单位高的滚动视口。现货及期货的下单表单位于盘口之前，长说明改用摘要与悬停全文，币号和账户号不再以前置格式符显示。

没有修改共同账本、撮合、发行、杠杆、清算及存档变量。沿用 canonical Workshop ID `3844765196`，不创建新条目。

完整玩家更新说明见 [Change Notes](../../../workshop/change_notes/financial-markets/0.1.0-alpha.2.txt)。源码几何与回调测试、真实引擎行为、上传、公开回读及缓存安装各自记实际结果；20 场景完整矩阵、4,096 币规模和长期性能仍未完成。

离线验证：716 项通过，0 失败／错误／跳过；129 个操作与启用表达式相对 Alpha.1 保持。没有新增 CK3 实机场次，实际鼠标命中和最终视觉仍待复核，详见[界面合同](../../../mod_financial_markets/docs/market-ui-runtime-contract.md)。
