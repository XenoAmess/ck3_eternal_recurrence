# 0.1.0-alpha.3

相对上一公开版本 Alpha.2：

- 改为有界顺序布局，恢复六个主标签和资金操作；筛选、刷新、行情与翻页各占独立区域。
- 行情分为币号名称、最新价、买一、卖一及日成交量；文字穿透鼠标，整行选币。
- 右侧详情与交易占用可用高度，期货保证金、减仓、止损止盈和保存按钮可滚动到达。
- 买卖盘口标题与第一档报价顶端对齐；动态编号和主分页禁用提示正常显示。
- 去掉发行页冗余内层滚动，恢复档位、目标、登记及完整经营按钮。
