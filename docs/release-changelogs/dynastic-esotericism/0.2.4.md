# 宗族化密教 0.2.4 — 宗家家主与宗族族长跟随所属礼仪领袖

本版已完成一场分离输入的12自然日有限实机与一次无夹具、零新增日的独立冷载再保存。实际范围与原件见维护记录；正式包与工坊发表仍以各自实际收据为准。

原问题是新建绑定宗族可能只有宗家家主跟随礼仪领袖，实际宗族族长仍不同；离任／死亡后的实际无头状态也不能靠家主写入推定解决。本版以两个实际职位均对齐为完成条件，适用于唯一有效双向绑定且稳定宗家可证的宗族，包括复用的原生宗族和可证旧绑定；缺少可证关系或稳定宗家、冲突绑定及原生pending不强修。

年度归宗仍包括全部在世支系；在年度之间，实际族长错位且存在在世支系时，才提前将该单一绑定宗族的在世成员归并回稳定宗家，包含玩家与异礼仪成员，再按原版规则重算。不改死者历史谱系，不做全世界强迁。相关生命周期局部复核、一次初始化旧档兼容与年度兜底共同覆盖；匹配离任／死亡的缺头状态可请求原版重新选择，有有效在世继任者时不重选。没有合法头或两个职位仍不一致则保留pending，不能用同Faith另一Rite的共享教宗代替。

年度归宗继续包括玩家；已对齐局部路径不全员扫描。未经过已覆盖事件的纯原生换届等变化可等年度兜底，不承诺通用即时响应。没有CPU／FPS／墙钟性能倍数承诺。归并与原生家主／族长计算可能改变家族归属及头衔／继承效果，保留升级前存档。

完整0.2.3功能保持：宗族化／无、普通礼仪默认无、查看与取消不建族；合资格创始人路径、改信与成员同步；背离-100及管辖限制、赦免／已消耗关系；旧档自动初始化和手动兜底；AI支系入口保护及年度全员归宗；繁育三信条与木乃伊、完整旧组合一次迁移、白绮与九语／媒体、RRF兼容顺序。新局专用神职校正不用于旧档。
