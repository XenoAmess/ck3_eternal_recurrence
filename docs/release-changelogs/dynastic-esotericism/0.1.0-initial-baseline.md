首发完整Change Notes：

宗族化密教 0.1.0 — 初始公开版本（initial baseline）

新增
- 在礼仪创建、改革与编辑的原版教义选择中加入“宗族化 / 无”。原版已有礼仪默认保持“无”。
- 宗族化礼仪创建对应宗族，创建者及全部在世信徒加入；支持玩家、AI、有地、无地与儿童。
- 现任家族族长优先交接族长后建族；没有合法交接对象或其他创始人时，生成并保留一名真实同礼仪成年创始人物，因此会增加人物并形成宗族历史。
- 新改信者迁入对应宗族；已有合法旁支保留家族。重复编辑、关闭后重新开启均复用原宗族。
- 仍属宗族却背离对应礼仪的人，受到该礼仪其他信徒的一项-100好感修正，并产生监禁、放逐、处决理由。
- 回归对应礼仪或停止宗族化后撤销本来源的背离规则；后台持续校正不反复刷新已赦免或消耗的犯罪理由。
- 提供新局初始化与旧档首次启用决议，保存礼仪、宗族与家族的对应关系。

兼容与存档
- 使用CK3 1.20礼仪系统，沿用原版创建、编辑资格、费用、监禁管辖与处决囚禁要求。
- 入教会替换人物原有的宗族和家族归属，可能影响继承、族长、宗族声望等玩法；不会改写血缘。
- 关闭宗族化保留已创建的宗族与人物当前身份，不自动恢复旧家族。

已知范围
- 其他模组直接改家族的路径可能需要等待周期校正。
- 多人尚未验收。
