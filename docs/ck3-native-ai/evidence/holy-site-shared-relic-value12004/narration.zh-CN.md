# 第一期共享圣地／圣物机制讲解候选

机器4-8e1c2f1861，2026-10-17离线整理；适用1.20.0.4。括号内为制作提示，不属于已拍画面陈述。具体sourcepin、实测和未测范围见[机制研究](../../holy-site-shared-relic-value12004.md)及对应evidence。不得用图卡替代尚待本期完成的实际换物／受益补镜。

同一个圣地可以被多个信仰共同使用。各信仰分别决定它是普通还是主要，但圣物并没有按宗教各存一份。大家引用的是同一个圣地、同一组槽位。你合法换掉一件圣物，改动的就是这份共享库存。

共享也不代表双方同时拿到全信仰收益。实际修正链还要求这个信仰把它列为主要，并且这里县主当前正信这个信仰。两教都主要、县主信A，不能据此给B也算上一份。县主改宗之后，收益资格和圣物有效性都要重新评估。

供奉也不等于生效。原版会看这里县主现在信什么、这个信仰是否还关联圣地，再判断槽里的物品是否被它认可，把有效物品的等级加起来。认可是原版动态圣化或模板条件的结果；动态名单为空，也可能是真正圣物。我们这次将斗篷放入纳杰夫，独立读到物品离开个人库存、归属圣地、零号槽装入，Active从关闭变开启，有效等级从零到四。取出后，所有权和槽位反向变化，Active也关闭。这些是实测；对各信徒实际加多少属性，还要对受益者单独读回，不能拿按钮说明当作到账。

还要区分固定修正和随圣物缩放的修正：Active不是所有效果共用的总开关。本期会按实际消费者分别核对，不能把界面隐藏说明直接翻译成“这里全部加成归零”。

更换时，旧物会交给本次执行角色，不是自动退给原捐献者或另一个信仰的宗教领袖。原版自动选槽只找兼容空槽；满了就偏向旧物稀有度较低的槽，它不会替你权衡别教圣物、装备价值或外交代价。真正值得换哪件，仍需要我们比较。

而且“取出来，再放新的”和“直接替换”不是同一笔账。单独取出自己信仰认可的圣物，可能扣虔诚和奉献经验；同一原生命令替换会同时走新物供奉、旧物移除的条件。等档或升级可能避开其中一段自己的损失，别教角色的意见风险仍可能存在。我们这次单独取出四档斗篷，钱包实际少了五百；奉献经验、关系数值和宣战理由没有在这段做后验，不能一起宣布验证通过。

（本期补一个真实共享非空槽同一原生命令替换：选新物、读旧物与费用预览、只提交一次，然后独立展示新物入槽、旧物进入执行者库存；不以先取出再供奉替代。）

退出圣地又是另一条规则。如果还有别的信仰关联，放弃自己的关联不会按退物脚本把圣物领回。只有最后一个信仰退出、而且县主存在，已供奉的物品才会给县主。县主若不是你，物品就不回你的口袋。这个决议有自己的虔诚、冷却和意见代价，也不是取出按钮的免费版本。

（R8已有空库存共享退出，只能证明本faith关联消失、另一faith和圣地对象保留。非空共享退出与最后faith返还，按本期最小补镜分别完成后再加对应实测句。）

因此规划圣地时，先问要为谁提供什么价值，再决定用哪件圣物、占哪个槽、是否值得替换。高稀有度、被认可、Active、主要等级和最终受益是几件不同的事。它们各有来源，也各有成本。
