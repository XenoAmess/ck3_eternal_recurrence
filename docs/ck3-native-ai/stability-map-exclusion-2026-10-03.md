# 地图只读等待的中心排除（2026-10-03）

真实长期游玩中，普通事件关闭后进入地图，但只配置普通事件/战争窗口的辅助会保守停止。
仅增加 HUD 模板也不能解决此问题：事件、未知结果窗口与地图可同时保留 HUD，普通窗口的无效首项尤其不能被绕过。
本工作将这些共性约束加入公共 `PixelRouter`，产品模板、坐标、颜色阈值、截图、存档和实际角色策略继续外置。

## 实现与必要验证

基于公开主线 `8fb41d1e3677ec506e63bfa9bba7f2f7a3597d06` 的短路径 detached checkout 开发；未修改活跃游戏使用的旧版本、原操作者工作树或历史证据。
只改像素路由、必要合成回归与本夹具文档。未领取/续租 SCREEN，未捕获桌面、启动游戏/Steam、发送输入或创建 SDK consumer。

路由次序为 STOP、唯一普通 shell 的完整验证、唯一 MAP 的 HUD+中心 guard。
中心 guard 的边缘、暗面板与中性浅面板规则全部由产品配置，严格校验原图矩形、采样点数及有限阈值；命中阈值即拒绝。
MAP 仍只读，日期/暂停/玩家状态为 `NOT_READ`，不增加按键或自动恢复操作。
旧 MAP 配置缺少 guard 明确拒绝，已有合法普通窗口路由继续可用。完整字段合同在 [夹具指南](../ck3-stability-fixture.md)。

一次必要回归运行通过 **36 tests**（既有 27 项及新增 9 项），耗时 13.958 秒，exit 0。
新增覆盖已知 shell/HUD 重叠、灰首项/第六项/无效战争按钮不得降级、普通 shell 歧义、未知宽边缘、暗/浅面板、边界值、缺 guard/越界/步长错误拒绝，以及合法地图零输入。
测试只有程序化像素，不含游戏或第三方 mod 素材；没有开展其他 mod 矩阵。

## 外置闭合样本与失败史

算法/政策经验参考外置证据 ID `r6-gui-century-assist-agent-a05`；其源码、素材和私有配置不搬入公共仓库。
本次必要接入回放使用三个原操作者已直接审阅的地图画面、一个已知普通事件、一个未知战争窗口，共五个既有闭合原图。
没有采集新图，也没有将路由结论当作业务或百年成功。

首个产品候选 `r7-public-map-routing-agent-a01` 保留原参考参数，未知窗口正确拒绝、已知普通事件正确路由，但三个地图因通知横幅/固定地图部件的边缘保守误拒。
该 RED 回执永久保留，SHA-256 `f5c8f85ae1482d229d4095960a0e262fd1b337dd9280d8d3ff1e7a337245122b`。
离线诊断还确认中心暗色地图本身会触发原暗面板阈值，因此不能只提高宽边缘阈值来使其通过。
初次候选 producer 的语法错误及一次重复诊断写入的 `FileExistsError` 也保留于外置 runtime；它们未执行输入，未改写原候选或诊断结果。

新候选 `r7-public-map-routing-agent-a02` 将扫描区限于已审阅的中心上部，避开上述固定部件，并显式调整产品暗像素阈值以处理暗色地图。
五个闭合样本分别得到三个 `MAP_WAIT/action=null`、一个正确普通事件路由及一个未知战争窗口拒绝；没有扩大战争模板范围。
候选配置 SHA-256 `1e41d200821cce8a270c24d772acf7e4a7e67d0fa544f537edc35e19094e7156`，回放回执 SHA-256 `6b5923153adc7ad205d5f086c059da6fc67b19ecd47b4f9a72dd72064139824d`。
它仍是 **未获原操作者本轮 guard 审阅、未上线的产品候选**。五张回放不能证明其他未知窗口安全；像素排除也不能证明没有未知窗口。
图像、坐标、参数和原始产品回执继续留在独立项目，公开文档仅引用 evidence ID 与 hash。
