The native network collector at RVA 0x1A24010 visits these stored sources:

* 0x1A24094–0x1A240AE: Character+0x1A8 family component, family+0x20 spouse-ID array, data at +0 and count at +0xC, stride four. A null family component selects the native empty fallback.
* 0x1A242F9: family+0x10 stored full betrothed ID; -1 is empty.
* 0x1A243F6–0x1A24416: Character+0x1B0 relation component, relations+0x20 array, data at +0 and count at +0xC, stride sixteen. Rows contain the full other-character ID at +0 and the relation pointer at +8. A null component selects the native empty fallback.
* 0x1A24426 and 0x1A24464 suppress spouse/betrothed duplicates. At 0x1A2447D the relation+0x94 value must be nonzero, and at 0x1A2448A relation+0x1A9 must be zero. The collector then resolves the full character ID and filters realm data at +0x1C0 for its power calculation.

The accepted native IsAllied at RVA 0x2911DF0 independently checks those actual family IDs, then calls relation lookup 0x28BC270. Its relation branch requires type tag 0x41637452 at +0x210, suspension byte +0x1A9 equal to zero and active value +0x94 nonzero. The saved IsAllied span is complete. The saved 0x28BC270 pdata entry is only an entry slice with an external jump; it is not presented as the whole function and the new leaf does not call it directly.

The proposed observation reads the stored ID sources and resolves each full ID through the existing generation-aware resolver. It publishes a living character only after native IsAllied returns true in both directions. A spouse or betrothal alone does not become an observed ally, and no parent, future spouse or guessed identity is added. Realm-data presence is a separate field: this collection proves native membership, while the existing per-recipient query proves war-specific call eligibility, final CanSend, ten cost slots and native recipient answer.

Null native components and readable zero-count arrays may yield an available empty collection. Unreadable or malformed containers yield an unavailable collection. Unresolved stored references are reported separately and never promoted to allies. At the initial static-ready stage, the current Robert ally IDs and paused collection completeness had not yet been observed. The v35 paused receipt below closes that membership observation.
