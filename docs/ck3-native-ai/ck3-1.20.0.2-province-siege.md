## 发布语义

`BindProvinceImage` 只做模块基址与固定 RVA 的运算，只接受上述精确 SHA。`ReadObjectiveProvince` 必须由 owning thread 调用；运行帧只发布占领与堡垒标量，暂停帧才读取驻军、兵力、围城和攻城子图。

围城通过省份 ID 回查、完整代际 SiegeID、原生 magic 和反向 Province 指针共同识别。读不到有效 Siege 时保留 `siege_observable=false`，只有原生 SiegeID 为 `-1` 时才发布真实的“没有围城”。占领者也要求完整 CharacterID 在 storage 中成立。

公共围城 ArmyID 通过有效 CUnit 的 `+0x178` 与 CSiege 的 CArmyID 匹配；只有唯一匹配才给出公共 ID。完整城墙的每日攻城投影是零，不调用按破口等级索引的原生伤亡函数。攻城合法性直接调用完整原生 validator，不从局部字段自行推断。

`CollectObjectiveProvinceIds` 原子收集目标头衔层级中的县首府省份，并使用原生县首府 getter 与当前 GameData 省份表互证。每个独立目标根分别维护递归访问集合，总遍历预算和去重省份集合则跨目标共享，保持旧版本对重复县目标及父子目标重叠的有效语义。层级读失败时输出为空且返回 false，不发布半份目标集合。
