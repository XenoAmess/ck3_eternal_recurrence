| --- | --- |
| `native_can_continue_observed` | bool；原生 getter 本次是否取得实际结果 |

原生 false fixture 的 status 仍为 `0=continue`、`native_terminal_state_observed=false`、cause unknown。
它表示当前 final getter 的 false，不能改写成已知结束、取消或失效原因。status1 retained terminal
fixture 完全不调用该 getter，返回 observed=false / value=null；nullable 值不能解释为 false。
