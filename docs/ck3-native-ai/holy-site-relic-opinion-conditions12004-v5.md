## 统一记号与方向

`A`＝实际执行者，`F`＝A 当前信仰，`N`＝新供奉的物品，`O`＝被取出或被替换的旧物，`S`＝圣地。`R(X,f)` 严格表示物品 X 的 `is_holy_relic_for = f` 返回认可，不等于曾捐献、不等于圣地关联或缓存价值。所有表内修正都为**被筛中角色对 A 的好感**；不是 A 对该角色，也不是一个信仰对另一个信仰。

“直属封臣”对应 A 的 `every_vassal`；“封臣同僚”对应 A 当前直属领主的 `every_vassal`，只在 A 确实有领主时执行；“各级上级”对应当前 `every_liege_or_above`，不是历史领主。原版同僚循环没有显式 `this != A`，不能凭 UI 名称补造自我排除规则。

“上级狂热门”在以下三项中满足任一项：`ai_zeal >= 50`、`has_trait = devoted`、`has_trait = zealous`。第一项是内在 AI 性格值；`devoted` 官方简中为**誓愿者**（男性显示修士、女性显示修女），`zealous` 为**狂热**。它们和封臣的**宗教狂热立场** `vassal_stance = zealot` 是不同检查；**少数族群立场**为 `minority`。

## 新供奉回调：+15 不是无条件奖励

进入 `on_holy_site_artifact_enshrined` 不等于进入奖励分支。L138–165：首先判断 `scope:replacing ?= { R(O,F); old.rarity_level >= new.rarity_level }`，满足时保存局部值 `no`，否则保存 `yes`；正面分支再要求 `R(N,F)` 且该值为 `no`。**对确有 O 的直接替换，等价于 `R(N,F) AND R(O,F) AND old_rarity >= new_rarity`。** 必须保留源码 `>=`，不能根据变量名或英文注释把它反写成升级才奖励。

空槽首次供奉没有 O；exact4 引擎对这处缺失 `scope:replacing ?=` 的真值尚未闭合，本件不把“首次供奉必定 +15”写成已知。实际分支需用本次预览/回读确认；这个未知不影响有 O 的分支表。

## 旧物移除回调：互斥的两个主体分支

单独取走会触发 `on_holy_site_artifact_removed`；直接替换也对 O 触发这一回调，`scope:replacing` 此时指 N（L322–329）。

定义损失门 `L = R(O,F) AND (没有 N OR new_rarity < old_rarity)`。L333–353 把局部标记设为 `no` 当且仅当 L 成立。L385–390 的本教损失分支同样等价于 L。不要把等档当作降档。

## 十年、衰减和重复施加

`enshrined_holy_relic_at_holy_site` 基值 +15，`removed_holy_relic_from_holy_site` 基值 −20；二者均 `years = 10`、`decaying = yes`。官方格式说明 L11–22 指向期限内衰减至 0，默认延迟为 0。本件不进一步声称某局实测了每月插值。

官方 `_opinions.info` L39–43 定义 `stacking = no` 为默认；两个实际修正均未开启 stacking。同一角色因多种身份再次得到**同名**修正时，规则是重置期限，而非按身份数量把 +15 或 −20 倍乘。正面和负面是**两个不同键**，可以并存；重复施加遇到已在衰减的修正时不能据此保证本次净跳变恰为 +15/−20。

本次没有对一个实际人物采集动作前后总好感及修正明细，故所有数字均为源码定义的修正值，不是本期实测净好感。已完成的是原版回调分支、术语和格式默认值复核；未完成的是空槽 nullable 真值及实际例子的净值回读。

以下文本可替换一期旧稿 V4-C11-01 至 V4-C11-07，后续费用段另保留。它已经按上述来源逐分支核对，**仍需放回新版全文连续审读**，检查共同前提、角色组、转场和一个变化反例能否被听者复述；未声称完成新版作者审读、配音或成片审阅。完整条件表承担查漏职责，列全条件不自动证明口播易懂。方法见[系列制作方法](../../promo/ck3_faith_and_power/docs/production-lessons.md)。

先把这笔关系账的方向说清楚：这里改变的是哪些人对你的好感。你是执行供奉、替换或取走的人，不管物品最初是谁捐的，好感账都记在你头上。

供奉的正面修正是十五点，但它有自己的入口，不能理解成每放一件物品，全体教友就一起加十五。尤其直接替换时，要看原版真正写下的比较：新旧两件都被你的信仰认可，而且旧物的稀有度大于或等于新物，才进入这一正面分支。同档符合，降档也符合，换成更高稀有度反而不进这一条。这个比较看着反直觉，我们按实际条件讲。至于空槽第一次供奉，我们还没有闭合它对缺失旧物的判断，不能保证一定触发这十五点。

一旦进入正面分支，谁会加十五？第一组是你的直属封臣：他必须站在宗教狂热立场，而且他的信仰认可新物。这组可以包含异信仰封臣。第二组是你当前的每一级上级领主：他的信仰要认可新物，还要满足三项之一——内在宗教狂热值至少五十、拥有誓愿者特质，或者拥有狂热特质。誓愿者在男性身上显示为修士，女性显示为修女。内在性格值、人物特质和封臣的宗教狂热立场，是三种不同的检查。第三组是你本教的信仰领袖：他必须存在，不能就是你本人，而且他自己当前的信仰认可新物；这组不再要求狂热立场或狂热特质。

再看取走。旧物被你的信仰认可，而且你直接拿走，或者拿一件稀有度更低的物品替换它，就进入本教损失分支。这时，与你同信仰、持宗教狂热或少数族群立场的直属封臣，各自会得到对你负二十的修正。如果你还有领主，你直属领主麾下与你同信仰、持宗教狂热立场的封臣也会受到这一修正；同僚这一组没有少数族群立场那一条。

你的各级上级也要逐个看：只要他的信仰认可旧物，并且满足刚才那三个狂热门槛中的任意一个，就对你负二十。上级不必与你同信仰。

这笔损失还可能传到信仰领袖，但范围有明确边界：从这座圣地关联的信仰中，筛出仍有伯爵领信众的信仰，再找它的领袖。领袖必须存在、不是你本人，而且他自己当前的信仰认可旧物，才会对你负二十。这里数的是该信仰拥有的伯爵领信众，不是只看圣地所在的那一个伯爵领。这条领袖分支不要求狂热性格、特质或封臣立场。

那么，同档或更高稀有度替换，到底避开了什么？当旧物被你本教认可时，它避开了刚才的本教取走费用和那一整组本教损失筛选。但旧物被取出仍会进入另一条关系分支：与你不同信仰、而且其信仰认可旧物的直属封臣，对你负二十；如果你有领主，他麾下同样与你不同信仰、认可旧物的封臣，也对你负二十；你的各级上级，只要与你不同信仰并认可旧物，同样对你负二十。这三组都不再要求宗教狂热立场、少数族群立场、狂热特质或内在狂热值。

所以，拿本教看来同档或更好的新物换走旧物，未必能安抚认可旧物的异信仰封臣和上级。反过来，如果旧物本来就不被你本教认可，单独取走也走这条异信仰关系分支。这里没有一条把所有信仰领袖统一罚二十的规则；一位领袖若同时是你的封臣、封臣同僚或上级，才可能按这些关系被筛中。

最后别把身份数量当倍数。正面的十五点和负面的二十点都持续十年，并在期限内衰减。同一种修正再次施加，会刷新期限，不会因为同一个人既是上级又是信仰领袖就翻倍。正负是两种不同修正，可以同时留在同一个人身上。我们没有拍到这些角色完整的动作前后好感明细，因此这里讲的是原版写定的修正和筛选，并没有把某个现实例子的净好感变化说成实测。
