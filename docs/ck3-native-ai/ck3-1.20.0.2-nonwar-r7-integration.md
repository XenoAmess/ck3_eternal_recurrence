## 实际查询路径

默认关闭选项为 `XAR_CK3_ENABLE_G2_PLAYER_RELIGION_DRAFT_GROUPS_PRIVATE_QUERY_V1`。候选增加这一项，合计 56 ON / 4 OFF；默认配置不开启私有查询。Python/MCP 的默认关闭只读许可为 `--private-player-religion-draft-groups-query`，工具 `ck3_query_player_religion_draft_groups_v1` 只接收可选 `expected_revision`。

新 `permitted_executor_religion_draft_groups12002` 在 install environment、实际 runtime、字段复制与 callback 准入中具有独立身份。中央 `RegisterNonwarMailboxExecutorsV1` 和 `PopulateNonwarMailboxExecutors12002` 注册真实 `ExecutePlayerReligionDraftGroupsMailbox12002`。worker matcher `IsPlayerReligionDraftGroupsPrivateStep12002` 分发至 `HandlePlayerReligionDraftGroupsPrivate12002`；bridge 使用该域实际 revision parser，允许未指定 revision 的当前帧只读查询。

生产增量只有 `religion_reform12002_group_model.cpp` 与 `religion_reform12002_group_mailbox.cpp` 两份显式源码。它们复用已闭合的 current creation-window、choices、selection 与 Tenet 来源。只开启 DraftGroups 时也会编译这些必要 provider，原 Reform 操作入口仍由原选项控制，不借依赖开启新的动作。

输出 `result.player_religion_draft_groups` 保存当前已存在创建窗口的实际 group、selected slot、当前 cache 与当前 Tenet final 结果。选中 group 的 source keys 是原生数据来源，不能将它们描述成全部合法候选。`all_group_materialized_choices_complete=false` 保留实际未物化集合的缺口，不抹除可独立读取的 current Tenet final bool。窗口不存在时返回实际 typed unavailable；查询不会创建、打开或刷新该窗口。
