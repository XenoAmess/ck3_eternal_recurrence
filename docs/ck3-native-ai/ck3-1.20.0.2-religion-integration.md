`PopulateNonwarRouterExecutors12002` 登记领域的实际执行器，现有 mailbox 安装、submit、owner-thread drain、wait/reclaim 使用该命名 permit。worker 精确路由到 `HandlePlayerReligionPrivate12002`；实际 provider 只在拥有线程的暂停帧中读取。

请求的 `expected_snapshot_revision` 与兼容的 `expected_revision` 由领域原有 parser 处理；两个值冲突时拒绝。中央 worker 对此 selector 使用同一 parser，避免标准前置检查挡住 canonical 请求字段。查询返回完整 `command_result`，包括 `protocol_version=1`、实际版本/SHA、snapshot revision/date、private/read-only/advertised metadata。

此结果区分玩家当前 Rite、其 Faith、Religion 和 Faith 的 main Rite，保留完整引用 ID、稳定 key，以及实际 fervor/spiritual fulfillment raw 值。`0` 是正常可观察值；合法缺少 Rite/Faith 的状态与内存读取失败分别表达，不以默认零冒充失败读取。该查询不广告公开能力，不添加任何宗教动作或策略。

第二候选为 41 ON / 4 OFF，新增的唯一 ON 是宗教上下文 option；旧 Council probe、旧 planner diag、war-cash、prewar 继续 OFF。默认构建排除宗教 provider/mailbox。其他宗教领域尚未验收的源码不因名称或 schema 被自动接入；后续独立专题 ready 后另行注册。
