# CK3 游玩智能体：跨代战役发展评分 v1 设计稿

状态：**规则提案，待用户审阅；未实现评分器，未给当前战役评分。** 设计日期：2026-10-19。

本方案用于反复运行同一起点的“罗贝尔的30年”，比较领地、财政、军事保障、家族与宗族是否取得了可持续的发展。评价单位是连续战役，不是某位君主的一生。自然死亡、继承、改朝换君、智能体连接恢复、录像分段均不重置分数或时间。

“客观公正”在这里指：评价对象固定、公式可复算、价值权重公开、输入有出处、坏结果不能事后豁免、缺数据不能伪造。**不存在唯一客观的六项权重。** 下列权重体现“领地与财政为主，能守住且传下去”的明确取舍，须在正式比较前冻结；不能看到哪局输在哪里再改权重宣布进步。

## 1. 从现有 mod 保留什么、改变什么

已阅读权威参数 [scoring_data.py](../../tools/scoring_data.py)、生成器 [gen_scoring.py](../../tools/gen_scoring.py) 和其生成的 [算分规则](../scoring-rules.md)。现有 mod 在单个玩家角色死亡时结算：六属性线性加分，金钱/威望/虔诚/影响力取向下整的 log₂，持有头衔计件，五代在世后代按人数/最高头衔加分，realm_size 取对数，另有契约进度、开局成长基线和祝福拒绝折扣。生成文件保持原样。

该设计适合 mod 的单人生涯和轮回资源，但不能直接作为三十年智能体能力榜：

| 旧方法的用途 | 本方案的处理 |
| --- | --- |
| 低边际收益，抑制单项无限堆叠 | 保留，但用连续有界函数，避免跨一个阈值突然跳分 |
| 开局基线、后代身份去重 | 保留，基线和宗族锚固定到整场战役 |
| 死亡时按当前君主结算 | 改为固定游戏日期结算；继承中间帧只是状态变化 |
| 六属性、个人威望/虔诚/影响力余额 | 不直接进入主分；能力若改善税收、军费、领地或传承，会通过结果体现 |
| 头衔计件、后代人数 | 改为去重后的实际县域资产和合法续局韧性；空头衔、重复封授、生育数量不直接加分 |
| 金币越多越好 | 改为真实现金减已存在负债/承诺，同时考察持续收入和军费负担 |
| 成长分最低截为零 | 改为允许负的“相对开局净变化”，不能掩盖失地和衰退 |
| 契约、祝福、余烬位阶 | 不采用；这些不是原版战役发展的共同评价对象 |

这是一套战役结果评价，不是道德评价。恐惧、暴政、宗教选择、政治手段本身不凭偏好加减分；它们造成的可观察稳定、财富、扩张和传承后果才计入。也不奖励宣战、战胜次数或杀伤人数，避免通过无收益战争刷分。

## 2. 固定评价对象与比较条件

每场必须在开始前冻结以下身份和条件：

| 字段 | 规则 |
| --- | --- |
| `campaign_id` | 一条从开局到终点的唯一血脉战役；不是每代的 episode ID |
| `founder_character_id`、`dynasty_anchor_id=D0`、`house_anchor_id=H0` | 从真实开局观测取得，跨代不变；使用完整角色 ID，不能只按人名匹配 |
| `T0`、`T*` | T0 是真实开局游戏日期；T* 是同一游戏日历上增加 30 年的日期 |
| `baseline_id` | 开局快照及其内容身份；记录全部公式所用的开局值，不能在继承时重采为新基线 |
| 游戏环境 | exact build/EXE、DLC、mod 内容、游戏规则、难度、开局书签、初始角色、AI 设置、合法动作约束 |
| 策略与评分版本 | 策略 commit/配置，评分版本和参数文件的内容身份；两者分开 |
| 初始随机状态 | 能证明时记录 seed/同一原始起始存档；不能证明时标 unknown，不能冒称同 seed |

不能从“1066开局”、文件名或影片标题猜 T0 是某月某日。T* 由游戏日历转换器生成并与原生日期绑定；如目标日历日期不存在，在开跑前固定为目标月最后合法日。不能用现实秒数、录制时长或粗略的 `30×365` 代替游戏日期。

**严格主榜要求准点 T* 观测。** 晚到几天的存档不自动视为准点，也不能把额外发展的几天收益算进去。可采用的处理只有：

1. 存在 T* 的可信原生快照：使用该快照；之后的保存时间不影响它的游戏日期。
2. 只有 T* 前后快照：保留端点未知，给分数区间；不能用线性插值补造 T* 状态。
3. 下轮若确需端点容差，先注册单独的 `endpoint-tolerance` 赛道、容差和统一采样规则；不与严格准点榜混排，不追认旧局。

例如假想 T*=1096-09-15，唯一快照却是1096-09-23，晚到8日；不能直接用它取得严格准点资格。本例不描述当前战役的实际日期或成绩。

同一评分版本下，同一起点和同一三十年窗口可比较。不同剧本、不同难度、不同 DLC/版本或不同起点的“600分”不能直接说明谁更会玩；需要各自赛道或另行预注册的校准。改变可用能力的系统版本须保留，不能把获得新观测/新动作与单纯策略改进混为一个因果结论。

## 3. 主分结构

每个评价时点计算六项 `0…100` 状态分：

| 项 | 符号 | 权重 | 为什么采用这个权重 |
| --- | --- | ---: | --- |
| 领地的规模与品质 | L | 25% | 真正保有的生产基础是主要成果；含附庸领地，但不是单纯数头衔 |
| 财政与偿付能力 | E | 25% | 防止靠破产、无资金战争或短期涂色取得虚高结果 |
| 可持续军事保障 | M | 15% | 要有真实可用的兵，也要负担得起；不把兵数当战斗胜率 |
| 治理稳定 | U | 10% | 控制力、内战要反映，避免只看地图颜色 |
| 家族与宗族的持久发展 | D | 15% | 宗族锚跨代固定，旁支也有价值；不能靠授独立转移资产刷分 |
| 合法继承韧性 | H | 10% | 领地必须能继续传承，但不能让人物属性压倒整体治理 |

```text
A(t) = 0.25 L(t) + 0.25 E(t) + 0.15 M(t)
     + 0.10 U(t) + 0.15 D(t) + 0.10 H(t)         # 0…100
```

采用同一 T0 起算的 360 个逐月周年采样点 `t1…t360=T*`。日期由同一游戏日历逐次从 T0 加月生成，不以上一次月底递推，避免月底漂移。每点须记录其真实游戏日期；漏点就是未知。暂停、现实运行速度和日志密度不改变样本权重。

```text
A_end  = A(T*)
A_last = 最后 12 个固定月度采样值的算术平均
A_mean = 全部 360 个固定月度采样值的算术平均
A_low  = 全部 360 个值从小到大排序，最低 36 个值的算术平均
F      = 0.60 A_end + 0.40 A_last
S30    = 10 × (0.70 F + 0.20 A_mean + 0.10 A_low)  # 0…1000
```

主分中 42% 来自准点状态、28% 来自最后一年、20% 来自全程月度状态、10% 来自最差十分之一月份。这样既重视最终留下的成果，也不让第 30 年前的长期崩溃完全消失。`A_low` 是固定月度样本的下行表现，不是臆测的灾难概率。

这是**月度采样指标**，不是声称已精确积分全部游戏日。战争、失地、继承、借款、重大支出前后的额外帧用于解释和核对，但不因为某场采得更密就给它更多平均分。未来改成逐日积分须另升版本，不悄悄改变本版口径。

每次同时公布 `S30`、`A_end`、六项终点分、六项开局分、六项差值和 `ΔA=A_end−A(T0)`。净变化允许为负；不能用 `max(0,ΔA)` 隐藏倒退。S30 是同起点主比较值，ΔA 用来说明增长来自哪里，不能把它再加一遍形成双重奖励。

## 4. 共同归一化与数值约定

正向存量采用同一函数：

```text
R(x; b, s) = 100 × x / (x + max(b, s))
clip01(z)  = min(1, max(0, z))
```

其中 `x≥0` 是当前存量，`b≥0` 是该指标固定的开局存量，`s>0` 是下限尺度。开局值不小于尺度时：维持开局为 50 分，翻倍为 66.667，四倍为 80，丧失全部为 0。没有离散 log 阈值，也不会因规模继续增长而无限加分。开局为零的项目起分可为零，不伪造“开局50”；尺度防止从 0 到极小值就满分。

尺度固定为：领地/宗族土地 `s=1` 品质县当量；月度收入 `s=1` 金；军事 `s=100` 标准兵当量；宗族传承等级数 `s=1`。这些是**评分参数**，不是 CK3 原版常数；正式冻结前用户可调整。所有单位、固定点 scale 和符号必须来自字段合同。钱用金、流量用金/月，不能把 raw 固定点值直接当金币。

内部按确定性十进制/有理数规则计算；R 的除法、汇总至少保留 12 位小数，最后才四舍五入展示 2 位。正式实现须固定精度和舍入方式，例如十进制精度 40、`ROUND_HALF_EVEN`。排名比较未取整值，展示值相同允许并列，不能以四舍五入的误差宣布胜利。

## 5. 领地 L：真实县域、发展与控制

先确定玩家当前实际统治的县集合 `C(t)`：包括直辖和所有层级附庸，按县头衔 ID 去重。不能把公国/王国/帝国头衔再作为同一片土地累加。法理宣称、未兑现的战争目标和挂名头衔不是已有领土；独立出去的县在实际生效后离开集合。

每县结构品质：

```text
q_c = 1 + 0.5 × min(development_c / 20, 2)
        + 0.25 × min(max(completed_holdings_c − 1, 0), 4)

v_c = q_c × (0.25 + 0.75 × control_c / 100)
          × (1 − 0.50 × occupied_fraction_c)

Q_realm = Σ(c in C) v_c
L       = R(Q_realm; Q_realm_at_T0, 1)
```

`development` 取实际非负发展度，`control` 取原生有效范围 `0…100`；范围外数据是输入错误，不静默裁成合法值。已完工地产按县内实际完工男爵领计数，空槽、在建项目、只创建的头衔不计；地产种类不凭主观偏好乘系数。`occupied_fraction` 是该县已完工地产中被敌对军事占领的比例，需真实占领者/战争关系，不能把军队路过当占领。无已完工地产或归属不明时该县输入未知。

q 的固定上限为 3。发展度和地产密度提高资产品质；高发展不是无限放大器。未单列任意建筑的名义造价，因为花钱多不等于有效建设。建筑升级通过实际税收、兵力、控制或军事结果体现；军事专用建筑的具体克制效果保留在诊断中。

低控制县仍保留 25% 的结构价值：不是立即蒸发所有永久基础；外国暂时占领再折半，法律上的拥有仍不是已经失地。正式割让/授独立则按实际归属全额移出。收复同一县不会另领“收复奖励”，只恢复当时状态。

直辖与附庸县在 L 使用相同结构资产口径。直辖更高的实际收入、封臣合同、超直辖惩罚通过 E/M/U 体现，不能无条件认定“收回直辖越多越强”。同一战争中多个阶段的 ACK 不改变集合，必须以实际领土后态为准。

## 6. 财政 E：净现金、经常收入与偿付

同帧取得：当前金币 `gld`、月总收入 `g`、月总支出 `e`、当前己方全部战争合并且仅计一次的月军费 `m`。

```text
n        = g − e
e_civil  = max(0, e − m)
u        = max(0, g − e_civil)
Flow     = R(u; u_at_T0, 1)

C_due    = 已存在且尚未支付的借款本金、已产生费用、不可撤销付款承诺之和
W        = gld − C_due
Debt     = max(−gld, 0) + C_due
Q12      = 12 × max(g, g_at_T0, 1)
Buffer   = 100 × clip01(W / Q12)
Solvency = 100 / (1 + Debt / Q12)

E_raw    = 0.55 Flow + 0.30 Buffer + 0.15 Solvency
E        = min(E_raw, 25) 当 n < 0 且 W <= 0；否则 E_raw
```

`g/e/m` 必须是相同 actor、日期和来源语义。当前月总支出已含军费，不能把 m 再扣一次。`e_civil` 只是该帧剔除当前已知军费后的支出，不称为未来和平财政预测；若 `m>e` 或军费口径不兼容，字段组合未知，不能靠 max 掩盖错误。g、e、m 应为非负月费；未来战争上界仍未知。

Flow 衡量当前经常收入可供军政分配的能力。当前战争烧钱通过净现金/负债、财政危急上限和 M 的全动员负担体现。一次性赎金、贡金、掠夺或礼物只能进入实际钱包，不能将一笔收入乘 12 当作经常税收。若原生总收入字段包含无法拆出的非经常流量，保留该来源的语义缺口，不擅自改名为税收。

`C_due` 必须逐笔按合同 ID 去重：

- 负金币已经体现在 gld，不能再以同一笔“赤字贷款本金”重复计入 C_due。
- 借款现金到账同时加入未偿本金；借 100 金不会凭空提高净现金 W。手续费和实际利息照实计入。
- 已预付的建筑款不是待付承诺，不能再扣一次。可取消建筑的退款在实际取消到账前不计现金；不能假定退款率。
- 尚未借到的合法贷款、可能获得的赎金、盟友承诺和未到账赔款不是资产。
- 雇佣合同只计真实尚欠、不可撤销的支付义务；不把一切将来可取消维护费都资本化进负债。月维护同时仅在 e/m 计一次。

金币囤积超过一年收入尺度不再增加 Buffer，鼓励把多余资金合理投入。为保领地合法借款、取消建设或雇佣兵不被视为作弊：E 反映代价，守住的 L/D 和后续恢复会体现收益。不能因为借债当期扣分就让策略无条件选择投降；评分是整场权衡，不替代原生合法动作与战争判断。

## 7. 军事 M：兵力品质与负担能力

使用当前可调遣己方常备/征召兵的实际人数 `n_i`，按军团身份去重，包含未集结但真实可用的兵；排除未补充的纸面编制、盟友、雇佣兵和一次性事件兵。暂时的雇佣力量通过真实保土/战果体现，另行报告。

以同build原版征召兵定义的 `d_ref/t_ref>0` 作固定参照，冻结定义及来源身份；各军团使用来源闭合的同帧有效伤害 `d_i`、坚韧 `t_i`，含角色/驻扎等常驻修正。只接受不依赖特定对手、地形、战斗阶段的值；不能剥离临战条件时记未知，不能拿名义基础属性冒充有效属性。标准兵当量为：

```text
P         = Σ_i n_i × sqrt(d_i × t_i / (d_ref × t_ref))
Cost_full = e_civil + m_all_raised
Afford    = 100 × clip01(g / Cost_full)
            # Cost_full=0 且已确认无费用时取100；未知费用不取0
M         = R(P; P_at_T0, 100) × (0.65 + 0.35 × Afford/100)
```

伤害/坚韧取非负值，sqrt按第4节精度计算。该对称几何均值明确认可攻防品质，既不凭空指定“精锐十倍”，也不因堆一项属性按乘积线性爆分；它是透明评价尺度，**不是克制、胜率或完整战斗模拟**。参照固定，不因继承而改变；P的开局基线同样固定。任何军团人数/属性未知都保留M区间，不将其当征召兵。骑士不套任意人数倍数。

`m_all_raised` 是**当前军队在当前帧的原生全动员月费报价**，不是未来所有战争费用上界，也不是预算填常数。不得同时累加角色总兵数与其Army/Regiment。单支已集结Army不能代表完整可用名册。

兵种相克、统帅、骑士、地形、补给、到场时间、盟友可靠性仍为诊断。围城单位只按其真实d/t贡献战斗当量；其破城速度尚无主分子项，必须另外披露，不能声称M覆盖完整军事价值。当前版本不由P之比推必胜/必败，也不奖励刷战斗次数。

## 8. 治理稳定 U：控制与真实内战

治理集合 `G(t)` 包括当前 C(t)，以及仍在进行的本国叛乱中、战前确属本国而尚未正式独立/割让的县。后者必须有叛乱关系和战前归属记录，不能把任意宣称领土加进来。按县 ID 去重，用结构 q 加权：

```text
Control_avg = Σ(q_c × control_c/100) / Σ(q_c)     # c in G
Rebel_share = Σ(q_c，当前属该叛乱方的县) / Σ(q_c)  # c in G
U           = 100 × (0.60 Control_avg + 0.40 (1 − Rebel_share))
```

G 为空时 U=0；叛乱清单或县控制未知时出区间。已经确认没有内战时 Rebel_share=0；不能把“未采集到内战”当作没有内战。普通对外战争不扣和平奖励，不以保持和平的时长加分。

低控制同时影响领土可用价值和治理分，分别表达资产折损与治理质量，这是公开的有限重叠。派系军力、怨恨、合法性、暴政、宗教/文化冲突和继位短期惩罚会进入解释，但 v1 不凭一张意见表主观预测叛乱概率。其实际影响会通过控制、内战、失地和财政入分。

## 9. 宗族 D：锚定宗族、县域去重、投资可继承

`D0` 是开局宗族，`H0` 是开局家族。后续当前玩家的家族、主头衔名或 episode 改变不能重设锚。H0 的分支家族仍算 H0 支系，需按家族分支关系判断，不能因建立支系而丢失身份。

以**县的实际持有人**为准，每县最多一次：

```text
family_factor = 1.0，县持有人属于 H0 或其分支家族，且仍属于 D0
                0.5，属于 D0 的其他家族
                0.0，其他宗族

K_inside  = Σ(q_c × family_factor)，县在当前玩家 C(t) 内
K_outside = Σ(q_c × family_factor × 0.5)，县在 C(t) 外
K         = K_inside + min(K_outside, 2 × Q_realm_at_T0)

J_legacy  = D0 当前已解锁的宗族传承等级总数，按传承key/等级去重
D         = 0.80 R(K; K_at_T0, 1)
          + 0.20 R(J_legacy; J_legacy_at_T0, 1)
```

K 使用结构 q，不把全宗族每个持有人的钱包、个人属性或头衔再叠加。境外宗族县折价，是因为它们有传承和合作价值，但当前玩家不能直接调度其全部税兵；外部总量另有限制，避免遥远旁系偶然继承整个帝国完全支配主分。内部/境外只是相对当前玩家 C 的位置，不假装境外亲属都是独立君主。

**授独立不会增加 K。** 原持有人和 q 不变时，原来内部的贡献变成至多一半的境外贡献；L 同时失去该县。因此不能靠放走同族附庸把同一资产重复变成“宗族扩张”。内部封地改给同族可增加宗族扎根，但不增加 L；这是本方案认可的家族布局，其治理与财政代价仍需承担。

宗族传承等级是可跨君主保留的制度投资，权重只占主状态 3%。本版不把不同传承路线武断换算为同一战斗收益，也不直接奖励出生人数。积存宗族威望、家族成员数、婚姻网络、优秀教育与遗传特质保留为诊断，不把“生得越多”当发展。未解锁传承的宗族威望也不直接计分；这是 v1 的简化取舍，财富式的宗族威望投资估值留待后续版本。

只读到当前玩家及其子女，不足以完成 D：需要宗族/家族和县持有人完整集合。无法确认某支系的身份时，该部分未知，不将其归为非同族，也不把未知支系全算给自己。

## 10. 继承 H：合法续局与备用继承链

v1 先使用可验证的合法继承事实，不在没有原生合同的情况下预测每个头衔的分割。

```text
k = 1，当前实际玩家继承通道确认：至少一名在世合法后继，
         可承接玩家继续游戏，且属于固定 D0；否则为0
b = 除首位后继外，在当前法律/选举状态下确认有资格的
    备用玩家后继数量，上限2；当前君主不计
H = 100 × k × (0.70 + 0.30 × min(b,2)/2)
```

`k=0` 必须是已确认的无合法续局者/不满足 D0；查询 unavailable 时 k 是未知，不能取0。首位主头衔候选不自动等于玩家后继，角色在世也不自动等于合法。备用人选必须满足当前实际规则，不从“有两个儿子”直接推出 b=2。多个重复角色、同一角色兼有多个头衔都只计一人。

合法儿童后继不会仅因未成年而被判为零。年龄、配偶、生育机会、教育、摄政、被囚禁等具体风险进入诊断，只有实际原生规则使其不能继承时才改变 k/b。这样避免把未验证的性别/政府/信仰规则写死为评分常识。

预计分割中留在下一玩家手中的资产比例、争位者军力、继位财政、继承后实际 1/3/5 年恢复曲线是**重要的继承诊断，尚不在 v1 主分**。实际分割、独立和内战一旦发生，L/E/M/U/D 按真实状态更新。未来若能可靠取得逐头衔原生预测，可在 v2 提升事前风险评价；不把仅有主头衔候选数组冒充完整分割模拟。

继承前后相同资产、财政、兵力、控制、宗族和合法继承链输入得到相同 A；君主人名和六属性变化本身不会导致分数跳变。真实的军队缩水、税收改变或失地应改变分数，不能用“只是继承了”免罚。

## 11. 死亡、Game Over、恢复与中止

| 情况 | 处理 |
| --- | --- |
| 君主自然死亡，合法后继继续 | 同一个 campaign、T0 和基线；记录旧/新角色边，继续采到原 T* |
| 在同一 CK3 进程恢复智能体连接 | 不加分、不重置；恢复后的每帧仍须绑定实际角色与日期 |
| 技术问题正常保存后恢复 | 若是同一已保存世界的连续推进且没有撤销游戏结果，可以接续；中断只影响完整性和墙钟效率 |
| 回档改变已发生的决策/结果 | 原成绩保留；新分支单独登记 research，不冒充原来未回档的严格样本 |
| 原生确认永久 Game Over，无合法续局 | 固定 T* 不变；从终止时刻起的所有后续月度 A 以及 A_end 均记0，终止前的完整采样保留 |
| 只有智能体卡住/接口失败，未证实 Game Over | 记技术中止/未完成，余下样本未知；不能冒充世界毁灭，也不能缩短窗口换“年均高分” |
| 只录了一部分，或原声/画面素材缺失 | 录像不是评分分母；可信游戏数据完整时可独立评分，否则缺字段按未知处理 |

真实 Game Over 的 0 是明确的吸收终态规则，不是给缺数据补零。可另报告此时尚存的旁系宗族资产，但不能让后续 AI 自行发展的旁系替代已结束的玩家战役。不能通过选一个方便的新角色延长同一参赛场次。

终止发生在固定采样点之前，该点起为0；若刚好同一日期，按原生确认的事件先后和该点暂停帧确定，无法确定则出区间。早死和晚死绝不通过减少月数获得较高平均分。

## 12. 缺数据、可信区间与可比较资格

每个原始字段保存 `{value, unit, date_raw, actor/scope, source_ref, availability}`。来源状态分 `observed`、`known_absent`、`unknown`；只有 known_absent 能按实际0/空集合计算。一个字段进入源码、ACK 返回或 private query 名称存在，都不证明本场已经获得该字段。

未知值不补均值、不用开局值顶替、不按剩余分项自动重分权重。先用已证明的范围推导分项上下界；无法缩小时该分项 `[0,100]`。例如只缺 H，单时点 A 的区间宽度最多10，不把另外五项放大到100%。衍生量共用原始字段时保留约束，不能用互相矛盾的最好值拼一个所谓精确上界。

主分公式对每个时点分数单调，故对所有月度 A 区间分别应用下界/上界，连同末12月平均、最低36月平均，可得到保守的 `[S_min,S_max]`。区间可能较宽，应如实呈现；若字段边界求解未实现，直接用保守分项边界，不伪装成统计置信区间。这是**数据不完整区间**，与多局抽样的95%统计区间不同。

每份结果带一个状态：

- `COMPLETE_COMPARABLE`：环境/基线/准点端点和360月度核心字段完整，同一规则可复算；包括真实 Game Over 按吸收规则封闭的失败样本。
- `BOUNDED_INCOMPLETE`：有可靠上下界但仍缺核心输入，只展示区间，不给单个伪精确总分。两局区间不重叠时可作有边界的结果排序，不能把它称为完整榜单成绩。
- `FINAL_STATE_ONLY`：端点状态可评，但历史不足；只能报 A_end 和分项，不能以它冒充 S30，不能补造月度历史。
- `NOT_COMPARABLE`：开局/环境/时间/血脉连续性不能证明，或存在未申明回档；保留研究价值，不进严格比较。

主榜不将“缺哪些字段”作为可以择优丢弃坏成绩的借口：所有预注册样本都列出，技术失败比例和区间一并公布。某局是否缺数据须按事前同一标准判断，不能看结果决定。

## 14. 假想算例与跨代一致性

**以下均为人为构造的演算输入，不是当前罗贝尔战役成绩，不代表已取得实际游戏观测。** 表中六项状态分是给定的已完整计算值，用来独立检查汇总公式；真实报告必须同时提供各项原始量，不能只填分数表。

### 14.1 一个县的品质与一组财政输入

某县发展20、完工地产3、控制80、2/3地产被敌对占领：

```text
q = 1 + 0.5×1 + 0.25×2 = 2
v = 2 × (0.25+0.75×0.8) × (1−0.5×2/3)
  = 1.133333333333… 品质县当量
```

开局领土总值10，当前合计20，则 L=`100×20/(20+10)=66.6667`；合计降为5，则 L=33.3333。单纯多建一个公国头衔不会改变这个计算。

另一假想财政帧：g=20、e=25、m=10，开局u=10；gld=−120，独立的真实未偿本金/费用/承诺C_due=180，开局g=20：

```text
e_civil=15；u=5；Flow=100×5/(5+10)=33.333333…
W=−300；Debt=300；Q12=240；Buffer=0；Solvency=44.444444…
E_raw=0.55×33.333333…+0.30×0+0.15×44.444444…=25
n=−5且W<=0，所以E=min(25,25)=25
```

若再借100且全部到账，同时C_due增加100，W不变。借款不能凭空增加Buffer，且额外真实负债会影响Solvency；它仍可能通过买兵保住领地改善整场结果。

第一行例如 `0.25×68+0.25×68+0.15×65+0.10×85+0.15×64+0.10×100=71.85`。第二行不能靠最大L抵销资金与守备崩溃。第三行确实因失地丢分，但宗族稳固具有保留下来的价值，并非将其判为与破产同一种失败。第五行下降来自真实家业变化；强君多出的个人六属性不会为第四行提供额外遮掩。H为0的假想帧表示已确认没有合法后继，但当前角色仍活着；尚未发生Game Over。

### 14.3 强君自然继承，不因换人扣分

假设父亲死亡前与儿子接手后，六项输入都保持 `(67,64,66,82,66,85)`。两帧均为 `A=69.25`。即使父亲六属性总和180、儿子只有75，评分也不因换君跌分；父亲的个人威望和虔诚消失不影响D0和宗族传承等级。若兵数、税收或合法备用继承链实际改变，按改变的输入计分，而不是按君主姓名加减固定分。

假设这条三十年战役A_end=69.25、A_last=69、A_mean=63、A_low=55，则F=69.15，S30=665.05。经过三次继承但具有相同月度状态序列，仍为同一分数；不能将三位君主各算一次家族/领土再相加。

| L/E/M/U/D/H | 50/25/46.5/100/40/100 | 33.3333/33.3333/33.3333/100/26.6667/100 |
| A_end | 51.725 | 45.6666667 |

借款从0现金借240、雇兵预付120，剩120现金但欠240；无其他待付款，雇兵不算常规P，已含月军费15。借款方W=−120、n=−5，E被压到25；失地方W=0且月净收入5，E=33.3333。两者剩余县控制/内战、k/b均不变。若前359个月A都为60，代入完整公式，S30分别为563.04和535.98：**财政节约8.3333分不足以抵销半国与军力损失**。这里保土是给定的已发生结果，不证明借款或雇兵一定能赢；若买兵后仍丢地，债务与失地同时入分。

### 14.5 早亡和未知不能缩短分母

某局前15年180个固定月度采样均为70，第15年采样之后原生确认永久Game Over，其余180点和准点终局为0：A_mean=35、A_low=0、A_last=0，S30=70。不能按“活着15年平均70”报700。

另一局只保存了前180个月，后半因技术中止未知。即使前半均为70，也不能套用上面的0终态规则。按未知后半的`[0,100]`计算：A_mean在`[35,85]`、A_last/A_end在`[0,100]`、A_low在`[0,70]`，得到保守S30区间`[70,940]`，状态BOUNDED_INCOMPLETE，不能把中点505当真实成绩。

## 15. 用分数改善策略，而不是训练刷分

每轮先做结果分，再做独立解释。建议固定报告：

1. 六项开局→终点变化，全年/月度曲线，最差36个月落在哪些战争/继承阶段。
2. 县集合变化账：获得、正式失去、授独立、分割转出、收复；同县去重，并标明是否仍在D0手中。
3. 资金账：经常收入、军费、净现金、债务、重大可选建设、取消退款、雇佣与借款的实际后态。
4. 继承账：每代起止、合法继续、核心资产在新玩家与旁系间的真实分布、继位后恢复情况。
5. 最多三项有证据的策略改进，注明当时能看到什么信息、可用合法动作、预期影响哪几项分数，以及验证方式。

机会成本通过财政余额、持续产出、实际军事和过程表现体现，不按“修一座楼扣几分”再重复罚款。例如危急战争仍花钱新建可延后建筑，若当时有真实可用雇佣报价、缺口和到场条件，可形成“保留军费/取消在建/合法借款”的具体策略诊断；不能仅凭战后失败倒推“当时肯定买兵能赢”。缺少原生报价或战况信息时，记“反事实未证实”，不能填一个确定损失归因分。

分数优化的对象是持续家业，不直接把单次动作的即时ΔA当贪心奖励：合法借款买兵可能先降低E，战争胜利与保土稍后才体现。发展投资、教育、外交和宗族布局也有时滞。评分器不决定下一步动作，不放宽原生合法性，不允许策略通过少处理战争、避战或提前投降换取更高游戏日/分钟。

防止评分套利的固定规则：

- 不计重复头衔、出生次数、继承次数、战斗次数或历史累计封授；同一资产在同一时点只有一次状态价值。
- 不把派系窗口关闭/战争通知ACK当作危机解决，不把借款ACK当到账，不把授独立ACK当领土已变化。
- 不能把敌军、盟军、雇佣兵重复加进永久军力；不能把当前金币和同一笔债务得到的现金同时当净财富。
- 不能在第30年最后一天借一笔钱、暂时转封或隐瞒欠款获得虚假分；净现金、固定样本和真实终态共同约束。
- 新旧规则不得择优混算。若v2修正设计缺陷，可以保留v1和v2两列、在数据完整时统一重算全部历史样本；不能只给坏局换公式。
- 离线评分可以使用战后全图事实；不能把当时智能体看不到的隐藏信息偷送进决策，再声称是同一观测条件的策略进步。

## 16. 随机事件、策略水平与多次比较

单局S30衡量发生的结果，不能保证等于纯粹的操作水平。瘟疫、偶发死亡、邻国行为和继承抽样会产生差异。主分不因事后认为“运气差”而加回失地、删除坏月份或减免Game Over。

另设不改主分的事件说明：事件定义/实例、当时输入、合法选择、实际结果、可归因范围。只有同源分支或可验证机制能支持有限反事实；不能给“不可控事故”随意标一个主观免罚系数。“同初始随机状态”也不保证后续随机事件逐项相同：不同策略会改变随机调用顺序和世界路径。

对候选策略A/B，优先复用同一组冻结起点的配对实验，每个初始状态两种策略各跑一次。多组起点应覆盖独立初始随机状态；无法控制seed时记录方法和限制，用独立重复，不冒充精确配对。不能从当前局反复读档挑最好结局作为一次样本。

建议先用3对做工程探索，只报告探索结果；正式比较预注册20对作为首轮规模建议，不是宣称20对必然足够。报告所有场次、游戏失败率、技术不完整率、平均S30、中央値、最差四分位和每对差值 `d_i=S_Bi−S_Ai`。主要改进量为配对均值 `mean(d)`，另列每项分数变化，防止总分掩盖严重失地率上升。

可以对完整配对的d向量做10000次有放回配对bootstrap，固定重采样seed，报告均值差的2.5%/97.5%分位区间；必须写明这是小样本估计、具有同分布等假设，不是保证。不要将同一局360个月当360个独立战役扩大样本量。若初始状态重复或相关，按独立初始状态分组重采样。多候选筛选后，保留未参与调参的一组起点验证，不能反复在同一组seed上调到过拟合。

真实Game Over按同一0终态规则计入比较，不作为异常值删除。技术缺失的样本保留其区间和比例；若只对完整配对出统计，明确是完整样本子集，并同时给全部预注册样本的保守结果界限，不据此单独宣布总体更优。需要补跑时，预先统一技术恢复/补跑规则，不按哪个策略得分差来决定。

性能指标另列游戏日/现实分钟、查询延迟、成功动作率与恢复次数。评分比较不直接奖励速度，速度优化不得修改战争意愿或结果偏好来投机。视频剪辑、配乐和录制段数不进入游戏水平分。
