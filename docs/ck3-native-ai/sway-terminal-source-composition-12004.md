# Sway terminal source composition, CK3 1.20.0.4

This producer composes copied source packets for an original full SchemeID. It does not query the game or change the action ledger. Its output keeps a native terminal observation, an attributed end cause, and a named material observation independent.

`xar_autoplayer.bridge.sway_terminal_source_producer_12004.compose_sway_terminal_sources_12004` accepts `original_resolved`, optional `completion_read`, optional `execution_frame` and `termination_frame`, and optional `opinion_read`. Journal arguments can be copied native command frames or already normalized private retained reads. It returns `xar.ck3.sway-terminal-source-composition.12004.v1`.

The original action receipt binds actor, target, full SchemeID and its generation. A retained exact 1.20.0.3 original receipt can identify the same instance subsequently observed by exact 1.20.0.4; it supplies no current native observation. Every supplied current source must independently identify exact 1.20.0.4 and the held executable digest. Foreign full identities cannot supply a cause or terminal observation.

## Independent output planes

`current_instance_observation` is a copied current storage observation. A present exact status 0 remains `continue`. A present exact status 1 remains `terminated_unattributed` in this plane. `retained_end_observation` similarly retains a validated original-once terminal record without inventing a reason.

`cause_input_pair` contains independent retained execute/end reads for the original full identity. Its entries can be passed as the existing consumer's `execution_read` and `termination_read`. `causal_observation` is produced by the existing .4 causal validator; absent or empty input journals leave it absent. The producer does not clear persisted proof or consumption markers.

`named_material_observation` requires a raw available exact .4 opinion source for the same actor/target and the same date/native revision as the exact original-instance completion read. It preserves observed/present/value independently for both named modifiers. A positive present sway modifier supplies dedicated benefit evidence; no prior comparison is fabricated, so incremental gain remains unknown. An authored end cause does not supply an opinion value.

`retained_material_context` copies the original ledger's historical derived material summary under that explicit classification. It is not a raw current opinion packet or a terminal cause input.

Its older derived material summary records sway modifier 45 at revision 17/date 53289816 and no incremental named gain. These packet dates are historical examples, not the latest runtime frame. The already GREEN native wholewire packet has different original fixture identities: actor 29829, target 31900, full SchemeID 33554454, generation 2. Those bytes and identities are reused intact. They are never relabeled as the current instance.
