# 八域 paused MCP 只读采样器

`tools/sample_g2_12002_paused_readonly_sdk.py` 消费 runner 生成的 `MCP-READONLY-NEXT-PLAN.json` 的真实 `argv`。默认调用只验证该文件的八个 nonwar private read flags，并输出采样计划与输入副本，不启动 MCP server。后续实机窗口由 root 唯一操作员增加 `--execute-readonly` 执行，使用当前已安装 SDK 的 `stdio_client`、`StdioServerParameters` 与 `ClientSession`；不接受任意工具或 action 清单，不调用游戏控制动作。

实际公开观测工具名是 `ck3_take_snapshot`。采样器先保存其完整 MCP 返回，再从真实 snapshot 取得 public revision、played actor、date raw 和 native revision；每个域查询前重新观察，并在返回后独立再观察。paused 为 false、actor/date 变化或观测不可用时记录原因并停止本批次。public revision 可随新观测更新，后续查询始终使用自己的实际 revision。

八域固定查询是 government runtime adapter、family obligations、player prisoner collection、Sway target、realm law final terms、council final gates、Feast hosted post 与 faction gift candidate。family subject/candidate 和 Sway target 只有显式 CLI 输入时才采样，未提供时明确 skipped。Gift 先调用 `ck3_query_campaign_root_context_v1`，使用其原始 `campaign_root_context`，检查实际帧与 `player_targeting_faction_count`；count 为零是原生 known empty，缺少 count 是 unavailable，两者分别跳过。Gift 使用既有 `10000000` raw Gold reserve，不自行寻找或创造 recipient。

文件准备命令（不会连接任何 server）：

```bat
Z:\ck3_mod_rewrite\tools\.venv\Scripts\python.exe tools\sample_g2_12002_paused_readonly_sdk.py --plan Z:\ck3_mod_rewrite\artifacts\g2-offline-2026-10-01\runner-files\MCP-READONLY-NEXT-PLAN.json --artifacts Z:\ck3_mod_rewrite\artifacts\g2-offline-2026-10-01\paused-readonly-samples
```

root 在后续已经恢复新版 candidate 的实机窗口执行同一命令并追加 `--execute-readonly`。可选参数为 `--family-subject-character-id`、`--family-candidate-character-id`、`--family-break-recipient-character-id`、`--family-matrilineal`、`--sway-target-character-id` 与 `--minimum-gold-reserve-raw`。不要把历史冻结存档中的 ID 当成当前观察；本工具不会为缺失 ID 填写历史样例。

每次 CLI 调用创建独立时间戳采样目录，保留 discovery、initialize、stderr、每次工具调用的参数和原始 MCP result packet、前后 paused snapshots、错误以及 `sample-result.json`。工具 unavailable、native RED 与 skipped 都保留原样；“captured”只代表取得了 packet，不代表对应能力 qualified、动作成功或 OODA 完成。

本轮只执行 `tools/test_sample_g2_12002_paused_readonly_sdk.py` 的 file/fake-MCP tests；真实 stdio 入口由 mock context/session 验证，未启动 server，未接触 CK3、pipe、进程、桌面或 Steam。runner 最终 plan 依赖 source/binary freeze，由 runner 工作包生成，本采样器不会提前制造该 receipt。相关入口：[G2 离线工作包](../autonomous-agent-progress/g2-offline-work-map-2026-10-01.md)、[Feast Python transport](ck3-1.20.0.2-feast-python-private-transport.md)。
