## 构建配置与资源修复

全部新私有能力的 CMake 默认值为 OFF。选定候选启用 40 项，显式关闭 4 项：旧 Council probe、旧 activity planner diag、war-cash query、prewar sources query。默认构建保留默认配置。完整 flaglist、实际源码/header pins 和 DLL/injector hash 以最终 manifest 为准。

Snapshot 原先对新版玩家 gold/prestige/piety/stress 留下默认零值。本轮使用实际 character extension source 填入四项：gold、prestige、piety 为带符号 Q100000；stress 为普通点数。负 gold 与 piety 保留。原生合法的空 extension 是零；失败读取不冒充合法零值。该修复同时进入默认构建，不依赖 private candidate flag。

新版 suspended-startup 复用实际已移植的 installer，安装正常刷新中的 slot12 成本观察与 guest-rule provenance；读取端消费复制的正常结果，不人为刷新 planner 或推进 stage。离线联编只证明源码与符号接线；安装和真实成本仍待实机验证。

2026-10-01 的冻结候选按当时战争停止指令排除了 war-cash 和所有 prewar CPP/selector/permit、未验证 supply router，以及 family alliance-war CPP。独立 treasury 来源仍用于普通 Snapshot；已完成的 prisoner release-pairs 仅复用为赎金生产依赖。宗教 context 包当时已单独完成研究和离线 fixture，但不在该轮源码名单。**2026-10-03 旧仅非战争、战争暂停及战争开关必须 OFF 的授权限制已撤销**，战争与战斗研究、实现、策略和实机验收全面开放；上述排除与 40 ON / 4 OFF 保留为冻结构建事实，不作为新候选的授权边界。后续应从对应 exact-build 原生树、provider 和真实缺口继续迁移接线，readiness 不因授权升级；唯一原普通罗贝尔 `29829` campaign、原生 AI 研究优先、exact-build 绑定和最小化/noFocus 继续有效，实机由 ROOT 单一 owner 操作。
