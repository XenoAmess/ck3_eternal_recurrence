# 两个维护版 mod 的验收范围

2026-10-03，用户再次明确：**只用简体中文进行实机验收，其他语言只做基本规格检查**。此前扩大为英文与其他语言实机的安排属于执行范围错误，已取消。

该要求适用于 `mod_de_jure_conquest` 与 `mod_change_holding_types` 的适配、功能、存档和发布验收。新会话 profile 固定 `l_simp_chinese`，以实际中文界面、原生状态、日志和存档读回判定结果。

其他语言只检查 key 集合、占位符与保护 token、文件头、编码、格式和可加载结构。它们的实机状态不是发布门禁，不再为语言检查启动游戏。

法理征服 R0002 以及地产转换 R0003／R0004 的已有英文实机、法语切换尝试原样保留为历史过程记录；这些记录不能代替中文验收。地产转换 R0002、法理征服 R0001 的中文证据按各自报告的实际覆盖保留，尚未完成的项目继续在新的中文会话中验证。

外置双产品多语言冷载 helper 只完成源码预验，没有分配组合身份、准备 profile 或启动游戏。该计划停止，不作为待完成工作。
