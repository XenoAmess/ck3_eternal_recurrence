# 《重整河山》四期 `0.4.0`：割据期外交附庸平衡计划

> 状态：`implemented / source-L1 GREEN；Workshop 与 fresh-cache L3 待完成`
> 制定日期：2026-09-14
> 当前公开运行时基线：`0.2.0`
> 前置：三期功能已与本期合并为同一 `0.4.0` 候选
> 本期目标：阻止后朝在群雄割据刚开始时依靠和平附庸“秒统一”，同时保留中长期外交统一路线

> 实施结论（2026-09-14）：exact-upstream 生成投影已排除后朝误取的三项现任中华霸权优惠；本轮实际释放者的主头衔获得五年、精确绑定后朝 title object 的【新近自立】-50。19 项静态合同、12 个接受度身份向量和源码树 R0024 全绿；实机两个通过完整原版 interaction validity 的独立目标均即时拒绝，状态自然到期。计划中的三个自然局宏观统计没有被受控 fixture 冒充，公开结论只覆盖已定位公式与受控复现。

## 1. 玩家问题与范围

玩家反馈：群雄割据刚发生，旧天子似乎因为某项数值过高，可以立刻让大量割据诸侯接受附庸，短时间内重新统一，破坏割据阶段的存在感。

静态分析表明，这不是单个角色属性异常，而是“后朝”这一空法理霸权头衔仍被原版外交附庸公式当成现任中华霸权。四期将单独修正这项身份误判，并为刚刚脱离旧朝的诸侯增加短期、可解释、可到期的独立意愿。

本期不改变：

- 二期冻结的忠臣留朝比例、二次忠诚判定和国号稳定规则；
- 三期的后朝继承、旧存档迁移和三省六部延续规则；
- 后朝的霸权等级、空法理、名称、纹章、首都和复辟资格；
- 战争征服、继承、联盟以及复辟决议；
- 其他军阀、无关邻国和原版游戏规则下的外交附庸逻辑。

## 2. 静态根因

原版 `offer_vassalization_interaction` 对天朝制霸权统治者设有特殊待遇。当提议者的最高头衔为霸权级、双方均为天朝制时，公式会出现三项显著优惠：

| 原版特殊项 | 对后朝的当前影响 |
| --- | --- |
| 国王／皇帝通常拒绝低阶附庸的负分豁免 | 天朝制王国不再承受至少 `-50`；领地规模达到 `10`、`20` 时还会分别少承受额外 `-50`、`-100` |
| 天朝制双方按头衔等级差每级 `+20` | 后朝对王国通常获得 `+40`，对公国通常获得 `+60` |
| 最高头衔为霸权级 | 再获得“霸权”`+10` |

这些判断只检查政府与最高头衔等级，并不要求提议者实际持有 `h_china`。后朝恰好是霸权级，旧天子又继续保持天朝制，因此同时吃到三项本应属于现任中华霸权的待遇。

此外，原版王朝循环期间的特殊附庸限制以“提议者持有 `h_china`”为入口。旧天子在《重整河山》路径中已经失去 `h_china`，所以后朝也绕过了这一限制。

旧天子保留其他个人头衔，还可能继续成为部分割据诸侯的法理领主；再叠加正常的好感、军力、恐惧、教育、技能、同盟、宫廷显赫度和合法性，便会把整批目标同时推过接受线。合法性不是唯一根因：非 `h_china` 的普通霸权在最高合法性等级只提供 `+25` 附庸接受度。

一个常见的非法理王国粗略小计已经可以达到正数：

```text
基础 -50
+ 天朝制霸权等级差 +40
+ 霸权 +10
+ 最高合法性 +25
+ 非法理领主 -20
+ 同语言 +5
= +10
```

若旧天子仍是法理领主，`-20` 会变成 `+20`，单这一项又产生 `40` 点摆动。因此没有任何异常的角色数值，也足以产生“刚割据就成片归附”。

## 3. 平衡设计

### 3.1 第一层：纠正后朝的外交身份

保留后朝霸权等级，但在 `offer_vassalization_interaction` 中，把带有 `rmtm_restoration_hegemony` 标记的头衔明确排除在三项现任中华霸权优惠之外：

1. 不豁免国王／皇帝的通常拒绝项；
2. 不使用天朝制霸权的“每级 `+20`”，回到普通高阶领主固定 `+10`；
3. 不取得通用“霸权”`+10`。

除这三项外，原版公式的好感、法理、军力、盟约、恐惧、合法性、语言、宗教和文化等因素保持原样。这样是在修正身份误判，而不是另造一套外交系统。

该 interaction 很可能需要整对象覆盖。实装必须先确认 CK3 对同名 interaction 的加载／覆写语义，再从当前 exact upstream 文件生成最小投影并锁定源哈希；不得手工维护一份会静默漂移的原版大段副本。

### 3.2 第二层：五年“新近自立”

群雄割据事务中，只有被《重整河山》实际释放为独立、且原先是旧天子直属封臣的角色，才获得五年“新近自立”状态：

- 状态写在叛离者当时的主头衔上，并耐久引用这一轮确切的动态后朝 title object；
- 五年内，该头衔的当前持有者收到该后朝当前持有者的附庸提议时，AI 接受度增加一条公开的 `-50` 原因；
- 关系绑定双方头衔而不是人物，旧天子或割据诸侯死亡不能通过换君绕过；
- 五年自然到期后只移除这条 `-50`，其余接受度即时回到原版计算；
- 留朝忠臣、非旧朝直属者、其他军阀旧臣和无关邻国不命中。

`-50` 与原版“新近战争”量级一致，而且是软约束：极高好感、强法理、显著军力优势等仍可能克服它。四期不硬禁提议，也不设每年附庸数量上限。

### 3.3 暂不调整合法性

四期首轮不清零、重置或普遍削减旧天子的个人合法性。这样做会把“天命已失”与角色在自身后朝的世俗正统性混为一谈，也会影响战争、封臣管理和其他系统。

只有在第一、二层都实装后，至少三个自然样本仍持续超过本期量化门槛，才允许提出第二轮、限时且有实机数据支撑的合法性方案。该分支不是首版实现内容。

## 4. 量化平衡目标

- 群雄割据瞬间的留朝规模继续服从二期目标：通常保留中华法理领土的 `15%..40%`，四期不得暗改忠臣结果来“做平衡”。
- 裂解后首月，高合法性、高好感旧天子分别面对普通受控王国、公国和伯国叛离者时，三者接受度都应低于 `0`，且每一项差值可解释。
- 至少三个不预设忠叛结果的自然样本中，后朝首年依靠和平附庸收回的中华法理领土不得超过 `10` 个百分点，也不得仅靠即时归附跨过复辟所需的 `51%`。
- 五年届满后，小型、友善、法理明确的目标可以重新出现正接受度，外交统一路线必须存在。
- 一个刻意堆叠外交教育、好感、盟约、军力与法理优势的极端样本可以突破普通门槛，但不能让所有割据诸侯无差别同意。

量化门槛用于发现系统性“秒统一”，不保证每局地图完全相同；报告必须同时给出人数、中华法理领土百分点、兵力、接受度明细和复辟决议状态。

## 5. 兼容与迁移

- 对升级后新发生的群雄割据，可以在释放事务中精确记录本轮叛离者与对应后朝。
- 已经处于群雄割据中的 `0.2.0` 存档没有保存“当时哪些直属封臣由本 mod 释放”的完整事实。不得按地理、好感、文化或当前独立状态猜测历史对象。
- 因此旧割据存档可以立即获得第一层身份修正；若没有可证明的耐久事实，第二层五年状态只适用于升级后新发生的群雄割据。正式兼容说明必须明确这一限制。
- 三期保证后朝 title object 可跨代继承，是四期头衔关系不因旧天子死亡而失效的前置条件。

## 7. MCP 优先验收方案

### L0：静态与 `open_kaishek` 离线预验

在任何 CK3 步骤前，先判断 parser、validator、IR 或 finite runtime 能覆盖的确定性子集；报告记录 `open_kaishek` commit、profile/version、CK3 exact build/EXE SHA-256、fixture/corpus ID 与 SHA-256、实际命令、结果和不支持项。

- 表驱动重算至少 `12` 个向量：王国／公国／伯国、法理／非法理、高／低合法性、高／低好感、高／低军力。
- 对每个向量比较原版、`0.2.0` 行为基线和四期预期，证明后朝只失去三项身份优惠。
- 对 upstream interaction 投影做结构与字节差异审计；除明确条件外，其余原版语义保持一致。
- 验证五年关联只写入本次实际独立者的主头衔，引用确切后朝 title object，并具备唯一到期路径。
- 验证留朝忠臣、无关独立者、其他军阀和原版游戏规则均不命中。

### L1：MCP-first 受控源码树实机

取得 CK3 排他槽后，优先通过 MCP 读取与操控真实 paused state：

1. 记录裂解前旧天子、`h_china`、后朝动态 title、直属封臣、中华法理领土和兵力基线。
2. 触发群雄割据，确认只有实际叛离者主头衔获得五年关联。
3. 以高合法性、高好感旧天子分别向普通王国、公国和伯国叛离者提出附庸，保存完整接受度明细；首月均须低于 `0`。
4. 用留朝忠臣、非本轮旧朝直属叛离者、另一军阀旧臣和无关邻国作负面对照。
5. 保存重载；分别让后朝持有者和一名叛离者换君，确认五年内不能绕过。
6. 推进到期，确认只消失“新近自立”`-50`，其余原版项目没有漂移。
7. 记录首月／首年和平归附人数、中华法理领土百分点、总兵力和复辟决议状态。

屏幕截图仅作为展示材料；接受度、title reference、持有者、日期、领土和决议状态以 MCP／存档可读状态为权威。

### L2：自然样本与冲突矩阵

- 至少三个不人为指定忠叛结果、也不预先堆叠外交数值的自然样本；这些样本执行量化门禁。
- 一个刻意堆叠好感、盟约、外交教育、法理与军力的极端样本；该样本只证明外交路线仍存在，不用于放宽自然门槛。
- 后朝与叛离者任一方在五年内死亡继承，状态不失效；五年届满后状态准确消失。
- 后朝用战争重新征服、另一军阀之间和平附庸、非旧朝邻国接受提议均沿用原版。
- 原后朝复辟销毁、另一军阀先取天命和多个后朝并存时，不产生悬空或串朝关系。

### L3：正式 staging 与 fresh-cache

- 从正式 staging 重跑关键受控用例，不以开发源目录结果代替。
- 上传后从 Workshop 订阅缓存复核三项身份排除、五年关联、接受度明细和首年和平扩张结果。
- 完成人工审阅、Change Notes、订阅缓存证据和永久 changelog 后，才可将四期标记为发布完成。

## 8. 验收退出标准

`0.4.0` 只有同时满足以下条件才可完成：

- 后朝不再取得现任 `h_china` 才应拥有的三项外交附庸优惠，其他原版接受度项无意外变化。
- 裂解首月普通受控王国、公国、伯国全部拒绝；结果能由接受度明细完整解释。
- 三个自然样本首年和平收回领土均不超过 `10` 个百分点，也没有仅靠即时归附跨过 `51%`。
- 五年关系只绑定本轮后朝与本轮实际叛离主头衔，保存重载和双方继承后仍成立，到期后准确消失。
- 极端经营样本仍可能获得外交成功；战争、继承、复辟和无关外交不受污染。
- 原版游戏规则以及二期、三期功能完成联合回归。
- 正式构建、source L1、fresh-cache L3、Workshop 更新、订阅缓存复核和 `0.4.0` 永久 changelog全部完成。

## 9. 风险与取舍

| 风险 | 处理口径 |
| --- | --- |
| interaction 需要整对象覆盖 | exact upstream 生成投影并锁定哈希；上游变化时停止构建并要求显式刷新 |
| 状态挂人物导致死亡绕过 | 叛离身份挂主头衔，并引用确切后朝 title object；人物只作为实时持有者 |
| 修得过重，外交统一消失 | 不硬禁、不清零合法性、不设数量上限；五年后自动恢复，保留极端经营样本 |
| 旧割据存档缺少叛离名单 | 不猜历史；第一层立即生效，第二层只覆盖有精确事实的新裂解 |
| 主头衔变化使关系判定漂移 | L1/L2 单列头衔易手用例；实装时定义转移或清理的唯一行为，不允许同时命中多个后朝 |
| 固定阈值被地图差异误导 | 同时保留受控向量与三个自然样本；门禁看领土百分点和接受度明细，不只看人数 |
