# 牛来 / ox here

一个独立的 Crusader Kings III 决议 mod。

## 内容

满足“统治者”与“已婚”条件时，决议会出现在单独的“牛来”分组中：

- **妈妈……**：邀请一名 25–35 岁、男性、非洲文化与非洲宗教的勇士加入宫廷。他的生成勇武为 40–60，并带有巨人、多产特质；隐藏 ethnicity 使用非洲外观基底和 100% Blonde 发色表。
- **我宁可跟他们豹拉**：不产生任何效果。

选择第一项后，勇士会被强制设为骑士；如果拥有 Royal Court 且勇士职位空缺，还会立即被任命为勇士，并且该名勇士的宫廷职位薪资为 0。配偶及所有可用的侧室/配偶都会分别与他建立情人关系，同时由他持有对应的 `secret_lover` 秘密。原本的情人和灵魂伴侣关系会先解除。最后，他会立即对决议发起者开始勾引阴谋，不检查性别或性取向条件。

AI 默认极不愿意执行该决议；当骑士数量不足、现有骑士中有人低于一般能力，或作为主要战争方陷入战争分数低于 -50 的绝境战争时，才会提高决议与第一项的权重。

## 安装与状态

将本目录作为 mod 源目录注册到 CK3 启动器即可。`descriptor.mod` 针对 CK3 `1.19.0.6`。

本目录只提供简体中文和英文文案，符合项目的日常本地化策略。没有添加缩略图。

本版本按要求只完成代码和静态结构检查，没有启动 CK3，也没有进行实机验收。
