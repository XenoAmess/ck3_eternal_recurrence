# 当前语言验收政策

用户2026-10-03明确指令优先于仓库通用国际化流程及本产品旧模板：**真实游戏验收仅使用简体中文；其他八语仅做格式规范检查。**

简体中文承担真实游戏功能和界面验收。英文、法文、德文、日文、韩文、波兰文、俄文、西班牙文只检查UTF-8／BOM、正确header、条目语法、重复键、完整键集与占位符格式。不要求语义、术语、母语审阅、翻译完成度，也不设置这些语言的游戏内渲染、交互、截图或签核门禁。不因正文与英文相同拒绝格式合格文件。

`tools/validate_static.py --release-localization` 是九语格式入口，不调用翻译服务或游戏。产品构建器只按既定16文件allowlist输出；没有语言审阅审批。外置夹具生成器及marker验证器不选择游戏语言，由根执行者以简体中文启动验收。

本产品没有独立翻译prompt或语言审阅模板。适配计划、测试计划、发布计划、发布前说明、README、Steam Change Notes和Workshop BBCode均执行本政策；以后添加的prompt、模板和发布检查也必须遵守。任何通用说明要求英文或其他语言实机、语义或术语评审时，本任务按用户明确指令省去该项。

历史来源、静态报告、本地化coverage、翻译候选和失败attempt保持原样。它们记录的review_decisions、native_speaker_reviewed或remaining_live_scope是当时状态，不产生新的待办或发布门禁。R0002英语实机只作为保存的诊断，不能改写为简中验收；R0001简中证据仍按实际场景使用。

这次语言政策修正不改变16份生产文件，也不改变R0005-CN夹具生成器或72条语义断言。实机与发布事实按 [当前测试报告](test-report.md) 和 [发布流程](release-plan.md) 另行记录。

格式入口变更的受控验证见 [language-format-policy-check-2026-10-03.json](language-format-policy-check-2026-10-03.json)：与英文正文相同的合法法文header／完整键集通过，缺key或错误header被拒绝。只执行实际validator中的语言格式分支，没有重跑生产静态、构建或游戏。
