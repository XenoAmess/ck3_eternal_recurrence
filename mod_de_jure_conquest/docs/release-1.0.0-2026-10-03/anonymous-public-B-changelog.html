Update: Oct 3 @ 4:10am
by XenoAmess

1.0.0 — 首个独立维护版本（initial baseline）

本版本是白绮“公国/王国/帝国法理征服”的独立第三方维护版，面向CK3 1.20.0.3（Crozier）适配，版本声明为1.20.*。维护版采用独立工坊物品，不更新原作。1.20.*是版本声明，不能外推为整个1.20系列均已实机通过。

玩法与费用
• 保留公国、王国、帝国三种法理区域征服借口，仅真人玩家可使用，AI没有进攻入口。
• 公国：威望等级2，基础100威望与200虔诚。
• 王国：威望等级3，基础500威望与1000虔诚。
• 帝国：威望等级4，基础2500威望与5000虔诚。
• 费用保留原脚本实际数值，原作页面的资源列顺序与脚本相反。宣战窗口显示借口费用；原版费用修正与宣战后果均保留，例如“上帝之和平”礼仪的同信仰战争惩罚可另扣100虔诚。
• 宣战以所选法理区域为目标；区域内其他独立顶级领主会加入防守方。请检查实际敌人数量，区域征服可能同时对抗多个强敌。
• 胜利取得当前防守方领地在目标区域内的伯爵领及其男爵领。玩家本人已有领土、自有封臣领土、当前战争的进攻方盟友及仍保持中立的领土、法理区域外土地不进入转移集合；取得后需自行分封。
• 白和平不转移领土，保留原有威望、按性格处理的压力与停战效果。战败不转移领土，保留正统性、威望、封臣评价及停战处理。
• 若战败时主防守者是真人玩家，原有赔款分支继续生效：进攻方月收入为正时支付3年收入，否则支付原版medium_gold_value所定义的金额。AI主防守者不触发这条脚本赔款分支。

维护改动
• 按1.20原版合同修整战争目标读取和防守方收集，按独立顶级领主加入并排除重复参战者。
• 使用普通战争模式并保留区域防守方收集，避免把本借口交给大圣战流程。
• 胜利只处理当前这场战争的防守方和所选法理区域，通过原版头衔事务一次交接。
• 增补AI禁用保护，修正自有领土排除及其他防守方仍持有目标时的失效判断。
• 增补明确的胜利、白和平与战败说明，修正王国战争名称；白和、战败、死亡继承及停战继续保留原有政策。
• 九语言按格式、键与占位符规范检查；真实游戏验收仅使用简体中文，其他八语仅做格式规范检查。
• 简中实机已核对三档宣战窗口、普通公国宣战的实际费用与次级防守者、新公国战争保存重载，以及三档胜利／白和平／战败共九格的72项语义断言。

兼容与限制
• 保留原作的三个宣战借口标识；请只启用原作或维护版其中一个，不要同时加载。
• 建议在新开始的战争上使用。保存重载验证限于本轮新宣战的公国战争；进行中的旧版大圣战迁移、自动军队与并发战争回归尚未完成独立验收。
• 九格结算使用资格检查后的脚本开战与原生战争结算，不代表原生议和界面合法性或所有存档均已验证。实机日志另有原版加载／旅行诊断与来源未定位的动态文本格式提示，完整范围见维护仓库测试报告。

感谢原作者白绮提供的玩法设计、脚本与预览图。
